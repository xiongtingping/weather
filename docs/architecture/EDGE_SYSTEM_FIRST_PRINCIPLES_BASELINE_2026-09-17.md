## 0. 目的、范围、与现有系统的关系

**目的**：给「在互斥温度桶市场上交易日最高气温」这类系统，定义 edge 是什么、如何测量、如何兑现，并据此划定层级、流程、边界与宪章。

**范围**：从信息摄入到盈亏归因的全链路。不规定具体模型算法，只规定每层回答的问题、输入输出契约、验收指标、失败方向与禁令。

**与现有系统的关系**：本文件不引用现有模块名、现有条款号、现有实测结论。它是一把尺子，用来逐层对照现有系统；对照时每层只回答本文件规定的那一个问题，答不出即为缺失。

## 1. 定义

以下定义在全文中严格使用，任何层不得私自改义。

| 术语 | 定义 |
|---|---|
| 事件 | 某站某事件日的日最高气温落入某个 1°C 桶。桶互斥且穷尽。 |
| 梯子 | 一个站日的全部桶及其盘口。梯子上的概率向量和为 1。 |
| 合约 | 对某桶的「命中赔 1、不命中赔 0」份额。窗＝若干相邻桶的合约集合，其概率为各桶之和。 |
| 真值 | 结算方按结算规则确定的落桶。带修订号 `truth_revision_no`。 |
| 可知时间 `knowable_at` | 一条信息在本系统内可以被读到的时刻。对真值即标签可知时间。一切拟合与评分只能用 `knowable_at ≤ 截止时刻` 的行。 |
| 决策时刻 `decision_at` | 生成一次信念与动作的时钟。所有输入按此刻 as-of。 |
| 信息集 I_t | 决策时刻 t 之前可知的全部信息。市场价属于信息集。 |
| 真实概率 π | 在「全部存在的信息」下的条件概率。不可观测，只能通过 proper scoring rule 间接比较估计量。 |
| 预报 p_t | 预报层输出的整梯概率向量，只用 I_t 中**非价格**的部分。 |
| 市场信念 m_t | 市场层由盘口解析出的整梯概率向量。定义见 §4.3。 |
| 全含成本 C | 执行一个动作实际付出的每股成本：可成交价 + 手续费 + 成交条件下的逆选择期望 + 延迟成本期望。 |
| 后验 b_t | 后验层输出：P(事件 \| p_t, m_t, 情境)。带后验分布，不只是点。 |
| edge | 对一个动作，edge ＝ E_b[赔付] − C。ex-ante 指用后验算，realised 指用真值算。 |
| 技能分 S | 在同一批事件上，b 相对 m 的平均对数得分之差：S = mean[ log b(真值桶) − log m(真值桶) ]。按事件日聚类给区间。 |
| IC | corr( b − m , t − m )，t 为 0/1 真值。衡量「我的仓位方向」与「市场的错」的相关。 |
| 独立下注数 N_eff | 按事件日聚类后的有效独立观测数。站数不是样本数。 |
| 半衰期 | 一条新信息进入后，其 ex-ante edge 衰减到一半所需时间。 |
| 逆选择 | 挂单成交的条件下，价格随后朝不利方向移动的期望。 |
| 实现率 | realised edge / ex-ante edge，在 ex-ante edge 分档上计算。 |
| 情境 ctx | 后验层允许使用的条件变量集合：距截止小时数、信息阶段、点差、陈旧度、分歧幅度、距上次信息事件时长、来源新鲜度。 |
| 影子 | 某组件在生产路径上计算并记录输出，但不影响任何动作。 |
| 晋升 | 影子组件被归因层裁定可以影响动作。 |

## 2. 公理

这些不是待验证的假设，是设计的出发点。违背任一条的设计不进入本基线。

- **A1 价格是预报**。m 是市场对同一事件的概率估计，且通常是可得的最强单一估计。任何只把价格当成本的设计都丢掉了最好的预测量。
- **A2 edge 是相对量**。按 Kelly 下注的长期对数增长率 = D(π‖q) − D(π‖b)，市场的错减我的错。我不需要准，只需要在下注的合约上比市场少错。
- **A3 校准不等于 edge**。给定 m 之后 b 仍有分辨力，才有 edge。检验：真值对 (m, p) 回归，p 的系数是否显著且样本外稳定。
- **A4 edge 是条件的且会衰减**。它只在某些情境、某些时刻存在，市场追上后消失。情境必须先由机制提出，后由样本外验证，不得事后翻找。
- **A5 兑现有五道关**：成本、方差、测量、选择、时机。任一道关没过，ex-ante edge 就不会变成钱。
- **A6 每层一个问题、一个指标、一个失败方向**。层的失败方向一律是「退化为不交易」，不是「按旧值交易」。
- **A7 唯一信念**。闸门、定注、执行读同一个 b 的后验。不存在第二个概率。

## 3. 架构总览

```
 L1 信息层 ──► L2 预报层 p ──┐
      │                       ├──► L4 后验层 b(后验分布) ──► L5 机会与成本层 ──► L6 组合与定注层 ──► L7 执行层
      └──────► L3 市场层 m ──┘            ▲                         ▲                    ▲               │
                                          │                         │                    │               │
      真值 ──► 标签(可知时间) ─────────────┴────── L8 归因与监控层 ◄─┴────────────────────┴───────────────┘
                                                  (评分、晋升/退役、熔断；只读全链、只写裁决)
```

三条时钟：
- **决策钟**：每次决策的 `decision_at`，全部输入 as-of 该刻。
- **标签钟**：真值的 `knowable_at`。拟合与评分的截止钟。
- **学习钟**：每日固定时刻的前瞻重拟；参数带「证据窗口」与「拟合时刻」。

两条路径：
- **常规路径**：按周期跑 L1→L7。
- **信息事件快路径**：新观测/新报文到达即触发 L2→L7，执行方式由半衰期决定。

## 4. 各层规范

每层按同一模板：职责 / 输入 / 输出契约 / 边界 / 指标 / 样本外检验 / 失败方向 / 禁令。

### 4.1 L1 信息层

- **职责**：把每条外部信息以不可变、只追加的方式落库，带 `issued_at`（发布/观测时刻）与 `knowable_at`（本系统读到的时刻）。真值也是一条信息。
- **输入**：NWP 各系统各轮次、官方预报、观测报文、TAF、气候统计、盘口快照、结算真值及其修订。
- **输出契约**：`(source, key, payload, issued_at, knowable_at, content_sha256)`。盘口快照另带 `venue_ts`（交易所钟）。
- **边界**：不做任何预报、不做任何合成、不填补缺失。价格在这里只是信息。
- **指标**：延迟分布 `knowable_at − issued_at`、完整率、陈旧率。
- **样本外检验**：无模型，只审 as-of 正确性：任意历史决策重放时读到的行必须 `knowable_at ≤ decision_at`。
- **失败方向**：来源缺失即向下游报「缺失」，下游据此退化；绝不回填后到的数据。
- **禁令**：不得以事后知道的信息修改历史行；不得用「发布时刻」冒充「可知时刻」。

### 4.2 L2 预报层

- **职责**：在决策时刻 t 给出整梯概率向量 p_t 及自身的不确定度描述。
- **输入**：L1 中除盘口以外的全部信息，按 t as-of。
- **输出契约**：`(station, event_date, decision_at, stage, p[桶], spread_stat, sources_used[], model_version, evidence_window)`。
- **边界**：**对市场盲**。不得读价格、不得读盈亏、不得读后验层的权重。这是为了让 L4 能测出「增量信息」；一旦预报向市场校准，增量信息不可测。
- **指标**：CRPS 与对数得分对真值；可靠性图；锐度；相对气候的技能分。按 提前量档 × 阶段 × 站 报告。
- **样本外检验**：滚动前瞻；每次模型改动先影子 N 个事件日。
- **失败方向**：输入缺失 → 分布变宽或明确「弃权」标记；不得沉默地沿用旧向量。
- **禁令**：不得因盈亏结果调参；不得叠加针对市场的修正；不得在同一个向量上叠加多个各自拟合的乘子。

### 4.3 L3 市场层

- **职责**：把一个站日的盘口解析成市场信念 m_t 与成本原语。
- **输入**：盘口快照（各桶买一/卖一/各档深度、最近成交、时间戳）、手续费表。
- **m 的定义**：先算每桶中价 mid_i = (bid_i + ask_i)/2，单边缺失时用可用一侧并打「单边」标记；m_i = mid_i / Σ mid_j。同时保存原始 bid/ask 向量、`overround_ask = Σ ask − 1`、`overround_bid = 1 − Σ bid`。
- **输出契约**：`(station, event_date, venue_ts, m[桶], bid[桶], ask[桶], depth[桶][档], spread[桶], staleness_sec, overround_ask, overround_bid, one_sided_flags)`。
- **边界**：不做预报、不与 p 混合、不做平滑。
- **指标**：m 自身对真值的对数得分与可靠性（它是 L4 技能分的基线，必须单独可查）；陈旧度分布；单边率。
- **样本外检验**：m 的可靠性图按情境分组，用于 L4 的市场自校准项 c(m) 的假设来源。
- **失败方向**：盘口不完整 → m 标「不可用」，L4 对该站日退化为「不交易」。
- **禁令**：不得用自己的挂单污染 m（解析时剔除本方挂单）；不得把卖一当信念。

### 4.4 L4 后验层（edge 模块）

- **职责**：给出 b_t = P(桶 | p_t, m_t, ctx_t) 的后验分布，并输出「预报相对市场的增量信息权重」。
- **模型形式（基线）**：在 logit 空间：

  `logit b_i = logit m_i + w(ctx) · [logit p_i − logit m_i] + c(m_i, ctx)`

  随后整梯归一化。w 的先验均值为 0（先验是「市场对」），层级收缩：整体 → 阶段 → 情境档。c 是市场自校准项，先验为 0，作为独立假设车道进入（见 §6 E18）。
- **拟合总体**：**全部站日 × 整梯全部桶**，其真值 `knowable_at ≤ 截止钟`。不是系统枚举的窗，不是入座的窗，不是成交的腿。
- **拟合方式**：每日前瞻重拟，滚动证据窗口；按事件日聚类自助或贝叶斯后验得到参数分布；由参数分布得到每桶 b 的后验分布（至少给 5% 与 50% 分位，或保留联合抽样）。
- **输出契约**：`(station, event_date, decision_at, stage, b[桶], b_q05[桶], b_q50[桶], draws_ref, w_point, w_ci, c_summary, ctx, model_version, fitted_at, evidence_window, n_eff_days)`。
- **窗的信念**：窗的 b 是桶 b 之和；窗的分位数由联合抽样求和后取，不得把各桶分位数相加。
- **指标（唯一验收指标）**：样本外技能分 S 的按事件日下界，以及 IC 的下界；在拟交易的情境上分别报告。
- **样本外检验**：前瞻；每个情境档的 S 下界 > 0 才允许该档 w > 0 参与动作。
- **失败方向**：证据不足或 S 下界 ≤ 0 → w = 0、c = 0 → b = m → 无动作。
- **边界**：不知道成本、不知道动作、不读盈亏。
- **禁令**：不得在自己产生的动作集合上拟合或评分；不得引入未经 §5.5 假设车道注册的情境变量；不得存在第二个信念。

### 4.5 L5 机会与成本层

- **职责**：枚举可执行动作，用后验计算扣除全含成本后的 EV 后验，给出候选。
- **动作空间**：`(站日, 桶集合, 方向 买/卖, 单型 吃单/挂单, 价位, 到期)`。结构性机会（Σask < 1 买整梯、Σbid > 1 卖整梯）在此层枚举，同样扣成本。
- **成本模型**：C = 可成交价 + 手续费 + AS(单型, ctx) + Delay(ctx)。AS 为逆选择期望，必须从本方历史成交样本外估计：E[ m_after − m_fill | 成交 ]；无样本时取保守上界。Delay 为信息事件后到成交的价格漂移期望。
- **EV 后验**：对 b 的每个抽样 k，EV_k = Σ_{桶∈集合} b_k − C；输出 EV 的均值与 5% 分位。
- **闸门**：`EV_q05 > h`，h ≥ 0 为未建模成本的安全边际。点估计不得触发。
- **输出契约**：`(action_id, 站日, 桶集合, 单型, 价位, C 分解, EV_mean, EV_q05, info_event_tag, half_life_est, b_version)`。
- **指标**：实现率按 ex-ante EV 分档（EV 估计的校准）；成本模型误差（预测 C 对实际 C）；被拒动作的事后 realised edge（拒绝集合的对照读数）。
- **样本外检验**：实现率曲线前瞻；成本模型逐月重估。
- **失败方向**：成本模型缺失或过期 → 全部动作按上界成本计算，通常即无候选。
- **禁令**：不得对被拒动作不记账（拒绝集合是唯一的对照组）；不得为通过闸门而降低 h。

### 4.6 L6 组合与定注层

- **职责**：在全部候选动作与现有持仓的联合后验下，决定目标仓位。
- **方法**：分数 Kelly：最大化 E_draws[ log(1 + Σ_a f·s_a·(payout_a − C_a)) ]，f ∈ [0.2, 0.5] 由回撤目标定；联合抽样必须包含跨站相关（同日天气型相关模型，由 L2 预报误差的联合分布估计）。
- **约束**：单站日敞口上限、单日总敞口上限、深度上限（不得吃超过可成交深度）、回撤熔断。
- **输出契约**：`(action_id, target_shares, kelly_fraction, exposure_after, constraint_binding[], corr_model_version)`。
- **指标**：实现增长率对预期增长率；最大回撤；N_eff 的估计与真实的回撤分布是否一致。
- **样本外检验**：用历史联合后验重放定注，检验回撤分布覆盖率。
- **失败方向**：相关模型缺失 → 同日全部动作按完全相关处理（最保守）。
- **禁令**：不得逐注独立定注；不得按点估计定注；不得在 Kelly 之外再加放大乘子。

### 4.7 L7 执行层

- **职责**：在成本限制内把目标仓位变成成交。
- **单型选择**：`info_event_tag` 为真 → 吃单立即执行，到期 ≤ 半衰期；否则挂单，仅当该情境的实测 AS < 可赚点差；否则不下单。
- **生命周期**：到期即撤；后验 b 变化使 EV_q05 ≤ h 即撤；不追价超过 EV_q05 允许的价位。
- **输出契约**：`(order_id, action_id, submitted_at, price, shares, type, expiry, fills[], cancels[], reason)`。
- **指标**：实施缺口分解：延迟成本、点差/冲击、未成交机会成本；成交条件下的 realised edge；逐情境逆选择。
- **样本外检验**：单型选择规则按情境前瞻对照。
- **失败方向**：网关/盘口异常 → 不下新单，只执行撤单与既定退出规则。
- **禁令**：不得改信念、不得改仓位目标；不得为提高成交率降价到 EV_q05 之下。

### 4.8 L8 归因与监控层

- **职责**：把已实现盈亏拆到各层，给出晋升/退役/熔断裁决。
- **归因恒等式（每股）**：

  `t − q_fill = (t − b) + (b − m) + (m − q_fill)`

  三项分别是：意外（若 b 校准则零均值；其与仓位的相关衡量定注偏差）、后验声称的超市场部分、执行与成本。按仓位加权汇总后，再把 (b − m) 拆为「预报层贡献」（p 相对 m 的技能）与「后验层贡献」（w、c 的校准）。
- **监控指标**：滚动技能分 S 及其按事件日下界；IC；实现率；alpha 衰减曲线（edge 对距信息事件时长）；各层失败率。
- **裁决**：
  - 晋升：影子组件在 ≥ N 个事件日上 S 下界 > 0 且 IC 下界 > 0。
  - 熔断：某情境档最近 M 个事件日 S 下界 < 0 → 该档 w 置 0。
  - 退役：某组件连续 K 个评估窗口贡献 ≤ 0。
- **边界**：只读全链，只写裁决表；不得改任何层的参数值。
- **禁令**：拟合者不得自证；同一份证据不得既用于拟合又用于晋升。

## 5. 流程

### 5.1 F1 决策周期

1. 取 `decision_at`，L1 按此刻 as-of 取快照。
2. L2 产出 p 与来源清单；L3 产出 m 与成本原语。
3. L4 读当前激活的参数版本，产出 b 的后验；记录 `w_point/w_ci/model_version`。
4. L5 枚举动作，算 C 与 EV 后验，闸门 `EV_q05 > h`。**被拒动作也写入记录**。
5. L6 在联合后验下定注。
6. L7 下单/撤单。
7. 写决策事实：全部输入的版本、可知时间、各层输出与裁决。一次决策一行，动作逐行。

### 5.2 F2 结算与标签

1. 真值到达 L1，带修订号与 `knowable_at`。
2. 生成标签 `(station, event_date, settled_bucket, truth_revision_no, knowable_at)`；修订即新行，不覆盖。
3. 对该站日全部桶评分 L2 的 p、L3 的 m、L4 的 b；评分行带标签可知时间。
4. 对该站日全部动作（含被拒）计算 realised edge 与归因三项。

### 5.3 F3 每日学习

1. 学习钟到，取截止钟 = 学习钟。
2. L4 用 `knowable_at ≤ 截止钟` 的全部标签前瞻重拟，产出参数分布与证据窗口；同样重估 L5 成本模型、L6 相关模型。
3. 新参数进入影子；L8 用影子期间的样本外 S/IC 裁定晋升。
4. 晋升即激活，激活记录 `fitted_at / evidence_window / activated_at`；旧版本保留可回查。

### 5.4 F4 信息事件快路径

1. 新观测或报文到达 L1，触发该站日的 L2 重算。
2. L4 产出新 b；L5 打 `info_event_tag`，估计半衰期（由历史 alpha 衰减曲线按情境查表）。
3. L6 定注；L7 走吃单路径，到期 ≤ 半衰期。
4. 超过半衰期后，该信息不再作为 edge 来源参与定价（w 在该情境按衰减曲线折减）。

### 5.5 F5 假设车道

1. 注册：机制描述、情境定义、预期符号、验收指标、所需 N_eff（按 §7 公式）。
2. 影子测量：在 L4 或 L3 上作为影子特征计算并记录，不影响动作。
3. 裁决：L8 按注册时的指标与样本量裁定；通过则成为 L4 的特征或 c(m) 项；不通过则归档。
4. 未注册的情境变量不得进入 L4。

### 5.6 F6 熔断与退化

- 任一层失败 → 向下游报「缺失」 → L4 退化为 b = m → L5 无候选 → 只执行撤单与既定退出。
- 熔断不改历史，不改参数，只改「当前是否允许新动作」的状态位，并写明原因。

## 6. 宪章

每条：陈述 / 可检验判据 / 违反处置。

- **E1 唯一信念**：闸门、定注、执行读同一个 b 的后验。判据：三处记录的 `b_version` 相同。处置：不一致的决策作废并报警。
- **E2 预报层对市场盲**：L2 的输入清单不得含价格。判据：来源清单审计。处置：含价格的版本退回影子。
- **E3 市场先验**：L4 的 w、c 先验为 0；证据不足即 b = m。判据：无证据情境的 w 为 0。处置：非零即回滚。
- **E4 全机会拟合**：L4 的拟合与评分总体是全部站日 × 整梯全部桶。判据：拟合日志的行数等于标签数 × 桶数。处置：子集拟合的参数不得激活。
- **E5 相对评分**：edge 模块唯一验收指标是 S 与 IC 的样本外按日下界。判据：晋升裁决引用的指标只能是这两个。处置：以其它指标晋升的版本撤销。
- **E6 前瞻性**：任何参数只用 `knowable_at ≤ 截止钟` 的标签。判据：重放时最大标签可知时间 ≤ 拟合截止钟。处置：泄漏版本作废并重拟。
- **E7 成本前置**：动作 EV 必须扣全含成本，成本模型自身有样本外校验。判据：每个动作记录 C 的四项分解。处置：缺分解的动作不得下单。
- **E8 后验下界定注**：闸门读 EV_q05，定注读联合后验。判据：无任何动作由点估计触发。处置：点估计触发的动作撤单。
- **E9 组合定注**：定注在联合后验与相关性预算下进行。判据：定注记录含 `corr_model_version`。处置：缺失即按完全相关重算。
- **E10 半衰期**：信息事件动作的到期 ≤ 半衰期，超期不再按该信息定价。判据：订单到期字段 ≤ `half_life_est`。处置：超期订单撤销。
- **E11 假设先注册**：任何情境 edge 先注册后检验。判据：L4 每个特征都能回查注册记录。处置：未注册特征剔除并重拟。
- **E12 单一修正**：不得叠加各自拟合的修正乘子；新校正只能作为 L4 特征进入同一拟合。判据：从 p 到 b 只有一次变换。处置：多重变换的版本不得激活。
- **E13 归因闭环**：每日盈亏按 §4.8 恒等式归因并回灌各层指标。判据：归因表每日有行且三项之和等于总盈亏。处置：缺归因的日子不得晋升任何组件。
- **E14 失败方向**：任一层失败即退化为不交易。判据：失败事件后无新开仓。处置：失败期间开的仓视为违规，纳入事故复盘。
- **E15 影子到晋升**：新组件先影子 ≥ N 事件日；晋升由 L8 裁定，拟合者不得自证。判据：晋升记录含裁决者与证据窗口。处置：自证晋升撤销。
- **E16 版本与血统**：每个信念带模型版本、拟合时刻、证据窗口；每个动作记录读到的版本。判据：任意动作可回溯到参数版本。处置：不可回溯的动作不计入任何评估。
- **E17 独立样本口径**：一切区间按事件日聚类；站数不是样本数。判据：区间计算代码只接受按日分组的输入。处置：按行自助的区间不得用于裁决。
- **E18 市场自校准独立车道**：c(m) 作为独立假设注册与检验，不与 p 混合。判据：c 的拟合不读 p。处置：混合版本退回。
- **E19 结构机会优先**：无风险结构机会先于概率型动作枚举与执行，同样扣成本。判据：L5 输出含结构机会扫描结果。处置：无。
- **E20 退役**：组件连续 K 个评估窗口贡献 ≤ 0 即退役；退役即删除活路径。判据：退役记录与代码删除提交对应。处置：无。
- **E21 拒绝集合记账**：被闸门拒绝的动作与被拒的站日同样记录并结算。判据：拒绝行数与枚举行数对得上。处置：不记拒绝的决策周期视为证据无效。
- **E22 熔断可见**：熔断只改状态位并写原因，不改参数、不改历史。判据：状态位变更有原因与时间。处置：无原因的状态变更回滚。

## 7. 指标、样本量与验收

**每层唯一指标**

| 层 | 指标 | 验收 |
|---|---|---|
| L1 | as-of 正确率 | 100%，否则该来源停用 |
| L2 | 对真值的对数得分/CRPS，相对气候技能 | 前瞻不劣于上一版 |
| L3 | m 的可靠性、陈旧度 | 单独可查，作为 L4 基线 |
| L4 | S 与 IC 的按日下界 | 拟交易情境上下界 > 0 |
| L5 | 实现率按 EV 分档、成本模型误差 | 实现率区间含 1，成本误差无系统偏 |
| L6 | 实现增长率 / 预期、回撤覆盖率 | 回撤在预期分布内 |
| L7 | 实施缺口、成交条件 realised edge | 缺口 < ex-ante edge |
| L8 | 归因恒等式闭合、裁决时效 | 每日闭合 |

**样本量公式**：要在显著性 z 下证明幅度为 δ 的 edge，所需独立样本 `N_eff ≥ (z · σ / δ)²`。以每日技能分差的标准差为 σ。示例：σ = 0.05 nat/日、δ = 0.01 nat、z = 1.64 → N_eff ≥ 67 个事件日。这个数决定影子期长度，不得用「行数」代替。

**Kelly 增长率量级**：小 edge 下每注增长率 ≈ edge² / (2·方差)。2 点 edge、40 点标准差 → 每注 0.00125。这是为什么测量必须在信念层而非盈亏层完成。

## 附录 A：三条推导殊途同归

目的：证明 L4 的形式 `logit b = logit m + w·(logit p − logit m) + c(m)` 不是任何既有实现的翻版，而是「给定市场价之后的最优信念」这个问题的唯一一阶答案。三条推导分别给出目标函数、函数形式、诊断量，没有一条以本系统为前提。

记号：桶 i 的真实概率 π_i，市场信念 m_i，市场可成交价 q_i，预报 p_i，信念 b_i，真值指示 t_i ∈ {0,1}。误差 e_p = p − π，e_m = m − π。对数几率 ℓ_x = logit(x)。

### A.0 一阶形式为什么唯一

任取一条光滑合成规则 g(p, m)，在 p = m 处展开：

`g(p, m) = g(m, m) + ∂g/∂p (m, m) · (p − m) + O((p − m)²)`

记 `c(m) = g(m, m) − m`，`w(m) = ∂g/∂p (m, m)`，得

`g(p, m) = m + c(m) + w(m)·(p − m) + 二阶项`

在对数几率坐标下同理。所以任何合成规则的一阶部分都是「市场 + 市场自校正 + 权重 × 分歧」三项；设计上剩下的自由度只有三个：坐标选概率还是对数几率、w 与 c 允许依赖哪些情境、要不要二阶项。§4.4 的形式就是这三个选择的结果。

### A.1 推导一：Kelly 增长率是两个 KL 之差（给出目标函数）

K 个互斥桶，Σ q_i = 1，赔率 1/q_i。持信念 b 的下注者按比例投注（Kelly 最优）。结果为 i 时财富乘以 b_i / q_i，长期对数增长率

`W(b) = Σ_i π_i log(b_i / q_i) = D(π‖q) − D(π‖b)`

即市场对真相的偏离减去我的偏离。

**推论 1，最优信念是后验均值**：π 未知，只知信息集 I。E_I[W(b)] 中与 b 有关的只有 `Σ E[π_i | I] log b_i`，在 Σ b_i = 1 下极大化得 `b_i = E[π_i | I]`。I 包含 p 与 m，所以最优信念是给定 (p, m) 的后验均值，这就是 L4 的定义。

**推论 2，技能分就是增长率之差**：相对「按市场信念下注」，

`W(b) − W(m) = Σ_i π_i log(b_i / m_i) = E[ log b(真值桶) − log m(真值桶) ] = S`

所以 §1 定义的技能分 S 不是一个方便的代理量，它在期望意义上就是相对市场的对数增长优势；b = m 是零点。这是 E5 相对评分与 E3 市场先验的来源。

**推论 3，成本是固定门槛**：以 `q_i = m_i + d_i` 成交（d 为半点差加费），

`W(b) = Σ π_i log(b_i / m_i) − Σ π_i log(1 + d_i / m_i)`

第二项与 b 无关且为负：成本从技能分里整块扣除，与信念好坏无关。这是 E7 成本前置的来源。

### A.2 推导二：对数几率空间的两信号合成（给出函数形式）

单桶二元化。设全信息对数几率为 L，市场与模型各自是 L 的一次有噪测量：

`ℓ_m = L + e_m`，`ℓ_p = L + e_p`，(e_m, e_p) 零均值联合正态，方差 σ_m²、σ_p²，相关 ρ。

两个无偏测量的最优线性合成（Gauss–Markov）权重和为 1，写成「以市场为基、加权分歧」：

`L̂ = ℓ_m + w·(ℓ_p − ℓ_m)`，`w = (σ_m² − ρ σ_m σ_p) / (σ_m² + σ_p² − 2ρ σ_m σ_p)`

读法：
- `w > 0 ⇔ σ_m² > ρ σ_m σ_p ⇔ Var(e_m) > Cov(e_p, e_m)`：模型的错不能只是市场的错的复制。
- 若 `e_p = e_m + η`（模型 = 市场 + 自己的噪声），则 `Cov(e_p, e_m) = Var(e_m)`，`w = 0` 恰好为零。重新加权同一份公共信息得不到 edge，这是它的数学表述。
- 若 ρ = 0（独立信息），`w = σ_m² / (σ_m² + σ_p²)`；ρ < 0 或 σ_p 远小于 σ_m 时 w 可以超过 1，即「极化」。概率线性空间表达不了 w > 1，对数几率空间可以。
- 若市场测量有偏或有缩放，`ℓ_m = α + γ L + e_m`，最优合成多出一个只依赖 ℓ_m 的仿射项 `c(ℓ_m)`。这就是市场自校准项，其估计不需要 p，故独立成车道，E18。

**后验方差为什么重要**：`Var(L | ℓ_m, ℓ_p) = s²`。信念是 `b = E[σ(L)]` 而非 `σ(L̂)`，近似 `b ≈ σ( L̂ / √(1 + π s² / 8) )`：参数不确定把 b 拉向 1/2。用点估计会系统性高估分歧的价值。这是 E8「读后验分布」的来源。

**为什么不用概率线性池**：校准预报的线性池除平凡情形外必然欠置信（Ranjan 与 Gneiting，2010）；而条件独立信号在贝叶斯更新里恰好在对数几率上可加：`logit 后验 = logit 先验 + Σ 对数似然比`。对数几率是合成的自然坐标。

### A.3 推导三：线性下注恒等式（给出诊断量）

回到概率空间。对每桶按分歧下注 `s_i = w·(p_i − m_i)`，以中价成交，盈亏 `Σ s_i (t_i − m_i)`。取期望：

`E[(p − m)(t − m)] = E[(e_p − e_m)(−e_m)] = Var(e_m) − Cov(e_p, e_m)`

于是 `EV = w · [Var(e_m) − Cov(e_p, e_m)]`，正负条件与 A.2 的 w > 0 条件逐字相同。

「真值减市场」对「分歧」的最优线性斜率

`w* = [Var(e_m) − Cov(e_p, e_m)] / Var(e_p − e_m)`

其标准化就是 `IC = corr(p − m, t − m)`。这是 L4 第二个验收量与 L8 归因项 (b − m) 的来源。以 `q = m + d` 成交时 EV 再减 `Σ |s_i| d_i`：IC 型收益减固定成本，与 A.1 推论 3 一致。

### A.4 汇合

| | 推导一 | 推导二 | 推导三 |
|---|---|---|---|
| 回答的问题 | 最优信念是什么、用什么评 | 后验的函数形式 | 分歧下注的期望盈亏 |
| 结论 | b = E[π \| p, m]，S = 增长率之差 | ℓ_m + w(ℓ_p − ℓ_m) + c(ℓ_m) | EV = w·[Var(e_m) − Cov(e_p, e_m)] |
| w > 0 的条件 | 由 S > 0 给出 | Var(e_m) > Cov(e_p, e_m) | 同左 |
| 验收量 | S 的下界 | w 的后验区间 | IC 或 w* 的下界 |
| 落到条款 | E3、E5、E7 | E8、E18、logit 坐标 | L4 的 IC、L8 归因 |

三条推导的对象是同一个权重，正负条件同一个不等式，验收量互为等价形式。任何「以市场为基、单权重加分歧」的实现都是这三条推导的特例：概率空间、c ≡ 0、每阶段一个常数 w，是其中最简的一个。本基线取的是 A.0 的一阶形式、A.1 的目标、A.2 的坐标与 c 项、A.3 的诊断量。
