# 单系统校准形状：交给 LogLoss 选，或四按钮参数族（计算前协议，2026-10-02）

熊先生裁决（2026-10-02）：两头鼓「肯定要解决」——它把尾部概率抬高，不符合离散温度桶概率的目标，是设计缺陷；方向二选一：①单系统校准方法向 LogScore 目标对齐；②加按钮：中心、宽度、偏度、峰度。本协议在同一重放上把两条路都做成臂，按下文规则选一条落地。生产在本研究期间未改。

## 现行形式与缺陷

`corrected = center + s·(member − mean)`，再套固定 0.5 °C 核（方差守恒收缩）。s 由矩起算、经宪章 216 的 (δ, s) LogLoss 重拟收缩一半。缺陷：s 乘在成员间距上，成员簇之间的空隙同比放大，而核不变——`REPORT.md`：单系统向量 ≥2 峰 13.1%（GEM 27%），当天离散度 ≥1.5 倍平均时 53.8%。

## 臂（全部沿用现行三分位偏差、H15 LogLoss 权重、L-BFGS-B maxiter 60、1e-6 下限、κ=0.5 回拉到各自起点）

- `base`：生产。
- `dress`：生产 (δ, s)，核 b = √(s²−1)·d（10-02 已测臂，作对照）。
- `fit_c0`（路①，锚在现行）：参数 (δ, s, c)。总宽 s·d；核 b = max(0.5, c·s·d)；成员间距由方差守恒收缩自动给出 s·d·√(1−c²)。c=0 即现行。起点 (0, s_mom, 0)，三参数一起按 LogLoss 重拟，κ=0.5 回拉到起点。它与 `base` 只差 c 这一个自由度：回答「LogLoss 自己想不想把宽度从间距挪到核」。
- `dress_fit`（路①，锚在加宽核）：同一形式，起点 (0, s_mom, c_dress)，c_dress = √(1−1/s_mom²)（s_mom ≤ 1 时 0）。
- `shash`（路②，四按钮）：sinh-arcsinh 参数族，μ = 三分位中心 + δ，σ = √(s²d² + 0.5²)，偏度 ε，尾重 τ（ε=0, τ=1 为高斯）。F(x) = Φ(sinh(τ·asinh((x−μ)/σ) − ε))。起点 (0, s_mom, 0, 1)，四参数一起按 LogLoss 重拟，κ=0.5 回拉。只用成员均值与离散度，不用成员位置。边界：δ (−3,3)、s (0.25,5)、c [0,0.999]、ε (−1.5,1.5)、τ (0.4,2.5)。

## 修订（2026-10-02，试跑 ZUUU 一站后、未看任何判定样本前）

`fit_c0` / `dress_fit` 的核参数原写为 b = max(0.5, c·s·d)。试跑 ZUUU：`fit_c0` 的 c 在 7,459 个系统×更新上 p10/p50/p90 全为 0——不是 LogLoss 不想动，而是 max(·) 在 c=0 处梯度恒零（c 要越过 0.5/(s·d) 才有任何变化），L-BFGS-B 的差分梯度看不见，c 被钉死。改为核方差份额：b² = 0.5² + c·(s²d² − 0.5²)，c∈[0, 0.999]；c=0 仍逐位等于现行，c→1 为同总宽的高斯，对 c 线性、在 0 处有梯度。`dress` 对照臂在该坐标下的锚点 c_dress 以训练期平均离散度 M 换算：b² = (s²−1)M²。臂的含义、起点、回拉、判据不变。ZUUU 试跑的其他读数（SHASH 在该站明显更差）不作为判定依据，全样本按原规则判。
