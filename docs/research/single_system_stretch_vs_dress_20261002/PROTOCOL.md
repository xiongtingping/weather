## 两个独立问题与臂

1. **形状**：拉宽是把成员间距乘 s（成员簇之间的空隙同比放大），而核固定 0.5 °C。备选是同样的总方差 s²·v，但成员保持原始间距、把核加宽到 b = √((s²−1)·v)（s ≤ 1 或 b ≤ 0.5 时与现行逐位相同）。实现即生产 `_probabilities(stretched, bandwidth_c=b)`——其方差守恒收缩会把间距收回原始尺度。
2. **宽度**：s 是常数，不看当天离散度。备选按当天原始离散度 d 与训练期平均离散度 M 取 s_eff = s·(M/d)^(1−β)，β = 0.5（d = M 时等于 s；当天离散度翻倍时服务 sd 只放大 √2 倍）。β 事先定为 0.5，不在样本上挑。

臂（全部用现行宪章 216 的 δ 与 s，不重拟）：`base`（现行）、`dress`、`beta`（拉宽，用 s_eff）、`dress_beta`。
