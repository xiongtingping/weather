## 已确认发现一：P0 的辐射验收与服务不是同一个尺度

**优先级高，属于验收实现问题。**

- `native_ensemble_oos.py:1594` 附近：留出侧取系统中心跨度，令 `sigma=(max(center)−min(center))/2`，然后把辐射标准化信号乘它。
- `native_ensemble_p0.py:3177` 附近：服务侧取混合／共识桥之后完整桶分布的标准差，再乘相同辐射信号。
- 系统中心一致并不代表每家成员或融合分布没有宽度。两家都预报 25°C 时，验收尺度可以是 0，服务尺度仍大于 0。

**最小反例已调用生产函数复现**：两系统中心都是 25°C，桶分布 `(24,25,26)=(0.25,0.5,0.25)`，同一份 Kt 信号。留出 helper 不产生位移，服务公式位移 **+0.68709°C**。这是构造输入的算术反例，不是成都某天被错移了 0.687°C 的实测结论，也不证明整个权重证书无效；它证明此物理变换的“验收等于服务”主张不成立。

此外，`_holdout_shape_stack` 在整数 °C 网格上跑；生产在实际市场梯子上跑。共享了中心宽度／band 函数和层顺序，仍不等于共享了相同分布、尺度和几何，F 市场和开放尾桶尤其需要单独核对。

**优化**：离线门与服务共用同一个纯概率变换入口，输入必须是相同的校准后混合分布、同一物理特征快照和实际桶合同；σ 在该入口内唯一计算。先通过同输入逐桶一致性，再重跑历史评分。不能靠调整 0.15 系数补偿两套 σ。

## 已确认发现二：P0 物理特征的 as-of 合同尚未闭合

**优先级高，属于历史证据问题，与上一项数学尺度问题分开。**

`_holdout_conditioning_signals` 按站、事件日读 `calibration_station_forecast_physics`，不读取或过滤 `captured_at_utc`，函数也不接收样本 cutoff；历史 TAF 回退同样没有逐样本 arrival 过滤。服务 `_forecast_radiation_sum` 也只按站日找行。Kt 的历史日期过滤已经去掉主路径的事件日之后行，但“事件日期早于目标日”不等于“这个版本当时已收到”。

**反例**：把相同物理值的 receipt 从 1900 年改成 2099 年，留出输出完全不变；在两系统中心分别 24/26°C 的反例里，未来 receipt 仍产生 **0.97169°C** 位移。此前源审计还确认该物理表用站×日×源覆盖写，无法仅从现值恢复历史版本。

这不意味着实时服务偷看未来，也不证明辐射无预测价值。它意味着用今天表里的现值重建历史，不能据此声称严格日前 OOS；仅对上游原生成员做 as-of 不能替这个协变量补证。

**优化**：给每个物理／TAF 协变量保留不可变版本与 source lineage、valid interval、available_at、received_at；每个样本显式携带 cutoff。离线和服务用同一 resolver。现存无法恢复历史版本的样本标成不能认证，而不是退化成 run_init、事件日期或当前表值。此项在增加新物理变量之前完成，避免为更复杂模型提供同样有缺口的证据。

此项不要求先撤掉已授权的 reference 协变量，也不把它重新命名为 native。来源权限与严格历史可知性是两项分别需要满足的合同。

## 已确认发现三：P1 b2 在 6h / 10h 仍有结构性跳变

**优先级高，属于当前已服务的模型表达式。**

`p1_direct_update.py:167` 的基础时钟帽函数连续，但 `late=1[h<6]`、`mid=1[6≤h<10]` 把整组标准化特征硬开关。只要对应系数非零，`f` 在阈值两侧就可以有有限跳跃。训练侧 `direct_x` 也使用同样开关，因此是设计不连续，不能通过修一个服务端 if 而保持拟合件不变。

本轮以冻结的实际 P0-M 根、观测状态、掩码和当前匹配 artifact，改变时钟跨阈值；共 **94 组边界探针**，每组用 `10⁻³、10⁻⁶、10⁻⁹` 小时反复逼近；另做 **47 组非阈值连续性检查**与归一化／硬排除检查。

较贴近实际状态的例子：MMMX 的包络时钟为 **10.0424h**，距阈值约 2.54 分钟。固定其余输入，在 10h 两侧极限，25°C 桶概率由 **32.12% 变为 45.59%**，差 **13.47 个百分点**；缩小步长后差异仍存在。KSEA 距阈值约 26 分钟的状态也复现约 4.96 个百分点跳变。

以上是边界反事实，不是历史相邻两条实际报文的跳变，也不是收益或损失。远离阈值的状态被强行移到阈值时出现更大的数值，只作为压力测试，不用于宣称生产普遍严重异常。

**优化**：保留 b2 的最终后验直接拟合，将状态×时钟交互改为连续基函数／平滑门控，强正则并与当前 b2 同数据对照；或者分段参数施加连续连接约束。训练和服务同时更换表达式并重拟，不能把旧系数直接套进平滑门。验收既看 NLL/CRPS，也要求固定证据情况下跨边界的概率差随时间步长趋零。

## 两项设计限制：需要量化，不直接判为生产错误

### A. P0-M 用桶代表点评价连续似然，开放尾桶近似可能失真

当前 `exponent_by_bucket` 对每桶中心 `c_k` 求高斯似然，包括把“某温度以上”压成有限代表点。严格的连续模型更新应计算桶内积分 `∫ p0(T)L(T)dT`，不是 `P0(k)L(c_k)`；若采用离散模型，代表点与训练目标的含义就必须明确，并检验更换梯子时的稳定性。

构造反例保持同一连续根和 TX，只细分 27.5°C 以上的尾桶：更新后 `P(Y≥27.5)` 在零地板前由 **99.0371% 变为 99.9788%**。差异在加地板之前就存在，不能全部归因于地板。此处用人工 a=0、b=1、τ=1，只证明几何近似的性质，不是当前 TAF 参数的历史损失估计。

优化方向是保留 P0 桶内分布或可积表示、联合更新后积分；若现阶段保留桶模型，先用当前参数在实际尾桶上量化误差与条件 NLL，不立即重写全链。

### B. band 是校准层，但不保证保持峰值、中心或宽度

乘因子后归一化必然可能改变分布矩；距 argmax 的轴还会在两个桶交换峰值时离散换轴。反例中 10⁻⁹ 的输入扰动配合 1.0/1.1/1.0 因子，可形成约 4.71 个百分点差异。但本次最新 45 站中，44 站该层为恒等；唯一非恒等 KSFO 使用旧 claim 轴。**不能拿距峰轴的反例解释当前全队症状，更不能直接关闭所有 band。**

建议先评估各固定版本的真实增量，和中心／宽度校准联合消融；如要替换，以连续、低自由度的校准函数对照当前末层，避免再增加独立补偿表。保留 pinned artifact 语义，旧版与新版分别认证。

## 不应再拿来当本轮新问题的事项

1. **P0-M 已采用条件似然，P1 已采用 b2。** 不建议再“改成似然／直接更新”；不把旧 g^α 重复基准问题套给当前 b2 主分支。
2. **P1 每次从根重算，并有重复证据保护。** 本轮没有发现“把每条报文逐次独立相乘”的证据。
3. **权重规则当前不是首要改造对象。** 原始中心残差协方差与已校准分布质量并不等价，但固定偏差减法不改变协方差；只允许严格时间交叉拟合的状态化残差候选。既有结果不足以替换现行权重，不再凭排名翻转立新规则。
4. **TAF 开闸是明确裁决，不是程序绕闸。** 冻结文件 measured gate 为 IDENTITY，均值增益 +0.01249 nat、区间约 [−0.03714,+0.06132]；loader 按第 151 条改为 SERVE 并保留 measured_state。本轮不撤销裁决，不把它说成统计显著通过。力度分组仍有自身的闸。
5. **b2 是条件对数概率更新，并非证明了生成式观测似然。** 这不妨碍按最终概率评分，但不能仅凭“贝叶斯”命名替代校准检查。其训练 loss 在零地板前，选择与评分在地板后，是代理目标的取舍；效果需量化，不能仅由不同就判错。

## 系统性优化顺序

保持现有阶段与权重基线。先把下面三项合同落实，后续所有候选都共用，避免每个层再修一遍历史错误。

| 顺序 | 交付 | 可验证终点 |
|---|---|---|
| 1 | 唯一版本化特征解析器 + 每样本 cutoff | 修改未来 receipt/未来记录不改变过去样本；未知历史版本明确不能认证；不把今天校准件套回过去 |
| 2 | P0 验收与服务唯一概率算术 | 同一输入、尺度、参数、C/F 市场合同、开放尾桶下逐桶一致；覆盖同中心不同 spread、0 分歧、大分歧、层消融；不再用代理 σ |
| 3 | P1 连续时钟交互候选 | 保留 b2 与 immutable root；边界差趋零，完整前缀回放及反向扫时钟一致；新参数严格 as-of 重拟并与当前 v17 对照 |
| 4 | 最终概率质量的联合验收 | 比较各阶段自己的现行基线；完整 NLL/CRPS、覆盖与宽度、尾桶与零地板命中、冷暖侧、C/F、站点覆盖、日期相关置信区间；未见历史外层一次使用 |

前三项中，第一、二项先修证据和算术等价性，不能把其必然性表述为必然提高预报精度。第三、四项才回答“概率是否更好”。同一天重复刷新不应当成独立天气样本；改 root／变换后，下游基线与样本必须标版本，不自动沿用旧收益证明。

这比继续加云雨风特征更靠前：现有系统已经在使用辐射信息，当前首先要保证**同一套信息被同一种算法检验和服务**，然后才知道新增信息能带来多少增量。不能把共同冷偏的根因强行归到上述任一发现；因果归因需要修正后的历史逐层消融。
