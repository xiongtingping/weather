# 把开仓最小宽度从 3 降到 2：本轮唯一一条稳健为正的臂（+8.3 个 ROI 点）

> WI-4 改道后的第一个读数。中心闸消融证明闸不是杠杆（只换 5 个座），
> 而"一次枚举只产出中位 1 条带价窗、只碰中位 3 个桶、窗宽几乎全是 3 或 4"指向**宽度界本身就是域**。
> 本文测两根界各自值多少。
>
> **结论：最小宽度 3→2 值 +8.3 个 ROI 点且稳健；最大宽度 4→6 不稳健。这是本轮全部臂里唯一一条稳健为正的。**

树 `fb004c5e`，窗 08-28→09-10，生产裁判，**成交模型＝已升默认的 `adverse`**，每臂干净账本表。

## 一、最小宽度 3→2

配对（217 条共同链）：**+22.75**；剔 |差| 最大 1/2/3 条后 **+32.60 / +23.59 / +16.45**——
**全正，且剔掉最大那条反而更大**，说明单条最大差是负的（−9.85），正效应铺在很多链上。
逐日 **9 好 4 坏**。123 条链改选。

分阶段：**P0 −27.5% → −18.3%（主体）**、P0-M −12.3% → −7.8%、P1 −28.4% → −30.2%。
链数 223→238，投入 928→1086——**它是买得更多而不是买得更少**，这在本账上很罕见：
过去唯一被反复量出正效应的动作是"少买"。

条件成交率仍在（赢腿 46.0% 对输腿 67.3%，差 −21.3），所以这不是成交模型伪象。

**机理读法**：开仓阶段的最小宽度是 3，而一次枚举本来就只碰到中位 3 个桶。
于是"至少 3 个"要么逼着篮子把第三条腿买下来（那条腿是模型最不信的那个位置），要么整个站日不入座。
放到 2 之后，这两种代价都消失：既省下第三条腿的钱，又救回一批本来开不了的站日。

## 二、最大宽度 4→6：不稳健

配对 +6.76（221 条共同链），但**剔两条即 −2.82**；只有 25 条链改选（8 好 17 坏），逐日 3 好 5 坏。
放宽上界几乎不产生新窗——域里本来就没有 5、6 个连续可入座桶。**不采纳。**

## 三、必须一起说的限制

1. **单窗口。** 08-28→09-10，223 条共同链。**下一步是全史（08-15 起）重跑**，之前不做裁定。
2. **改选的 123 条链里 47 好 76 坏**——总量为正但多数单链变差，收益集中在少数几条。
   剔最大 1/2/3 条仍正说明它不是一条链撑的，但"多数链变差"这件事要写在任何条款里。
3. **这是宪章级改动。** 第 50 条把开仓最小宽度定为 3、P1 为 2。降到 2 要走裁决，
   并且要对照第 93 条地板（2 宽篮子在支持集内仍不得亏）与第 49 条中心包含（2 宽窗仍须含中心）。
4. 第一次跑这两臂时它们是**空转臂**：开关只接了生产对枚举器的调用，账本的生产裁判有自己的调用点、
   照旧读政策字段，于是两臂指纹不同而读数与基线逐字段相同（283 链 / 配对 +0.00 / 0 条改动）。
   已修（05c9da97），测试改为遍历两个模块里**每一个**把界交给枚举器的调用。
