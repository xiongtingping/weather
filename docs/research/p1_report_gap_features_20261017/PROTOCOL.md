# 预登记：P1 加「报文缺失」特征（距上一份报文小时数、应到未到报文数），严格前推（2026-10-17）

熊先生 10-16「预登记并严格前推：P1 加「报文缺失」特征（距上一份报文的小时数、应到未到的报文数），看深夜校准与 LogScore，按站给结论」。
写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改。

## 起因
`p1_late_night_shared_arm_20261016`：训练样本深夜「之后又升」59 行中 50 行集中在 09-09/09-21/09-22，均为样本当时报文前缀不全（采集断档、事后补齐），不是夜间升温；P1 没有「报文缺了」的特征，只能把这部分摊到所有深夜，宪章 274 现行形式深夜「还会升」美国 1.40%（实际 0.43%）、非美国 1.09%（实际 0.55%）。

## 特征（严格 as-of，事先固定）
来源：`data/archive.db` 的 `reported_trajectory_observations`，`source_lane='awc'`（官方 AWC METAR/SPECI），只用 `canonical_committed_at ≤ 样本时刻` 的报文。
- `gap_h`：样本时刻 − 最近一份已到达报文的 `valid_at`（小时；向前最多看 24 小时，没有则记 24）。
- `missing_n`：max(0, 应到数 − 已到数)。已到数＝当地事件日内、已到达的报文数；应到数＝该站报文率 × 当地事件日已过小时数，报文率＝该站在事件日之前 14 个完整当地日的每日报文数中位 ÷ 24（不足 3 天用全队中位）。
两列缺失（站无历史）用训练均值填，按训练行标准化。

## 数据与对照
同 `p1_slope_refit_arms_20261016` 的 design（生产样本库）、30 个评估日（09-16..10-15）、严格 as-of 训练、同 λ 选法。
**对照 CURRENT**＝宪章 274 现行形式（`p1_evening_arm_20261016` 的逐日前推）。
**辛**：CURRENT 的 x 末尾加 `gap_h`、`missing_n` 两列；rise、slope 两块都能用。

## 指标
1. 整梯子 −log p 之差（辛 − CURRENT）；2. 深夜行（站钟剩余 ≤3h）同上，分美国（K 开头）/ 非美国；
3. 深夜「还会升」校准（平均 vs 实际、Brier），分美国 / 非美国，并另报「断档行」（missing_n ≥ 2 或 gap_h ≥ 2）与「正常行」；
4. 按站 BH q=0.10（整梯子与深夜各一份，≥10 站日）。区间：按事件日 bootstrap 2,000（seed 7）。

## 判据
深夜 Δ 区间 < 0、整梯子不显著变差、无 BH 显著变差站 → 上线候选（是否上线另裁）；深夜 Δ 跨零 → 不成立，报校准表。

## 已知限制
美国站样本的报文前缀可能来自 ASOS 车道，缺失特征只看 AWC 车道；评估期本身也含断档日；评估 30 天。
