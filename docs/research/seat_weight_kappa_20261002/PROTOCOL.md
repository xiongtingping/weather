# 预注册协议：席位权重的收缩 κ，在宪章 242 之前与之后各值多少

写于 2026-10-02，评分之前。裁决人：熊先生（「继续打席位权重」「还有服务权重」）。

## 问题
席位权重 = (1−κ)·技能权重（中心误差最小方差）+ κ·家族均分，现役 κ=0.5（宪章 134）。宪章 242 起服务权重以席位权重为先验、按站日数收缩到站级 LogScore 最优权重。
问：(1) 只看席位权重，κ ∈ {0, 0.25, 0.5, 0.75, 1} 谁最好；(2) 在 242 之后（服务口径），换 κ 还能不能动服务 P0。

## 数据与机器
`station_model_weights_20261001/pass1_all`（六家 1–9 月生产走查）；score.py 的代表决策、下游（桥、物理、今日 λ=0.75）与评分。
技能权重由捕获的席位权重反推：skill = 2·seat − baseline（baseline＝该决策入座集合的家族均分），截到 ≥0 再归一；κ 臂 w_κ = (1−κ)·skill + κ·baseline。
- 席位口径：w_κ 直接下游。
- 服务口径：w_κ 作 242 先验（EBP*，τ 同法前推选，站级拟合与 κ 无关）。
## 判决
计分 2026-04-01..09-30，宪章 240 门（`_proper_score_gate`，簇=站日）；对照＝现役 κ=0.5 同口径。某 κ 在**服务口径**过门且前后两段（04-06/07-09）ΔLogScore 同负才提议改；只在席位口径过门不提议（不进服务）。
