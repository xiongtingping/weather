# 结果：席位 κ 在席位口径上 0.25 略好，但到服务口径影响已不到 0.0015 nat——不改

协议 8ec2190b 先提交。六家 1–9 月走查，计分 04-01..09-30，7,093 站日；对照现役 κ=0.5。
健全性：κ=0.5 服务口径对席位口径 −0.0132 [−0.0197, −0.0068]，与宪章 242 主判决逐位一致。

| κ | 席位口径 ΔLogScore [95%] | 服务口径 ΔLogScore [95%] | 服务 ΔBrier | 两段（服务） |

读法：
- 席位权重本身，技能（中心误差最小方差）值得比一半更多的信任：κ 越大越差，0.25 显著好于 0.5。
- 但宪章 242 之后，κ 从 0 到 1 全程只让服务 P0 变 0.0026 nat，κ=0.25 的服务口径差 −0.0004 跨零。席位权重在服务里只剩约一成作用（τ=5，各家 α≈0.9）。
- 按协议，只在席位口径过门不提议；席位权重仍决定 OOS 门认证的池与否决闸的退路，κ=0.25 的好处只会体现在那两处，量级 0.002 nat。

结论：不改 κ。服务权重已由站级 LogScore 拟合主导，席位层没有值得开的臂。
