# 均值桶为中心的篮子：P0 开仓 + 贝叶斯更新随均值桶移窗（计算前协议，2026-09-24）

熊先生 2026-09-24：「按照篮子均值桶为中心的选桶策略啊，不是叫你选中心」。上一版 `PROTOCOL_MODEL_BELIEF.md` 让效用求解器按概率÷价格自由挑桶，不是这个策略；本协议按均值桶窗口重做。只读，不改生产、不下单。

## 规则

- **信念**：服务中的模型概率，事件与阶段优先级同 `PROTOCOL_MODEL_BELIEF.md`，即 P0 新 run、P0-M、P1 新报文，P1 > P0-M > P0。
- **均值桶**：把桶按梯子顺序编号，计算 Σ p_k·k，取整后得中心 c。编号从桶名的温度解析，"或以下"排最前，"或以上"排最后。
- **窗口**：
  - 主口径 W3 = {c−1, c, c+1}；
  - W2 = {c, 均值所在一侧的相邻桶}，即 Σp·k ≥ c 取 c+1，否则取 c−1；
  - W1 = {c}。
  - 碰到梯子两端时整体向内移，保持桶数不变。
- **开仓**：该站日第一个有盘口的 P0 事件。窗口内每桶最优卖价之和须 < 1，否则本事件不开，等下一个事件再判。
  - 份数 n：窗口内各桶同为 n 份，逐档吃深度，总花费 ≤ 10 USDC 的最大整数 n。n < 5 不开，因为交易所最小单是 5 份。
- **更新**：此后每个事件重算窗口。
  - **只补不卖**：新窗口里持仓少于 n 的桶，按卖盘补到 n；不看价格，只要卖盘深度够；移出窗口的桶继续持有。
  - **补齐并卖出**：同上，另外把移出窗口的桶按买盘全部卖出。
- **只开仓**：开仓后不再交易，用来单独量出更新的价值。
- **对照（仅参考）**：中心换成价格隐含概率的均值桶，其余不变。
- **真值**：交易所结算（`venue_truth_overrides.json`）；费率 0，卖价即全包价。

## 读数

- 每站日盈亏的均值，以及回报率 = Σ盈亏 ÷ Σ花费，均按事件日自助 90% 区间，前后半按事件日切。
- 命中率：真值落在期末持仓桶里的站日占比。
- 均份成本：Σ花费 ÷ n，超过 1 的站日占比，这是追窗的代价。
- 盈亏按阶段归因：开仓、P0 更新、P0-M、P1。

## 判据

主口径（W3、只补不卖）回报率日聚类 90% 下界 > 0，前后半段同号，交易事件日 ≥ 15。不过即不接入；结果出来后不改规则、不加臂。
