# 模型概率当信念：P0 开仓 + 贝叶斯更新（2026-09-24）

协议见 `PROTOCOL_MODEL_BELIEF.md`（a8549c58，先于读数提交）。只读，不改生产、不下单。

## 结论

**所有臂都亏，不过线，不接入。**
- 贝叶斯更新让亏损放大，而不是缩小：只开仓亏 2,132 USDC，加上逐事件更新后亏 9,200 USDC。
- 按中间价成交时，P0-M 与 P1 的更新方向是对的，但赚到的比点差少；P0 开仓和 P0 更新则连方向都错。

- 1,316 个站日，30 个事件日（08-25..09-23），每站日 100 USDC。

## 读法

1. **P0 在远提前量上方向就错**：即使不付点差也亏。
2. **P0-M 与 P1 的更新方向对，但薄**：不付点差能赚，按真实成交价就亏。它们的边际小于买卖价差。
3. **更新越频繁亏得越多**：后半段（09-12 起 P1 状态刷新上线，事件数每天约 1,300–1,800 个）比前半段差得多。每次重解都在付点差。
4. **模型的近零概率是破产源**：成交越便宜、求解越敢下注，越会在"模型认为不可能"的桶上被击穿。
