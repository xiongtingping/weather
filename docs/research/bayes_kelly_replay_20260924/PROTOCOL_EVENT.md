## 事件

- **P1 报文事件**：同一站日的一份 P1 包络，其 `canonical_observation_event_id` 与上一份 P1 不同，而且概率向量有变化。
- **三个时钟**：
  - t_pub = 该观测在 `archive.db.reported_trajectory_observations` 的 `valid_at`，是市场最早可能看到它的时刻；
  - t_ours = P1 的 `decision_at_utc`，是我们的信念可用的时刻；
  - t_trade = t_ours + L。
- 事件日 2026-08-25..09-23；真值按交易所结算（`venue_truth_overrides.json`）。

## 信念（只有一个自由参数 β，按档前推拟合）

- **我们的增量** ΔL = 本份 P1 ÷ 同站日上一份 P1，逐桶取比值，地板 1e-6。当天第一份 P1 用 P1 ÷ norm(预测根 × 掩码)。
- **软掩码**：本份新排除的桶乘 κ = 0.01，不取 0。κ 取对账基准率，写死不拟合。
- **两个先验**：
  - **PRE**：m_pre = `observed_at ≤ t_pub` 的最新盘口价格隐含概率，也就是报文之前的市场；
  - **NOW**：m_now = `observed_at ≤ t_ours` 的最新盘口，也就是我们出信念时看得到的市场，可能已部分吸收报文。
- q = norm(m × ΔL^β × 软掩码)，β ∈ {0, 0.25, 0.5, 0.75, 1, 1.5}，按档前推拟合；训练只用事件日 ≤ d−3、至少 8 个事件日。
- 基线：成交时刻价格 m_L = `observed_at ∈ [t_ours, t_ours + L]` 的最新盘口价格隐含概率；L ∈ {2, 5, 15} 分钟，窗口内没有盘口的事件在该 L 下不评。

## 分档

按 t_ours 距结算日结束的小时数分三档：[10, 24)、[6, 10)、[0, 6)。

## 读数与判据（与第一次重放相同）

1. **对数得分差** q − m_L：按 档 × L × 先验 报，按事件日自助取 90% 区间，前后半按事件日切；事件按站日等权。
2. **实际增长**：主口径 L = 5 分钟、先验 PRE。
   - 每站日 100 USDC，γ=4，按事件时间顺序在 m_L 那份盘口上逐档买卖，持仓连续，最小单 5 份。
   - 门控：该档训练期对数得分差的日聚类下界 > 0 才交易。
   - L = 2、15 和先验 NOW 作敏感性。

过线：某档某 L 的对数得分差下界 > 0 且前后半段同号；并且主口径门控增长下界 > 0、前后半段同号、交易事件日 ≥ 15。不过线即不进前向影子。结果出来后不改分档、L、β 网格、κ，也不增加变体。
