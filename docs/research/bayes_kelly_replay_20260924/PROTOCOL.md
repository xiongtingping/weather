# 贝叶斯链 × 效用最优篮子：离线前推重放（计算前协议，2026-09-24）

熊先生 2026-09-24：「用历史站日按时间顺序跑贝叶斯链、效用求解和增长恒等式检验，不改生产。先读出 π 对价格的对数得分差和实际增长。这两个数过线，再谈接入生产。」只读 SSOT，不改生产、不下单。

## 样本与时点

- 站日：`basket_station_day_settlement_label` 最新修订，事件日 2026-08-25..09-23；真值 = `settled_bucket`。
- 时点网格：距该站结算日**结束**（`calibration_station_market_timezone_binding` 的逐站时区，事件日次日 00:00 本地）H ∈ {44, 36, 30, 24, 18, 14, 10, 7, 4} 小时。
- 每个时点的信息集：
  - 信念：按 P1 > P0-M > P0 取 `decision_at_utc ≤ 时点` 且 `fresh_until_utc ≥ 时点` 的最新包络。
  - 盘口：`basket_official_ws_snapshot` 中 `observed_at ∈ [时点−60 分钟, 时点]` 的最新快照；价格隐含概率 = `market_reference_v1`（仅 state=complete 进对数得分比较）。
- 提前量分档（参数与门按档拟合）：远 H≥24、中 10≤H<24、近 H<10。

## 被比较的信念 π（全部按事件日严格前推）

链拆解：P0 根 r（P1/P0-M 血统里的 `p0_root_checkpoint_id`）；TAF 似然 L_TAF = P0-M ÷ r；观测似然 L_obs = P1 ÷ norm(预测根 × 硬掩码)，硬掩码 = `hard_excluded_buckets`。

1. **MARKET**：价格隐含概率，基线。
2. **SERVED**：服务中的包络原样。
3. **CHAIN_T**（回火链）：log π ∝ log r + η₁·log L_TAF + η₂·log L_obs + log 掩码；η₁, η₂ ∈ {0, 0.25, 0.5, 0.75, 1, 1.25}，按档拟合。
4. **CHAIN_T_PRICE**（价格作证据）：log q ∝ a·log π_CHAIN_T + b·log m；a ∈ {0, .1, .2, .3, .5, .75, 1}，b ∈ {0, .5, .75, 1, 1.25}，按档拟合。

前推：评事件日 d 时只用事件日 ≤ d−3 的站日拟合（真值必已结算），至少 8 个不同事件日，否则 d 不评；目标 = 平均对数得分（站日等权，桶概率地板 1e-6）。

## 两个读数

1. **对数得分差**：每个变体减 MARKET，按档与全体；按事件日自助 2000 次取 90% 区间；前后半按事件日切。
2. **实际增长**：每站日本金 100 USDC、彼此独立；按网格时点依次重解，持仓连续携带。
   - 目标：CRRA 期末财富效用，γ=4 为主口径，γ=2、8 作敏感性。
   - 成交：买按卖盘逐档（每桶前 6 档、价 <0.95），卖按买盘逐档（不超过持仓）。
   - 规则：交易所最小单 5 份，净买或净卖不足 5 份的腿丢弃；费率 0（卖价即全包价）。
   - 增长 = log(期末财富/100)，期末财富 = 现金 + 真值桶持仓。
   - 两个版本：
     - **不门控**：每个时点都解。
     - **门控**：该变体在该档的训练期对数得分差，日聚类 90% 下界 > 0 才解，否则持有不动。

## 过线判据（写死，看结果前定）

两条同时满足才谈接入生产：
- **对数得分**：某变体在某档，前推差值日聚类 90% 下界 > 0，且前后半段同号。
- **实际增长**：同一变体门控版，每站日平均 log 增长日聚类 90% 下界 > 0，前后半段同号，且有交易的事件日 ≥ 15 个。

不满足即结论为「不接入」，只报读数，不改网格、不改档、不加变体后重判。
