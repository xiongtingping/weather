## 三个事前假设

数据来自生产 SSOT。决策点取 `basket_policy_training_fact` 中 stage='P0' 的 fact：
- p：信封概率，归一后过 `floor_probabilities`，与 Proper 线一致；
- 盘口：fact 绑定快照的逐档买一、卖一与挂量；q 取 `market_reference_v1`；
- 真值：`basket_station_day_settlement_label` 的最新修订；
- 均值与标准差：在信封 `bucket_intervals_c_json` 经 `served_bucket_axis` 得到的轴上算。

距结算 h 用生产 `hours_to_settlement`。事件日从 2026-08-15（标签起点）起。

### H1 尾桶做空，只在点差吃不掉时做（γ 的可执行部分）

- **规则**：对 h>36 的 P0 fact，逐站日按时间顺序、逐桶取首次满足以下三条的时刻，以吃单价买 NO：
  - p_k ≤ 0.01；
  - YES 买一 bid_k ≥ 0.02；
  - p_k ≤ bid_k / 2。
- **成交价**：NO 卖一 = 1 − bid_k。每份盈亏 = bid_k − y_k，成本 = 1 − bid_k。
- 每个（站日，桶）只做一次。
- **成立**：ROI 的 95% 区间下界 >0，且前后两半（按事件日对半）ROI 都 >0。
- **只报不判**：
  - 阈值网格：bid ≥ {0.01, 0.02, 0.03, 0.05} × p ≤ {bid/2, bid/3}；
  - 按 h 分档；
  - 只取站日首决策的版本；
  - 买一挂量；
  - **纯市场版**：不看模型，只要 q_k ≤ 0.05、离市场众数 ≥3 档、bid_k ≥ 0.02 就做。用来看模型比「市场自校准」多带来多少。

### H2 中心一致日的宽度差（绕开中心劣势）

- **条件**：h>36 的 P0 fact 上同时满足：
  - |模型均值 − 市场均值| < 0.3°C；
  - 模型标准差 < 0.9 × 市场标准差。
- **下注**：每个站日取首次满足条件的 fact，按 Proper 线的方向吃单：
  - p_k > ask_k 的桶，按卖一买 YES；
  - p_k < bid_k 的桶，按 NO 卖一 1 − bid_k 买 NO；
  - 份数取 |ln(p_k/q_k)|，即 Proper 线的形状。
- **成立**：ROI 的 95% 区间下界 >0，且前后两半都 >0。
- **只报不判**：
  - 同样的腿放在每站日首个 h>36 fact 上（不加条件），作对照；
  - YES 腿、NO 腿分开报；
  - 每腿 1 份的版本。

### H3 新 run 到货后，市场会不会跟着模型走（时间差优势）

- **事件**：同站日相邻两个 P0 fact 的信封不同，且模型均值变动 |Δp| ≥ 0.5°C，事件时刻 h>12。
- **读数**：市场均值在事件后 H＝3、6、12 小时的变动 Δq_H。取事件时刻之后、t+H 之前最后一张已提交快照；缺快照的事件计数剔除。
- **回归**：Δq_H = a + β1·Δp + β2·(事件前模型均值 − 事件时市场均值) + ε。
- **成立**：H＝6 时 β1 的 95% 区间 >0，且前后两半的 β1 都 >0。
  - 这表示市场会滞后跟进模型的更新，差异来自时间。相应的做法是「到货即进、市场跟上即出」，不持有到结算。
- **只报不判**：H＝3、12 的 β1；Δq 与 Δp 同号的比例（剔除 |Δq|<0.1°C）。
