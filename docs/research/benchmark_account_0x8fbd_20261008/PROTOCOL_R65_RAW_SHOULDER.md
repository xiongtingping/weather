# 第 65 轮事前协议：原始确定性模型里的肩部方向信息（2026-10-16，熊先生「我不认同，既然缺分辨率，那原始模型肯定带有信息，继续打继续找！」）

第 64 轮只看了每家「挂牌时最新一轮的日最高」一个数及其中位数。本轮把原始确定性数据里**其余的量**全部摊开，问：在 F 的桶位置之外，它们能不能判对真值落在 F 哪一侧。读数前提交，读数后不改。

## 样本

舰队站日，事件日 09-12..10-14（原生 GFS/HRES/AIGFS 历史起点允许的范围）、已结算；挂牌时刻 L＝生产 `listing_instant`（D−2 05:00Z）；
参照桶 fb＝`listing_forecast_f.compute(now=L)` 的 `f_c` 所在桶（真值只读到 L 日期 −2），READY 才进；梯子取 gamma。
目标行＝**真值不在 fb 的行**（主读肩部 |y−fb|＝1，另报全部离开行）；标签＝真值在 fb 上方（暖）或下方（冷）。

## 候选特征组（全部只用 L 时可知的原始确定性运行，`regional_point_lane.runs_for(as_of=L)`，与生产同一读口）

- **G1 轮次改动**：F 六家每家「最新一轮 − 上一轮」「最新一轮 − 两轮前」对同一事件日的日最高；组特征＝各家改动的中位数、升温家数−降温家数。
- **G2 成员结构**：六家各加自身站修正（`bias_c`）后：均值−中位数（偏度）、标准差、最高−F、最低−F、按站历史 MAE 倒数加权均值−F（权重只用 L 前已结算日）。
- **G3 曲线形状**：各家逐时曲线的峰值时刻（当地小时）、抛物线插值峰值−采样峰值（漏峰量）、日较差（日内最高−最低）、峰值后一步降幅（峰尖还是平台），取各家中位数。
- **G4 日际趋势**：同一轮对事件日与前一日日最高之差（升温/降温中的日子），各家中位数。
- **G5 近期误差**：每家在该站最近一个已结算日（≤ L 日期 −2）按挂牌时刻读到的预报误差（真值−预报），减去其站修正（＝近期异常），取中位数；再报最近 3 日均值版。
- **G6 F 外确定性家族**：库里已采集、不进 F 的确定性产品（ARPEGE、UKMO 原生/转发、IFS 9km 转发、CMA、ICON-EU、MSM、HRRR、NBM、GFS 逐时/13km 通量）——每家加自身站偏差（只用 L 前已结算日，≥5 日）后减 F，取中位数与家数。转发产品为 `aggregator_republisher`，**只作研究**，库里已有、不新花额度。

## 打分

- **单特征（原始自身有没有方向）**：sign(特征) 判侧的准确率（肩部行），按事件日整块自助 95% 区间，对照 50%。
- **增量（在 F 位置之外有没有）**：基线＝逻辑回归 side ~ F 桶内位置 (F−中心)/桶宽；每组＝基线＋该组特征；按事件日前推（≥7 个更早事件日训练，L2＝1）；
  在肩部行上报前推判侧 LogLoss 与准确率，及对基线的成对差（事件日整块自助）。全部组合并一臂。
- 6 组 BH 校正（q＝0.10，按 ΔLogLoss 的单侧自助 p）。**「原始模型带有方向信息」成立＝至少一组在增量检验下过 BH 且前后两半同号。**
