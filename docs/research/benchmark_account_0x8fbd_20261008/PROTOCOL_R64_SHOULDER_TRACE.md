# 第 64 轮事前定义：肩部信息在哪一步丢的（2026-10-16，熊先生「目前核心问题是肩部概率分配的问题吗？从原始模型到校准后逐步排查，看哪一步把信息丢了！挂牌前预算的确定性六家中位数加站修正在肩部能判对多少」）

诊断，不是上线检验；定义写在读数之前，读数后不改。

## 样本

舰队全部站日（不限簇交易过的），事件日 09-28..10-14、结算真值已落（最新修订）；挂牌时刻 L＝gamma 各桶最早 `acceptingOrdersTimestamp`。
参照桶 fb＝**挂牌前预算的生产 F**（`listing_forecast_f.compute(now=L)` 的 `f_c`，真值只读到 L 日期 −2）所在桶，READY 才进样本。

## 逐层（同一个参照桶 fb 上回答「真值在 F 的哪一侧」）

确定性线（点值，时刻 L）：
- D0 六家各自原始最高温（AIFS 单成员 / IFS HRES / GFS / AIGFS / GDPS / ICON 全球）；D0c 各家加自己的站修正 `bias_c`
- D1 六家原始中位数 → D2 ＋全队平移 c → D3 ＋λ×站修正（`f_base_c`）→ D4 ＋条件重校准（`f_c`＝生产 F）
- D5 补记六站点值 F_v3（`v3.f_c`）与 D5r（`v3.f_recal_c`）

集合与服务线（分布，时刻 T＝L+6h 与 L+24h）：
- E0 六家原生集合成员原始频率（家间等权，不改中心）
- E1 ENS@F：E0 按桶内均匀平移使中位数落在 F
- P0 生产服务向量（P1>P0-M>P0，≤T 最新 COMMITTED；挂牌头两天即 P0）。P0 中间层（单系统校准、融合池、宽度、尾混、压顶）的信封已被冷归档清空，**只能读最终向量**，中间层不在本轮可测范围内。
- MK 市场：≤T 最近一份官方 WS 快照、报价 ≤1h 内，各桶 (买一+卖一)/2 归一；缺任一桶则缺。

## 指标

真值相对 fb 分三类：落 F（y＝fb）、肩部（|y−fb|＝1）、远端（≥2）。主读**肩部行**：
- **判侧准确率**：点值层 sign(x − fb 中心)；分布层 sign(P(>fb) − P(<fb))；另报只看相邻两档 sign(p(fb+1) − p(fb−1))。与真值一侧比对；按事件日整块自助 95% 区间；相邻层之间做成对差（同一批行）。
- **肩部分配分数**（分布层）：s＝p(真值那一档)/(p(fb−1)+p(fb+1))，报 mean(−ln s)，对照 ln2＝0.693（五五开）。
- 辅报：各层自己的众数桶命中、±1 覆盖；分布层整条梯子 LogScore（1e-3 下限）；三类行的占比。

「哪一步丢了信息」＝判侧准确率或肩部分配分数在某一步显著变差（成对区间不含 0）；若各层都接近 50% 而市场明显更高，则信息不在我们的输入里，而不是被校准丢掉。
