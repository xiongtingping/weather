# 第 64 轮事前定义：肩部信息在哪一步丢的（2026-10-16，熊先生「目前核心问题是肩部概率分配的问题吗？从原始模型到校准后逐步排查，看哪一步把信息丢了！挂牌前预算的确定性六家中位数加站修正在肩部能判对多少」）

诊断，不是上线检验；定义写在读数之前，读数后不改。

## 样本

舰队全部站日（不限簇交易过的），事件日 09-28..10-14、结算真值已落（最新修订）；挂牌时刻 L＝gamma 各桶最早 `acceptingOrdersTimestamp`。
参照桶 fb＝**挂牌前预算的生产 F**（`listing_forecast_f.compute(now=L)` 的 `f_c`，真值只读到 L 日期 −2）所在桶，READY 才进样本。

## 逐层（同一个参照桶 fb 上回答「真值在 F 的哪一侧」）

确定性线（点值，时刻 L）：
- D0 六家各自原始最高温（AIFS 单成员 / IFS HRES / GFS / AIGFS / GDPS / ICON 全球）；D0c 各家加自己的站修正 `bias_c`
- D1 六家原始中位数 → D2 ＋全队平移 c → D3 ＋λ×站修正（`f_base_c`）→ D4 ＋条件重校准（`f_c`＝生产 F）
- D5 补记六站点值 F_v3（`v3.f_c`）与 D5r（`v3.f_recal_c`）

**修订（读数前，熊先生「不是 p0，是确定性模型」）**：本轮只查确定性线，集合、P0、市场层全部删除。确定性线另加两层：
- DV 票数：六家各加自身站修正后整体平移使中位数落在 F，落 fb 以上家数 − 以下家数（分布层的「肩部质量」由票数给出）
- DP F 在桶内位置：F − fb 中心（与 D4 判侧等价，单列是为报不同死区）

两种视角：①**共同参照**——全部层都对挂牌前生产 F 的桶 fb 判侧；②**各层自身**——每层自己的点值落桶 b_s，判 b_s 命中率、±1 覆盖、真值在 b_s 肩部时按 x_s 在 b_s 内的位置判侧的准确率。

## 指标

真值相对 fb 分三类：落 F（y＝fb）、肩部（|y−fb|＝1）、远端（≥2）。主读**肩部行**：
- **判侧准确率**：点值层 sign(x − fb 中心)；票数层 sign(上方票 − 下方票)。与真值一侧比对；按事件日整块自助 95% 区间；相邻层之间做成对差（同一批行）。
- **肩部分配分数**（票数层）：s＝(真值那侧票数+0.5)/(两侧票数+1)，报 mean(−ln s)，对照 ln2＝0.693（五五开）。
- 另报按 |x−fb 中心| 分档（离桶中心越远越应判得准）的判侧准确率；三类行的占比。

「哪一步丢了信息」＝判侧准确率或肩部分配分数在某一步显著变差（成对区间不含 0）；若原始各家就接近 50%，则信息不在确定性输入里，而不是被校准丢掉。
