# 对标簇策略全景报告（截至 2026-10-11）

对象：Polymarket 天气温度市场上的 8 钱包机器人簇（主号 `0x8fbd7cf5…a959`）。本报告汇总 10-08 至 10-11 的 36 轮拆解、另一会话的相关研究、已落地的宪章条款与实盘读数。每条结论都标明状态与出处；轮次指本目录 `README.md` 的章节，脚本在 `scripts/`，输出为同名 `.out`。

**状态口径**
- **已证实**：多轮、多口径一致，或有会计核对、或有独立复现，或按事前协议前推通过。
- **前推在跑**：样本内成立，前推窗口已登记，给出复读日。
- **有冲突**：不同口径读数相反，未定。
- **已否定**：按预设判据不成立，不再重做。
- **已更正**：本报告或 README 先前的说法被后来的核对推翻，附更正出处。

## 0. 一页结论

1. **对象是一个机器人簇**：8 个钱包，同桶同边 ±5 分钟重合 57–95%，节拍相同、分工明确。16 天买入约 45.5 万 U，已结算净赚约 5.7 万 U（约 +15%）。10-06 起交易量降到高峰的约三分之一（第 26 轮）。
2. **核心盈利结构（第 32–36 轮新结论）**：
   - **先有预报，后有众数**：所有市场在事件日前两天、UTC 04 点多挂牌；梯子中位要到挂牌后 3.5 小时才形成众数。约一半站日的第一笔下在这之前（UTC 05 点前后），那时还没有「市场众数」可参考。
   - **第一笔买什么**：YES 买在「十家确定性全球模式的中心值 + 全站统一暖校准约 +0.8°C（再加约三成站点偏差）」所落的桶，按「最可能中」选、不挑便宜。前推精确约 45%、上下一档约九成。NO 打离中心不远、标价偏高的肩档（多在冷侧两档），不是最不可能的桶。出价随模式票数集中而升（0 票付 0.24 → 七成票付 0.44），每一档都是命中高于价格。
   - **赚在成交价**：同一批站日同一口径，簇市场成形前的第一笔 YES 每股 +7.3 分，我们照抄（预报桶、按我方快照卖一）−8.1 分；差的 15.4 分里**价格占 12 分、命中只占 3 个点**。同一个桶簇付 0.398，我方快照卖一 0.506。
   - **众数随后围绕预报形成，但之后自己走**：成形时众数约一半在 F、三成在 F+1；簇早买的桶不是 F 时，众数六成形成在簇的桶上（部分是它自己的成交推出来的）。之后众数不再向 F 靠，随新信息更新，最终比 F 准（0.50 对 0.37）。
3. **后续加仓与离众数腿**：延续自己已持的腿、逆着一小时价格买（刚便宜的买、刚贵的空）；离众数方向的可观测部分约等于「ECMWF 家族最新一轮改动、市场还没跟上」，市场约 12 小时吸收完，已进宪章 265 兑现层；约四分之一来源未知。
4. **其他收入**：挂单深折价与流动性奖励（大半被逆选吃掉）、完整集套利（约成交量 7%）、YES→NO 合并锁利、0.998 回收高周转。
5. **能还原到什么程度**：选桶范围 94–98%；第一笔 YES 的确切那一档约 45%；后续加仓确切那一腿积分表 33%（前三 73%），黑箱上限 45%（前三 82%）。剩下的取决于它比公开模式更好的预报、它的持仓历史与分钟级时点。
6. **我们能用的路**：
   - 跟单（在役，宪章 257/266）；
   - 动量等方向分量（前推在跑，10-13 复读、10-27 裁）；
   - **新线索：挂牌后头两小时在预报桶挂低价 YES 买单**（第 34 轮主检验刚过线，挂 0.35 +21.7% [+0.1, +43.8]，挂 0.25 +62%），属「前向样本该跑」，开前向影子线需裁；
   - 当天实况与预报之差：市场反应不足（10 点只计入约 83%），但单桶优势 1–1.5 分小于吃单半价差（第 30 轮）。
7. **今天的两处重大更正**：第 33 轮「挂牌照抄显著为负、补齐不会翻」收回——错在把我方快照卖一当成交价；第 29.2 轮「当天实况约九成已进价、剩下不够下注」收回——第 30 轮按协议证实市场反应不足。

| 规则 | 前推精确 | ±1 档 |
|---|---|---|
| 原始十家中位数 + 0.8°C + 0.3×站偏差（第 33 轮公式） | **45.4%** | 约 87% |
| 去头尾均值 + 0.8 | 42.6% | 85% |
| 第 75 百分位 | 42.6% | 92% |
| 多数票桶（平局取暖） | 41.8% | 83% |
| 十家加权（研究集拟） | 44.7% | — |
| 校准分布概率最高的桶 | 47.5% | — |
| 我方修正桶 F（按站偏差，只用 d−2 以前） | 36% | 87% |

- 相对我方修正桶 F：落 F 36–38%、F+1 33–36%、两者合计 69–74%。
- **为什么是上一档**＝偏差校准：它对所有站统一加约 +0.8°C（同批站日原始中位数的全队冷偏差 +0.83°C），站自身偏差只用三成；我方按站修正在历史短的站修得少。我方修正量越小它越往上（k=+2 组 −0.12°C、+1 组 +0.29、0 组 +0.57、−1 组 +0.88）。不是季节、站点、单位，也不是抄某一家。它往上挪是对的：选上一档时真值落上一档 45%、落 F 39%。
- **选法**：F−1/F/F+1 里选最可能中的（43%），不挑最便宜（15%）、不挑最大优势（31%）。
- **还原不了的约 55%**：统计量、加权怎么换上限都在 45–48%；它偏离我们复现的桶时更常对——是更好的预报信息，不是结构规则。

**NO**：约四成第一笔是 NO，相对 F 散开、偏冷侧（−3..−1 共 53%）；三档中最不可能那一档仅 18%，被空桶在 11 档信念里平均第 3.5 位——空的是离中心不远、标价偏高的肩档。均价 0.738、实际该桶没中 0.899。

**边（YES 还是 NO）**：没有两段同向的决定条件；挂牌 30 分钟内与 F 站更偏 YES。用十家重建的任何信念（套正态或票数）比较两边优势，选边准确率约 50%（第 35.3–35.4 轮）。

**市场成形后才下的第一笔**：没有可写死的规则——任何中心对上 19–28%；范围（众数 ±2、YES 0.03–0.65、NO 0.25–0.90）覆盖 96–98%，积分表首选 26%。

**众数与预报的先后**（第 36 轮，440 个站日）：梯子成形中位挂牌后 3.5 小时（p10 1.25 h、p90 8.25 h）；成形时众数＝F 45–52%、F+1 23–30%、F−1 6–13%；簇早买的桶 X≠F 时，首次成形众数＝X 61%、＝F 25%；首次成形众数≠F 的站日到事件日 06 点只有 23% 走到 F，众数换桶朝 F 49.1%（随机）；众数命中真值 0.47→0.50，F 0.37–0.42。

**白话例子**：某站十家模式日最高温 17.1–19.0°C，中位 17.95；站偏差 +0.3 乘三成 +0.09；17.95+0.8+0.09＝18.84，落 19°C 档。挂牌后半小时内主号大约一半的机会正好吃单买 19°C YES，九成落在 18–20°C。就算 19°C 卖 0.48、18°C 卖 0.30，它照买 19°C。做空则多挑 17°C 这种「有点可能、标价偏贵」的桶。

### 4.2 后续加仓与离众数腿（第 14、24、31 轮）
- **范围**：众数 ±2 档、YES 价 0.05–0.60、NO 价 0.25–0.85，覆盖 94%，候选 18→6。离众数 ≥3 档从不碰（第 14、31 轮）。
- **96% 的首笔吃单事件发生在已持该站日腿之后**：选桶主要是在已有的腿里挑哪条再加——刚变便宜的、或上一笔那条（顺序条款前推首选 33.5%）。
- **众数桶选 YES/NO**（前推准确 63–65%）：已持 NO→NO 0.85/0.79；已持 YES 且众数刚跌→YES 74%/84%；众数刚涨 >1 分→NO 0.75/0.63。众数价位 ≥0.55 就做空，前推消失。
- **选众数是结构动作**（第 24 轮）：抄刚跌的众数、空刚冲高或被捧高的众数、实况进桶后买；与动量无关。
- **同格同价**：被选的桶命中 0.303、+17.3%；同格未选 0.224、−15.4%，价一样（第 14 轮）。
- **逆势**（第 27 轮）：拿的腿成交前一小时在变便宜（离众数 YES −1.05 分，没拿的 +0.18），处在一小时区间低位。

- **成交价（重要）**：我方 WS 快照卖一**不是**可成交价——挂牌段高估约 3–11 分，成形后约 1 分；比较簇与照抄的盈亏必须同站日、同口径拆成「命中差 × 价格差」，结论对执行价敏感时给价格敏感性（−3/−6 分），不说「显著」。
- **挂单成交推断**：第 34 轮用公开成交带的保守口径（窗口内有成交严格低于我方挂价才算成交），未模拟排队与成交量；要求 ≥5 股时读数明显变弱。
- **CLOB `prices-history`**：交易所显示价——价差大时是最后成交价，挂牌初段单边盘口不能当中价；簇自己的成交会把那一档推成「众数」（第 36 轮的机械成分）。
- **快照表两种写法**：带持仓字段（`active_before`/`pending_shares`）的行不写 `best_ask` 与 `book_observed_at`，不是建簿问题。
- **数据源**：Open-Meteo（含单轮历史 single-runs）是 `aggregator_republisher`，只作研究；单轮接口每日 1 万次额度，多模式请求按多次计，并发 ≤3、撞限即停。生产按宪章 266 显式例外只用于跟单线执行选择，不进 P0/P0-M/P1。
- **对象可能变**：一切跟单收益依赖 8 个公开钱包继续以现在的方式交易；交易量已降到约三分之一。
- **单站数值**：每站只有约 14 个站日，单站排名只作描述。
