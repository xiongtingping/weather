## 第二轮（10-08 下午）：吃单那刻的信息源对齐

**问题**：吃单成交前后 ≤15 分钟中价跳 +4.7 分且不回吐，这信息从哪来？逐项对齐公开数据到达时刻（`scripts/align.py`、`test_*.py`、`station_sources.py`、`fetch_minute.py`）。

### 1 分钟中价轨迹（抽样 701 笔吃单，`fetch_minute.py`，CLOB `prices-history?startTs&endTs&fidelity=1`）
