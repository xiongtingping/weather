## 第八轮（10-09 上午）：（1）他们的确信度能否用市场量近似；（2）我方 p 对市场按分歧分层有没有边

### 8.1 规模 → 市场可观测量（`enrich_events.py` 给 10,247 个簇事件在首笔时刻补盘口；OLS 为内联）
- 有健康盘口、中价与真值的 2,975 个事件：log(事件金额) 对 13 个市场量回归，**R² = 0.158**。系数方向：本侧中价越高越大（+0.95，即 NO 众数桶的腿更大）、点差越窄越大（−7.4/单位点差）、提前量越长越大（+0.40/天）、YES 腿更小（−0.92）、F 站更大（+0.24）、我方 p − 中价 +0.31（弱）。
- 全部 8,074 个有中价与真值的事件用简化特征（中价、中价²、提前量、YES、F、首笔吃单）：R² = 0.272。
- **边不随「可预测规模」单调**：五分位信息（命中 − 成交前中价）−5.0 / +6.5 / −0.9 / −1.1 / +9.9 分（全特征）；−7.1～+8.0 分来回翻（简化特征）。**按残差规模分组也不单调**：−1.3 / +1.1 / +2.7 / 0.0 / +4.4 分。
- 他们的规模与我方 p − 中价三分位的关系：我方 p 远低于中价时他们反而下得最重（中位 17 U 对 10 U），那组回报 +8.6%、信息 +0.7 分；我方 p 高于中价组回报 +12.8%、信息 +4.3 分。
- **读数**：市场量只解释他们规模的两三成，可解释部分不带稳定的边，残差部分也不是边的干净载体。他们的确信度来自我们看不到的量，无法用盘口近似成一条规模规则。

### 8.2 我方 p 对市场按分歧分层（20,303 条桶腿，三时刻，内联）
- **YES 在卖一**：按（我方 p − 卖一）分七档，D-1 12:00 / D0 02:00 / D0 08:00 没有一档两半同为正；p − 卖一 > +0.20 那档 +11.3%（H1 −7.6 / H2 +71.3）、−24.1%（−27.6 / −17.2）、+0.3%（−4.6 / +12.0）。我方越自信于市场，命中并不随之提高（p 0.44～0.46 的桶实际命中 0.13～0.19）。
- **YES 在中价（挂单成交价）**：同样无稳定正档；最好的是 D0 08:00 >+0.20 档 +7.9%（H1 +6.9 / H2 +9.7，n=235），但 D0 02:00 同档 −6.8%。
- **NO 在 1 − 买一**：按（买一 − 我方 p）分档，只有「> +0.20 且在市场众数桶」在 D0 两个时刻两半为正：D0 02:00 +14.2%（H1 +13.1 / H2 +16.2，n=215），D0 08:00 +8.7%（+5.5 / +13.3，n=208）。**按周看 +12 / +20 / −10 / −2 / +57，33 个日期里 16 个为正，逐日中位 −4%**：均值由 10-04 那周的几天拉起，不是稳定规则（与第四轮 gap>0.2 规则是同一条）。
- 逐腿 Brier：我方 p 0.111 / 0.129 / 0.133，市场中价 0.1005 / 0.117 / 0.120，五五混合 0.103 / 0.120 / 0.123。**任何比例掺入我方 p 都比纯市场差。**
- **读数**：分歧分层找不到我方 p 对市场的正边；Proper 线没有可用的「确信度」来配规模。

### 8.3 对第七轮下一步两问的回答
1. 他们的规模规则不可用市场量复刻。2. 我方 p 没有分层后的正边，确信度定注没有可配的量。两条都结案。

## 第九轮（10-09 中午）：倒推法——从行为反推他们心里的 p

熊先生指示：不拿我方 p 当尺，用倒推。把簇在每个站日的一段连续买入（间隔 >6h 切段）与段首时刻的完整市场梯子对齐（`enrich_sd.py`，593 段、433 站日，526 段有真值），用四种方法反推其信念并对真值打分。

### 9.1 市场变形法（`inverse_deform.py`）
假设其信念 = 市场分布做幅宽变形 λ 与平移 s，以「其下注资金中有多大份额在该信念下为正边」为目标拟 (λ, s)：
- 最优解只能让 56%～63% 的资金显得有正边（以市场本身为信念是 18%～41%）；且拟出的变形对真值打分远差于市场（LogS 1.72 对 1.29），交叉验证两折参数反号（λ 1.5/−0.9 对 0.5/+0.9）。
- **他们的下注不是市场分布的任何变形。**

### 9.2 凯利反解（`inverse_kelly.py`，1,201 条腿、95.8k U）
按 f = (p − 价)/(1 − 价) 用价与量反解 p：拟出的 1/本金 ≈ 0.0005（约 2,000 U），两折外推 logloss 仅从 0.577 降到 0.573；按量反解的 p 分十档，实际命中 0.34～0.56 与反解值 0.41～0.89 完全不成比例。**他们的量不是按凯利对一个已校准边配的**，只有最大一档（USDC 加权命中 − 价 +0.118）带边。

### 9.3 倾斜法（信念 = 市场中价在他们买过的桶上 ±δ）
全部 526 段：δ* = 0——**往他们买的桶倾斜任何一分都让梯子预报变差**（H1→H2、H2→H1 两折皆然；均匀与按资金加权皆然；只倾斜最大 YES 桶亦然）。按段规模分三组：小、中两组 δ* = 0；**大段且只倾斜 YES 桶：δ* = 0.10，两折外推 LogS −0.017（n=142）与 −0.006（n=34）**。按提前量分组无增益。
- 市场中价对真值 LogS 1.149～1.340，我方服务 1.313～1.449；他们的「隐含信念」在小中段 = 市场，在大段 = 市场 + 对其大额 YES 桶约 0.1 的倾斜。

### 9.4 隐含中心法
其 YES 份额加权中心 − 市场均值：均值 +0.13 桶（偏暖），与（真值 − 市场均值）相关 +0.25；但两者都 >0.3 桶时符号一致率 **0.51**；相关几乎全由 ≥36h 的 44 段贡献（0.70），<12h 为 0.06。

### 9.5 倒推的合成读数
四种倒推指向同一处：**他们的 p ≈ 市场**。他们的买入作为一个整体并不比当刻市场更知道哪个桶会中；唯一超出市场的成分是大额段里的 YES 桶约 0.1 的倾斜（第七轮事件级 +5～10 分的另一种表述）。而他们对价赢钱（命中 > 成交价 5 分）与此并不矛盾：
- 成交前的中价是陈旧的（薄盘口、挂单不更新），他们吃掉陈旧卖一后中价跳 4～5 分并停住，**结算命中 ≈ 跳后中价**（无跟买事件：差 0.1 分）；
- 即他们知道的不是「天气」，是「当前报价相对公允价陈旧了多少」，每小时整点与 METAR 到达后重算一次公允价、扫掉低于公允的卖单。这解释了为什么各种公开数据到达时刻都对不上（他们对的是价格而不是数据），也解释了为什么我方 p 在他们买的桶上是反指标（我方 p 比陈旧报价更陈旧）。
- 我方「p − 卖一 > 0.10 买 YES」为负，说明我方公允价识别不出陈旧卖一；市场跳后的中价能。

### 9.6 还能倒推的
- 报价陈旧度直接量：用我方盘口快照看他们吃掉的卖一在成交前已挂了多久、期间别的桶中价动了多少（陈旧卖单 vs 新鲜卖单），对照未被他们吃的卖一。
- 挂单侧倒推：其 NO 挂单深埋的折价随什么变（提前量、集中度、点差），即他们要求的边际。
- 退出侧倒推：买 NO 退出时的隐含上界 1 − NO 价 对最终命中的校准（第六轮：退出比持有略好 0.045/股）。

### 9.7 补做的三个倒推（10-09 下午，`staleness.py` 与内联）
- **报价陈旧度**（700 笔簇吃单抽样，对照同桶 2～5 小时前的随机时刻）：他们吃掉的那一档**更新鲜**而不是更陈旧——档位上次变动距成交中位 6 分钟（对照 24 分钟），挂了 >60 分钟的只占 16%（对照 30%）；上次变动方向上/下 0.51/0.49 与对照相同；整个梯子最近一次任何变动都在几分钟内（两组皆 92%/89% ≤10 分钟）。**「捞陈旧卖单」假设不成立**：他们吃的是刚刷新过的报价，判断的是新报价相对公允价是否便宜。
- **挂单侧倒推**（主账号 2,168 笔挂单成交）：YES 挂单要求的折价≈1 个点差（中价的 7%），NO 挂单≈2.4 个点差（中价的 15%，6～11 分）；NO 挂单成交后实际命中普遍低于中价（D0 当日 −13 分、暖侧邻桶 −14 分、点差 >0.04 时 −7 分），即折价大致等于被逆选的量；YES 挂单在冷邻桶、D0 0～12h 反而高于中价 +8～11 分。
- **退出侧倒推**（576 个用 NO 合并退出的 YES 仓位）：退出时接受的 NO 价给出其信念上界 1 − NO 价。上界 <0.5 的三档，被退出的 YES 实际只中 0.13 / 0.20 / 0.40（上界 0.26 / 0.36 / 0.45）：**退出决策带 6～15 分的信息**；吃单退出（主动）ub 0.439 对实际 0.349（+9 分），挂单退出中性。上界 ≥0.5 的两档略早（−6 / −4 分）。

### 11.3 方法论回答：LogScore 换二元 LogLoss，或加第二层
- 整条梯子的多类 LogScore 与逐桶二元 LogLoss 都是 proper score；前者评价整个分布一次到位，后者是各桶边际的 one-vs-rest 分解。把训练目标从 LogScore 换成逐桶二元 LogLoss，不会改变模型该学什么，只会把权重挪向远离真值的桶的边际（与 09-25「训练目标改 Brier 修不了 RMSE」同理）；**不建议换**。
- **加第二层——只对实际买入（或规则选中）的桶算二元 LogLoss、对照市场中价——建议做，但只做评价层，不做训练目标**：它直接回答「我下注的地方我是否比市场准」，等价于宪章 254 兑现层 b=P(Y|p,q) 的车道切片；用它做训练目标会循环（选择依赖模型）。两条纪律：一是永远与同一批腿上的市场中价成对比较（选择偏差对两边同时作用），二是只认前推样本。按这一层，今天的读数是：我方 p 在自己下注处比市场差 0.10 nat；在跟单过滤后的腿上（他们出手且我方同意）我方 p 与市场持平或略好。

## 第十三轮（10-09，熊先生：「对标账号的 logloss 和我系统实现的 logscore 有什么区别」）

## 第三十轮（10-11，熊先生「我不认可你的说法，实况云雨辐射等，市场并不一定完全在价格上」）——事前协议（打分前提交）

29.2 的「约九成已进价」是三等分平均，可能把大意外稀释掉；也只看了真值，没看市场之后是否继续往同方向挪（滞后＝当时没完全进价）。本轮正面检验「市场是否完全计入当天实况云雨辐射」。

**数据**：08-15..10-10 已结算站日（最新真值修订）；每站日整条梯子每个桶的 CLOB `prices-history`（5 分钟，当地 04–22 点；09-21 起 token 取 SSOT 登记表，之前取 gamma 事件）；报文取 archive；Open-Meteo previous-runs `*_previous_day1` 逐小时气温/总云量/短波/降水；卫星短波 34 站（aggregator，仅研究）。

**定义**：
- 梯子按下界排序得序号 k；单位一律「档」（C 站 1°C、F 站 2°F）。
- 时刻 τ 的市场：每桶取 τ 及之前 90 分钟内最后一个价，全部桶都要有、原始价和在 [0.8, 1.3]，归一得 q；市场均值 M(τ)=Σk·q_k；真值序号 y。
- 预报：前一日轮当地日逐小时最高 fc_max；站偏差 β＝该站 d−2 及以前各日 (真值−fc_max) 的均值（≥5 天，否则用全队同期均值）。
- 信号（当地 06 点到 τ，偏暖为正）：temp＝τ 前最后一份报文气温−同小时预报；cloud＝预报总云量−报文云量的均值；rain＝预报湿小时−报文降水小时；rad＝07..τ 卫星短波和/预报短波和−1（34 站，缺则记 0 加缺失指示）。
- 物理位移 Ŝ(τ)：按日前推（训练只用 d−2 及以前、≥10 个训练日）OLS 拟 (真值−fc_max−β) ~ [temp, cloud, rain, rad, rad缺失]，换成档 Ŝ_ord＝Ŝ/档宽。

**主检验（4 个，Bonferroni，98.75% 日聚类自助区间，2000 次）**：
- P1 真值：τ=10、12 点，(y−M(τ)) 对 Ŝ_ord(τ) 的斜率；**通过＝区间不含 0，且按日前推（a+b·Ŝ 只用 d−2 以前拟）的平方误差改进 95% 区间在 0 以下**。斜率>0＝市场对实况反应不足。
- P2 市场滞后：τ=10、12 点，(M(τ+2h)−M(τ)) 对 Ŝ_ord(τ) 的斜率；**通过＝区间不含 0**（>0＝之后继续往物理方向挪＝当时没完全进价；<0＝过度反应后回吐）。

**次级（只描述，不作裁决）**：四个原始信号分别、Ŝ 十等分与两端各 10%、09–14 逐时、仅卫星站、C/F 分开、控制 (fc 序号−M) 的多元回归；交易回测——τ=10/12 点 |前推预测 y−M|≥0.25 档时把市场 CDF 平移该档数得 p′，买 p′−q 最大且 p′≥原始价+c+0.02 的那个桶的 YES 一份持有到结算，成本 c=1¢、2¢，报回报率与日聚类区间。

**裁决**：P1 或 P2 在 10/12 点任一通过 → 市场对当天实况确实没有完全计入，下一步做交易车道研究（本轮不改生产）；全不通过 → 维持 29.2。

## 第三十一轮（10-11，熊先生「簇对标在什么条件下选众数yes，什么时侯选no？有确定性结论吗」「和选择其他桶一起联合分析。我要选桶的确定性规则」）

数据：第 25–26 轮的 2,103 个首笔吃单事件（研究 1,491 到 10-07、前推 612 为 10-08..10-12），每事件约 18 个有价候选腿（桶×YES/NO）。规则一律只在研究集上定，在前推集上读。

### 31.1 众数桶上选 YES 还是 NO（`mode_side.py`，输出 `mode_side.out`）
首笔腿型：离众数 YES 48%、离众数 NO 20%、众数 NO 19%/14%、众数 YES 13%/18%（研究/前推）。打众数桶时 NO 占 59%/43%。两半同向的条件（NO 占比，研究 | 前推）：
- **自己在这个桶上已持有哪边就继续哪边**：已持 NO → NO 0.85 | 0.79；已持 YES → NO 0.42 | 0.36（即 YES 六成左右）。
- **反着这一小时的价走**：众数 YES 一小时内跌 >1 分 → NO 0.38 | 0.21（买 YES）；涨 >1 分 → NO 0.75 | 0.63。
- 两条合起来：已持 YES 且刚跌 → YES 74% | 84%；已持 NO 且刚涨 → NO 92% | 83%；已持 YES 但刚涨 → NO 65% | 60%。
- D0：实况最高温还在众数下方且众数刚涨 → NO 81% | 74%；实况已进众数 → 多买 YES（样本小）。
- 不稳定的：众数价位 q≥0.55 → NO 0.71 | 0.43（前推消失）；领先第二档、我方 p、金额都不稳。
- 规则准确率：最好的单条「已持 NO 才买 NO」前推 65.4%、「众数刚涨就买 NO」64.4%；两层树 研究 72.8% → 前推 62.8%（前推全买 YES 为 56.5%）。
- NO 首笔里一半（50% | 53%）落在自己已持 YES 的同一桶（锁利/合并退出）；新开 NO 落在众数 40%/27%、众数 −1 32%/34%、+1 18%/26%。

### 31.2 所有桶联合的选桶规则（`bucket_rules.py`，输出 `bucket_rules.out`）
- **第一层·范围（确定）**：只在市场众数 ±2 档内（覆盖 98.8% | 100%）；再加 YES 价 0.05–0.60、NO 价 0.25–0.85 → 覆盖 94.2% | 93.6%，每事件候选从 18 条缩到约 6 条。
- **第二层·积分表**（条件 logit 定权后取整，挑分最高）：+2 YES 价 0.10–0.50、+2 NO 价 0.30–0.75、+2 同一条腿已持有、+2 D0 实况已在本桶、+4 D0 实况已超过本桶（该桶 NO 必赢）、+1 众数下一档的 YES/NO、+1 这一小时变便宜 >1 分；−1 众数 YES、−1 众数 NO、−1 离众数两档的 YES、−1 已持同桶另一边、−2 腿与自己已有倾向相反。前推首选 33.0%、前三 72.7%（范围内随机 16.9%；第 26 轮 LightGBM 全特征 38.4%/76.8%）；首名与次名分差 ≥3 时首选 46.4%。
- **同一规则写成顺序条款**：R2 已持的腿里有这一小时变便宜 >1 分的 → 加仓变便宜最多的那条（触发 42% | 53%，对 32% | 39%）；R3 否则 → 再买上一笔那条腿（51% | 36%，对 31% | 30%）；R4 新站日 → 两肩 YES（±1 档、价 0.10–0.50）里这一小时跌得最多的（4% | 9%，对 20% | 25%）。整体前推首选 33.5%。
- 簇的首笔有 96% 发生在它已持有该站日某些腿之后：**选桶主要是「在自己已有的腿里挑哪条再加」**，挑法是「刚变便宜的、或上一笔那条」。

**读数（确定性）**：能写死的只有三件——①范围：众数 ±2 档、YES 0.05–0.60、NO 0.25–0.85（覆盖 94%）；②延续：已持哪条腿就多半继续加那条，众数桶上已持 NO 再买 NO 约八成；③逆势：刚变便宜的买、刚变贵的空（众数 YES 刚涨 >1 分时买 NO 六到九成）。在这三件之内挑哪一条，确定性规则前推只对三分之一（前三约七成三），黑箱全特征也只到 38%；剩下的取决于它自己的持仓历史与分钟级时点，天气模型零增量（第 25 轮）。按这些规则自己挑腿不赚钱（第 27–28 轮逆势纸面回测 −2.2%）。

## 第三十六轮（10-11，熊先生「如果信念是校准后的预报桶 F……市场众数桶是后面自然形成的，也就是先有预报桶 F，再有市场众数桶，而不是反过来！验证这个想法！」）——事前协议（打分前提交）
