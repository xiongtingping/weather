# Proper 首个 P0、距结算 >36h：准确度证据

读取时点：2026-09-27T02:41:48.257525+00:00。只读生产 SSOT，无生产写入、服务重启或下单。

## 口径

- 按 Proper 的 stage_first_decisions：每站日首个 P0 training fact；先取首个再筛 >36h，禁止取窗口内任意更新代替。
- 用 production settlement_time 合同、每站 canonical 时区，要求该事件日已闭；decision 和实际 fact/envelope 提交时刻均须 >36h。
- 真值只取 FORMAL_TRUTH_LANES_SQL 的 AWC/SETTLEMENT_SOURCE 最新修订，再查 QC，按 envelope 区间唯一落桶；近期样本真值均 FORMAL_NATIVE_ELIGIBLE。
- envelope 通过 history_envelope_payload 重建和哈希校验；取当时存储概率，不套用今天的宽度、不重新 floor、不改桶。
- 近期窗口按决策时间 >=2026-09-14T05:52:13Z；事件日 09-16 至 09-26；477 首决策，3 个有引用激活记录缺失，主结果排除后 474 个站日、45 站、11 个事件日。
- 每站日一票，区间按事件日聚类 bootstrap 2000 次；校准偏差区间 5000 次，未作多重比较修正，仅 11 个日簇。

## 结果

- 桶 Brier 0.766379，95% 区间 [0.7453686573613195, 0.7867021854973106]；同梯 11 桶平分布 0.909091，相对误差下降 15.70%。这不是胜率。
- Top-1 命中率 33.12%，95% 区间 [29.14831867227109, 37.288687084083975]。
- 原始 NLL 为无穷：2 个真实结算桶当时 p=0。epsilon=1e-12 的截断诊断为 1.735457；1e-6 为 1.677164。不能把截断值说成原始严格 proper score。
- 结算桶 p<=1% 共 12/474。零概率个案：KSEA 2026-09-19（v5，64.6h），SBGR 2026-09-20（v6，60.9h）。不能据此声称当前 v19 仍有同样问题。
- p>=40% 的 272 个桶案例，平均声称 47.65%，实际 38.60%，高估约 9.05 个百分点；实际减声称的 95% 区间为 [-14.856581568344396, -3.1912469047031227] 个百分点。
- ECE 1.588% 会掩盖高概率段偏差。

## 时点与版本限制

近期未经激活剔除的477样本中，36–48h仅2个，48–60h有233个，60h以上242个；不能给36–48h单独可靠结论。
首决策版本为 v5/v6/v7/v8/v9/v12，当前 v19 已闭日首决策样本为0。看板的当前版本所有更新样本与 Proper 首决策样本不是同一总体。
3 个引用缺失：KLAX 09-19 IFS；NZWN 09-16 IFS/GEFS；NZWN 09-17 IFS。未把缺失解释为已证明的时间穿越。

所有近期样本 native_formal_p0_eligible=false，activation 仍为 PRODUCTION_NO_LIVE_ONLY。历史已服务、已闭日、激活时钟可查，不等于已经逐条完成成员原始 arrival/receipt、训练真值可知时点、历史 OOS、exact scope 与权重 artifact 的全链路 strict-as-of 审核。本分析是历史服务质量审计，不是 OOS 晋级证书；不把未来/forward 数据补算为 OOS。
