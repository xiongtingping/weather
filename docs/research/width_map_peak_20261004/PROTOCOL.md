# 查峰与宽度层映射：协议（先于任何读数）

2026-10-04，熊先生：「先查峰，修概率」。

## 事实（读代码得到，算之前就成立）

- 生产宽度层 `center_width_calibration.apply_center_width_calibration` 把每个内部桶的质量当作桶中心上的一个点，
  按 x → mean + λ(x − mean) + δ 移动，再在相邻两个桶中心之间线性分摊。
- 线性分摊等价于「把这块质量当成宽度仍是 1 档的均匀块重新落桶」：中心按 λ 收了，块宽没收。
- 开口端桶（宪章 190）已经按密度处理：指数尾经各边界的原像落桶。内部桶与开口端桶是两套算术。
- λ=0.75、均值在桶中心时：点映射把每个邻桶 25% 的质量并进峰值桶；块宽也乘 λ 的密度映射是 16.7%。
- 10-04 实服读数（`final_vector_acceptance_20261004`）：线性池 p≥0.5 档 命中−预测 +2.2 点，最终向量 −9.7 点 [−14.6, −4.8]。

## 数据

`conditional_width_lambda_20261003/pass1_c`：现行链重放（dress_v1、宪章 242 overlay、246 桥、现行辐射位移），
45 站、事件日 07-31..10-01、整度格、每次更新存**宽度层之前的向量**。
代表决策＝每站日 × 5 个提前量档（距当地日终 ≥48、36–48、24–36、12–24、0–12 小时）取档内最后一次。
真值桶＝`native_ensemble_oos._temperature_bucket`。每个向量过 `floor_probabilities` 后用 `native_ensemble_oos._metrics` 计分。
层的其它输入（下限抬升、站尺度）取现役 P0 层（`p0_gate_tables`），只换映射与 λ。

## 臂

- **PRE**：宽度层之前的向量。
- **P@0.75**：生产映射、现役 λ。现役。
- **P@fwd**：生产映射、全队一个 λ 逐日前推。对照：只重选 λ 能得到多少。
- **B@0.75**：块映射——内部桶＝桶区间上的均匀块，块宽随 λ 缩放，按目标边界的原像落桶（开口端桶的同一套算术）；同一名义 λ。
- **B@fwd**：块映射、λ 逐日前推。
- **C@fwd**：P@0.75 之后压峰——最高桶超过 0.40 的部分乘 κ，多出的质量按质量比例给左右邻桶；
  κ 逐日前推＝前缀上使「最高桶 ≥0.40 的格」Σ(y − p′)=0 的矩估计，夹在 [0, 1]。

前推：计分日 d 只用 event_date ≤ d−2 且 truth_known_at ≤ d 00:00Z 的行；前缀不足 8 个事件日用 0.75（κ 用 1）。
λ 网格 0.500..1.500 步长 0.025，目标＝前缀平均 LogScore（下限后）。

## 读数

1. **查峰**：各臂在 p∈[0.4,0.5)、p≥0.5 两档的平均预测、命中率、差；全部提前量与 >36h（前两个提前量档）各报一次；事件日成块自助 2000 次。
2. **三分数**：各臂对 P@0.75 的 ΔLogScore、ΔBrier、ΔCRPS，用生产门 `center_width_store._proper_score_gate`（簇＝站日），
   另报事件日成块自助；全期与两段（07-31..08-31、09-01..10-01）。
3. **形状**：各臂最高桶 ≥0.5 的决策占比、整度轴上的 E[z²]。

## 判决（事先定）

- **峰修好**＝该臂 p≥0.5 档的差的 95% 区间含 0，且 |差| 比 P@0.75 小、两臂之差的区间不含 0；全部提前量与 >36h 都成立。
- **分数不变差**＝对 P@0.75，全期三个分数都不显著变差（区间整体在 0 之上才算显著变差），且两段的 LogScore 点估计都不高于 +0.001。
- **落地次序**：块映射两条（B@0.75、B@fwd）里满足两项判决的优先——它是对现有算术的修正，不加参数；
  B 不满足而 C 满足才取 C；都不满足则不改生产，如实报。
- **落地前复算**：在实服信封回执的 `input_probability`（市场梯子、含 F 站与开口端）上用生产实现再算一次——
  点映射须逐位复现当时的服务向量；块映射的峰值档与三分数须与本数据同向。

## 限制

回放的到货是模拟的，不是严格 as-of；整度格不是 F 站的市场梯子；>36h 用「距当地日终」近似距结算。
