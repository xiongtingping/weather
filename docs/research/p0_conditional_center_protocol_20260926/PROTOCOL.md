# 现行 P0 条件中心校准：实施协议草案（2026-09-26）

状态：方法与验收协议，尚未提取本实验样本、拟合候选或运行效果检验；不构成有效性结果、激活或上线。回答熊先生“条件校准如何进行”。

## Goal

验证：在冻结现行 P0 全链之后，仅用决策前可得的 NWP 信息，是否可以识别当天的剩余中心误差，并使完整市场桶概率的 LogLoss 与 Brier 在独立闭日历史中同时下降。
第一轮只研究中心修正；市场不入特征或训练目标。宽度参数、共识桥、辐射、band、支持集地板均冻结；已有修正必须保留在基线上，不能把同一增益再算一次。

## 1. 先核对输入，再决定能拟合的候选

一行＝station × event_date × decision_at 的 P0 更新，附完整原始概率向量、实际市场梯子、源对象与参数 artifact 的 lineage。
- 冻结全部服务算术依赖、参数 artifact、registry/梯子版本、数据截止时间和代码指纹；不能只记 HEAD 而忽略工作区或动态 artifact。
- 原生对象必须有可验证 publication/arrival/receipt，均不晚于决策时刻；训练真值的 known_at 也必须早于拟合时刻。
- AIFS/AIGEFS 推算到货的旧回放只能作开发材料；按公开可用性反事实回放必须独立标识，不能冒充实际已收到的正式 OOS。
- 标签使用最新修订的正式 canonical truth，按唯一桶合同映射；C/F 换算、时区和开口桶只用现有合同。无法唯一映射即拒绝。
- 首轮候选输入只包括：参与系统的已校准中心相对当前中心的有方向差值；各系统内部离散度和系统间离散度；exact lead/run、站点本地季节相位。
- 同一 independence family 不作为多个独立投票。系统身份保留，以 family 共享/收缩系数；不能为齐维度给缺失系统填 0。
- 第二组输入：同源、同事件日的新旧原生 run 中心变化及各自年龄；用决策时已知的同一套校准参数重算新旧 run，避免把校准版本变化误当模型趋势。
- 旧 run 没有完整时钟或成员证据时，不启用该组候选；不得用 Previous Runs 的固定日偏移猜 native run/arrival。
- 分别报告每组特征的真实覆盖、拒绝原因和日期。覆盖不足即给出未能检验，不用更晚字段回填。

本协议没有确认上述所有输入已覆盖历史全域。现有原生物理审计不足以直接证明逐成员峰值、云雨风字段已齐；首轮不增加这些特征或新采集。

## 2. 小模型与准确接入位置

拟合有收缩的低维函数 δ=f(x)，单位为 °C；零函数是基线。站点系数向共用系数收缩，避免 45 站各自拟一套不稳定参数。
首轮仅线性主项及事先定义的 lead 交互，不进行树深、神经网络、任意阈值或大量交互搜索。参数正则强度仅在内层时间验证选择。

将 δ 通过现有开口尾桶概率搬运机制施加到 `native_ensemble_p0.compile_native_ensemble_p0` 的 `pre_layer_probability`；随后重跑完全相同的 `apply_served_table_layers` 和唯一一次 `floor_probabilities`。
不能直接平移最终 served 概率后跳过 band，也不能对已经加过地板的向量再加一次地板。δ=0 必须逐桶复现冻结基线。
宽度参数冻结并不意味着离散概率搬运后方差严格不变；实际中心、方差、尾部概率均记录，用于检查收益是否真的来自中心。

直接最小化经过完整下游形状链后的真实桶损失：
`平均站日权重 × [-log p'_y] + 参数收缩惩罚`。
真值减中心的摄氏残差仅作解释性读数，不把 RMSE 改善当最终选择目标。
若使用安全位移上限，它必须在内层训练确定并冻结，不得根据外层收益挑上限。

## 3. 固定消融，避免误认信息来源

| 臂 | 相对冻结 P0 的变化 | 回答的问题 |
|---|---|---|
| A0 | δ=0 | 当前基线能否逐桶重现 |
| A1 | 仅站点/lead/季节条件的收缩小修正 | 重新校准本身是否有收益 |
| A2 | A1 加各系统有方向分歧与离散度 | 多系统结构是否有新增信息 |
| A3 | A2 加合格的新旧 run 变化 | 模型更新方向是否有新增信息 |
| A4 | 与 A3 同输入、同容量，仅训练损失换为 Brier | 改进来自信息还是评分目标 |

A3 输入不合格时，以 A2 作为 A4 的同容量对照，必须在查看评分前记录。候选选择仅在内层进行；外层只检验内层选出的算法，消融结果不得用于再挑赢家。
所有臂在共同有效样本上配对；同时报告全目标总体的覆盖与“未适用保持原 P0”的效果，不能通过删掉难样本制造改进。

## 4. 严格时间验证与独立留出

- 开发与内层：可复用已经看过的历史；滚动训练窗口沿用冻结生产配置，只允许训练时已经闭日且真值已知的数据。
- 外层：预留未参与本轮特征/模型选择的已闭日历史整段。已有 08-16..09-23 分歧诊断不能再次称为未见检验集；没有合格独立段时明确缺证据，不把未来采集叫 OOS。
- 同一事件日所有站点、所有更新在同一折；按全球事件日期阻隔并检查逐行 known_at，防止不同站点结算时区造成泄漏。
- 内层选择标准化参数、正则、位移上限和候选；外层逐日前推，不做随机行拆分、不做使用未来日标签的留一日训练。
- 首要评估严格为距结算 24≤h<60；同站日先平均，再站日等权。另报提前量、C/F、前后时段、全部站点与逐站结果。
- 外层目标至少 20 个不同闭日；这不是替代底层 single-system exact-scope 的 20 train+8 holdout 与 activation 合同。样本不足只报估计、不晋级。

## 5. 如何判定成功或失败

第一终点是独立 P0 改善：配对 ΔLogLoss 与 ΔBrier 都小于 0，并且按事件日三日块 bootstrap 的 95% 区间上界都小于 0；这是本次研究建议预注册的保守成功标准，不声称自动改写现有宪章。
第二终点是差距缩小：在同刻新鲜 WS 盘口可得的固定子集，另报对市场的两项差距。市场只用于该外部比较。
“模型与市场相差≥0.5°C”和原七个沿海站只作预先标记的诊断切片；既有沿海名单由旧结果选出，不能当独立证据或部署白名单。
收益应通过去掉最大贡献站、去掉最好两天、前后时段复核。若收益依赖极少数站日，判不稳健；不得重新改切片或挑日子过门。
必须同时报告：评分变化、差距收回比例、未收回部分、覆盖率、位移分布、尾部损失和证据限制。中心有变化但 proper score 不改善，即失败。

## 6. 工程与研究反例

δ=0 精确恒等；C/F 与非标准桶宽；上下开口桶及多次往返平移；极端分歧；系统或旧 run 缺失；两个相关系统不能增加独立家族数；未来 receipt/未来真值注入必须拒绝；改动外层标签不能影响此前任何参数或预测；NLL/Brier 独立复算；资源探针失效立即停止。
离线独立进程执行，逐站流式、单线程，硬限制 RSS/运行时间/输入与输出/临时文件/最低剩余磁盘；不进入 SSOT 写者轮转，不重启服务，不改生产或下单。
