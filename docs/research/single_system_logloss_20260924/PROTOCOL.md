# 单系统校准是否符合宪章 211：按 LogLoss 重拟单系统参数的历史回放（计算前协议，2026-09-24）

熊先生：「那单系统校准，是否符合模型目标？测试一下」。

单系统校准层（每家系统 × 站 × 季相 × 提前量档 × 周期）现在两个参数都是矩估计：偏差 = 半衰期 5 天加权的平均误差（分三档水平修正），spread_factor = 残差标准差 / 成员离散度，核宽 0.5°C。宪章 211 的训练规则是 LogLoss。本研究问：同一训练窗、同一分布族，只把这两个参数改成最小化桶 LogLoss，服务出去的 P0 在面板上会不会更好。只读，生产未改。

## 样本与装置

与 `fusion_blend_historical_20260923` 第一遍同一套生产重放（`scripts/replay_p0_stable_pool.py` 的函数；五家原生、07-20..09-22、45 站；每次「某家最新 run 变了」算一次更新；逐系统 60 天滚动窗、真值须在更新前可知、run 须在更新前到货）。

## 三个臂（同一次更新、同一批训练行、同一席位权重、同一桥接／形状栈／该小时服务表）

- **生产 `prod`**：`oos._fit_parameters` 的参数。
- **只重拟宽度 `ll_spread`**：偏差不动，spread_factor 在 [0.5, 5.0]（生产上下限）内最小化训练窗加权平均 −log p(真值整度桶)，权重＝生产偏差的半衰期 5 天衰减。
- **中心和宽度一起重拟 `ll_both`**：在 `ll_spread` 基础上再加一个统一中心平移 δ ∈ [−3, 3]°C（加在总偏差与三档偏差上），与 spread_factor 联合最小化同一目标。
- p 的下限 1e-6。拟合用向量化的真值桶概率，开跑前断言它与生产 `oos._apply_parameters` 在抽样训练行上逐项一致（误差 ≤1e-9）；服务分布一律用生产 `_apply_parameters` 由新参数生成。席位权重固定取生产参数下的席位（只隔离单系统这一层）。

## 判据（事先写定，宪章 211 面板）

主读数＝全部更新、站日等权。某个 LogLoss 臂**桶 Brier 降、LogScore 降、Reliability 降、Resolution 升，四项同时成立**，即判「单系统层不符合目标、应按 LogLoss 重拟」；否则判「现行矩估计在服务面上不输，符合目标」。另报 3 日块 bootstrap 95% 区间（四项）、日前根与宪章 134 之后两个切片（只报不判）、拟合出的 spread_factor 与 δ 的分布。RMSE、CRPS 只作诊断。不按结果改协议。
