# 宪章 68 逐桶 λ：在当前树上重测（2026-09-09）

> 差额 100% 在选谁开仓，形状那一半是中性偏正的，而亏损可以定位到一张从未被拟合过的表里的一个未拆细的顶档。

## 为什么值得重测

逐桶臂自己的实现没动，但**它在折算的那一切都动了**。

## 跑之前先修了一个会让臂作废的缺陷（提交 80fa4754）

宪章 68 的 scope 是**两个常量、两个环境变量名**：运行时读 `DELTA_V2_EFFECTIVE_EDGE_SCOPE`，
账本读 `PAPER_LEDGER_EFFECTIVE_EDGE_SCOPE`。运行时的注释写着"账本带同一个开关，两者必须一起动"，
**而没有任何东西让它们一起动**。默认生产裁判下，折算座位的是**运行时**那个常量：

- 只设运行时的 → 每一本账都变，指纹纹丝不动 `0b0a4ae769f2`；
- 只设账本的 → 指纹变，生产裁判仍按整窗折。

两个方向都产出一条与基线无法区分的臂——正是今早宪章 72 那个判例的镜像。
现在两个键都进指纹，四种组合各不相同（默认 `0b0a4ae769f2` / 只运行时 `a599b5db495c` /
只账本 `4e199259b001` / 都设 `bed20baf25e8`），标准账指纹不动。

## 亏在哪一档：未拆细的顶档 1.38

逐桶臂读的是内核里写死的四档常量 `EFFECTIVE_EDGE_BUCKET_LAMBDA`：

    a<0.50 → 0.22 ；0.50–0.70 → 0.43 ；0.70–0.85 → 0.80 ；a≥0.85 → 1.38

顶档 **1.38 是抬价**——市场出价高于我们声称的腿，它的声称被放大 38%。按腿落档：

| 档 | 逐桶新开、亏 19.77% 的 33 席 | 逐桶拒掉、赚 5.69% 的 57 席 |
|---|---|---|
| a<0.50 λ=0.22 | 18.8% | 27.4% |
| 0.50–0.70 λ=0.43 | 5.8% | 16.2% |
| 0.70–0.85 λ=0.80 | 7.2% | 6.0% |
| **a≥0.85 λ=1.38** | **68.1%** | 50.4% |

新开那批亏钱的席位里**三分之二的腿坐在抬价档**：顶档把它们的声称抬过闸，整窗口径下这些窗根本进不来。

**这正是宪章 96 在窗口表上发现并修掉的毛病**——开口顶档内部异质，池化值会放行一段亏钱的切片，
于是窗口表在 0.95/1.00/1.10 处拆开。**逐桶表从来没有做过这件事。**

## 两个结构性事实

1. **逐桶表从未被拟合过**。`calibration_effective_edge_lambda` 只按 `stage_scope`（P0 1225 席 /
   P0-M 137 / P1 162）拟**窗口**表；store 里没有任何逐桶拟合。窗口臂读每日重拟的活跃表，
   **逐桶臂读的是 09-03 手设的常量**——两条臂不同源。
2. 顶档开口且未拆，值 1.38 > 1，是四档里唯一会放大声称的一档。

## 结论与欠账

- **不晋升**：−6.25% 对 +0.37%，−59.44 USDC，远超本账干扰底噪（±15 USDC）。09-03 的否决成立。
- **但否的是这张表，不是这个想法**：共同席位上逐桶折算 +0.19%，形状没输；亏损集中在一个
  未拆细、未拟合、且唯一会抬价的顶档。
- **欠账（按值排序）**：①给逐桶表做第一次拟合（今天它没有拟合入口）；②照宪章 96 拆它的开口顶档；
  ③拟完再跑一次这两条臂。在①之前不要再跑这条臂——测的是一张手设常量。
