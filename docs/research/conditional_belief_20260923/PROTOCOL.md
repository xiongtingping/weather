# 条件化概率校准与逐特征归因：计算前协议（2026-09-23）

用户裁决：「全量做，但是能单独测量增益信息，也就是能归因」。

## 问题

给定模型概率 p、市场中价 m 与条件特征 x，下注用的信念 b = P(桶开出 | p, m, x) 是多少；每一族特征相对「只看市场」和「市场+模型」各带来多少样本外信息（对数得分），以及多少可兑现 edge。只读 SSOT，不改生产。

## 样本

- 估值车道总体（`valuation_store.population`，宪章 132/140 同一取数）：每个生产决策一行——提交的信封向量 p、决策所用 WS 快照重建的整梯中价 m、知道时点可证的结算桶、逐桶半点差。阶段 P0 / P0-M / P1；事件日 2026-08-15 起到最新可知；不锚定（跨算术版本全用，符合宪章 202「用旧样本」），另报证据纪元之后的切片。
- 降相关：每个 (站, 事件日, 阶段, 当地 3 小时块) 取中间那个决策；权重 = 1 / 该站日该阶段的块数（一个站日每阶段总权重 1）。
- 桶：只算 m > 0 的桶（市场有价的集合）；桶中心取服务轴（`served_bucket_axis`，宪章 190）。

## 模型（条件 logit，按决策内的桶做 softmax）

记 Lm = logit m、Lp = logit p（都截在 [1e-4, 1−1e-4]），D = Lp − Lm。

- **M0 市场校准**：score = βm·Lm
- **M1 市场 + 模型**：score = βm·Lm + w·D
- **族 k**：在 M1 上加该族的项（下表）
- **全量**：M1 + 所有族

| 族 | 条件 g（站日/决策级） | 桶级项 |
|---|---|---|
| T 时间 | 距结算小时 h/24、(h/24)² | g·D、g·Lm |
| S 模型自身 | 服务宽度 σp、峰值概率、P0 各家中心极差（缺失置 0 + 缺失标记） | g·D、g·z²（z = (c − μp)/σp） |
| R 区域模型 | 决策时刻最新可读区域 run 的当日最高温 Treg（≤12 小时）；P1 另加剩余升温空间、当前偏差 | 可得·(c − Treg)²、可得·|c − Treg|；P1 条件 g·D |
| A TAF | 决策时刻最新可读 TAF 的 TX、发布时长 | 可得·(c − TX)²、可得·|c − TX|；时长·D |
| O 实况 | 当日已出现最高温 H（P0-M、P1）；P1 已升温、回落、动量、剩余小时 | 桶低于 H 的标记、(c − H)₊·剩余小时；P1 条件 g·D |
| W 云雨风 | 云量、降水、风速、辐射/晴朗度（TAF、物理量版本表、P1 血统，均按决策时刻） | g·D、g·(c − μp) |
| K 盘口 | 头两桶中价差、市场熵 | g·D；桶级半点差 |

所有非基础系数做高斯先验收缩（特征在训练折内标准化，先验方差 1，相当于 N(0,1) 岭）；βm、w 不收缩。

## 滚动与归因

- 按事件日滚动：每个测试日单独拟合，训练集 = 结算真值在该日最早测试决策之前已可知的行；至少 8 个训练事件日才开始打分；每阶段各自拟合。
- 指标：样本外对数得分（每站日加权平均，nat）；相对 M0、M1 的增益。
- **归因**：加一（M1 + 族 k 对 M1）、减一（全量对全量 − 族 k）；两者之差报告为交互量。连续 3 日块 bootstrap 2000 次给 95% 区间。
- **可兑现 edge**：卖一 ≈ m + 半点差（0.01–0.99 之间）；b ≥ 1.05×卖一（宪章 130 同一门槛）即买 1 股；每站日实现盈亏 = Σ(开出 − 卖一)；报每站日盈亏、ROI 与区间，各模型同一套规则。
- 不根据结果增删特征、改分档或改先验；全部结果（含不显著、负的）都报。

## 修订记录（首轮结果出来后，均在重跑前写入）

1. **数据 bug（修正，非设计变更）**：W 族 `cloud` 在 TAF 缺失时回退到物理量版本表的 `cloudcover_mean`，该列是百分数（0–100），TAF 是分数（0–1）；同一特征混两种单位。改为回退值 ÷100。首轮 P1 的 EGLC 2026-09-01 一个站日因此 −21 nat。
2. **区间计算 bug（修正）**：3 日块自助法原先不循环，末尾几天抽中概率偏低，天数少的切片（证据纪元 4–8 天）区间可不含均值。改为循环块。
3. **事后稳健版（新增、次要结果，预注册版仍为主结果）**：首轮暴露线性交互的病态——有效模型权重 w + Σθ·z 在部分条件下变负，模型判 0 的桶（D≈−8）被反向抬高；二次项 z² 无界，模型中心错时命中桶被压到 e^-6 以下。稳健版只加有界变换、不增删特征、不改先验：D 截到 [−3, 3]；条件标准化后截到 [−3, 3]；z² 封顶 9。两版同一样本、同一折、同一交易规则，全部报告。
