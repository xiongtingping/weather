# 训练评分规则的性格：Bucket Brier / multiclass LogLoss / 部分篮子窗口规则（计算前协议，2026-09-24）

熊先生裁决（宪章 211）：模型唯一优化目标是条件离散温度桶概率分布 P(Y=k|X)；RMSE、CRPS 退为中间诊断；评价至少同时看 Bucket Brier、LogScore、Reliability、Resolution。裁决末尾留下的问题：**训练时用 Bucket Brier、multiclass LogLoss，还是针对部分篮子的 scoring rule——三者会把分布训练成不同的性格。** 本研究回答这一问。只读，生产未改。

## 样本

- `docs/research/conditional_belief_20260923/rows_{P0,P0-M,P1}.npz`：三阶段已服务的概率向量 `p`（N×11，真实市场梯子，含两端开口桶，行和为 1）、结算落桶 `hit`、事件日 `day`、站日 `sd`、`scored`（已结算且真值可知）。只用 `scored` 行。P0 997 站日 / 29 天（08-25..09-22），P0-M 411 站日 / 10 天（09-13..09-22），P1 958 站日 / 24 天（08-30..09-22），45 站。
- 一个站日可有多格（不同小时的服务格）；**站日等权**（每格权重 = 1/该站日格数），与看板北极星同一规则。

## 被训练的对象

同一族后验映射 `M(λ, ε)`：`q_k ∝ p_k^λ`（宽度/温度缩放，生产宽度层 λ 的同义物），再 `r = (1−ε)·q + ε·u`（`u` 为梯子上的均匀分布，尾部地板）。恒等映射 = `(1, 0)`。网格：λ ∈ {0.30, 0.35, …, 2.00}（35 档），ε ∈ {0, 0.001, 0.002, 0.005, 0.01, 0.02, 0.03, 0.05, 0.08, 0.12, 0.20}（11 档）。选择这个族是因为它**能**表达三种性格的差别（尖 / 平、有没有尾部地板），又只有两个参数，滚动 5 天就能拟。

## 四条训练规则（同一族、同一样本、同一网格，只换目标函数）

- **BRIER**：Σ_k (r_k − 1[k=y])²
- **LOG**：−log r_y（r_y 取 1e-9 地板，只在训练时用于让 ε=0 且 p_y=0 的组合出局）
- **WINDOW（部分篮子规则）**：全部连续 3 桶与 4 桶窗口 B 上 (r_B − 1[y∈B])² 的平均（11 桶梯子上 9+8=17 个窗口；交易层买的就是 3–4 桶窗，宪章「3–4 桶窗」）。这是 r 的线性泛函上的 Brier，是 proper score。
- **CRPS（对照）**：梯级 CRPS Σ_j (F_j − 1[y≤j])²，被裁决退为诊断的那一个，放进来看它训练出什么性格。

## 前推协议

按事件日排序；对每个事件日 d，只用 d 之前 28 个日历日内的已结算站日训练（至少 5 个不同事件日，否则 d 不评），四条规则各选出自己的 (λ, ε)，应用到 d 的行上。**没有任何一天用到当天或之后的真值。**

## 评价（每阶段、每规则对恒等映射，站日等权）

- 面板（宪章 211）：Bucket Brier、LogScore（真值桶 p 取 1e-6 地板，与看板 `CORE_NLL_FLOOR` 同）、Reliability、Resolution（看板 `_core_murphy` 的分档与权重，本脚本向量化实现并对拍到 1e-12）。
- 交叉矩阵：用 A 训练、用 B 评，四规则 × 四分数。
- 性格读数：峰值桶质量、最佳 3 窗 / 4 窗质量、众数±2 以外尾部质量、零概率命中数（r_y<1e-6）、熵、拟合的 (λ, ε) 逐日路径。
- 篮子读数：每行按各规则的向量取质量最大的 4 窗（交易层的「主篮子」），与恒等映射所选窗口不同的比例；所选 3 窗 / 4 窗的**声称质量对实现命中率**（部分篮子的可靠性，就是 EV_B = P_B − K_B 里 P_B 靠不靠谱）。
- 区间：按事件日 3 日循环块 bootstrap 2000 次，报 Brier / LogScore / REL / RES 差值的 95% 区间。
- 不按结果改网格、改窗、改规则；全部结果都报。市场价格不进任何训练目标（宪章 211），只在篮子读数里作已实现对照。

## 判读口径（事先写定）

- 「性格不同」的证据 = 同一族里四条规则选出的 (λ, ε) 系统性不同，且交叉矩阵非对角劣于对角。
- 「该用哪条」只按宪章 211 面板判：四项里更多项改善、且 LogScore 与 Brier 的区间不跨零到反向；若面板互有胜负，报出来，不硬判。
