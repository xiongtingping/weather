# 上午 P1 相对市场众数押错边：查源头（2026-10-16，熊先生「查」）

只读诊断，生产未改。样本 = `obs_minus_forecast_station_direction_20261015/rows.jsonl.gz`（10,597 行逐小时服务 P1 × 盘口，48 站，09-01..10-06），
逐行接上 P1 的 P0-M 根与其下的 P0（`build.py`，14,226 个根信封）。指标：真值离开市场众数的行上，谁判对了「偏暖/偏冷」一侧
（侧 = 众数以上质量 − 以下质量的符号）。

## 1. 错在哪一层：P0

| 当地时段 | P0 | P0-M（根） | P1 | 市场 |
|---|---|---|---|---|
| 07–10 | 63.1% | 63.9% | 66.6% | **75.2%** |
| 10–13 | 61.3% | 65.3% | 71.5% | **76.6%** |
| 13–16 | 65.0% | 73.7% | 82.4% | **85.5%** |
| 16–20 | 78.1% | 90.6% | 92.2% | **98.4%** |

- TAF（P0 → P0-M）上午只加 1–4 个点；P1 的观测更新再加 3–6 个点，**两步都在纠偏，不是造偏**。
- P1 与市场方向相反（真值离开众数）的 581 行里，P0-M 与 P1 同侧 73%、P0 与 P1 同侧 71%：**错边从 P0 带下来**。
- 无冷暖系统偏：错边的行一半偏暖、一半偏冷（49%）；上午 P0 均值偏差 −0.00°C。

## 2. 不是什么

- **不是旧轮次**：P0 决策年龄中位 0.2 h；最新一轮 NWP 距决策 6–8 h，0–12 h 档里差距照样 +13.5 点。
- **不是少家数**：六家全座的行 P0 64% 对市场 75%，两家/四家同样落后。
- **不是个别站的 bug**：48 站里 43 站市场更准；差距最大 LIMC +37 点、KLAX/NZWN/KLGA +33、KHOU/CYYZ/ZSQD +31–32；
  只有 LEMD、RKSI 上 P0 略好。
- **不是形状**：用「均值在众数哪侧」代替质量判边，P0 62.4% 对市场 74.8%，与按质量几乎一样——是**中心**的问题。

## 3. 是什么

上午 2,163 行里 P0 与市场押相反边 574 行（27%），市场对 76%。这些行上两边均值相差中位 0.52°C（约半个桶），
P0 均值 MAE 1.34°C，市场 1.01°C。**这就是已知的 P0 中心缺口**（[[model-market-gap-decomposition-20260926]]：P0 24–60h 差
0.10 nat、八成在中心），在当天上午的样子：市场的中心比我们的六家集合中心准，差半个桶时市场四次对三次。

附带一个新事实：**P0 押边比市场更用力**——|上方质量 − 下方质量| 平均 0.34，市场 0.24。P0 自己的倾斜偏自信。

## 4. 结论

「上午押错边」不是 P0-M 或 P1 的 bug，是 P0 中心不如市场准，在上午还没被观测纠正时最明显。中心缺口本仓已经用
区域模式、NWS 点预报、条件校准、Brier 目标、几何池等试过，样本外都没收回（见记忆索引）。所以：
- 用市场倾斜在后面补（冻结的那一臂）是目前唯一测得过门的办法，落点在兑现层 b；
- 不需要单独修 P0-M 或 P1；
- 唯一在本仓之外、不靠市场的新线索是「P0 倾斜偏自信（0.34 对 0.24）」——可以预登记测「把 P0 两侧比例往对称收一点（保众数、不看市场）」，
  这是合规的 P0 校准形态，不是信息来源，预期量级小。
