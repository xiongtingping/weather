# 区域模式能不能补上 P0 在分歧日的中心缺口（计算前写定，2026-09-26）

熊先生：「继续」，续 `model_market_gap_decomposition_20260926` 的下一步。只读研究，生产未改。

那份研究的结论：今天的 P0 在 24–60h 比市场差约 0.10 nat，八成在中心，集中在模型与市场分歧 ≥0.5°C 的日子，也集中在沿海站。本研究问两件事：

1. 区域、高分辨率模式在那些日子是否掌握市场掌握的局地信息？
2. 第 201 条的中心修正规则前推后，能否收回这部分中心缺口，按第 211／227 条两个分数都显著下降？

## 总体

- 取 `model_market_gap_decomposition_20260926` 的「现行算术 P0」决策：
  - 今天的 P0 向量配 30 分钟内的盘口；
  - 距结算 24–60h；
  - 事件日 08-23..09-23，即 HRRR、NBM、JMA MSM 开始采集以后。
- 每次决策 t、每个区域源：
  - **R**：该源在 t 可知、覆盖当地下午的最新一轮的日最高温。用生产 `deterministic_forecast_family.feature_at`，区域行按站日由 `regional_point_lane.runs_for` 读一次。
  - **b**：该源的去偏。用生产 `regional_point_debias.resolve_correction`，参数取 `replay_curve(事件日)`，只用更早的事件日拟合，准入名单照生产 `CALIBRATED_SYSTEMS`。
  - 去偏不可得的源，这次决策不计。
- **记号**：
  - c = P0 均值；m = 市场均值；T = 结算最高温（均在服务轴上，单位 °C）；
  - d = (R+b) − c：区域模式对 P0 的分歧；
  - e = T − c：P0 的误差；
  - g = m − c：市场对 P0 的分歧。

## 读数（按源，分沿海七站与其余站；站日等权）

1. **准确度**：同一批决策上，R+b、c、m 各自对 T 的 RMSE。
2. **方向**：
   - corr(d, e)，以及样本内最优收缩 k* = Σde / Σd²；
   - 在 |g| ≥ 0.5°C 的分歧决策上，d 与 g 同号的比例，以及 R+b 比 c 更接近 T 的比例。
3. **前推修正（第 201 条的规则）**：
   - k = clip(Σ(T−c)·d / Σd², 0, 1)，每站每源只用 t 时刻已可知真值的更早站日拟合；不足 10 个事件日时 k = 0。
   - 平移量 δ = clip(k·d, ±1.5°C)，用宽度层自己的变换（width 1、开口按尾巴），即生产 `shift_distribution` 同一算术。
   - 修正后过第 224 条下限，与未修正的 P0 比桶 Brier 与 LogScore，区间按事件日整日重抽 2,000 次。
   - 另报：修正后对市场的差，以及收回的比例 =（未修正缺口 − 修正后缺口）/ 未修正时的中心分量。

## 判定

某个源在某组站上被判「补得上」，须同时满足：

- 分歧决策上与市场同号的比例显著大于 50%；
- 前推修正后两个分数都显著下降。

只满足前者的，判「有信号、规则没吃到」。都不满足的，判「这个源不掌握市场的局地信息」。沿海七站逐站报，小样本只作描述。
