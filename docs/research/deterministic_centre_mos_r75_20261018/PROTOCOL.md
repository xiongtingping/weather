# 第 75 轮：确定性模型的中心校准——四层 MOS，逐层严格前推（事前协议，打分前提交）

熊先生 10-18：「确定性模型如何进行校准？目标是中心更准，校准条件是中心点校准（忽略当前系统实现）」→「按照这套来做」。只研究，不改生产。

## 对象与时点
- 量：结算站当日最高温的点值（中心）。
- 成员：F 的六家确定性模型（IFS HRES、AIFS 单成员、GFS、AIGFS、GDPS、ICON 全球），各取挂牌时刻 D-2 05:00Z 前最新可知、覆盖午后的那一轮（`listing_forecast_f.system_maxima`，与 F 同一读口）。
- 真值：宪章 225 两车道（`listing_forecast_f.formal_truths`）。训练只用结算时刻 ≤ 评估日挂牌时刻的站日。
- 评估日：事件日 2026-09-01..2026-10-17，全部有坐标与时区绑定的站；某站日要求 ≥3 家成员有站点值，**所有臂在同一批站日上比**。训练历史从 07-25 起。

## 四层（每层在上一层之上）
- **L0 基线**：各家原始值的中位数。
- **L1 物理换算（不拟合）**：每家换成站点值 x′＝x ＋ 递减率海拔订正（`listing_forecast_f_terrain.offset_c`，该家自己的格点高度）；无订正值的成员丢弃（fail closed）；取中位数。
- **L2 系统偏差、收缩**：每家每站偏差 b̂ ＝ b_家 ＋ k·(b_家站 − b_家)。b 都是误差 e＝真值 − x′ 的**指数衰减加权中位数**（半衰期 25 天，按事件日距评估日的天数）；b_家用该家全部站。k ＝ n_eff ⁄ (n_eff ＋ σ²⁄τ²)：n_eff＝该家该站的有效样本数（衰减权重和的平方 ÷ 权重平方和），σ²＝该家站内误差方差的全站加权平均，τ²＝站偏差的站间方差减去平均抽样方差（矩估计，下限 0；τ²＝0 时 k＝0）。该家该站 n_eff < 3 时 k＝0。输出：各成员 x′＋b̂ 的中位数。
- **L3 天气状态条件修正**：每家各自一个 L1（最小绝对误差）线性回归，全站合并：y＝e − b̂（L2 之后的残差，b̂ 按训练日自身的 as-of 估计），特征＝该家**自己同一轮**预报的 ① 短波日总量 ② 当地 09–17 时总云量均值 ③ 露点差（x′ − 当地 09–17 时露点均值）④ log(1＋日降水) ⑤ 距平（x′ − 本站该日前已结算真值的 30 天衰减均值）。物理量取 `calibration_deterministic_point_physics_run` 在挂牌时刻可知、且 run_init 与温度成员同一轮的行；AIGFS 只有 ③④⑤。特征按训练集标准化，ridge 1e-3，IRLS（与 F 重校准同法）。训练行 <200 或 <10 天时该家不修正（等于 L2）；某成员当日缺任一特征时该成员不修正。GDPS、ICON 没有历史物理量，预期整段等于 L2。输出：各成员 x′＋b̂＋β·z 的中位数。
  - **季节对照臂 L3s**：同一回归，只用一个特征「事件日序号」。L3 只有在也胜过 L3s 时才算状态修正有效，否则只是季节漂移。
- **L4 加权合成**：L3 各成员的加权平均。权重 ∝ 该家该站 L3 误差的衰减加权 MAE 的倒数，向等权收缩：w＝λ·w_inv ＋ (1−λ)·等权，λ＝n_eff ⁄ (n_eff ＋ 20)；n_eff < 3 的成员只拿等权份。

所有超参数（半衰期 25 天、k 公式、ridge、200 行/10 天、n0＝20）事先固定，不调。

## 指标与区间
- 主：MAE（°C）。次：偏差、单桶命中（该站日实际定价梯子，`station_day_rungs(prefer_registry=False)`，无梯子按整数 °C）。
- 配对差按事件日整块 bootstrap 2,000 次（seed 7），95% 区间；另报评估日前后两半。
- 参照：现行生产 F（第 73 轮 `walk.jsonl` 的 A0，按站日连接，只在交集上报）。ZUUU 单站读数照报、不判。

## 判据（逐层）
- 一层**保留**＝该层减上一层的 MAE 差 95% 上界 <0，且两半点估计都 <0。
- 不保留的层，下一层改接在最后一个保留层之上（即实际链条按判决生成，另报完整四层链供参考）。
- L3 另须 L3 − L3s 的 MAE 差上界 <0，否则记「季节漂移」、不保留。
- 最终链与现行 F 比：MAE 差与命中差都报；无论结果，本轮不改生产。
