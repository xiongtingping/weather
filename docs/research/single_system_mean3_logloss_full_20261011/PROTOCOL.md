# 预注册协议：单系统校准完全按 LogLoss 拟合，按「市场均值桶 ±1 的二元 LogLoss」评分

写于 2026-10-11，任何评分之前。提问人：熊先生（「评分指标换成LogLoss，就不要管LogScore了，重新测试，用LogLoss当成单系统校准的评分规则，特别是市场的均值加减1桶的yes和no的双边！」「别取一半，完全按照LogLoss来」）。研究，不改生产。

## 与 10-09 研究（single_system_mode3_logloss_20261009）的区别
- 窗口：市场**均值**桶 ±1（10-09 用众数桶 ±1）。均值桶＝生产 `p1_consensus_lane.mean_bucket`：市场归一中价向量按梯子序号加权的均值，四舍五入到最近一档（并列取低档）。
- 训练**不再取一半**：κ＝0，LogLoss 拟出的中心平移 δ 与宽度系数 s 原样服务（10-09 两臂都保留 κ＝0.5）。
- 评分只用二元 LogLoss，不看 LogScore / CRPS / Brier。

## 三臂（同一次走查、同到货钟、同训练集、同席位）
- **CUR**：生产宪章 216（矩估计 → 整条梯子多类 LogLoss 拟 δ、s，半衰期 15 → 向矩估计收缩 κ＝0.5）。
- **FULL**：同 CUR 的目标（整条梯子多类 LogLoss，生产 `_logloss_refit`），κ＝0。
- **MEAN3**：目标换成训练样本各自的市场均值桶 ±1 的二元 LogLoss（YES/NO 双边：y·log p＋(1−y)·log(1−p)，p 截到 [1e-6, 1−1e-6]），κ＝0；同起点、同边界 δ∈[−3,3]°C、s∈[0.5,5]、同 L-BFGS-B 60 次、同半衰期 15、同 247 加宽核。训练样本的均值桶取该 run 到货时刻（as-of 整点）的市场；挂牌前取挂牌后第一份完整盘口；无市场的训练样本不进目标；剩余 < `replay.MIN_TRAIN` 时退回 FULL，计数报告。
- 非原生集合（点预报等）三臂都不重拟，与生产相同。

## 机器与样本
- 10-09 研究的走查原样复用（`capture.py` 一脉：生产单家规则、模拟到货、稳定池席位 κ＝0.25、市场梯子上逐项调生产服务函数：`_apply_parameters_on_ladder` → `bridged_cross_probability` → `_holdout_shape_stack` → 224 下限）。逐小时市场向量复用 10-09 的 `market_modes/`。
- 站点：同 10-09 的 23 站；计分事件日 2026-09-01..10-07；只看 P0、日终前决策；代表决策＝每站日按距结算小时数 5 档（≥48、36–48、24–36、12–24、<12）各取最晚一次，站日内平均。

## 评分
- 窗口＝**决策时刻**的市场均值桶 ±1（边缘桶只有两档）。每桶二元 LogLoss（YES/NO 双边），报「每桶平均」。
- 两个层面：
  1. **单系统层**：每个入座系统自己校准后的梯子向量（各臂），系统间等权平均。
  2. **服务 P0 层**：融合 → 桥 → 分布层后的服务向量（224 下限）。
- 市场 q（同一决策时刻）在同一窗口上的二元 LogLoss 作参照。
- Δ（FULL−CUR、MEAN3−CUR、各臂−市场）按站日簇自助 95%（2000 次），前后两段（09-01..09-19、09-20..10-07）。

## 判决
- 某臂在**服务 P0 层**的窗口二元 LogLoss 比 CUR 显著低（95% 区间整体 <0）且前后两段同号，才算「值得提给熊先生裁」；否则维持 216。单系统层作说明，不单独判。
- 附报：全部桶的二元 LogLoss（同口径）、拟合参数分布（δ、s）、MEAN3 退回次数；<12h 市场已看实况，只作背景。
