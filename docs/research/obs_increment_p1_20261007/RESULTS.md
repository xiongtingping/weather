# 观测增量（实况减预报）作 P1 强似然：前推不过（2026-10-07）

熊先生 2026-10-07：以 ZUUU 10-07（25°C）为例，要求把「实况云/雨/辐射对比预报的增量」作为强似然、强权重改 P1；裁决「历史拟合强度后上线」。

## 做法
- 48 站、2026-09-01..10-06 已结算日，每站日每当地小时 07–19 取最后一份服务的 P1（19,618 行，1,626 站日）。
- 预报：Open-Meteo previous-runs 的 `*_previous_day1`（发布早于所对小时 ≥24h，严格 as-of）：逐小时气温、总云、日照、降水。历史没有低云（`cloud_cover_low_previous_day1` 全空）。
- 增量似然（方向锁死）：k = exp(γ·(r − r0))，r = ln((按报文低云推算日照+30)/(预报日照+30))；预期最高 M = max(H, T_now + 预报余下升温 × k)；X = max(H, M+ε)。P1_new ∝ P1 × (L+1e-4)^w。拟 w, γ, r0, σ0, σ1。
- 按日滚动前推：每测试日只用此前日子拟合（≥12 天，每 4 天重拟），判据宪章 240（LogScore 主、Brier 护栏），按事件日自助。

## 读数
| 组 | ΔLogScore | ΔBrier |
|---|---|---|
| 全天 | −0.0104 [−0.0374, +0.0097] | −0.0075 [−0.0160, −0.0005] |
| 当地 12–18 时 | −0.0220 [−0.0601, +0.0075] | −0.0155 [−0.0284, −0.0041] |
| 日照明显低于预报 (r<−0.5) | +0.0008 [−0.0269, +0.0284] | −0.0029 |
| 日照高于预报 (r>0.3) | −0.0147 [−0.0559, +0.0122] | −0.0028 |

- 拟出的天空增量强度 γ 一路缩到 0.02–0.10（≈0）：数据不给云/日照增量任何权重；收益全部来自「实况气温 + 预报余下升温」那部分（w 0.4–0.8）。
- 强行把 γ 设为 1、2（先验固定，前推参数其余不变）：12–18 时整体 LogScore 收益变小，**比预报暗的小时更差**（γ=0 +0.038 → γ=2 +0.059）。

## 结论
- 云/雨/辐射「实况减预报」增量作强似然：前推不过，强度越大越差，不上线。
- 「实况气温 + 预报余下升温」似然：Brier 显著变好、LogScore 主判据跨零 → 按宪章 240 不过。
