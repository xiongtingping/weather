# 第一步：模型有没有市场没有的信息（对数得分，2026-09-06）

脚本 `scripts/probe_model_vs_market_logscore.py`，只读 `data/bayes_basket_target_ssot.db`。
不复刻任何席位规则、窗口、注码：问题只有一个，**同一时刻，模型向量和市场价，谁离真值更近。**

## 方法

- 样本：有结算真值的站日（`calibration_station_daily_high_truth`，ACCEPTED，最新修订），
  取 `basket_probability_bridge_history` 每个提前量档里每个阶段的最后一个 checkpoint。
  提前量 = 距当地日终（结算时区午夜）的小时数。服务向量 = 该档里权威最高的阶段（P1 > P0-M > P0）。
  同一次编译写出的三阶段时间戳格式不同（`…792Z` 与 `…792009Z`），按字符串取"最新"会误选 P0，故按阶段权威取。
- 市场隐含分布：`basket_official_ws_snapshot` 里 checkpoint 之后的第一本盘口（诚实配对，90 分钟容差），
  每桶取 (best_bid + best_ask)/2，单边缺失用另一边，归一化。
- 两边同一地板 0.005 后归一化再打分（11 桶时上限 0.95，故"确定"读数为 −0.05）。
- 得分：log p(真值桶)。差值 = 模型 − 市场，单位 nat/事件。正 = 模型比市场准。
  满 Kelly 在公平盘上的期望对数增长率恰等于这个差值，所以它就是"能赚多少"的上限。
- 增量检验：几何池化 p_w ∝ p_model^w · q_market^(1−w)，前半段（<08-18）拟合 w，后半段打分。
  w=0 表示市场单独就是最优预报，模型没有可加的信息。
- 线性收缩 β = cov(y−q, p−q)/var(p−q)：模型与价格分歧里有多少是真的。

## 这意味着什么

1. 满 Kelly 按模型信念在公平盘下注的期望增长率 = 这里的差值 = −0.4 nat/事件。
   任何按"模型 − 价格"选桶的规则，都是在模型比市场差 0.4 nat 的地方寻找正边际。
2. 账本上 P1 的正 ROI（36–61 条链）在这张 5,000+ 样本的信息检验面前不成立：
   P1 向量在 10–15h 相对市场增量为 0，其正收益只能来自薄盘选择效应或小样本噪声。
3. 宪章 68 的 λ(a)、81 的抬价、74 的门票，全是在"信念比市场差"这个前提下的止血；
   它们改变不了第 1 条。
4. 真正剩下的信息在 ≥30h 的挂牌初期（β≈0.2）和日终之后，两处都没有可执行的价：
   前者抽水 9%，后者无 ask。
