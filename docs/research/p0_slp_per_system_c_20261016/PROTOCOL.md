# 预登记：SLP 每家各自的收窄系数 c_s（按「合成后最好」拟）对全队一个 c（2026-10-16）

熊先生 10-16「测试一下」（针对：各家宽度按「单独最好」拟、SLP 再统一乘一个 c，二者重复；更干净的是各家宽度按「合成后最好」拟）。
写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改，不用市场。

## 问题
宪章 273 的 SLP：每家展宽系数 × 一个全队共用的 c（按距结算小时分档），再合成。若各家欠散布/过散布的程度在「合成语境」下不同，
让每家有自己的 c_s（等价于按合成目标重拟各家宽度，单家证书的中心、核、可靠度不动）应在样本外更好。问：c_s 是否胜过一个 c？

## 行
与 `p0_spread_adjusted_pool_20261016` 同一取行口径：事件日 D−K 当地 09:00 前最新 P0（K=0/1/2），事件日 09-01..10-14，48 站；
逐家用入座轮原始成员（到货早于决策）＋该 P0 的系统证书重建（c=1 重建与存档各家向量逐位一致，否则弃行）；该 P0 的系统权重、各家校准中心、辐射 shift_sigma。

## 臂（事先固定）
每家向量在网格 c ∈ {0.4,0.5,…,1.3}（10 值）上预先算好；合成一律：按该 P0 权重 → 共识桥（生产函数）→ 辐射平移（回执 shift_sigma × 新池标准差）→ 1e-3 下限；不施宽度表层。
- **GLOBAL_WF（对照）**：一个 c，各档逐日前推选（训练 ≥10 事件日，按整梯子平均 LogScore）。
- **PER_SYSTEM_WF（主）**：每家一个 c_s（按系统 id，全站共用，各档分开），逐日前推：训练集上从 GLOBAL 最优 c 起坐标下降（逐家在网格上换值、其余固定，取 LogScore 最小，最多 3 轮或不再变）。
  训练行里没有某家时该家沿用 GLOBAL 值。
- **FIXED（生产现值，诊断）**：c 按距结算小时 0.6/0.8/1.0（宪章 273）。注意这三个值是在同一批日子上选的，对它的比较对 FIXED 有利。

## 判据
主比较 PER_SYSTEM_WF − GLOBAL_WF，分 D0/D1/D2：宪章 240（ΔLogScore 主、ΔCRPS 不稳定变差、ΔBrier 不显著变差），站日等权、按事件日 bootstrap 2,000（seed 7）。
按站：每站 ΔLogScore、BH q=0.10（≥10 站日）。另报末次拟合的各家 c_s。
**成立**：某档主比较三项过 240 且无 BH 显著变差站 → 该档「按合成目标拟各家宽度」成立，可作替换候选（是否上线另裁）；跨零 → 一个 c 已够，重复无害。

## 已知限制
权重沿用为现行池拟的（宪章 242）；c_s 按系统 id 全站共用，不按站（参数太多）。
