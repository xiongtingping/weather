- P1 的 63 次全部继承自 P0 根：似然乘上去救不回 0。
- 根因：
  - 每家分布是「拉伸后成员 × 0.5°C 高斯核」，支撑只到成员 ±2°C，外面恰为 0。
  - 合成、形状与服务表都不会把 0 变成正数。

## 尾部形式（主规则）

在服务 P0 的最后一步：

```
P'(k) = (1 − ε)·P(k) + ε·Q(k)
```

- Q 是位置取 P 自身均值 μ、尺度 s（°C）、自由度 ν=3 的 Student-t，在各格区间上积分。开口格取到 ±∞。
- 因此每一格 P'(k) ≥ ε·Q(k) > 0。
- 对称。不偏冷；也不掺气候，第 86 条已退役气候混合。

## 参数

- ε ∈ {0.002, 0.005, 0.01, 0.02, 0.03, 0.05}，s ∈ {1.5, 2, 3, 4, 5}°C。
- 只在训练期按 LogLoss（站日等权）选一组。
