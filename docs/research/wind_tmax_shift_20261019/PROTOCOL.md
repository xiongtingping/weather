# 风 · 实况对比预报 → 最高温 ΔT（协议，先于读数）

2026-10-19 熊先生「风 · 实况对比预报：这个也拟合一下」。与露点（`dew_tmax_shift_20261019`）同一套做法，只读研究，只进看板显示。

## 数据
- 报文风速：`archive.db` 例行报（整点 ±10 分钟），`report_explain` 解析的 10 分钟平均风速（m/s），与看板同一函数。
- 预报风速：Open-Meteo `wind_speed_10m`（最新预报，卡片口径），previous-runs 接口，09-01..10-14，单位换成 m/s；研究额度记账。
- y：结算真值 − 日前预报最高温（站去均值），与云、露点同一个 y。

## 定义（事先写定）
- **主口径（卡片口径）**：x = H 点报文风速 − 同一小时最新预报风速（m/s），H = 9..17。
- 辅口径：05..H 逐小时差的平均（只报告）。
- 模型：ΔT = 截距 + 偏弱斜率·min(x,0) + 偏强斜率·max(x,0)，x 截在 ±4 m/s；卡片只用斜率部分。
- 至少 8 个站日的站才进样本；按事件日五折样本外，按日自助 95% 区间。

## 判据
- 样本外 ΔMSE 区间上沿 < 0 才算「样本外显著」，否则卡片 ΔT 标灰「不显著」。
- 另报：加进日照线是否更好。

## 追加：风的南北分量（2026-10-19，先于读数）
熊先生「风推算最高温应该要区分风的方向吧，北风好像才降温？」→「按风的南北分量重新拟合……哪个好卡片用哪个」。

- **极向分量**：风「来自」极地方向的分量（m/s）＝ 风速 × cos(风向) × 半球符号（北半球 +1、南半球 −1）。
  北半球的北风、南半球的南风为正，赤道向的风为负，纯东西风为 0。静风（00000KT）为 0；风向不定（VRB）不计（该小时缺）。
- **报文**：例行报的风向风速（与看板同一解析口径）；**预报**：Open-Meteo `wind_speed_10m`、`wind_direction_10m`（最新预报）。
- **x_polar** ＝ H 点报文极向分量 − 预报极向分量；其余（y、两段直线截 ±4 m/s、站去均值、五折、按日自助）与风速差相同。
- **比较（事先写定）**：每个 H 点，在两种 x 都有的同一批站日上，用同一套五折得出两者的样本外平方误差，
  按事件日自助求「极向 − 风速」的平均差与 95% 区间。**9–17 点平均差 < 0 → 卡片改用极向分量；否则保持风速差。**
  两者各自对「只用均值」的显著性照旧逐小时判定，卡片按所用口径的那一小时标灰或着色。
