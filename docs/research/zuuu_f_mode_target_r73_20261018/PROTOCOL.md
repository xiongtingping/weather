# 第 73 轮：ZUUU 的 F 校准目标由「最小绝对误差」改「桶命中（众数）」——事前协议（打分前提交）

熊先生 10-18：「先把 ZUUU 的 F 校准目标从最小绝对误差改成桶命中（众数）做严格前推对比，只研究不上生产。」

## 起因（打分前已看到的读数，如实记下）
只读重放 ZUUU 38 个结算日（09-04..10-17，F 按各日挂牌时刻 as-of 重算）：raw（各家中位）误差 truth−raw 呈双峰——约一半日子 |误差|<1°C，另一半冷偏 3–5°C。现行 F 把中心整体抬约 +2.2°C，落到两峰之间：F 偏差 −0.70°C、MAE 1.49，但单桶命中只有 16%，而不校准的 raw 是 34%。最小绝对误差的最优常数是中位数，双峰时中位数正好落在两峰之间的低密度区；桶命中的最优常数是众数。**这个读数是提出本轮的原因，所以本轮在 ZUUU 上不是独立检验；全队次要读数（见下）才是对「改目标」本身的样本外检验。**

## 对象
F 的点中心（宪章 267 补记五，`listing_forecast_f.py`），不碰 P0/P0-M/P1、选桶（补记七）和任何车道。只研究，不改生产代码与产物。

## 臂（全部严格 as-of：每个评估日只用该日挂牌时刻 D-2 05:00Z 前可知的预报与已结算真值）
记 raw＝进 F 各家（≥3 家）最新可知轮的当地日最高温的中位；e＝truth − raw；训练集＝本站在评估日前 60 天内、结算时刻 ≤ 挂牌时刻、且当日 ≥3 家的站日。
- **A0 现行 F**：生产链（全队平移 c＋0.5×站修正＋全队三特征最小绝对误差重校准），重校准按挂牌时刻 as-of 重拟。
- **A_med 本站中位平移**：raw ＋ median(训练集 e)。最小绝对误差目标、本站单独拟——与 A_mode 只差目标函数。
- **A_mode 本站众数平移（主臂）**：raw ＋ δ，δ 在 −6..+6°C、步长 0.05 的网格上取「训练集里 |e − δ| < 0.5 的日数」最大者（＝宽 1°C 的箱核众数，即单桶命中最大化）；并列时取并列区间中点里离 median(e) 最近的一个。
- **A_raw**：raw，不平移（参照）。
- **A_Fmode**：现行 F 的 F_base ＋ δ'，δ' 同上取「训练集里 truth−F_base 的箱核众数」，替换全队最小绝对误差重校准（问「留着全队链、只把最后一步换目标」行不行）。
训练集 < 10 日的评估日不进评估（全部臂同一批日子）。

## 桶
该站日实际定价的梯子（`station_day_rungs(prefer_registry=False)`，最新已提交决策的梯子）；没有梯子的日子按整数 °C 桶（[n−0.5, n+0.5)）判并单列计数。

## 指标
1. **主**：单桶命中率（点所在桶＝真值桶）；
2. ±1 桶命中率、偏差、MAE；
3. 配对差（A_mode − A0、A_mode − A_med、A_Fmode − A0）：按事件日 bootstrap 2,000 次（seed 7）95% 区间；不一致对的精确符号检验 p。
4. **次要（全队）**：同一套臂逐站各自拟、各自评，全队所有站日合并，事件日 bootstrap 同上；另报两半日期各自的差。

## 判据
- ZUUU：A_mode − A0 的命中差区间下界 >0 → ZUUU 成立；点估计 >0 但跨零 → 方向一致、未成立；≤0 → 不成立。
- 「改目标本身有用」只看全队 A_mode − A_med：区间下界 >0 且两半同号 → 成立。否则即便 ZUUU 成立，也只算本站特例（且受起因读数污染）。
- 无论结果，本轮不改生产；上线另裁。

## 限制
ZUUU 约 25–35 个可评估日，命中差的区间会很宽；起因读数来自同一批日子；箱核宽固定 1°C、不调。
