# P0 推倒重建：一次分布回归（NGR）对现行 P0 的严格对照（预先登记，2026-10-25）

熊先生 10-25「方案二先实验再重建」：P0 不再走「各家校准 → 线性合成 → SLP 收窄 → 桥/辐射 →
下限 → F 平移」，而是在各家单独校准之后，用一次分布回归把集合与确定性预报合成原始信念。
本文件跑数前提交；跑完不改判据，改动只以补记追加。

## 数据边界（为什么从「各家校准后」开始）

原始集合成员在 SSOT 只存到 08-01，之后只在缓存里，无法严格 as-of 重建 60 天历史。每个 P0
回执都记有 `native_system_probabilities_json`（各家单独校准后的桶向量，宪章 216/247 的单家
证书）与 `system_family_ids_json`。这正是最佳实践的第 0 步「各来源先校准到站点」；本实验
推倒的是它之后的全部层（线性合成、权重、SLP、桥、辐射平移、尾混、压顶、F 平移）。

## 臂

| 臂 | 定义 |
|---|---|
| P（对照） | 现行 P0 含 F：集合服务向量（v31 起读 `pre_shift_probabilities`）＋研究 B 形态的中心回归（逐家去偏、截距、连续提前量权重、LogScore 拟）——即上一实验的 B，在 >36h、12–36h、<12h 三段都施加 |
| N1 | 分布回归，只用集合＋确定性 |
| N2 | N1 ＋ 辐射项 |

N1：对每个已入座家族 f，取其校准向量的分布均值 m_f 与标准差 s_f（桶内均匀、开口桶截一个桶宽）。
- 集合中心 μ_E ＝ Σ π_f m_f / Σ π_f，π_f ＝ exp(β_f)，只在当天入座的家族上归一（β 按家族拟，缺席即不计）。
- 中心 μ ＝ μ_E ＋ a ＋ (w0 ＋ w1·L)·(F − μ_E)。
- 宽度 log σ ＝ c0 ＋ c1·L ＋ c2·log S_E ＋ c3·log(SD_det ＋ 0.2)，
  S_E ＝ sqrt(Σπ_f s_f² / Σπ_f ＋ Σπ_f (m_f − μ_E)² / Σπ_f)（家内＋家间）。
- 分布：正态，按桶界积分（开口桶到 ±∞），1e-3 下限（宪章 224）。
- F、SD_det、L 与上一实验相同（十家逐家去偏中位数，≥3 家；L ＝ (距结算小时 − 36)/24）。

N2：μ 再加 r_w·max(z,0) ＋ r_c·min(z,0)，z 为回执 `synoptic_cooling_json.standardised`（宪章 222 的晴空指数标准分；无则 0）。

## 样本与前推

- 48 站、60 天窗；每站日三段各取首个 P0 决策：>36h、12–36h、<12h。十家确定性 <3 家或无各家校准向量的决策不入样（各臂同一样本）。
- 严格前推：每个打分事件日只用之前的日子拟参数（含 F 逐家偏差与 P 臂的 B 参数）；拟合目标为训练集平均桶 LogScore（L-BFGS-B，β 初值 0，c2 初值 1）。
- 打分：只给 2026-10-01 及以后的决策（宪章 255）。

## 判据（宪章 240）

主比较 N1 − P、N2 − P：LogScore 差（事件日 bootstrap 2000 次）95% 上界 < 0，RPS 与 Brier
不显著变差，≥20 可评事件日。另报 N − A（A＝集合服务向量，不含 F）、分三段、前后两半、逐站符号、
E[z²]、参数轨迹。
