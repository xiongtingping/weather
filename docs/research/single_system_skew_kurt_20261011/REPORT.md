**维持宪章 216，不加按钮。** 按预注册判决，FULL4、MODE4 没有一臂在服务 P0 上同时显著好于 CUR 和 FULL2。加了两个按钮后：

- 单系统层比现役也显著更差（FULL4 +0.0047*、MODE4 +0.0064*）。

拟合出的偏度、尾部约一半时间顶在边界上，中位偏度≈0。它们拟的是训练窗口里的噪声，不是稳定形状。
