# 大账本方案（2026-09-15）

**一句话**：一天一本书。全部站点的篮子放进同一个目标函数、同一份风险预算、同一条覆盖恒等式里做联合优化；单篮不再各自护底，风险由整本书扛；账本、看板、验收只认整本书的覆盖率。

核心指标（用户原话的数学形式）：

    覆盖率 R = Σ(命中篮子的赔付) / Σ(所有篮子的成本)   R ≥ 1 即"命中的收益覆盖未命中的成本"

等份篮子下 R = H / c̄，H 是整本书的篮子命中率，c̄ 是篮子每股全含成本的均值。两根杠杆：抬 H（窗更准）、压 c̄（买更便宜）。

## 1. 为什么"统一优化"有东西可优化

书的期望收益 = Σ_i n_i·(P_i − c_i)，逐篮相加。**没有耦合约束时，联合最优 = 各篮各自最优**，统一优化不会多出一分钱。统一优化的全部价值来自三种耦合：

1. **风险按书量、不按篮量**：单篮的最差结算不再单独护住，整本书的尾部才是约束。这解开了现在压在每个篮子上的四道单篮护栏（地板、等份、2–3 桶窗、单站 2% 上限），让每篮的形状按"每股边际"自由选。
2. **资金按边际分**：资金和成交容量稀缺时，按边际价值/边际方差分配，同气团的站合并计一个头寸。
3. **门槛按书的边际读**：每篮的准入是"加进书里书变好了多少"，含与已持仓的协方差，不是"这篮自己好不好"。

所以方案的实体不是"把 ROI 加总"，而是**把单篮护栏换成书级护栏 + 资金联合分配 + 覆盖恒等式做验收**。

## 2. 方案

### 2.1 一个目标函数

    max  E[ log(1 + PnL_书 / (f·W)) ]
    PnL_书 = Σ_i ( payout_i − C_i )，对当天所有开放站日 i 联合

f = 0.25，W = 资金池余额，W·f 口径承 2026-09-09。小注下按 delta 法展开：

    Σ_i EV_i − Var(PnL_书) / (2·f·W)
    Var(PnL_书) = Σ_i Var_i + Σ_{i≠j 同气团块} Cov_ij

同气团块内按完全相关计（承配置器的"括号"设计：块内先加再平方），块间独立。不估 45×45 相关矩阵。

### 2.2 决策变量（联合）

对每个开放站日 i：窗 B_i（任意桶集合，不要求连续、不要求 2–3 桶）、每桶股数 n_{i,b}（不要求等份）、每腿挂价（买一锚定阶梯，逐腿不变）。

### 2.3 约束（全部在书级）

| 约束 | 内容 | 取代的单篮规则 |
|---|---|---|
| 资金 | Σ_i C_i ≤ ρ·W（ρ 现值 25%） | 单站 2%×阶段份额上限（第 72 条） |
| 尾部 | CVaR_α(PnL_书, 当日) ≥ −κ·W，α = 10%，κ 待裁（建议 5%） | 单篮地板 q_min ≥ 1.05·C（第 37/38/41/93 条） |
| 集中 | 单站 ≤ 25% W，单气团块 ≤ 50% W，单结算窗 ≤ 25% W | 保留，即现有 Tier-1 外墙 |
| 合法性 | 价格 < 1、交易所整手与 $1 底线、只买不卖 | 保留（第 70/83 条） |
| 形状 | 无 | 三态席位、2–3 桶、等份、命中保护（第 131 条） |

### 2.4 准入与定注（每篮读书的边际）

篮子 i 以其最优形状入书，当且仅当

    ΔObj_i = EV_i − [Var_i + 2·Cov(i, 在途书)] / (2·f·W) ≥ h·C_i     h = 5%（第 130 条的门槛，改读书的边际）

股数闭式：n_i* = f·W·(P_i − c_i − 协方差项) / Var_i(每股)，再受资金与尾部约束缩放。这就是把现在的"整篮二元 Kelly"换成"含协方差的联合 Kelly"。在途很小时两者数值几乎相同；接近资金上限或同气团重仓时才分开。

### 2.5 形状自由意味着什么（示意数字，不是读数）

KLGA 某日三桶：28°C 市价 0.15 / 模型 0.20，29°C 市价 0.45 / 模型 0.42，30°C 市价 0.18 / 模型 0.22。

| 形状 | 每股成本 | 命中概率 | 每股边际 | 期望覆盖率 |
|---|---|---|---|---|
| 三桶等份（现规则） | 0.78 | 0.84 | +0.06 | 1.08 |
| 只买两翼 | 0.33 | 0.42 | +0.09 | 1.27 |

两翼形状命中率低一半、单篮更容易归零，但每一美元的期望覆盖更高。单篮视角拒绝它（地板不过、命中保护不过）；书的视角接受它，因为 40 个站的归零与命中在书上互相抵消，尾部由 CVaR 约束和 Kelly 缩注管。这就是"整篮命中的收益覆盖未命中篮子的成本"在形状上的含义：**书允许更多篮子归零，换每美元更高的赔付**。

### 2.6 执行层（一个目标贯穿三阶段，读书不读篮）

- 每周期先铸一份**书状态**：W、在途按站/块/窗、当日 CVaR、已持腿（沉没）。
- 逐 scope 编译时读书状态做**边际优化**（贪心坐标上升 = 联合优化的顺序实现，不用重写轮转）；scope 服务顺序按边际价值/美元排序，用现有轮转键里的 quota 钩子。
- **部分成交不是残篮，是小头寸**。补腿、撤单、加仓统一为"以已持腿为沉没成本，重跑边际检验"：ΔObj ≥ h·ΔC 则买，否则不买；已持仓不因形状不完整而被迫补齐。第 136 条的"本链最差结算"不再是判据。
- 挂价逐腿不变（买一锚定阶梯、GTD+post-only 建仓、FOK 补齐）。
- 配置器改为**每周期对全部可见站算一次**，不再一次一站。

### 2.7 站点的角色

- 站点不再有自己的盈亏门槛：不按站 ROI 禁入、不按站 ROI 放行。
- 保留**结构性禁入**（结算源不可用、数据链缺、挂牌规则异常），作为操作员开关。
- 观察期（5 次结算）从"禁入"改为**缩注**：新站前 5 次结算注额 ×0.5。
- 站点差异只通过概率向量的站级校准进入书，不通过账本。

### 2.8 账本（生产与账本同步改）

- 纸面账本新增臂 `book_v1`：一本资金池顺时间走（`paper_flow_ledger` 的走法升为评分路径），生产信息集（第 80 条），指纹随规则移动，旧读数不可比。
- 表头四个数：覆盖率 R、命中率 H、每股成本 c̄、书级 PnL；辅以书级 CVaR 实现值、按气团块 PnL、在途按站/块/窗。
- 按站表只作诊断，永不作门。
- 现役臂与 `book_v1` 在**同一批站日、同一信息集**上重放对照。

### 2.9 看板

新增"大账本"版面置顶：R（当日/7 日/全史）、H、c̄、期望 vs 实现、书级 CVaR、在途按站/块/窗、W 曲线与回撤。这就是用户要求统一的四个数（结算收益、单腿暴露、单站暴露、整本盈亏）。按站表降到版面下方。

## 5. 落地顺序与验收

1. **账本臂先行（不动生产）**：内核加 `PM_BOOK_MODE=book_v1` 开关（默认 off），实现书状态、边际准入、联合 Kelly、CVaR 约束；纸面账本臂在 08-15 起的候选窗历史上按生产信息集重放；产出 R、H、c̄、书 PnL，与现役臂同站日对照。
2. **无冲突项先落**：配置器改全站一次（今天不改任何读数）；看板大账本版面。
3. **验收**：≥ 300 站日（历史重放 + 前向），`book_v1` 的实现覆盖率 90% 下界 ≥ 1.0，且同站日 PnL 优于现役臂。两条同时满足才升生产。
4. **升生产**：`PM_BOOK_MODE=book_v1` 上线，账本指纹同步移动，旧条款加退役标注，观察期改缩注，重启常驻并核对进程启动时间。

**已知风险，由臂来量，不预设结论**：形状自由会把买入压向便宜桶；便宜桶的成交是否被逆选择吃掉、其结算率是否达到模型概率，是这条臂要回答的第一个问题。臂说不覆盖，方案就不升生产。

## 6. 白话版

现在是 45 个站各开一本小账，每本小账都要求"自己这篮就算只中一个桶也不能亏"，所以每篮都得把最贵的中心桶买满，贵桶挤掉了便宜桶的赔率。大账本是把 45 本合成一本：每篮只买"值"的桶，允许一部分篮子归零，靠整本书的命中把归零的成本盖住，尾部风险由整本书的一条线（CVaR）管，注额由整本书的 Kelly 管。验收只看一个数：整本书命中篮子的赔付除以所有篮子的成本，过 1 才算覆盖。现在这个数是 0.76。
