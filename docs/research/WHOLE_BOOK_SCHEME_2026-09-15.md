# 大账本方案 v2（2026-09-17 重估；v1 2026-09-15）

**一句话**：一本在途书。全部站点的篮子共用一个目标函数、一份风险预算、一条回本恒等式；**书的大小由书自己的实测回本比定，篮子的声称只用来排序**；单篮不再各自护底，风险由整本书扛；账本只做规则对比，钱一律读实盘。

回本恒等式（用户原话"整篮命中的收益覆盖未命中篮子的成本"的数学形式；不叫"覆盖率"，看板上那个词已经指"窗口盖住真值"）：

    回本比 R = Σ(命中篮子的赔付) / Σ(所有篮子的成本)      R ≥ 1 即覆盖

等份篮子下 R = H / c̄（H 命中率，c̄ 每股全含成本均值）。

## 1. 统一优化能优化什么（不变的数学，变了的约束）

书的期望收益 = Σ_i n_i·(P_i − c_i)，逐篮相加；没有耦合时联合最优 = 各篮各自最优。v2 的耦合有四种，前两种是今天就在咬的：

1. **资金**：书在上限上，13 个站日/天用满账户，谁被编译到谁拿钱。
2. **书的实测回本比**：每篮的声称都说"有边际"，书的实测说 0.82。书的大小该由后者定。
3. **风险按书量**：单篮护栏（地板、等份、2–3 桶、原子性）换成书级 CVaR。
4. **协方差**：同气团块内先加再平方，块间独立。

## 2. 方案 v2

### 2.1 一个目标函数（基线 L6 原文）

    max  E_draws[ log(1 + Σ_a f·s_a·(payout_a − C_a)) ]     f = 0.25，联合抽样含跨站相关

小注下展开为 Σ_i EV_i − Var(书)/(2·f·W)，块内完全相关、块间独立（基线 L6 的失败方向：相关缺失按完全相关）。W = min(真实权益, 预算旋钮)，即宪章 141 的本金。

### 2.2 书的大小读书自己（v2 的核心改动）

    ρ = 总敞口上限（占本金的份额），由书的实测回本比定：
      R_LCB ≥ 1 + h            → ρ = ρ_max（旋钮值，现 0.9）
      R_LCB ≤ 1                → ρ = ρ_取证（建议 0.15：每天约 3 个站日，够继续量）
      1 < R_LCB < 1 + h        → 线性插值
    R_LCB：实盘已结算站日、全站池化、滚动 14 天、90% 下界；h = 5%（第 130 条的门槛）

这就是整本书的 Kelly：定书的大小的 edge 是书实测出来的 edge，篮子的声称只排序。它把宪章 141 的 −20% 熔断悬崖改成连续旋钮，熔断留作外墙。**今天的后果要说清**：R = 0.82 时 ρ = 0.15，书从 78 缩到约 13 USDC。这不是副作用，这就是"不追求单站盈利、追求大账本盈利"在定注上的含义：一本量出来不回本的书不该满仓。

### 2.3 书内怎么排（资金在咬时的顺序）

- 每周期先铸一份**书状态**（内存）：W、按成本的在途（分站/块/窗）、当日 CVaR、已持腿（沉没）、R_LCB、ρ。
- 可服务 scope 按**边际价值/美元**排序：(b_窗 − c)/c − 协方差项；轮转的日级防饥饿保证不动，排序只在合格集合内。
- 配置器改为每周期全站一次，配额 = 上式；不再一次一站。

### 2.4 书读的信念（形状自由的自锁）

- 准入、排序、形状一律读 L4 的 b；L4 未晋升时 b = m（市场向量），这是基线 §4.4 的规定。
- 桶进窗的条件：b_桶 > c_桶。b = m 时没有桶能过（m 就是价），所以**形状自由在信念层拿到前瞻技能分下界 > 0 之前自动不生效**。v1 的"只买两翼"示例只有在 L4 说两翼真的比价高时才会出现。
- 这条把 v1 最大的风险（把买入压向便宜桶）交给信念层的晋升规则，而不是交给一条形状规则。

### 2.5 约束（全部在书级，且**按成本**）

| 约束 | 内容 | 取代 |
|---|---|---|
| 敞口 | 按成本的在途（已成交未结算 + 在挂）≤ ρ·W | 141（四）按市值比的敞口 |
| 尾部 | CVaR_10%(书, 下一结算窗) ≥ −κ·W，κ 待裁（建议 5%） | 37/38/41/93 单篮地板 |
| 集中 | 站 25%、块 50%、窗 25%（现值） | 保留 |
| 单站日 | 141 的定注 5% / 上限 8% 作为外墙保留 | — |
| 合法性 | 价格 < 1、整手、$1、只买 | 保留（70/83） |
| 形状 | 无（受 2.4 的信念门自锁） | 131 |

### 2.6 执行层（读书不读篮）

- 部分成交是头寸不是残篮；补腿、撤单、加仓统一为"已持腿沉没，重跑边际检验 ΔObj ≥ h·ΔC"。143 v2 的"只补发过单的腿、≤ 原量"在 book 模式下是这条检验的一个特例（不发过的腿 b 不会过价），方向一致。
- 挂价逐腿不变；单型规则按基线 L7。

### 2.7 站点

- 不按站盈亏禁入或放行；自动禁入层（09-16 起读实盘）在 book 模式下退役，其两把钥匙（兑现比、实得差）改作站级校准输入。
- 结构性禁入保留为操作员开关；观察期改缩注 ×0.5。

### 2.8 账本与看板（按 09-16 裁决）

- 表头四个数读**实盘**：R、H、c̄、书级 PnL；辅以按成本的在途（分站/块/窗）、当日 CVaR、ρ 与 R_LCB、W 曲线与熔断线。这就是用户要求统一的四个数（结算收益、单腿暴露、单站暴露、整本盈亏）。
- 纸面账本只出**规则 A 对规则 B**：现役 vs `book_v1`，同站日、同信息集（第 80 条），指纹随规则移动。
- 不新增逐周期表（SSOT 在上限上）：书状态在内存，快照表加三列（按成本在途、R_LCB、ρ_served）。

## 5. 落地顺序与验收（v2）

1. **今天可落、无需裁决**：看板"大账本"版面（四个数读实盘）；配置器全站一次；快照表加三列。
2. **裁决后第一刀（冲突 1）**：敞口上限改按成本比。以今天的数，按成本在途 108.9 已超 78.3，落地即停新单直到结算腾出额度。
3. **第二刀（冲突 2、3）**：ρ 读 R_LCB。今天会把书缩到 ρ = 0.15。
4. **账本臂 `book_v1`**：现役 vs book 同站日重放，出 A 对 B；不出表头数。
5. **形状自由与地板退役（冲突 5、6、14）**：等 L4 晋升（基线 E15：前瞻技能分下界 > 0）之后才有效，之前是空转臂。
6. **验收**：书级用实盘 R_LCB ≥ 1（滚动 14 天）；样本量按基线 §7：N_eff ≥ (z·σ/δ)²，σ 取每日回本比之差的标准差，不按行数。

**已知风险**：（一）ρ 读 R_LCB 有反馈环——书缩小后 R 的样本变少、下界变宽、更难回到满仓；解法是 ρ_取证 不能低于能在 14 天攒够 N_eff 的规模，这个数由基线公式算，不拍脑袋。（二）形状自由压向便宜桶的风险由 2.4 的信念门承担，不由本方案另立规则。

## 6. 白话版

现在 45 个站各开一本小账，每本都要求"自己这篮只中一个桶也不能亏"，所以每篮都得把最贵的中心桶买满。资金层上周还是虚构的池子，这两天换成真实余额之后，书已经顶到了敞口上限，权益一天从 103 掉到 88，谁先被编译到谁拿钱。大账本 v2 做三件事：**书有多大由书自己实测的回本比定**（现在 0.82，所以书该缩到取证规模）；**钱先给边际价值最高的篮子**，不按轮转顺序；**单篮护栏换成书的一条线**，但"只买值的桶"这件事要等信念层先证明它认得出哪些桶值，之前书读的信念就是市场价，什么都不多买。验收只看一个数：整本书命中篮子的赔付除以所有篮子的成本，过 1 才算回本。
