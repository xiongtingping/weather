# P0 远端宽度：距结算＞36h 单独一个 λ，现役算术下严格前推（计算前写定，2026-09-27）

熊先生：「评估logscore校准是否好」→「继续」。上一轮评估里，Proper 线下单窗口（P0 首决策，距结算＞36h）的峰值格过度自信：承诺 35–50% 的格实际少 3.6 个点，≥50% 的少 7.3 个点。09-24 研究（`high_bin_overconfidence_20260924`）把 P0 高概率格过度自信定位到宽度层统一收窄（λ=0.75），且提前量越长越重；当时按提前量分档的 λ 在「LogScore＋CRPS」口径下没过。第 211 条之后，判据换成桶 Brier 与 LogScore，算术也换成了 216＋219＋224，这一轴没有在新口径下测过。本研究只测最小的一种改法：＞36h 单独一个 λ，近端不动。只读研究，生产未改。

## 数据（仓库内，不重跑回放）

- `width_lambda_recheck_20260925/pass1`：60,494 次更新，每次在 λ∈{0.60, 0.70, 0.75, 0.80, 0.85, 0.90, 1.00} 下的精确（桶 Brier, LogScore）。现役算术（六家全链、修正训练集、第 216 条拟合），其余服务层照该小时的表，11 格开口梯子，过第 224 条 1e-3 下限。
- `p0_replay_219x216_20260925/pass1`：同一批更新，按（站, 事件日, 时刻）逐条对上（已核：60,494 对 60,494）。提供时区、真值到库时刻，以及 `ll_on` 照表服务向量。照表的意思是：09-03T22:15Z 之前没有在任宽度表（恒等），之后 λ=0.75。
- 距结算小时数 h：同生产 `settlement_time.hours_to_settlement`，即事件日在结算时区的日终减决策时刻。已核：h 的最大值是 70.8。

## 臂

- **基线 B**：全部更新 λ=0.75，即今天的服务表。
- **主臂 F**：h≤36 仍用 0.75；h>36 用 λ_far(d)。
  - λ_far(d) 的取法：只用真值到库早于 T_d 的更新，T_d 是检验日 d 全部更新里最早的决策时刻。在这些更新中取 h>36 的，在网格上按 LogScore（站日等权）取最小；并列时取离 0.75 近的。
- **副臂 G（只报不判）**：全部更新共用一个 λ(d)，取法同上，只是在全部更新上选。用来区分「远端单独一个 λ」与「整体重选一个 λ」。

## 检验期与判据

- 检验日：事件日 09-01..09-23，与 λ 复查同一检验期。
- 判定面板：检验期内 h>36 的全部更新，站日等权；按三日块对事件日自助 2,000 次（seed 20260927）。
- **成立**（第 211 条）须同时满足：
  - F 对 B 的 ΔBrier 与 ΔLogScore 都 <0，且两个 95% 区间上界都 <0；
  - 前后两半（09-01..09-12、09-13..09-23）两项的点估计都 <0。
- 否则不成立，不提改。
- 只报不判：
  - 首决策子切片（每站日第一次更新，且 h>36）；
  - h≤36 面板（F 与 B 逐位相同，应恒为 0，用作核对）；
  - 副臂 G 在全部更新上的读数；
  - 每个检验日选出的 λ_far。

## 三项校准读数（只报不判，先过保真门）

- **向量重建**：拿 `ll_on` 照表服务向量，按宽度层自己的搬运规则重算。规则同 `center_width_calibration.center_width_adjusted_grid` 的内点规则：位置 = 均值 + (格心 − 均值)×λ_rel，质量按线性分到相邻两格。其中 λ_rel = λ ÷ 该小时的表 λ，无表时表 λ 按 1.0 计。
- **保真门**：在判定面板上逐个网格 λ 比较重建与精确的面板层 Δ（λ 减 0.75）：
  - LogScore 允许差 max(0.2×|精确 Δ|, 0.002)；
  - Brier 允许差 max(0.2×|精确 Δ|, 0.0005)；
  - 任一 λ 超出，就不报 PIT／reliability，只报两个分数。
  - 逐条的平均绝对差另报，不作门。
- **读数**：口径同上一轮。
  - 随机化 PIT 取期望，分 10 格，报最大偏离与平方和；
  - Murphy reliability 与 ECE，5% 分箱，封顶 50%；
  - 承诺 35–50% 与 ≥50% 两档的「实际 − 承诺」。
  - 折到同一副 11 格开口梯子，中心取照表服务向量的均值取整（与 λ 复查一致），过 1e-3 下限。
- 同时报 B 在今天算术下的这些读数（全部更新都按 λ=0.75）。它更正上一轮混了有表、无表两个时期的「现役」读数。

- 网格上限 1.00。λ_far 选到 1.00 时记为「顶格」，不外推。
