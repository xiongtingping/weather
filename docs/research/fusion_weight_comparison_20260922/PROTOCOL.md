# 多系统权重：独立比较协议

Goal：复用冻结日前服务包，比较现行权重、等权、最近 3/5 日准确度加权、站点向全队收缩、受约束直接优化；区分中心筛查与服务概率验证，交付可复核结果和上线条件。生产不动。

本协议在本轮候选计算前写入。旧数据的 09-12 至 09-19 已被此前 TAF 研究查看；本轮属于回顾性走查，绝不冒称新盲测。其他会话 `fusion_weights_20260922` 的文件不改动，其重建历史在独立审计前不作主证据。

输入复用 `../p0_physical_20260920/samples.json`：实际物化的日前中心和权重，每站日一个截止本地零点前可用的包。样本因既有研究要求 TAF 到达而被筛选，因此不代表所有 P0 包。仅非 ASOS、已核对 canonical truth 的范围进入主分析；美国 ASOS 标签未绑定唯一历史赢家时单列缺口。使用当前五系统许可集合；维持每行原有系统集合和家族上限，缺系统不填造。

训练标签仅在 `truth_known_at <= 当时决策时间` 时可用；当前冻结版本未到达则整行暂不训练，不借首版到达时间使用末版温度。训练预报本身也必须早于决策。历史中心沿用各包当时结果，不用今天校准件重算。实际市场几何和量纲沿用原包，中心评分统一 °C。

主评估期 2026-08-28 至 09-19，之前数据作暖启动；全部候选同一批样本。3/5 日指目标站决策时刻当地日期之前的 3/5 个日历日，且真值已知；不足即按规则回退，不用最近 N 条记录悄悄扩窗。每个训练行对当日参与系统必须全员配对。最近 21 日作较慢对照。

固定候选（未经外层挑参）：现行；按模型等权（投影家族约束）；站点 3/5/21 日倒 MSE；全队 5/21 日倒 MSE；站点 3/5 日向现行收缩，混合系数 n/(n+10)；站点×提前量 21 日 MSE 向全队相同提前量收缩（10 个本地样本等效强度）；站点 21 日直接优化中心平方误差并向现行 L2 收缩（正则系数 1°C²），及等价原点残差二阶矩优化。最后二者数学相同，不重复记作两项发现。

倒 MSE 下限为 0.25°C²，以免一两个近零误差获得无限权重；权重非负、和为 1，按当行家族上限投影。短期无配对样本时回退现行；多维度全队先验不足也回退现行。短期 3/5 日只给弱调整，不额外探索季节×天气×站点×起报时次硬分格。

主指标：中心 RMSE/MAE/bias；权重周转与极端集中；逐站、逐日、系统分歧/共同偏冷/偏暖切片（后两者只作事后诊断）。配对的连续 3 日 moving-block bootstrap，保留同日跨站相关，95% 区间只作探索性描述，不作多重检验后的晋级依据。另做前后半窗、站点胜率与最大影响站检查。

概率层只有当历史单系统分布以及完整后处理可忠实还原、原权重能复现历史服务输出时才报告“服务 CRPS/NLL 改善”。只有中心时，不能给各候选套同宽高斯冒充原分布，也不能把中心指标替代概率指标。单系统线性池 CRPS 优化是下一候选：在 simplex/家族约束下最小化样本 CRPS + 向稳定权重正则；最终必须经原下游桥接、物理、中心宽度、band 层验证。

计算前补充：源审查恢复了 516 个非 ASOS 样本的全员单系统分布：使用归档成员及历史 lineage 精确 hash 对应的参数，每家恢复中心与历史中心误差不超过 1e-7°C。可在这一子集计算**后处理前线性池**的离散 CRPS/NLL，并加入固定正则 1°C、最少 5 个本地已知标签的 `crps_stack21`。其比较基线是原权重的线性池，不是最终 P0；原运行代码及完整下游尚未历史复现。开尾桶用市场有限桶中位宽度延伸半桶得到代表点；因此 CRPS 是离散代表点代理，不是连续尾部分布 CRPS。NLL 零命中单列，完整 NLL 应为正无穷，不可删零后说完整分数。未能绑定 canonical winner 的两行（MMMX 08-31、RKPK 08-17）也从训练和评估移除。

研究只读 SSOT，不重启、不下单、不晋级；每进程 RSS 384 MiB、300 秒、目录输出 32 MiB、剩余磁盘 2 GiB、查询只读且有索引/进度超时。任何数据缺口保留为缺口。

首轮结果后的探索性扩展（不可冒充预注册主候选）：单站 CRPS 拟合 93.7% 的评估行回退，故追加 `crps_hier21`，检验样本借力能否解决训练不足。先用全队相同提前量配对分布做 CRPS 拟合（缺该维度则全队配对），L2 向当行现行权重收缩，系数 1°C；再用本地数据拟合、向全队权重收缩，正则 10/n°C。无本地数据用全队，无全队或当前分布缺失用原权重。此臂仅作架构可行性研究，不能根据本窗成绩调参后宣称验证通过。
