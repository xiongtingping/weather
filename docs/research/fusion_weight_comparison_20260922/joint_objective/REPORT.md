# 中心优势与分布优势能否组合？

熊先生，可以。本轮预先指定的 **50:50 权重组合**，在同一批 515 个历史站日上，相对现行权重实现 RMSE −0.38%、CRPS −0.28%、NLL −0.21%。这足以保留为明确候选，但还不能宣称未来稳定三降或上线过闸。

## 正确组合方式

令 w_C 为上一轮“中心误差＋正则”的权重，w_P 为上一轮“分层 CRPS”的权重：

\[
w_*=0.5w_C+0.5w_P,\qquad F_* = \sum_m w_{*,m}F_m.
\]

一个站日只产生一套 w_*；中心按相同权重组合原校准中心，概率按相同权重组合原单系统分布。由于气候混合和桶代表点，原系统校准中心未必等于离散概率均值，本轮保留原中心指标定义，未偷换为另一种 RMSE。实际生产仍需验证后处理后的服务中心与分布。

两端权重均满足非负、归一和家族上限时，它们的凸组合自动保持这些约束；完整激活、至少两个独立正权重系统及来源资格仍须走生产合同。并不新增 P0/P0-M/P1 阶段或叠加中心/宽度修正。

## 共同分母上的结果

全部三指标都使用 515 条、33 个非 ASOS 站、2026-08-28 至 09-19 共 23 日。上轮 RMSE 用 604 条，因此本轮数值应与本表基线比较。CRPS/NLL 仍为后处理前线性池；原中心和恢复分布沿用上一轮冻结证据，没有重新取今天参数。

| 候选 | RMSE（°C） | 线性池 CRPS（°C） | NLL | 相对现行变化：RMSE / CRPS / NLL |
|---|---:|---:|---:|---|
| 现行 | 1.283902 | 0.662243 | 1.584997 | 基线 |
| 中心误差＋正则 | 1.276113 | 0.660667 | 1.584723 | −0.607% / −0.238% / −0.017% |
| 分层 CRPS | 1.284625 | 0.661270 | 1.579986 | +0.056% / −0.147% / −0.316% |
| 中心 25%＋分布 75% | 1.281492 | 0.660686 | 1.580667 | −0.188% / −0.235% / −0.273% |
| **中心 50%＋分布 50%** | **1.279026** | **0.660390** | **1.581672** | **−0.380% / −0.280% / −0.210%** |
| 中心 75%＋分布 25% | 1.277232 | 0.660384 | 1.583013 | −0.520% / −0.281% / −0.125% |
| 三指标联合优化 | 1.286780 | 0.662233 | 1.578242 | +0.224% / −0.002% / −0.426% |
| 联合优化＋训练三项不劣约束 | 1.286815 | 0.661740 | 1.577170 | +0.227% / −0.076% / −0.494% |

25%/75% 仅是预先固定的敏感性检查；没有根据本窗挑选最优比例。50:50 是本轮计算前指定主组合，不把 75% 在某列略胜视为改参数的理由。需要更细 α 或随站点变化的 α 时，必须用较早的内层数据选择，再在未用于设计的历史外层验证。

在共同分母上，“中心误差＋正则”本身也已经平均三降，只是 NLL 改善几乎为零。50:50 保留了部分中心优势，同时放大 NLL 改善；并非每项都超过两端各自最好的成绩。它的 CRPS 略优于两端，RMSE 逊于中心端，NLL 逊于分布端。

## 为什么平均能更好

对相同真值，中心平方误差、CRPS 和 NLL 对这种凸组合都是凸的，因此每条样本有：

\[
L(F_*)\le 0.5L(F_C)+0.5L(F_P).
\]

对 RMSE 应先在平方误差层使用此式，再汇总开根；不能把两个 RMSE 直接当训练损失相加。中心平方误差的组合收益恰为 0.25×mean[(e_C−e_P)²]。这解释了两端互补时为什么可获得额外收益；**该不等式约束的是与两端平均相比，无法保证比现行基线更好**。

本轮 4,635 项逐样本 Jensen 检查、4,120 项独立 CDF 积分评分检查均通过；训练目标梯度、预测标签污染不变性和家族约束也经过复核。没有零概率命中，NLL 未删零或用 epsilon 改写评分。

## 为什么不优先选更复杂的联合目标

联合候选使用 MSE、CRPS、NLL 各按训练参考损失归一后等权，加分层正则；训练不劣臂还把三项训练损失分别约束在当前权重以下。476 行有可用训练数据，39 行按协议回退；拟合无优化器失败。

然而两项联合候选都让本窗 RMSE 恶化约 0.22%。这不是目标算错，而是总损失最小允许指标间交换，训练集上的逐项不劣也不能约束未知的未来误差。当前证据更支持保留简单的 50:50 组合作为下一验证对象。

## 稳健性与边界

- 50:50 的总体三项下降，在逐一剔除任一站后仍保持，说明收益不是单个站独撑。
- 但只有 11/33 站各自实现三降；总体三降不等于每站都三降。
- 前半窗：RMSE −0.816%、CRPS −0.385%、NLL **+0.0266%**。后半窗：−0.022%、−0.207%、−0.361%。所以尚未跨时段稳定三降。
- 连续三日块 bootstrap 的 50:50 差值 95% 区间：RMSE [−0.009389, +0.001882]°C；CRPS [−0.003877, +0.000203]°C；NLL [−0.007964, +0.001549]，均跨零。
- 同一批重采样中约 80.9% 同时三降。这只是该探索性样本的重采样描述，不是未来成功概率、p 值或晋级通过率。
- 这批历史已用于发现两个端点，本轮候选属于探索性组合；内部预测计算遵守 as-of，但整体研究过程不是独立未见外层。TAF 选样、ASOS 标签缺口和完整服务链尚未复现等前轮限制全部保留。
