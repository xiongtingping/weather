# 中心与分布优势组合：计算前协议

目标：验证同一批站日、同一模型集合下，RMSE、线性池 CRPS、完整 NLL 能否同时低于原权重。生产不动；本轮是已查看历史上的探索性追加，不能称全新盲测或晋级证据。

输入为上一轮冻结样本及权重，禁止重新抽取生产数据、用今天参数更新过去。主分母固定为具有全员恢复分布的 515 个评估站日，原来中心 RMSE 的 604 条不再与 515 条概率分数拼在一起。保持原 bucket 几何、中心定义、家族上限、当时可知标签与日历窗口。

候选：
1. current / center_stack21 / crps_hier21 三基线，在共同分母上重算。
2. 固定权重凸组合：w=α w_center+(1−α) w_hier，α=0.25/0.50/0.75；50:50 是预先指定的主要组合，另两项只作敏感性，不从外层择优。
3. 三指标联合分层优化：21 日全队（优先同提前量）先验，再用站点数据收缩；目标是 MSE、CRPS、NLL 各除以同训练行上当前权重的参考损失后等权相加，加 L2 正则。分母设下限 MSE 0.25°C²、CRPS 0.1°C、NLL 0.1，避免极小尺度主导。全队正则 1，本地 10/n；无本地用全队，无可用全队回退 current。模型概率不足或训练目标含不可修复全零真值桶则回退并记账；不删零分数。
4. 同一联合目标加训练集三项不劣约束：各项平均损失≤当前权重在这些训练行的平均损失。当前权重为可行起点；约束只保证训练集，不能宣称未来三项不劣。

所有候选冻结规则后计算；不根据外层成绩调 α、损失系数、正则或窗口。联合优化只能用当时已知训练标签；预测函数不得读待预测行 truth。全队样本按站日平均，此轮尚未改成每站/天气事件等权，需保留跨站相关性限制。

评估：三指标配对变化、共同分母上的两端点、前后半窗、逐站去一稳健性、零概率命中计数、平均权重变化。用同一批连续三日块 bootstrap 同时计算三项差值；报告各自区间及三项共同小于零的重采样比例（不是成功概率/检验 p 值）。明确区分样本均值三降与稳定样本外三降。

方法校验：凸组合保持 simplex/家族约束；逐样本 MSE、线性池 CRPS、NLL 均满足 Jensen 上界；独立 CDF 积分复核评分；归一化目标梯度有限差分；真值未可知边界与待预测标签污染不变性；独立复算汇总。不把三项简单加法的最小值当作三项都降低的保证。

资源：复用前轮 Guard，RSS 384 MiB、单阶段 300 秒、输出 32 MiB、剩余磁盘 2 GiB。仅写本研究子目录。最终服务 P0 的完整后处理仍未复现，研究指标不越界宣称服务收益。
