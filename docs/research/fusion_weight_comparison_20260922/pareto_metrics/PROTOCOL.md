# 冻结三候选：桶概率质量与可兑现价值

本轮固定三个候选为 center:hierarchical = 25:75、50:50、75:25（上一轮 blend25/50/75），沿用上一轮逐站日权重，不重训、不换比例、不增删候选。current 为共同基线。样本严格沿用具有完整恢复分布的 515 个站日；不得因某候选表现或报价有利而改变分母。

用户称 OOS 的这批数据，其每次训练确实只用当时可知标签，但候选设计已经查看该窗，故本轮必须标为 retrospective_asof_comparison，不称独立未见 OOS。新增指标不能改变这一资格。正式晋级仍需未参与设计的历史外层和完整服务链。

主概率指标：多类别 Bucket Brier = 每站日 sum_b(p_b−1{y=b})²，先按站日计算再等权平均，不除以 2；LogScore = mean log(p_truth)，越高越好；NLL = −LogScore，零命中为无穷损失，不删零。两端开尾桶用原真实合同映射真值。

Reliability/Resolution 使用明确的 one-vs-rest 校准事件：每站日权重 1/N，再均分该日 K 个桶，故每个桶事件权重 1/(N K)。这对应“每站日平均单桶 Brier”，不是上面的总 Bucket Brier。概率分档固定 [0,.01,.025,.05,.1,.2,.3,.4,.5,.6,.7,.8,.9,1]；另用固定 10 档/20 档作敏感性检查，不用结果选分档。

用各档加权平均预测 p̄_g、发生频率 ȳ_g：REL=ΣW_g(p̄_g−ȳ_g)²，RES=ΣW_g(ȳ_g−ȳ)²，UNC=ȳ(1−ȳ)。报告 BS_original = REL − RES + UNC + binning_correction；分档内原概率不恒定，correction 不得省略。分解描述本评估样本，未将这些真值频率反灌预测。分档移位、有限样本和不同桶数会影响 REL/RES，不能把小幅更高 RES 直接解释为稳定新增信息。

统计：共同日期块 bootstrap（连续 3 日、4000 次）比较 Bucket Brier 和 NLL；Reliability/Resolution 在同一日期重采样下重新分解；前后半窗一致性。三候选固定，区间只描述已看历史，不当晋级依据。

经济证据先审查：每站日以原预测实际可用时点为 as-of，查官方 CLOB WS 快照，必须满足 observed_at、quote_observed_at、created_at 均不晚于决策且 quote_expires_at 晚于决策；同一 bucket/token 合同、原始 ask 深度、费用、最小份额、有效报价、资本/库存/订单状态与固定策略均可核验才允许进入经济共同子集。严禁使用后来盘口、mid/last 替代 ask、假定 Maker 成交或虚构固定本金。

可兑现 EV 指同一执行规则下、真实可用 ask 深度及费用后构成的情景收益曲线在预测分布下的期望；必须同时报告结算实现的 PnL 与 log(实际期末净资产/期初净资产)。候选自报 EV 不能用于证明候选盈利。独立站日 log 不能在资本重叠、跨站相关和持仓尚未结算时直接相加冒充组合财富增长。无反事实真实成交证据时最多是可执行盘口的离线反事实，不能称实际成交收益。

经济层如缺关键证据，返回 NOT_IDENTIFIED 和缺口计数，不填 0、不从概率分数推导收益、不报告伪实际 EV。完整 515 条概率比较照常完成；经济可比子集单列覆盖率，并对三个候选使用完全相同的资格过滤。

执行时点补充（在计算任何经济损益前固定）：精确预测发布时点的初查只有 3 条完整盘口；同步要求会把正常“预测发布后等待盘口”排除。因此单列一个可部署的等待口径：保持原预测及权重不变，只在发布后最多 300 秒、原 P0 有效期内且本地事件日开始前，取**第一份实际已到达且仍有效的完整官方快照**；可用时点为 snapshot/created/quote/book/cash 各时钟与预测发布时间的最大值。旧快照若在发布时仍有效可直接使用。不得等到更有利价格、不得延长到观察到成交才选时点。该延迟执行子集不冒充全部 515 条，同时保留精确时点审计。之后仍须费用、资本、库存、订单状态和固定执行政策过关；这一步仅修正执行时点资格，不是放松真实成交要求。
