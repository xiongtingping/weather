# 冻结三候选的执行条件经济回放（2026-09-23）

**结论：四个臂全部亏钱，候选只让亏损少一点；亏损的来源是模型比市场差 0.24 nat，权重改动只挪动 0.01 nat，量级差 20 倍，换权重翻不了 EV 符号。**

资格：`execution_conditioned_replay_pool_stage`——后处理前线性池 + 发布后 300 秒内第一份真实官方盘口 + 生产费用合同（`runtime.py` fee_rate=0）。不是完整服务 P0，不是实际成交。协议见 PROTOCOL.md（算之前写定）。

## 样本

## 三个要点

1. **自报 EV 与实现收益完全脱节**：自报 ROI +185%，实现 −45%。按卖一价分档：卖一 <5¢ 的桶，池给 1.1%～6.4%，实际命中 0%～0.8%；卖一 ≥50¢ 的桶，池给 35.5%，实际命中 57%。市场自己基本校准（命中≈卖一）。**池化入口的分布太宽**——尾部说多了、热门桶说少了——门槛吃单因此 73% 的腿买在 <5¢ 的长尾上。这是 Reliability 问题，不是权重问题：四个臂的池宽（1.606°C）几乎相同。
2. **候选的相对改善在这 152 天上是真的，但只是「少亏」**：¼ Kelly 三个候选都比 current 少亏约 0.06 log 单位，区间不跨零；LogScore 改善 +0.012 nat/站日，同样不跨零。按比例全仓买整条梯子时，两臂对数增长差**恰等于** LogScore 差（价格在差值里消掉），所以 NLL 就是对数增长的正确代理。
3. **符号由「比市场差多少」决定**：−0.24～−0.26 nat 的差距是候选改善量（0.012 nat）的 20 倍。换权重不可能让这一层转正；要转正先得让服务分布的 Reliability 贴住市场、Resolution 超过市场。

## 边界

- 152/515 的覆盖有选择偏差（有盘口的站日集中在后半窗，全样本的前半窗 LogScore 候选略差）。
- S1 是宪章 130 不等式的单桶版，不是生产的篮子/席位规则；吃单按快照深度计，没有模拟队列、部分成交、他人抢单。
- 这批历史已参与候选设计，不是独立 OOS。
- 复现：本目录 `python3 replay.py`；输入 hash 在 results.json。
