# 四个中心合起来看：模型均值桶/众数桶 × 市场均值桶/众数桶 —— 第六轮事前协议

写于 2026-10-03，本轮数字算出之前。熊先生：「那模型均值、众数和市场均值、众数桶呢」。

第二轮 C 节只在秤砣线自己的 701 个触发行上看过四中心；这一轮放到**全部** 3,568 个已结算首决策（事件日 ≤10-02）上，四个桶都可以买，不设价带。窗口照旧：发现期 ≤09-20，验证期 09-21..10-02。

**已经看过、不算新证据的**：两众数不同时真值落在谁的众数桶（第四轮：模型 22.5%/27.5%，市场 43.2%/47.3%）——但没配过价格；市场众数桶各份额带的校准（第五轮）；近段是最好报的两周，「买中心」的臂在验证期沾光。

## 量

四个桶：模型众数 Mo、模型均值 Me、市场众数 Ko、市场均值 Ke（`evaluate_consensus` 口径）。每个桶取市场归一化份额、模型概率、卖一、买一、是否命中。

## 形态（互斥，覆盖全部行）

- A 四心同桶。
- B 两众数同桶、市场均值桶也同桶，只有模型均值桶偏出。
- C 两众数同桶、市场均值桶偏出。
- D 两众数相邻不同桶、市场均值桶落在**模型**众数桶。
- E 两众数相邻不同桶、市场均值桶落在**市场**众数桶。
- E′ 两众数相邻不同桶、市场均值桶两个都不是。
- F 两众数相隔 ≥2 档。

## 臂

- 每个形态下分别买 Mo / Me / Ko / Ke（买 YES，按卖一；同桶的臂自然相同）——7 × 4。
- 全体上按两中心相距 |model_mu − market_mu| 分四档（<0.25、0.25–0.5、0.5–1.0、≥1.0 档），各买 Ko 与买 Mo——4 × 2。
- 形态 D / E / F 下买 Mo 的 NO（按 1 − 买一）：模型与市场不一致时做空模型的桶——3 个。
- 共 39 个臂，全部扣吃单手续费 0.05·p·(1−p)。

## 交付与判据

- **形态表（描述）**：各形态占比，四个桶各自的命中率对卖一，前后段并列。
- **选臂只凭发现期**：发现期按事件日中位切两半，每半 ≥30 行、两半扣费后 ROI 都 >0、合并扣费后 ≥ +3%。
- **判「有特征」须**：入选臂（k 个）验证期扣费后 ROI 的日聚类单侧下界在 0.05/k 水平上 >0。
- 读完不加臂、不改切点。

脚本：`capture7.py` → `data7.json`，`analyze7.py` → `results7.json`。

**选臂**：39 个臂按发现期判据入选 **0 个**。
- 四心同桶：扣费后 −2.8% → −1.7% [−11.3, +7.0]。四个中心全同意的桶，命中率两段都正好等于卖一。
- 模型的桶与市场中心不同（E、F）时买模型众数桶：E −12.6% → −26.6% [−40.6, −10.8]，F −36.0% → −35.2%；两中心相距 0.5–1 档时 −15.9% → −24.4% [−39.8, −9.6]。两段都亏。
- 反过来做空模型的桶也不赚：E −4.6% → +3.5% [−2.4, +8.6]，F −2.3% → −4.9%，D −1.7% → −20.4%。
- 前后反号的格：D 买模型众数桶 −20.5% → +24.0%；E 买市场众数桶 −14.4% → +8.9%；C 买市场均值桶 −21.2% → +1.4%；B 买模型均值桶 −23.9% → +22.5%。

## 判定：没有

四个中心怎么组合，可买的桶的命中率都落在它自己的买一与卖一之间，或者前后段反号。两段都成立的只有三件事，都已经在价格里：四心同桶的桶命中率等于卖一；模型的桶偏离市场中心时不值它的卖一、也不低于它的买一；四心同桶的占比从 41% 升到 55%（模型向市场靠拢）。
