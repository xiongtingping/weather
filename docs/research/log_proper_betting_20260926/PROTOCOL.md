## 恒等式（论文 Lemma 1，先手核一遍）

- 位置 `s = log p − log q`，逐档收益 `1_y − q`，单次利润 `s·(1_y − q) = log(p_y/q_y) + Σ_k q_k log(q_k/p_k) = ΔS + KL(q‖p)`。
- 真实分布为 `p*` 时的期望利润是 Bregman 三点恒等式：`E[利润] = KL(p*‖q) + KL(q‖p) − KL(p*‖p)`，
  等价于 `(p* − q)·(log p − log q)`：赚钱的充要条件是模型偏离市场的方向与真值偏离市场的方向同向，与模型比市场准不准无关。
  `q = p*` 时期望利润恒为 0，无论 `KL(q‖p)` 多大。
- `Σ q = 1` 时位置加任意常数不改利润，所以纯 YES 版 `s' = s − min_k s_k ≥ 0` 在无摩擦下与论文版逐次同值；
  两者的差就是这套方案在真实盘口上的 `L`。

## 每次决策算什么

1. `ΔS = log(p_y / q_y)`；`D = KL(q‖p)`；无摩擦利润 `Π = s·(1_y − q)`，核 `Π = ΔS + D`。
2. 纯 YES 版按卖一：`s' = s − min s`，成本 `Σ s'_k · ask_k`，利润 `s'_y − 成本`；`L = Π − 该利润`。
   有任一 `s'_k > 0` 的档没有卖价的决策记为不可执行，主读数只取可执行子集并报剔除数。
3. 论文 3.3.4 价差版，只做 YES 腿（本仓禁止自动买 NO）：`p_k > ask_k` 的档买 `log(p_k / ask_k)` 份。
4. 对照：Brier proper `s_k = 2(p_k − q_k)` 的无摩擦利润。
5. 暴露：`Σ|s_k|`、最大单腿、落在第 224 条下限档上的 `|s_k|` 合计；每次决策利润的最小值与 5% 分位。
6. 动量版（论文 3.4 B）：同一站日按时间排序的相邻两次决策，`s_t·(q_{t+1} − q_t)`，正表示市场向模型移动。

## 重验：按论文自己的实证协议（读完全文后写定，2026-09-26 第二轮）

第一轮验证用的是论文第 2 节的 K 结果单纯形位置 `s = log p − log q`（`Σq = 1`）。论文第 4 节、附录 C.1、C.2、D.2、D.7 的实证协议不是这个，逐条照抄：

- **每桶一个二元市场**（C.1、D.2）：对每个桶 k 只看 `p_k`、YES 卖一 `ask_k`、YES 买一 `bid_k`。`p_k > ask_k` 买 YES；`p_k < bid_k` 买 NO（NO 卖一 = `1 − bid_k`）；`bid_k ≤ p_k ≤ ask_k` 不动（价差 no-trade band）。
- **份额**（D.2 与 Table 1 原文）：Brier `w = |p − q̃|`；Log `w = |log p − log q̃|`（D.2 原文）；另加 C.1 二元约化的严格形式 `w = |logit p − logit q̃|`。`q̃` 是实际成交侧的 YES 等价价：YES 腿为 `ask`，NO 腿为 `bid`。
- **成交**：按六档深度走盘口，填不满按实际成交份额记（D.7：「下一周期按实际成交仓位算」）。手续费 0。
- **ROI**（Table 3）：全部下注的盈亏合计 ÷ 全部投入合计；`ΔS` 与 `D` 按同一份额尺度记，使每笔 `ΔS + D = 盈亏`（Brier 与 logit 形式精确成立；D.2 原文的 log 形式只对 YES 坐标成立，只报 ROI）。
- **离线读数**（4.1，一市场一预测）：每个网格时点 H 单独一张表；另按 |p − q̃| 分档做论文的 persona 表（份额、方向胜率、档内 ROI）。
- **基本面式**（C.2 Corollary 4）：每个时点各下一次注，全部持有到结算。
- **动量式**（C.2 Corollary 5、D.7 实盘）：每站日按时点顺序把每桶仓位调到新目标；加仓走卖盘、减仓走买盘、反向先平后开；最后一档 H=4 后持有到结算（论文结算前 3h 停手）；变体：自上次成交价起未动满 10¢ 的桶跳过（D.7）。ROI = 盈亏 ÷ 累计买入投入。
- **总体**：`bayes_kelly_replay_20260924` 重放盘口（1,324 站日、30 天、H ∈ {44,36,30,24,18,14,10,7,4}，served 向量按 P1 > P0-M > P0，真值按交易所修订），盘口完整的 8,787 行。模型向量过第 224 条下限（论文的 log 规则遇到 0 概率无定义，生产服务的就是过下限的向量）。
- **本仓约束**：另报只做 YES 腿的版本；NO 腿只作论文协议复现，不入生产。
- 区间：事件日整日重抽 2,000 次。

判定沿用：论文自己的协议下，Brier 与 Log 两种 proper 策略的 ROI 95% 下界 > 0 才算「按论文能赚」。
