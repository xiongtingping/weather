# 对数评分 Proper Betting（arXiv 2607.06166）在本仓数据上的三个量（计算前写定，2026-09-26）

用 `ΔS + KL(q‖p) − L` 解释利润。本文只算论文自己要求验证的三个量，不加新规则，不改生产。

## 恒等式（论文 Lemma 1，先手核一遍）

- 位置 `s = log p − log q`，逐档收益 `1_y − q`，单次利润 `s·(1_y − q) = log(p_y/q_y) + Σ_k q_k log(q_k/p_k) = ΔS + KL(q‖p)`。
- 真实分布为 `p*` 时的期望利润是 Bregman 三点恒等式：`E[利润] = KL(p*‖q) + KL(q‖p) − KL(p*‖p)`，
  等价于 `(p* − q)·(log p − log q)`：赚钱的充要条件是模型偏离市场的方向与真值偏离市场的方向同向，与模型比市场准不准无关。
  `q = p*` 时期望利润恒为 0，无论 `KL(q‖p)` 多大。
- `Σ q = 1` 时位置加任意常数不改利润，所以纯 YES 版 `s' = s − min_k s_k ≥ 0` 在无摩擦下与论文版逐次同值；
  两者的差就是这套方案在真实盘口上的 `L`。

## 每次决策算什么

1. `ΔS = log(p_y / q_y)`；`D = KL(q‖p)`；无摩擦利润 `Π = s·(1_y − q)`，核 `Π = ΔS + D`。
2. 纯 YES 版按卖一：`s' = s − min s`，成本 `Σ s'_k · ask_k`，利润 `s'_y − 成本`；`L = Π − 该利润`。
   有任一 `s'_k > 0` 的档没有卖价的决策记为不可执行，主读数只取可执行子集并报剔除数。
3. 论文 3.3.4 价差版，只做 YES 腿（本仓禁止自动买 NO）：`p_k > ask_k` 的档买 `log(p_k / ask_k)` 份。
4. 对照：Brier proper `s_k = 2(p_k − q_k)` 的无摩擦利润。
5. 暴露：`Σ|s_k|`、最大单腿、落在第 224 条下限档上的 `|s_k|` 合计；每次决策利润的最小值与 5% 分位。
6. 动量版（论文 3.4 B）：同一站日按时间排序的相邻两次决策，`s_t·(q_{t+1} − q_t)`，正表示市场向模型移动。

## 判定（写死）

论文自己的盈利条件是 `mean(ΔS) + mean(D) > mean(L)`。
- 无摩擦 `Π` 的 95% 下界 > 0，且纯 YES 按卖一的利润 95% 下界 > 0，才算「这套方案在本仓数据上有正利润」。
- 否则报三个量各是多少，以及缺口几成来自 `ΔS`、几成来自 `L`。
- 动量版：`s_t·(q_{t+1} − q_t)` 的 95% 下界 > 0 才算「市场向模型移动」。
