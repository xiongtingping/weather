# 新模型入座后重查：高概率档与宽度 λ（2026-09-24）

熊先生：「新模型入座之后重新检查」。判据按宪章 211 的 09-24 补记：**桶 Brier 与 LogScore 的点估计都降**才算更接近 P(Y=k|X)；Reliability / Resolution 只作诊断。只读，生产未改。

## 样本

生产稳定池重放，六家（IFS、GEFS、ICON、ECCC、AIFS ENS、AIGEFS），事件日 2026-07-20..09-22，45 站，56,981 次更新 / 2,457 个站日；函数与 `fusion_blend_historical_20260923/capture.py` 相同，加 `--model-backfill-arrivals`。

**必须先说明的一个数据问题**：AIFS ENS 与 AIGEFS 的历史成员是后灌进 SSOT 的，行上的到货时刻是灌库那天（AIFS 09-22/23、AIGEFS 09-23，平均比起报晚 734 / 763 小时）。生产重放按到货时刻判断能不能用，所以照原样重放，这两家的历史**几乎全部「没到」**——EDDM 758 次更新里 AIGEFS 只出现 2 次。本次把后灌行（到货晚于起报 24 小时以上）改用模拟到货：AIFS 取同一轮 IFS PF50 的到货，AIGEFS 取起报后 8 小时 11 分（宪章 212 实测最晚）。前向实采的行不动。

由此更正：`fusion_blend_historical_20260923` 标的「五家含 AIFS」，实际 09-21 前基本只有四家。

六家时各提前量都偏 4–8 个百分点；60–70% 这一档仍然只开到一半左右。两份重放的更新集合和站日集合不同（六家多出 AIFS/AIGEFS 到货引起的更新），总分不能直接相减比较好坏；两家新模型的价值以宪章 212 的固定时刻比较为准。

**这份偏自信值多少**：Reliability 是桶 Brier 的一个分量（Brier＝REL−RES＋UNC），六家时为 0.000113，每桶平均 Brier 为 0.072491，只占 0.16%。把可靠性误差全部消掉，桶 Brier 最多降这么多；按宪章 211 的判据，它不是值得单独去修的地方。

## 2. 宽度 λ：六家时维持 0.75

62 天、43 个滚动测试日（每天只用至少提前 3 天已结算的日子选 λ）：

| 规则 | LogScore | 桶 Brier |
|---|---|---|
| 现役 0.75 | 1.53713 | 0.71533 |
| 全队一个 λ（样本外选，最近选到 1.1） | 1.54623，差 [−0.013, +0.032] 跨零 | 0.72296，差 [+0.0047, +0.0106] **显著变差** |
| 按提前量各选一个 λ | 1.54299 | 0.72219，**显著变差** |

- 全样本看，LogScore 想放宽（各档 0.9–1.1），桶 Brier 想略宽（0.8–0.9）；但每天用过去选出来的 λ 在样本外两项都不赢现役，Brier 显著变差。
- **更正昨天的建议**：昨天在五家重放上看到「全队 λ≈0.8 对数得分好 0.008」，那份重放的 AIFS 历史到货口径不同、判据也还是旧的（CRPS 持平）。六家、按宪章 211 的判据，现役 0.75 最好。

## 3. 宪章 199 融合权重（六家）：按修订后的判据过了

同一批六家更新，融合权重直接取生产的 `fusion_blend.overlay_system_weights`（训练行是重放自己的日前根）。区间为 3 日循环块 bootstrap 95%，单位是绝对差：

- 桶 Brier 的改善区间不跨零；LogScore 在日前根上区间也不跨零，主读数上略跨零。
- **和 09-23 那份结论相反的原因**：那份实际是四家（见上文数据问题），判据也还是旧的「五项」；这份是六家、按宪章 211 修订后的判据。
- 「全部更新」里混进了当地日终之后的迟到/后灌到货触发的更新，那些不是真实决策，所以主读数改为只算日终之前的决策（`score.py` 的 `before_day_end`）。
