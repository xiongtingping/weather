# 结果：P0 宽度改为逐站不成立，维持全队 λ=0.75

协议 `PROTOCOL.md`（87adf0b4）先提交，之后才计分。生产未改。

## 结论

八条逐站臂（数据 A 四条、数据 B 四条）没有一条过宪章 240 门，全部输给同口径的全队对照。在现役的主要情形（五六家池）里，逐站一律显著变差。每站"该宽还是该窄"在前后两段之间不持续，逐站拟出来的 λ 是噪声。宽度维持全队 0.75，生产逐站宽度车道继续夜判，按现状它也一直在拒。

- **对 0.75 的 LogScore 收益全部来自"全队放宽"**：长数据 2–7 月七成是两家池，两家池偏窄要放宽。这就是宪章 239/245/248 薄池车道管的那件事，不是站维度。站维度只在这份收益上加噪声，所以每条逐站臂都输给 F，而且 CRPS 显著变差。
- 现行主要情形（五六家池）里，F 对 0.75 是 +0.0025（不动最好），逐站是 +0.011 到 +0.015。
- 样本内上界（每站拿计分期本身选最优 λ，不算证据）是 −0.054，比 F 只多 0.016 nat，前推之后全部丢掉。

## 探索性诊断（判决之后，不作证据）

- **只用五六家池训练、也只在五六家池计分**（`explore_b.py`）：逐站 κ=0 为 +0.0178 [+0.0082, +0.0287]、κ=30 为 +0.0075 [+0.0023, +0.0130]，都显著变差。所以失败不是家数混杂造成的。
- **每站最优 λ 在两段间的相关**（`explore_a.py`、`explore_b.py`）：A（04-06 对 07-09）+0.03，B 五六家池（08-01..09-15 对 09-16..10-01）−0.23。按"放宽到 0.9 的收益"算，相关为 −0.12 / −0.06。没有可持续的站宽度个性。
- 旧记忆里"EHAM/LEMD/EDDM/EFHK 偏宽、WSSS/RCSS/WMKK 偏窄"在这两份数据里不复现：B 最终逐站选值 EHAM 0.85、WSSS 0.8、RCSS 1.1。
