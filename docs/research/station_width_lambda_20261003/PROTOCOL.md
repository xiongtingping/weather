## 臂（全部逐日前推）

计分日 d 的参数只用 `day ≤ d−2` 且 `known ≤ d 00:00Z` 的行（02-15 起，扩张窗）。L_s(λ) = 站 s 前缀行的平均 LogScore；L_F(λ) = 全队前缀行的平均 LogScore；n_s = 站 s 前缀站日数。

- **S0（主臂，字面「逐站」）**：λ_s = argmin_λ L_s(λ)；n_s < 20 用 0.75。
- **S10 / S30 / S100**：λ_s = argmin_λ [n_s·L_s(λ) + κ·L_F(λ)] / (n_s + κ)，κ = 10 / 30 / 100 站日；n_s < 20 用 0.75。
- **F（全队前推）**：λ = argmin_λ L_F(λ)——把「全队重拟」与「逐站」分开。
- 对照：**0.75 固定**（现役）。
- 上界（不作证据）：ORACLE——每站在计分期本身上选最优 λ。

## 判决（事先定）

1. 计分 04-01..09-30。门 = 宪章 240（`center_width_store._proper_score_gate`，簇 = 站日）：ΔLogScore 上界 < 0、CRPS 下界 ≤ 0、Brier 下界 ≤ 0。四条逐站臂（S0、S10、S30、S100）多重比较按 Bonferroni，置信度 1 − 0.05/4 = 98.75%。
2. 某逐站臂「过」＝ 全期过门 **且** 前后两段（04-06、07-09）ΔLogScore 点估计都 < 0 **且** 对 F 的全期 ΔLogScore 点估计 < 0（收益来自站维度而非全队重拟）。
3. 稳健性另报：3 日块 bootstrap（同 `score_fit.compare`）的 ΔLogScore 区间；按入座家数（2 / 3–4 / 5–6）分层读数。
