# 降水条件对信念的分辨率增益与重复性：计算前协议（2026-09-23）

用户提问：「测试以上降水对于条件概率是否增益分辨率信息？是否和 TAF 的降水、METAR 的降水、P0 的辐射偏移重复。」

## 装置

完全复用 `../conditional_belief_20260923/`：同一样本（`dataset.json`，估值车道总体、每站日×阶段×当地 3 小时块取中间决策、站日权重 1）、同一条件 logit（`fit_attribute.py` 的 `Stage`/`columns`/`fit`/`log_prob`）、同一折规则（按事件日滚动，训练集 = 真值在该测试日首决策前已可知，≥ 8 个训练日）、同一先验（非基础项 N(0,1) 岭）、同一自助法（3 日循环块 2000 次）、同一 REL/RES（看板 `_core_murphy`）。用稳健版边界（D、条件截 ±3）。只读 SSOT，生产不改。

## 条件（都是决策级 g，桶级项 g·D、g·(c−μp)，缺失置 0 加缺失标记）

| 名 | 含义 | as-of |
|---|---|---|
| kt | 晴朗度指数（P0 辐射平移读的量），来自决策时刻最新回执/版本 | 是 |
| taf | TAF 降水概率（宪章 150 P0-M 似然读的量） | 是 |
| obs | P1：决策时刻最新报文的现在天气含降水（P1 似然读的量，`obs_precipitation_present`） | 是 |
| sofar | 当地日内到决策时刻（报文 +15 分钟）为止任一报文含降水 | 是 |
| om_asof | Open-Meteo 当日降水量 log1p(mm)，决策时刻最新前向版本 | 是（P0 几乎无、P0-M 5%、P1 22%） |
| om_sameday | 同上，取当地日结束前最后一次前向捕获 | **否，前视上限** |
| truth | 当天真实降水：全部站按现在天气组「有无」（0/1）；美国 ASOS 站另给 log1p(mm) | **否，神谕上限** |

## 模型（都在 M1 = βm·Lm + w·D 上加）

M1；+kt；+taf；+obs；+sofar；base = kt+taf(+obs, P1)；对每条 om 臂 a∈{asof, sameday, truth}：+a；+a+kt；+a+taf；+a+obs；base+a。

## 读数（每阶段各自）

- 加一：+X − M1；减一：base+a − base；配对：(+a+kt) − (+kt) 等，量 a 在某一个已有条件之上还剩多少。
- 每个模型的样本外 REL/RES（北极星）。
- 报全样本，另报「om_asof 可得」子集（同一批行上比 asof 与 sameday）。
- 描述：按 om_sameday / truth 分档的站内去均值残差 z=(结算−μp)/σp、众数命中率、M1 对数得分；六个条件两两相关（池化与站内去均值各一份）。
- 不按结果增删条件；上限臂为零即结论为零，上限臂为正只说明「值得等 as-of 样本」，不构成上线依据。
