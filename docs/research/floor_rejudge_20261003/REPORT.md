## 读法

- 下限只改变真值落在 <1e-3 桶上的那些决策的 LogScore，Brier 和 CRPS 几乎不动。三条条款里，242 和 246 的 Brier 或 CRPS 本身就显著变好，所以下限后照样过门，只是 LogScore 收益缩小（242 减半、246 减四成）。
- 244 原判决全靠 LogScore 那 −0.0022，下限后剩 −0.0007、区间跨零。CRPS 仍显著好（−0.0009），Brier 平；服务口径（经 242 后真正服务的权重）前后都只差 −0.0004、不显著。也就是说：κ=0.25 对服务 P0 没有可测影响，改不改都一样。
- 246 前推宽度 λ 的选择也随打分口径变：不加下限多选 0.9 / 1.05，下限后多选 0.85 / 0.8。不加下限的打分会把宽度往宽推，与 `conditional_width_lambda_20261003` 一致。
