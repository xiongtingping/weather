## 结论

1. 无条件没有优势：现行链在 P0 >36h 仍比市场差约 0.08 nat（最近一周约 0.03–0.05）。
2. 有条件信息：模型带着市场价以外约 1/4 权重的信息，09-12 以前的旧链为 0。
3. 这点信息过不了「点差＋手续费」：照规则全梯子吃单，NO 打平、YES 亏。
4. 唯一站得住的条件性优势是远尾 NO（上表第 4 节），两套数据、两半样本、紧盘口、剂量—响应都成立；中心附近模型与价格分歧时错的是模型。
5. 以上「目前模型」读数来自回放（C 站、不含 248）与 v14–v20 实服；v21–v26 的前向样本要等结算，每天约 45 站日。
