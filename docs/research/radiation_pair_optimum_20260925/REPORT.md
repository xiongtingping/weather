# 辐射两侧系数的当前最优值（生产 41 天，服务形式，宪章 211 判据）

熊先生：「目前最优值是多少？」。协议 [PROTOCOL.md](PROTOCOL.md)（计算前写定）；`diagnose.py` 是看到 `scan.py` 读数之后加的诊断，标为事后。只读，生产未改。

## 结论

**按桶 Brier（平滑、可信），最优约为升温 0.14 / 降温 0.07，但 0.12–0.18 / 0.04–0.08 是一块平地，与现役 0.12/0.04 的差 −0.00017 [−0.00078, +0.00041]，样本外两半挑出的最优都不比 0.12/0.04 好。** 所以当前数据给不出比 0.12/0.04 更好的可确认值；方向上一致的是「升温侧大于降温侧」。

按宪章 211（桶 Brier 与 LogScore 点估计都降），**0.12/0.04 对对称 0.07 在生产上是过的**：LogScore −0.00055 [−0.00275, +0.00204]、Brier −0.00008 [−0.00041, +0.00026]；去掉灾难站日后 LogScore −0.0014 [−0.0029, +0.00005]。宪章 222 的预先复核用的是中心残差平方（第 210 条的旧目标），那一项上 0.07/0.07 最好——宪章 211 已把它降为诊断。

- **LogScore 的最优不可信**：9 个站日（FACT 09-09、KORD 09-19、KSEA 09-19、RCSS 09-06、RKSI 09-12、ZSPD 09-11、ZUCK 09-11、ZUCK 09-14、ZUUU 09-14）的真值落在概率 <1e-6 的档，每个扣 27.6 nat，占全部 LogScore 的 7.3%。0.24/0.20 把其中 4 个救回、又新添 1 个（RCSS 08-21），净少 3 个×27.6/1,716≈0.048——这就是它 −0.046 的全部来源。样本外两半各挑出 0.00/0.24 和 0.24/0.20，后者在另一半上比 0.12/0.04 和 0.07/0.07 都差。
- **去掉任一臂下的灾难站日（剩 1,705）**：LogScore 最优 0.18/0.06，Brier 最优 0.16/0.07；0.07→0.12/0.04→0.14/0.07→0.18/0.06 依次 1.70491→1.70351→1.70249→1.70215。
- **Brier 样本外两半**：前半挑 0.14/0.24、后半挑 0.16/0.02，互不一致；到另一半上 0.12/0.04 分别 0.75709（三者最好）与 0.80142（三者持平）。

## 方法与局限
- 每臂的平移用生产 `forecast_clearness_shift_sigma`（本站 180 天居中）× 服务宽度；桶概率从服务向量按回执里的实际平移量反推、再按各臂平移（桶内均匀、开口档一个中位桶宽），所有臂同一近似。窗口内服务系数先后是 0.15、0.07、0.12/0.04，一律按每包回执的实际平移反推。
- 41 天仍短：宪章 222 研究里复刻自己的 40 天窗口拟合就与 451 天差很远。

复现：`scan.py`（约 3 分钟）→ `results.json`；`diagnose.py`（约 3 分钟）→ `diagnose.json`。
