# 预登记：P1 傍晚臂（剩余小时 × 根高出已测最高、过峰后小时数），严格前推（2026-10-16）

熊先生 10-16「预登记并严格前推测傍晚臂（剩余小时×根高出已测最高、过峰后小时数）」。写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改。

## 起因
ZUUU 10-16 当地 20:06，根（P0-M）均值高出已测最高 2.4°C，P1 仍给「还会升」0.17（22°C 0.09、23°C 0.07）；全队傍晚平均「还会升」与实际大体相符，偏高集中在「根高出已测最高 ≥2°C」的傍晚（真正在傍晚的约 20 站日几乎没有再升，P1 给 0–54%）。
现行 f(k) 的状态里有「根均值 − 已测最高」，但只有 late（剩余<6h）/mid（6–10h）两块门控，没有它与时钟的连续交互，也没有「过峰后多少小时」。

## 数据与对照
与 `p1_slope_refit_arms_20261016` 完全相同：同一 design（生产样本库、生产 `direct_design`）、同样 30 个评估日（09-16..10-15）、同样严格 as-of 训练与 λ 选法；BASE 同上一轮（现行形式逐日重拟）。

## 臂（事先固定）
**戊**：BASE 的 x 末尾加三列（原始值构造，缺失用训练均值填，按训练行标准化），rise、slope 两块都能用：
- `clock × rmh`：站钟剩余小时（`OL.clock_hours`）× 根均值高出已测最高（`root_mean_minus_high_c`）；
- `hpp`：过峰后小时数 ＝ max(0, 24 − 全队峰值钟点 − 站钟剩余小时)，全队峰值钟点取现行工件 `station_clock.fleet_peak_local_h`（13.88）；
- `hpp × rmh`。

## 指标
1. 整梯子 −log p 之差（戊 − BASE），全部评估行；
2. 傍晚行（样本当地钟点 ≥ 17）同上；傍晚且 rmh ≥ 1°C 的子集同上；
3. 傍晚「还会升」校准：P(高于已测最高档) 的平均对实际频率、Brier，戊与 BASE 并列（rmh 分组 <0.5 / 0.5–1 / 1–2 / ≥2）；
4. 按站 BH q=0.10（整梯子，≥10 站日）。区间：按事件日 bootstrap 2,000（seed 7）。

## 判据
整梯子 Δ 不显著变差（区间上限 ≤ 0 或跨零但点估计 ≤ 0）、傍晚 Δ 区间 < 0、无 BH 显著变差站 → 上线候选（是否上线另裁）；
傍晚 Δ 跨零 → 不成立，报校准表。

## 已知限制
傍晚 rmh ≥ 2°C 的行很少；站钟与全队峰值钟点取现行工件（各臂共用）；评估 30 天。
