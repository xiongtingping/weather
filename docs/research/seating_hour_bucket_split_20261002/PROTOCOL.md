# 预注册协议：入座——按小时桶拆座（hour_bucket_split）值多少

写于 2026-10-02，评分之前。裁决人：熊先生（「继续打模型入座」）。

## 现象（生产 10-01 06Z 起 2,123 条 P0，时间加权）
- >60h 与 48–60h 的少家池 94–97% 是「没观测到」（到货/证书成熟度，已知为时间问题）。
- **36–48h 有 19.7% 的小时、≤36h 有 10.2% 的小时，六家都已观测到却只坐 2–4 家**；90 个站日里 32 个在 36h 截止前最后一个决策只坐 2–3 家（观测 6）。Proper 线正是在这一刻读 p。
- 机制：P0 的训练提前量桶跟最新到货的那家走（如北美站 10Z 后 NOAA 06Z 进入 h12_24），其余家的最新 run 还在 h24_48 桶 → `hour_bucket_split_riders`，整家被拆出池子；一个跨桶激活并不存在（激活按 station×lead_bucket 存）。CYYZ/KAUS 10-01 10:21Z→22:09Z 整整 12 小时只坐 2–4 家。

## 问题
**同一时刻，把被拆出的家按它们自己提前量桶的证书一起入座（六家池），比现行「只坐最新桶的 2–4 家」在第 240 条判决上更好还是更差？**

## 数据与机器
`station_model_weights_20261001/pass1_all/`（六家、1–9 月、生产单家规则走查，各家带自己的 scope 提前量桶 `sys[s].lead`，行的 `lead` 是最新家的桶）。
代表决策同 score.py（五档各最后一个）。只取「拆座」决策：存在某家 `sys[s].lead ≠ lead` 且最新桶内 ≥2 家。
- 臂 A（现行）：只坐最新桶内的家，席位权重在座归一；下游同 score.py（桥、物理、λ=0.75 今日层）。
- 臂 B（候选）：全部观测家入座，席位权重归一；同一下游。
- 判决：B 对 A，`_proper_score_gate`（LogScore 上界 <0、CRPS/Brier 下界 ≤0），簇=站日；计分 2026-08-10..09-30；分 36–48h / 24–36h / 12–24h 报；另报被拆出的家数分布。
- 若 B 过门 → 提议改 P0 入座：允许跨桶同座（每家按自己桶的证书），属扩大范围须熊先生裁；若 B 不过 → 现行拆座保留，结论留档。
