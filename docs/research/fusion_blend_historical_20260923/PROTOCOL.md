# 宪章 199 融合权重：用历史样本判切换（计算前协议，2026-09-23）

熊先生裁决：「别等向前日了，先用历史样本」。

## 问题

宪章 199 的融合权重（`center_crps_blend_v1`：中心误差 + 正则、分层 CRPS 各半）替换现役席位权重（宪章 134 稳定池，κ=0.5），在五家（含 AIFS ENS，宪章 204）的生产口径下，历史上是否让服务出去的 P0 同时 RMSE、CRPS、NLL 下降，且 Reliability 降、Resolution 升。

## 样本

- 生产稳定池重放（`scripts/replay_p0_stable_pool.py` 的同一套函数）：五家原生成员回填，事件日 2026-07-20 至 2026-09-22，45 站；每次「某家最新 run 变了」算一次更新，逐系统滚动拟合（`_fit_parameters`，60 天窗，真值须在更新前可知、run 须在更新前到货），再过生产的共识桥、形状栈和该小时生效的服务表（中心宽度、band）。
- 与原重放唯一的差别：只算现役 κ=0.5 一个臂、不跑子集赛（已退役）；每次更新额外存下逐系统分布和中心，供第二遍重新合成。

## 两条臂（同一批更新、同一批逐系统分布、同一批服务表）

- **席位**：`stable_pool_weights(skill, family, kappa=0.5)`，即现役。
- **融合**：把席位权重交给生产的 `fusion_blend.overlay_system_weights(mode=blend)`；它读的训练库由第一遍产出，口径与生产训练库一致：每个已结算站日取「当地午夜前一天内最后一次更新」为日前根，存各家中心误差与 CRPS 中间量（`fusion_blend.row_statistics`），真值可知时刻 = 首次提交与当地日终的较晚者。ASOS 11 站不入训练、不改权重（与生产相同）。融合函数返回什么就服务什么（状态非 APPLIED 即退回席位）。

## 指标与判据（事先写定）

- 逐更新打分：服务均值对真值的 RMSE、CRPS、NLL、桶 Brier（`replay._score`，整度桶）；Reliability / Resolution 用看板 `_core_murphy`，站日权重 1（每次更新权重 = 1 / 该站日更新数）。
- 主读数：全部更新（站日等权）；副读数：只取日前根（每站日一次）。
- 3 日循环块 bootstrap 2000 次给 95% 区间（单位：绝对差）。
- **切换判据**：主读数上 RMSE、CRPS、NLL 三项点估计同时低于席位，且 Reliability 低于席位、Resolution 高于席位。另报：研究没用过的站日（2026-08-14 前、2026-09-22 后）与宪章 134 之后（2026-09-14 起）两个切片，只报不判。
- 不根据结果改规则、改窗、改参数；全部结果都报。
