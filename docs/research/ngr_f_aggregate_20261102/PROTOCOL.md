## 判据（宪章 240）

主比较 MEAN − MED、TRIM1 − MED，逐决策三分数差按事件日聚类：LogScore 差（事件日 bootstrap
2000 次，种子 281）95% 上界 < 0，且 CRPS、Brier 差 95% 下界 ≤ 0 → 该臂 PASS（优于中位数）；
可评事件日 < 20 记 INSUFFICIENT；其余 REFUSED（不优于中位数）。反向（MED 是否显著优于另一臂）
以同一区间读出。分段（>36h / 12–36h / <12h）与各臂对旧链的前推只作描述，不进判决。
