# 纽约 / 西雅图月降水市场回测（2026-10-08）

熊先生 2026-10-08「做西雅图和纽约回测」。协议在看分数前写死在 `backtest.py`、`replay.py` 的文档串里。

## 结论

**按事先判据，没有证实的优势；不建实盘车道。**

| 判据 | 读数 | 过没过 |
|---|---|---|
| 预报臂 vs 市场图表价：Brier | −0.042 [−0.090, +0.003] | 跨零 ✗ |
| 预报臂 vs 市场图表价：LogScore | −0.176 [−0.273, −0.087] | 显著 ✓ |
| 吃单回放·买 YES（主臂，边际 ≥0.05，扣 0.05x(1−x) 手续费） | +6.0¢/股，ROI +26% [−10%, +63%]，13/20 事件为正 | 跨零 ✗ |
| 吃单回放·买 NO（副臂） | +8.5¢/股，ROI +12.5% [+3.0%, +21.3%] | 95% 显著；6 臂多重校正后 [−0.7%, +24%] 跨零 ✗ |

区间均为按事件分块 bootstrap 的 95% 区间（20 个事件）。

- **预报确实有信息**：预报臂比纯气候臂 Brier −0.044、LogScore −0.098；纯气候臂与市场 Brier 打平（+0.002）。所以图表价大约只反映到「已下 + 历史气候」这一层，6 天预报没有完全进价。但 20 个事件撑不起显著性，而且图表价在价差宽时取的是最后成交价，不能直接拿来成交。
- **买 NO 的苗头不是天气预报带来的**：同样规则只用气候、不用预报，也有 +10.7% [+2.3%, +18.5%]，比预报臂只差 1.8 个点。收益来自市场自身价格结构（月初各桶 YES 定价偏高）。前后两半不稳：12–4 月 +6.7%（跨零），5–9 月 +20%。另外按 AGENTS，买 NO 只属于宪章 231/234，降水要做需另行裁决。
- **西雅图结算站是 SEWthr（Sand Point 气象台，KSEW）**，不是 SeaTac（KSEA）。用 SEWthr 和 NYCthr 复现，20 个事件的结算桶全部对上。有 6 个月 SeaTac 与 SEWthr 落在不同桶，但市场没有被这一点系统性带偏：两站同桶的月份，优势一样大。

## 口径

- 事件：Polymarket 已结算的全部「Precipitation in NYC/Seattle in <Month>?」，2025-12 到 2026-09，共 20 个；578 个决策点，每天 12Z 一个。
- 真值：NOAA ACIS 序列 `NYCthr`（中央公园）、`SEWthr`（Seattle City Area），按当地标准时的气候日计。
- 决策时可得的信息：截至前一天的 ACIS 日值；Open-Meteo best_match previous-runs 降水，每小时取满足「发布时刻 + 8 小时 ≤ 决策时刻」的最短提前量（技能随提前量衰减：西雅图 r 0.71→0.37，纽约 0.63→0.21，说明没有用到未来信息）；1945 年到决策年前一年的气候。
- 预报臂：月内拆成三段——已过日用观测；之后 6 天的总量取历史上预报总量最接近的 40 个窗口的实况（训练窗口全部早于决策日，从 2024-01-08 起）；更远的日子用同日历日 ±7 天的历年总量。
- 市场：决策时刻之前最后一个小时级图表价，归一化后使用。
- 吃单回放：真实的吃单 BUY 成交（data-api，只保留方向、价格、数量、时间），说明那一刻能以该价买到；同价买 1 股，每桶每方向每个决策日最多一次。

## 复跑

依次执行 `fetch_prices.py`、`fetch_forecasts.py`、`fetch_trades.py`（ACIS 用 curl 拉，命令见 git 历史），再执行 `backtest.py` 和 `replay.py`。`raw/` 下的原始 JSON 抓取后用 gzip 压缩；读取函数会自动识别 `.gz`。每月新结算 2 个事件；协议不改，样本到 ≥30 个事件（2027-03 结算后，约 2027-04-01）原样重读一次，两项判据都过才谈立车道。
