## 补记一（2026-10-26，跑数前）：历史上直接测用法

熊先生「不向前，直接用历史数据，怎么用？」。在前向复核之外，先在历史上用**严格逐日前推**测一个通用用法；
为避免细查里挑出来的切片带来的选择偏差，**只用不分切片的通用规则**：

- 事件同正文（08-20..10-24，1,171 次修订）。对每次修订，参照为后一份 TAF 发布时刻**当时服务的信念向量**（P1 > P0-M > P0）。
- 臂：R ＝ 服务信念原样；**U ＝ 服务信念整体平移 δ ＝ κ·步长**；U_sign ＝ δ ＝ κ·sign(步长)。平移用桶内均匀重积分、1e-3 下限，
  实况硬下界（已排除桶）保持排除并按比例重归一。
- κ：每个打分日只用该日之前的事件按平均桶 LogScore 拟（κ ∈ [0, 1]），≥7 个训练日后开始打分。
- 判据（宪章 240）：U − R 的 LogScore 95% 上界 < 0、RPS/Brier 不显著变差、≥20 可评事件日。另报逐站、前后半、拟出的 κ 轨迹。
- 过门只表示「修订方向可以这样用」；进生产另行提请，前向复核照旧在 11-26 跑。

## 补记二（2026-10-26，跑数前）：挪动持续到下一次修订

熊先生「按协议测：修订后每个决策都保留 κ·步长 的挪动，直到下一次修订，全部决策打分，过门再提请上线」。

- 决策：有修订的站日，从首次修订（后一份 TAF 发布）起，**每个整点**取当时服务的信念（P1 > P0-M > P0 的最新信封），直到当地 23 时。
- **主臂 P**：δ ＝ κ·(当时最近一次修订的步长)——下一次修订到来即替换。
- 副臂 C：δ ＝ κ·(当时 TX − 当日最早 TX)，即累计净修订（读数）。
- 平移与下界同补记一（桶内均匀重积分、已排除桶保持排除、1e-3 下限）。κ 每个打分日只用之前日子的决策拟（0–1，步 0.02）。
- 判据（宪章 240）：P − R 在全部决策上 LogScore 95% 上界 < 0、RPS/Brier 不显著变差、≥20 可评事件日。另报按「修订后经过小时」
  （0–3 / 3–6 / 6–12 / ≥12）与当地时段分档、前后半、逐站、κ 轨迹。
- 过门即提请上线（上线形态另附方案，含声明、升版与宪章条款）。

## 补记三（2026-10-26，跑数前）：衰减形态

熊先生「另立协议测衰减形态：δ = κ·步长·e^(−经过小时/τ)，κ 和 τ 都只用之前的日子拟，全部决策打分，过门再提请上线」。

- 决策集与补记二相同（有修订的站日，首次修订起每个整点到当地 23 时；服务信念 P1 > P0-M > P0）。
- **臂 E**：δ ＝ κ·(最近一次修订步长)·exp(−(决策时刻 − 该次修订发布)/τ)；下一次修订到来即以新步长重新起算。
- κ ∈ [0, 1]（步 0.02），τ ∈ {0.5, 1, 1.5, 2, 3, 4, 6, 8, 12, 24} 小时；每个打分日只用之前日子的全部决策按平均桶 LogScore
  联合网格拟合。打分与平移同补记一（桶内均匀重积分、已排除桶保持排除、1e-3 下限）。
- 判据（宪章 240）：E − R 在全部决策上 LogScore 95% 上界 < 0、RPS/Brier 不显著变差、≥20 可评事件日。另报经过小时与当地时段分档、
  前后半、逐站、κ/τ 轨迹。
- 声明：「约 3 小时」的衰减尺度是在同一份历史上看出来的，τ 由前推自由拟；最终仍以 11-26 前向复核为准。过门即提请上线。
