# P0 三层配对消融（2026-09-28，计算前冻结）

目标：在相同实际历史预测、相同模型集合和相同市场桶上，量化融合重拟、共识桥、宽度层的独立与交互影响。只读生产数据库，不晋级、不改服务。

## 来源与限制

- 使用真实已物化 P0 的单系统概率、中心、最终权重、融合回执和物理变换回执；不模拟模型到货、不用今天数据重新训练过去权重。
- 查找 2026-09-01..2026-09-26 的 45 个交易站。每站日固定选当地事件日开始前最后一份实际已提交 P0，提交与 decision 都必须在日开始前；每站日一票。完整输入缺失明确计数，禁止拿更早/更晚的完整包顶替该固定选样。
- 补充口径：Proper 首个 P0、距结算超过36小时的已冻结审计引用，只核对完整输入覆盖；不能拿上述日前末次更新冒充首决策。
- 真值读取 AWC/SETTLEMENT_SOURCE 最新修订后再检查 QC、时区、闭日和真值唯一落桶。
- 原始信封用 canonical helper 重建并核对 content hash。核对各模型来源时钟和激活记录的 station、有效窗与激活时点。记录 authority，不把历史服务/observational 数据自动升级为 strict OOS。
- 已有长期研究的 AIFS/AIGEFS 模拟到货回放只作背景证据，不混进本轮样本。

## 配对臂（不根据结果挑参数）

- 权重三档：实际 served、去掉融合重拟后的 seat prior、入座模型等权（诊断用，不承诺满足生产家族上限）。seat 本身仍含逐站历史能力，不能把该对比称为移除一切站点信息。
- 共识桥：按实际回执启用 / 关闭。
- 宽度收缩：按原回执有效宽度 / 1.0；固定原 delta；其余物理输入不变，随上游分布变化重新计算以 sigma 为尺度的物理位移。
- 共 3×2×2=12 臂；首要对比为逐一去掉一层与完整基线，其他臂用于交互/等权诊断，不逐站挑赢家。
- 先用实际回执重建当时服务概率，最大逐桶绝对误差阈值 1e-7；失败单列、不得悄悄放宽容差。原 band 若为非恒等则拒绝，不以当前已退役函数冒充历史实现。
- 消融评分统一在末端使用当前生产 model-zero floor=0.001。同时保留实际历史向量及其复现误差、是否改变 floor；这是固定当前下限的回顾比较，不称为当时已服务概率或未经接触的 OOS。各臂共用 floor，避免历史零概率变化成为层贡献。
- 所有非研究层须能从回执严格复现；没有回执则明确无变换，不猜测未存字段。宽度 tier 或非零 sigma floor 需精确参数，缺失拒绝。

## 指标与验证

- 主指标：多分类桶 Brier=sum(p-y)^2、自然对数损失=-ln(p_truth)，越小越好。
- 校准/分辨：固定概率分箱的 one-vs-rest reliability/resolution 描述统计；同时报分箱余项、ECE与高概率段声称/实际率，不把小样本分辨读数当成模型技能证明。
- 尖锐度：熵、最大桶概率；仅为形状指标，不以更尖判更准。
- 按六模型、融合真正 APPLIED、桥确实开启、C/F 市场、逐日期/站点、提前量做配对分解；完整总体与交集分母同时给出。
- 日期簇少于10时不输出显著性结论；给逐日删除敏感性与明确的覆盖限制。足够日期时使用日期块重采样，并核对块长敏感性。
- 验证覆盖向量归一/非负、独立公式复算、全部臂相同样本、移除层的恒等边界、C/F与开口桶、反向恢复、重复执行确定性及一次只改变指定开关。
