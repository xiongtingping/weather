# 阶段 0 预登记：太阳几何、η 标定、K* 表、晴空天花板判别力（2026-10-15）

只读研究；不改生产代码、配置、拟合件、服务或订单。写在读数之前，读数出来后本文不改（补充写 RESULTS.md）。

## 问题

正推物理似然（DESIGN.md）新增的第一件事是**晴空天花板**：从决策时刻 t 到峰值，哪怕天空全晴，
能量也只够再升 `η × S0_rem(t)`。超过它的桶物理不可能。阶段 0 只问一个问题：

> 现行 P1（v39）与它的根（P0-M/P0）在天花板以上放了多少质量？真值落在天花板以上的频率是多少？
> 把天花板以上的质量清掉、归一化、套 1e-3 下限，LogScore 变好还是变差？

## 定义

- **S0(τ)**：晴空地表全球短波 (W/m²)，Haurwitz 型：`S0 = 1098 × sin(h) × exp(−0.059 / sin(h))`，
  h 为太阳高度角（站点纬度、经度、日期、UTC 时刻），海拔修正 `× (1 + 0.0001 × z_m)^?`——
  阶段 0 用 Ineichen 简化：`S0 × (1 + z_m/8000 × 0.1)`，不拟合。坐标 `station_registry`，海拔 NOAA AWC stationinfo（48 站官方，本目录 `awc_stationinfo.json`）。
- **t_end(站)**：该站在训练窗内「当日最高温首次出现时刻」的当地时间 95% 分位。S0_rem(t) = ∫_t^{t_end} S0。
- **K(小时)**：实测短波 / S0 同小时均值；实测源：美洲 16 站 NOAA GOES ABI-L2-DSRF（官方、带回执）；
  其余 32 站 **Open-Meteo 转发的 JAXA Himawari / DWD SIS / EUMETSAT LSA SAF**（aggregator_republisher，
  **只作研究标定**，不进 P1；阶段 1 须换官方源重做）。
- **日效率** `η_d = (Tmax_d − T_09_d) / ∫_{09}^{t_max,d} K·S0`，T_09 为当地 09:00 ±30 分钟最近 METAR；
  ∫ 用逐小时 K。只取闭日、真值来自 AWC/SETTLEMENT_SOURCE 最新修订、ACCEPTED 的站日；
  ∫ ≤ 0.3 MJ/m² 的日剔除（除数太小）。
- **η_q(站)**：站内 η_d 的分位 q，q∈{0.50, 0.90, 0.95}，**按日前推**：评 D 日只用 D 之前闭日；
  站内闭日 < 8 时用全队分位（标注 fleet_fallback）。
- **天花板** `T_ceil(t) = H(t) + η_q × K_cap × S0_rem(t)`，K_cap = 1.0；**主臂 q=0.95**，0.90/0.50 为诊断。
- **天花板掩码**：桶下界 ≥ T_ceil 的桶质量清零（整桶在天花板之上才清；跨线的桶不动），归一化，
  套生产 1e-3 下限（`floor_probabilities`）。
- **决策行**：09-01..10-14 的每条 P1 信封，决策时刻在当地 09:00 之后、t_end 之前；根向量取
  `prediction_root_checkpoint_id` 指向的 P0-M/P0（charter 241 的比例向量若有）。

## 预登记判据（宪章 240）

主：ΔLogScore（天花板掩码后 − 掩码前），负为好；站内按日块 bootstrap 2,000 次 95% 区间。
结构：ΔCRPS（°C）。护栏：ΔBrier。三者对 P1 v39 与对根各报一次。

预登记切片：当地 12–18 时；距结算 6–10 h；GOES 站 / 转发源站；F 站；天花板以上质量 ≥ 2% 的行。
**样本量门**：切片 < 300 站日只叫读数。

判别力读数（无需判决）：
1. 真值 ≥ T_ceil 的站日比例（q=0.95 应 ≲ 5%；若 >10% 说明 η/S0 低估，天花板不可用）；
2. P1 与根在 T_ceil 以上的平均质量、分位 90；
3. 同上按距结算小时数分箱。

## 预期与止损

10-07/10-08 已测天空增量在 P1 最好 −0.004 nat。天花板只在远上方桶起作用，预期 ΔLogScore 量级 0–0.005。
**止损**：主臂 ΔLogScore 区间跨零且 12–18 时切片也跨零 → 天花板无判别力，阶段 1 不以天花板立项，
只保留 η 表作后续通道的物理参数。
