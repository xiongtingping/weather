# P1 正推物理似然：结构与框架设计（2026-10-15）

熊先生 10-15 裁决「我想建立正推模型，先帮我设计结构和框架！核心是用物理证据，比如云、雨、辐射、日照、太阳高度角、风等信息」。本文只设计，不改生产。

## 0. 终点线（Goal）

交付一个 **生成式似然** `L_phys(k) = P(E_t | Tmax = k)`，E_t 是决策时刻 t 之前已到的物理证据，
在现行 P1 中取代倒推的 `exp f`：

```
P1(k) ∝ root(k) × 1[k ≥ 已报最高温桶] × L_phys(k)^λ
```

验收：严格 as-of 前推 ≥16 闭日，按宪章 240（LogScore 主裁、CRPS 结构、Brier 护栏）对三个对照
（root+硬下界、现行 v39、市场买一中价）判决；通过才接入，否则留作诊断。

## 1. 为什么现在是倒推、正推要改哪一层

| | 现行 v39（宪章 161） | 本设计 |
|---|---|---|
| 学的量 | 「报文让每个桶的对数概率加多少」f(k) | 「若今天最终是 k，此刻会看到什么证据」P(E_t \| k) |
| 拟合目标 | 最终 P1 的 LogScore | 每个证据通道各自对自己的观测拟合（η 对升温、K 对卫星） |
| 时钟 | 距结算小时数（站峰值平移） | 剩余晴空能量 ∫ S0（太阳高度角积分） |
| 上方桶 | 斜率 S、平方 Q 压衰减 | 晴空天花板：需要的晴空率 K* > 1 的桶物理不可能 |
| 可外推 | 否 | 是（新站只需经纬度 + η） |

层级定位：只改 P1 的似然项。root（P0/P0-M）、硬下界、1e-3 下限、`served_belief_row` 都不动。

## 2. 物理骨架：能量收支

记 t 为决策时刻，H 为当日已报最高温，T_t 为当前气温，候选桶 k 的中心温度 c_k。

**需要的剩余升温** `d_k = c_k − H`（k 在 H 桶内时 d=0，H 以下已被硬下界清零）。

**剩余可用能量**（确定性，无参数）：

```
S0_rem(t) = ∫_t^{t_peak_max} S0(τ) dτ          S0 = 晴空地表短波 (W/m²)
```

S0 由太阳高度角 sin(h) 决定：h 由站点纬度、经度、海拔、日期、时刻算出（Haurwitz/Ineichen
型晴空模型，海拔修正大气质量）。`t_peak_max` 取站×季节的历史最晚峰值时刻（分位 95%），
不是结算时刻——傍晚的太阳不会再抬最高温。

**升温效率** η（°C 每 MJ/m²）：站×季节参数，受三项物理调制：

```
η_eff = η_station,season × m_wind(风速) × m_bowen(露点差) × m_rain(降水)
```

- 风：混合层加深，地表加热被稀释，m_wind 单调递减；
- 露点差：Bowen 比。干空气（露点差大）更多能量进显热，m_bowen 递增；
- 降水：蒸发冷却，m_rain < 1；只算加热窗（当地 09 时 → t）内的雨，峰后雨无信息
  （10-01 判例，`precip-conditional-resolution-20260923`）。

**需要的剩余晴空率**：

```
K*_k = d_k / (η_eff × S0_rem(t))
```

K* 是本设计的核心中间量：候选桶 k 被翻译成「从现在到峰值，天空平均要多晴」。

- K*_k > K_max（≈0.95–1.05，站拟）：物理不可能，L ≈ 0 → **晴空天花板**；
- K*_k ≤ 0（k 在 H 桶内）：「已到顶」分支，见 §3.2；
- 0 < K*_k ≤ K_max：正常分支。

## 3. 证据生成模型：P(E_t | K*_k, η_eff)

证据按通道分，**每种物理量只进一次**（10-07 教训：云/雨/辐射当三份独立证据相乘会重复计数）。
给定 (k, η_eff) 后各通道条件独立，L_phys(k) = ∏ 通道。

### 3.1 天空通道（辐射/云/日照）

观测到的晴空率 K_obs 来自三个源，按优先级合成一个数 + 一个不确定度：

| 源 | 覆盖 | 性质 | 量 |
|---|---|---|---|
| 卫星实测地表短波 | GOES DSR 美洲 16 站、JAXA Himawari P-Tree 亚太 16 站 | 官方、带到达回执 | 过去 2–3 h 实测 / S0 |
| METAR 云量 | 48 站 | 官方 | okta → K 的站拟映射 a + b·cloud |
| 官方 GEFS DSWRF 集合平均 | 48 站 | 原生 NWP | 未来小时的 K 预报 |

生成式写法（正推方向：先定结果，再说观测长什么样）：

```
K_obs_past  | K_rem = K*_k  ~  N( ρ·K*_k + (1−ρ)·K_clim ,  σ_past )     # 持续性：过去晴，剩下大概率也晴
K_fcst_rem  | K_rem = K*_k  ~  N( K*_k ,  σ_fcst )                       # 预报对真实剩余晴空率的误差
cloud_now   | K_rem = K*_k  ~  映射 + 噪声                                # 无卫星站退化到这一条
```

ρ（日内持续性）、σ 各自用卫星序列按站拟合，与 Tmax 无关，所以不会倒推。

### 3.2 温度路径通道

给定 k 与 η_eff，预期路径 `T̂(τ | k) = T_morning + η_eff × K*_k × ∫_{t0}^{τ} S0 − 夜间残余`。
观测路径与它的残差 ~ N(0, σ_path)。这条通道说的是「曲线进度」：中午已经到 H 还在陡升，和下午
三点停在 H 两小时回落 1°C，对同一个 k 的似然不同。

**已到顶分支**（k = H 桶）：条件是「剩余能量不足以再跨一档」或「冷却项已压过加热项」。
写成 `P(回落量, 回落时长, 风向突变 | 已到顶)` 与 `P(同样观测 | 还要升 d≥1 档)` 的比。

### 3.3 冷却通道（风/雨/锋面）

- 风速与阵风增量（相对上午）：对「还在升」为负证据；
- 降水出现（加热窗内）：进 m_rain，不再单独作似然；
- 风向突变 + 气温骤降 + 露点上升：锋面/海风通道，直接支持「已到顶」。

### 3.4 时钟

不再单独作特征：太阳高度角已经在 S0_rem 里，纬度、季节、海拔自动进去，
替代现行的「距结算小时数按站平移 + 6h/10h 两段斜率」。

## 4. 参数与拟合（保证是正推）

| 参数 | 拟合方式 | 数据 | 与 Tmax 有关？ |
|---|---|---|---|
| S0(τ) | 无参数 | 经纬度、海拔、日期 | 否 |
| η_station,season | 闭日 Tmax − T_morning 对 ∫K·S0 的回归 | 卫星站用实测 K；其余用 METAR 云量映射；IEM 历史可用 | 用真值 Tmax 作因变量，但这是物理参数标定，不是按 P1 评分拟 |
| m_wind / m_bowen / m_rain | 同一回归的乘法项 | 同上 | 同上 |
| ρ, σ_past, σ_fcst | 卫星序列、GEFS 对实测 | 不看温度 | 否 |
| 云量→K 映射 a, b | 有卫星站上 METAR 云量对实测 K | 不看温度 | 否 |
| K_max | 站晴空率分位 99% | 卫星 | 否 |
| λ（回火） | 走前推，按 LogScore | 服务 P1 | 是，唯一一个 |

规则：除 λ 外，任何参数不准以「最终 P1 评分」为目标拟合，否则又回到倒推。

## 9. 例子：ZUUU 2026-10-07（25°C 日）

13:00 当地：H = 25.0，P0-M 给 25°C 13%、26°C 约 30%、27°C 20%。
- S0_rem(13:00→17:00，10 月成都，海拔 493 m)≈ 1.9 MJ/m²；η_eff（微风、露点差 6°C、无雨）≈ 1.6 °C/(MJ/m²)
  → 晴空还能升 ≈ 3.0°C。
- 卫星 11–13 时实测 K_obs ≈ 0.65（比预报暗 30%）；GEFS 预报下午 K ≈ 0.7。
- 需要：26°C 要 K*≈0.33，27°C 要 K*≈0.66，28°C 要 K*≈1.0（天花板）。
- 天空通道：K_rem 大概率 0.5–0.7，所以 26 可能、27 勉强、28 几乎不可能；路径通道：12–13 时
  已平；→ L_phys 把 27/28 压低、26 与 25 相近。**不保证**把 25 推成众数——10-07 的研究说
  12 时少晒只把 25°C 从 13.2% 抬到 13.7%；正推形态能多做的是把 28 的质量清掉、把 27 砍半。
