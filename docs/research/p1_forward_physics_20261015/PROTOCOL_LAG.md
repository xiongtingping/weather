# 预登记（二）：热滞后核 τ 的天花板重跑（2026-10-15，熊先生「登记热滞后核 τ 的选法与切片，再跑一次天花板」）

写在读数之前。读数后本文不改，结果补在 RESULTS.md 第 8 节。生产不改。

## 阶段 0 的失败点

天花板 `T_ceil = H + η95 × ∫_t^{t_end} S0` 在距峰值 ≤2 h 被真值突破 3.8%（P1 只放 1.8%）。
物理解释：气温对入射能量的响应滞后 τ 小时，t 之后的升温由 [t−τ, t_end] 吸收的能量支付，
不是 [t, t_end]。同时整日一个 η 的分位把近峰值行（能量小、升幅整度）的比值压平了。

## 新定义

- **滞后能量** `E_τ(t) = ∫_{t−τ}^{t_end} S0 dτ'`（K_cap = 1，S0 同 solar.py）。
- **按时刻标定**：每个标定站日取当地 10:00 起每整点 t ≤ t_max 的行，`r(t) = Tmax_obs − H(t)`
  （H(t)=t 前报文最高），`E_τ^obs(t) = ∫_{t−τ}^{t_max} K·S0`（实测 K，逐小时，缺即弃行），
  行比值 `ρ_τ(t) = r(t) / E_τ^obs(t)`，只取 E ≥ 0.3 MJ/m²。**η_τ,95(站) = 站内 ρ_τ 的 95% 分位**，
  按日前推（评 D 日只用 D 前闭日），站内行 < 60 用全队分位（标注）。
  与阶段 0 的区别：分位取在「剩余升温 / 剩余能量」上，近峰值行自己进分位，不再借整日比值。
- **天花板** `T_ceil_τ(t) = H + η_τ,95 × E_τ(t)`；掩码、归一化、1e-3 下限同 PROTOCOL.md。
- **行**：阶段 0 修正后的同一批前缀当前行（`ol_state=APPLIED`，1,199 站日）。

## τ 的选法（两臂，均事先固定）

1. **主臂 τ_phys(站)**：站内训练日 `t_max − 太阳正午` 的中位数（小时，截到 [0, 5]），按日前推。
   只用历史时刻，不看任何评分；这就是该站气温对太阳的实测滞后。
2. **诊断臂 τ_grid**：τ ∈ {0, 1, 2, 3, 4} h，全队一个 τ，按日前推用训练日 P1 ΔLogScore 最小者
   （本线唯一允许按最终评分选的量，等价于设计里的回火 λ）。两臂都报 τ=0 同口径作对照
   （即「按时刻标定但不滞后」，用来分离「按时刻标定」与「滞后」各自的贡献）。

## 判据（宪章 240，不变）

主：ΔLogScore 掩码后 − 掩码前，站日等权，按日 bootstrap 2,000，95% 区间；结构 ΔCRPS；护栏 ΔBrier。
对象：P1 v39；根 P0-M 另报。

预登记切片：全部；当地 12–18；距峰 <3 h / 6–10 h；GOES 官方源站 / 转发源站；F 站；
**天花板绑定行**（天花板低于 H 之上第二桶下界，即最多只允许再升一档）。
分箱诊断：按距峰值 {0–2, 2–4, 4–6, 6–8, 8–10} h 报真值突破率与 P1 天花板以上质量，
判 τ 是否把突破率拉平到 ≈5%（q95 的名义）。

## 止损

主臂 τ_phys 的 ΔLogScore 区间跨零或为正 → 天花板（含滞后）结案；τ_grid 若选中 τ=4 且 ΔLog≈0，
说明「不绑」才是最优，同样结案。样本量门同前（切片 < 300 站日只叫读数）。
