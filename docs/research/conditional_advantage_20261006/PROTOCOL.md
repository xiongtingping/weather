# 条件化优势（conditional advantage）：协议（先于任何读数写死）

2026-10-06，熊先生裁定的框架：
- 校准回答「模型报的概率可不可信」；条件化优势回答「什么时候该信模型胜过市场」。两者不是一回事。
- 条件 Z ＝ 结算揭晓**之前**已知、且能改变模型相对市场预期表现的任何信息。
- 单次优势 d_t ＝ log p_t(Y_t) − log q_t(Y_t)；整体比较是 E[d]，要研究的是 **E[d | Z]**。
  等价地 A(Z) ＝ KL(R_Z‖Q) − KL(R_Z‖P)：找的不是「P 与 Q 差很大」，而是「P≠Q 时真实条件分布系统性更靠近 P」。
- 条件分四层，优先级 ① P–Q 分歧形态 ＞ ② 模型可信度 ＞ ③ 市场信息质量 ＞ ④ 时效/站点 ＞ ⑤ 天气（极少数）。
- 有价值的条件通常是复合的（例如 Δμ＞+1°C ∧ 分布明显不同 ∧ 六家高度一致 ∧ 市场价格未更新）。
- 两条独立的盈利路线：A 条件准确度优势 E[S(P,Y)−S(Q,Y) | Z]＞0；B 分歧红利（论文 2607.06166）ΔS＋D−L＞0 即使 ΔS≤0。本协议主判 A，B 作经济换算同表报出，不混。
- 新一层只回答「P0 与市场不一致时信谁」，不改 P0，不再堆气象变量去重训一个天气模型。

本文件在抽数和计算之前提交。之后要改口径，只在文末「偏离」一节追加，不改上文。
读数之后新增的条件只算候选，不进判词。

## 0 终点线（Goal）

一张表：每个预注册条件（单变量与复合）在各家族里的 E[d|Z] 发现半/确认半读数与区间、BH 后是否存活、经济换算（吃单扣费 ΔS＋D−L，挂单情景另列）；
前推回归的样本外读数（预测 d 与实现 d 的相关、顶十分位实现 E[d] 下界）；
判词只有三种之一：**有**（哪一格、读数、影子登记）／**没有**（最接近的格与缺口）／**前向在跑**（读数与日期）。
存活格登记为影子格，前向 ≥30 事件日读一次。不改 P0、不据此改任何车道。

## 1 样本

- 总体：实服记录 `basket_policy_training_fact`，每个已结算站日的**每次决策、每个阶段**（P0、P0-M、P1），真前向（当时真的服务了这份 p，对着当时的盘口）。
  p ＝ 该决策信封 `probabilities_json`；q ＝ 同一决策 `ws_snapshot_id` 的归一中价（`market_reference_v1` state=complete 才算有 q，否则该决策只进不需要 q 的读数）；
  y ＝ `basket_station_day_settlement_label` 最新修订（宪章 225）。p、q 同过 1e-3 下限后归一（宪章 224）。
- 窗口：
  - **W1 主窗**：事件日 2026-09-12 起到最新闭日（此前旧链对市场的混合系数为 0，已知）。①③④⑤ 与 ② 中除成员 σ 外的全部条件。
  - W2：09-24 起（信封开始保留各家向量），加成员 σ。
  - W3：实服 v21+（事件日 10-04 起，现行链）只报不判，样本不足。
- 家族：阶段 × 提前量窗 ＝ P0 >36h（主）、P0 ≤36h、P0-M、P1。每个家族单独做多重检验。
- 权重：站日内各决策等分、站日合计 1。区间：事件日 3 日块 bootstrap 2000 次，95%，seed 20261006。
- 发现/确认（主口径）：按事件日中点把 W1 切成前后两半；每格两向各算一次（前半发现→后半确认，后半发现→前半确认）。
  次口径（只报）：事件日奇偶交替切，用来看时间切法是否把链版本混进去。
- 最小规模：每半 ≥40 站日 且 ≥8 事件日，否则该格不判（记「样本不足」）。

## 2 目标量

- 主目标 d ＝ log p̃(y) − log q̃(y)（下限后归一的 p̃、q̃）。
- 腿目标（位置类条件用）：r_k ＝ sign(p_k−q_k)·(1[y=k] − q_k)，即「按模型方向站队这只桶，相对市场中价兑现多少」；
  声称 ＝ |p_k−q_k|，夸大 ＝ 声称 − 兑现。
- 经济换算（论文路线 B，只报不判）：每单位 λ 的 ΔS ＋ D − L，D ＝ KL(q̃‖p̃)，L 取可成交价：YES 腿卖一、NO 腿 1−买一，吃单手续费 0.05·price·(1−price)；
  挂单情景（买一+1 档、假设成交）另列并标明是情景不是上下界。

## 3 条件清单（预注册）

切点固定写死（档＝该站梯子一档；°C 量跨站前已换算，宪章 53）；写「三分位」的用发现半算切点并原样套到确认半。

### ① P–Q 分歧形态（9）
1. Δμ ＝ μ_P − μ_Q（档，带符号）：≤−1 / (−1,−0.3] / (−0.3,+0.3) / [+0.3,+1) / ≥+1
2. |Δμ|：<0.3 / 0.3–1 / ≥1
3. KL(P̃‖Q̃)：三分位；JS 同报
4. 宽度比 log(σ_P/σ_Q)：<−0.2 / [−0.2,+0.2] / >+0.2
5. 熵差 H(P)−H(Q)：三分位
6. 众数一致：是/否；不一致时模型众数在市场众数的热侧/冷侧
7. 三项分解份额：按 10-04 协议的 v0→v1→v2→v3 把 p−q 拆成中心/宽度/形状，取 |·| 的 L1 份额最大者 ∈ {中心, 宽度, 形状}
8. 逐桶 log-odds gap s_k ＝ log(p_k/q_k)（腿级，与 9 联用）：≤−0.7 / (−0.7,−0.2] / (−0.2,+0.2) / [+0.2,+0.7) / ≥+0.7
9. 位置（腿级）：z_k ＝ (T_k − μ_P)/σ_P，中心 |z|<0.5 / 肩 0.5–1.5 / 尾 >1.5；并报离市场众数档距 0/1/≥2

### ② 模型可信度（7）
10. 六家中心离散 B ＝ Σ_j w_j (μ_j − μ̄)²（°C²）：<0.1 / 0.1–0.5 / ≥0.5
11. N_eff ＝ 1/Σ w_j²：<1.5 / 1.5–3 / ≥3
12. 入座家数：2 / 3–4 / 5–6
13. 方向一致度 ＝ 中心与池中心在市场中心同侧的家的权重和：<0.6 / 0.6–0.8 / ≥0.8（只在 |Δμ|≥0.3 时定义）
14. run-to-run：同站日上一决策到本决策的 |Δμ_P|（档）：0–0.2 / 0.2–0.5 / ≥0.5；首决策单列
15. 轨迹波动：本站日此前 24h 内各决策 μ_P 的标准差（档）：<0.2 / 0.2–0.5 / ≥0.5
16. 最新成员到货龄 ＝ decision_at − max_j archive_query_at_j：≤1h / 1–3h / >3h
17. （W2）成员平均 σ A ＝ Σ_j w_j σ_j²（°C²）：三分位

### ③ 市场信息质量（8）
18. 快照龄 ＝ decision_at − snapshot.observed_at：≤5min / 5–30min / >30min
19. 市场自上次决策的变化 |Δμ_Q|（档）：<0.1 / 0.1–0.3 / ≥0.3；q 向量 L1 变化同报
20. 「模型动了市场没动」：|Δμ_P|≥0.3 且 |Δμ_Q|<0.1（是/否）
21. 所议桶点差（卖一−买一）：≤0.03 / 0.03–0.08 / >0.08；众数桶点差同报
22. 所议桶买一/卖一深度（份）：<50 / 50–300 / ≥300
23. 梯子卖一合计（抽水）：≤1.05 / 1.05–1.20 / >1.20；中价合计 |Σmid−1| 同报
24. 市场熵 H(Q)：三分位
25. 市场内部不一致：归一中价非单峰（存在局部次峰）或相邻桶断层（相邻中价比 >5 且两者都 ≥0.03）：是/否

不可用（记录在案）：成交量、最近成交频率、逐 token 盘口时间（tick 不落库；逐 token `book_observed_at` 自 10-06 才写）。

### ④ 时效与站点（4）
26. 距结算小时：>60 / 48–60 / 36–48 / 24–36 / 12–24 / ≤12
27. 阶段：P0 / P0-M / P1（即家族）
28. 结算单位：C / F
29. 季节相位 `season_bin`

### ⑤ 天气（3）
30. 晴空指数（lineage `synoptic_cooling_json.clearness_index`）：三分位
31. TAF 现象（P0-M）：报降水或雷暴 / 否
32. P1 已观测下界距 μ_P（档）：<0 / 0–1 / >1

### 复合条件（预注册，只在 ①×②×③ 内）
- C1：Δμ ≥ +1 档 ∧ 一致度 ≥0.8 ∧ 市场自上次决策未动（|Δμ_Q|<0.1）
- C2：Δμ ≤ −1 档 ∧ 一致度 ≥0.8 ∧ 市场未动
- C3：|Δμ| ≥ 1 ∧ N_eff ≥ 3 ∧ 快照龄 ≤5min（模型可信且市场新鲜——预期市场对）
- C4：|Δμ| ≥ 1 ∧ 到货龄 ≤1h ∧ 市场未动（新信息还没进价格）
- C5：众数一致 ∧ 宽度比 < −0.2（同中心、模型更窄）
- C6：众数一致 ∧ 宽度比 > +0.2（同中心、模型更宽）
- C7：尾腿 |z|>1.5 ∧ p_k<q_k ∧ 卖一深度 ≥50 份
- C8：中心腿 |z|<0.5 ∧ p_k>q_k ∧ 点差 ≤0.03
- G12：Δμ 符号×大小（≤−1 / |·|<0.3 / ≥+1）× 一致度（<0.8 / ≥0.8）× 市场未动（否/是）＝ 12 格

## 4 方法

- A 单变量格表：每个条件按上面的档位，报每档站日数、事件日数、E[d|Z]（两半各向）、区间、腿级 r_k（位置类）。
- B 复合格表：C1–C8 与 G12，同上。
- C 前推回归：E[d|Z] 用 L2 正则线性（条件 1–31 的数值版）与浅 GBM（深度 3、100 树）各一；每 3 个事件日重拟一次，只用检验日之前的事件日；
  读数：样本外预测 d 与实现 d 的 Spearman 相关；按预测 d 分十分位的实现 E[d]，顶十分位的下界；校准斜率（实现 d 对预测 d）。
  基线：09-26 的 22 特征 GBM 顶十分位 ≈ 打平（d −0.06～−0.08）。
- D 经济换算：存活格的腿级 π ＝ ΔS＋D−L（吃单扣费）与挂单情景，按事件日块区间。
- E 对照：无条件 E[d]（各家族）；只含市场的兑现层版本（M1p）作为「市场自身结构」基线——格内优势若在 M1p 上同样出现，记「市场结构，非模型」。

## 5 判据（事先写死）

存活 ＝ (i) 确认半 E[d|Z] 的 95% 下界 > 0；(ii) 发现半同号；(iii) 家族内 BH q ≤ 0.10；(iv) 每半 ≥40 站日 且 ≥8 事件日。
可交易 ＝ 存活 ∧ 吃单扣费 π 的 95% 下界 > 0。挂单情景点值 > 0 而吃单未过的记「候选」。
家族内一个条件的多档只数「预先指定的方向档」一次（例如 Δμ 的两端各一次），其余档只报不计入多重检验。
零假设期望假阳性数按家族内检验数 × 0.025 报出，放在表头。
