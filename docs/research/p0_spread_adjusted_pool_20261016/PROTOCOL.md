# 预登记：合成前按各家收窄的线性池（spread-adjusted linear pool, SLP）对现行「池＋λ＋尾混＋压顶＋271」（2026-10-16）

熊先生 10-16「预登记并测试……按提前量和站给结论」。写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改，不用市场。

## 问题
现行：各家单独校准（偏差＋展宽 1.3–2.0 倍＋核）→ 线性合成 → 共识桥 → 辐射平移 → 宽度表层（λ 整体收窄、薄池尾混、F 站尾混、>36h 压顶，271 起再加众数→肩部）。
合成单独校准过的分布必然偏宽，表层再整体收窄把质量堆到众数。SLP：**合成之前**把每家的展宽乘一个池级收窄系数 c（各家共用一个 c，按提前量档），
合成后不再经过宽度表层。问：SLP 能否在样本外胜过现行整套表层，从而让表层退役？

## 行
D0/D1/D2：事件日 D−K 当地 09:00 前最新 P0（K=0/1/2），09-01..10-14，48 站；逐家入座轮原始成员（到货早于决策）＋该 P0 的系统证书＋该 P0 的系统权重。

## 臂（事先固定）
- **现行**：存档服务 P0（池＋桥＋辐射＋λ＋尾混＋压顶＋下限）。271 尚未服务这些行。
- **现行＋271**：服务 P0 再施 271 已激活的份额（h48_plus=0.15，按距结算小时；在压顶前施加不可得，故施于服务向量之后）——诊断臂，份额是在同一批日子上拟的，样本内偏乐观。
- **SLP（主）**：每家 `_calibrated_system_probability`，展宽系数×c（c∈{0.50,0.60,0.70,0.80,0.90,1.00}，夹在证书允许范围内），按该 P0 权重线性合成 → 共识桥（生产函数，各家校准中心）
  → 辐射平移（生产口径：回执的 shift_sigma × 新池标准差）→ 1e-3 下限；**不施任何宽度表层**。c 按档逐日前推选（训练 ≥10 事件日、按整梯子 LogScore）。
- **SLP＋λ（诊断）**：SLP 后再施该 P0 回执的宽度表层，看两者是否叠加。

## 判据
宪章 240：ΔLogScore 主、ΔCRPS 结构、ΔBrier 护栏，SLP 对 现行，站日等权、按日 bootstrap 2,000；分 D0/D1/D2。
按站：每站 ΔLogScore 与区间，BH q=0.10（≥10 站日）。另报：众数/两肩/更远 三块的概率对实际频率；判肩 AUC。
**能否替代整套表层**：某档 SLP 主臂三项过 240 判决且按站无显著变差站 → 该档表层可退役的候选；跨零 → 不替代。
