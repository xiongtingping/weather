# 报告：手头的信息判不出「真值落在市场众数哪一侧」——没有

2026-10-10，按 PROTOCOL.md 与补记一。事件日 09-12..10-08，两个时刻：I1＝D−1 当地 03:00（约 45h）、I2＝D0 当地 03:00（约 21h），各约 1,060 个站日；目标只取真值不在市场众数桶的站日（每时刻约 400），y＝真值在众数之上。

## 1. 基准：市场自己的方向倾向已经很准
在这两个清晨时刻、全部站日上，市场倾向（众数以上 vs 以下的质量）判对方向 **68–75%**。对标簇在它自己出手的事件上判对 71%，而那些事件里市场倾向只判对 57%——**簇专挑市场对方向拿不准的时候出手**。

## 3. 唯一苗头的历史样本外复现：不复现
I2「昨日实测最高离市场众数多远」在发现样本里的形态是**回归**：昨日最高离众数 ≥1.5 档时，市场方向倾向偏向昨日一侧（0.54 / 0.41），真值向上只 0.46 / 0.46。系数冻结后放到此前未看过的 **08-15..09-11**（28 个事件日、320 个站日）：Δ −0.0011 [−0.0146, +0.0105]，两半 +0.0060 / −0.0084 → **不复现**。暖侧（昨日 ≥ 众数 +1.5 档）市场倾向 0.586、实际 0.500 的偏差还在（n=62），冷侧不在。

## 4. 事后切片（只报）
- 「市场方向拿不准」（|倾向−0.5|<0.15）这一格里，各信号同样不过；I2 持续性 −0.029 [−0.047, −0.013] 在这格最大，但它的全局规则已不复现。
- I2 C 站持续性 −0.0205（区间不跨零），切片多重检验下不作判。

## 5. 判词
**没有。** 我方 P0、六家各自中心、7 个区域确定性模式、METAR 的气温/露点/气压变化、昨日实测、市场误差延续与漂移，都给不出市场方向倾向之外的增量，也都与簇的方向判断无关。簇的方向信息不在这些数据里（与第 15 轮「不来自 NWP、不随区域、不是站常量」一致）。能用上它的现有途径只有跟随他们出手（宪章 257 跟单线，前向在跑）。
