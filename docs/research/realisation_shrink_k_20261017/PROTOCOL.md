## 候选

`b_k = belief(terms, START + k·(θ − START))`，`START` 是恒等点（b=q），θ 是现行 v2 拟合（十列，含改动三列），k∈[0,1]。k=1 即现行 b，k=0 即市场 q。

**k 怎么选（内层前推，不看被打分日）**：

- 每个日子 d 的前推 θ_d 与生产 `walk_forward` 同一规则：只用 `event_date ≤ d−2`、`event_date > d−2−28`、真值在 d 零点前已知的决策，前缀不足 8 个事件日的日子不出 θ。
- 对外层被打分日 D，内层日 = 所有 `d ≤ D−2` 且有 θ_d 的日子中最近 28 个；内层只计真值在 D 零点前已知的决策。
- 在网格 k∈{0, 0.05, …, 1.00} 上取内层日加权平均 NLL（每站日权重 1，同 `realisation_store`）最小的 k；并列取较大的 k。内层日少于 5 个时 k=1。
- D 的信念 = `b_{k_D}` 套用 θ_D。
