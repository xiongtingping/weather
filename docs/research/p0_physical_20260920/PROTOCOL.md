# 日前共同失误与官方物理信息：冻结实验协议

状态：离线研究，禁止生产激活；不改变服务、权重、监控或 SSOT。

## 问题与终点

检查日前 P0 共同误差能否被当时已经收到的官方预报信息改善。交付来源审计、逐站日样本、统一条件概率候选、独立时间留出评分与反例测试。数据不足或未改善均如实报告，不把接口测试或单站结果当作完成全域效果验收。

## 冻结定义

- 样本：站点 × 事件日，2026-08-14 至 2026-09-19；取该站结算日开始前最后一份已提交 P0，且不早于前一日开始。时区必须匹配唯一 market timezone binding。
- 基线：该历史 envelope 的实际概率，不用今天的校准件重写过去。核对原生产品、正权重、至少两个不同 family、成员到达时间不晚于决策时刻。
- 可用时点取 max(decision_at, created_at)，两者均早于本地零点；名义时点不冒充已经提交的时点。来源核查发现九月中旬存在数分钟编译延迟，不能用任意 60 秒容差删除这些日期。此口径在外层评分前固定。
- 标签：已闭日且完整时间戳的 ACCEPTED、FORMAL_NATIVE_ELIGIBLE AWC 日高最新版本，保留 truth ID/commit/version。训练只用标签版本已经提交的样本。美国 ASOS 的优先真值未完成逐日 canonical 赢家证明前，仅统计覆盖、不进主效果评分。
- 物理来源审计覆盖 45 站。Open-Meteo reference covariates 缺原生 run/publication lineage，不得改名充作官方原生信息；不得按事件日把迟到快照接回过去。
- 预报特征只用官方 forward TAF 的 issued/received/provider-available 三时钟均不晚于 P0 时点且有效期与目标日重叠的版本。保留 TX 可用状态、云量、降水概率、风速、预报年龄、有效覆盖比例。
- TAF 候选属于 P0-M 研究；不是 P0 成员，不引入市场价格或观测到的未来温度。不存在合格 TAF 时原样回到 P0。
- 训练集 08-14..09-04；内层选择 09-05..09-11；一次外层评价 09-12..09-19。参数选择只读内层。外层所有日期在首个外层决策前冻结模型；标签必须在拟合时已可知。
- 不根据外层结果修改特征、候选或选择规则。ZUUU 是已被用户反复检查的站，另报告剔除 ZUUU 的外层结果；不能称作全新未知天气的前瞻试验。

## 候选

固定现行 P0 和权重，条件指数族一次输出完整桶概率：q(k|x) ∝ p0(k) exp(a(x)z(k)+b(x)(z(k)^2−1))。a、b 同时优化；不再追加独立中心、宽度、band 或末端地板。z 根据实际 registry 区间推导，截断在 ±4 控制条件数。任何原基线零概率不允许静默删除命中样本；若存在此类样本，报告无限 NLL/支持集失败，不伪造有限 log score。

对照为 P0 恒等、无条件重新校准、TX 信息、云雨风信息、TX+云雨风联合；全部使用同一配对样本。TX 与物理臂不默认独立相乘。参数 ridge 候选固定为 0.01/0.1/1，训练主目标为离散分布 CRPS；内层 CRPS 最低选择，平分优先恒等/更强收缩。

指标：完整 NLL、离散 CRPS（°C）、80/90% 覆盖、区间宽度、中心 MAE/RMSE；按日期分组 bootstrap 并附短块敏感性。市场尾桶的代表点由相邻有限区间宽度推导，只用于离散 CRPS 与区间近似；不把它宣称连续密度 CRPS。NLL 按实际市场区间命中，边界合同单独测试。

切片：共同冷/暖中心失误、真值位于系统中心区间内、系统分歧、预报变温（仅使用此前可得预测）、站点及 TX 缺失。共同误差的 d=dist(y,[min centers,max centers]) 与可改善部分 |blend−y|−d 在同一中心层计算；最终 envelope 均值另列。
