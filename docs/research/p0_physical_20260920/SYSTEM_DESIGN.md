# 系统性方案：一个预测对象，三个信息阶段

> 2026-09-21 复核更正：本文件的阶段职责不构成新增架构方案；P0-M 条件似然与 P1 b2 在当前实现中已经存在。仓库 band 校准表实际是概率变换，不能与市场桶映射混称。当前实现审查与可复现发现以 `../model_layer_review_20260921/REVIEW.md` 为准。本文件不再作为“需要重新建设这些阶段”的建议。

熊先生，能提出可检验的系统方案，但不能承诺现有信息足以预测每一次共同偏差。此次实验尚未证明云雨风具有稳定增量价值；“需要缺失物理信息”仍是待检验假设。方案的目标同时包括提高可预测部分的精度，以及让不可预测部分的不确定性表达更可靠。

以下是研究目标架构，不是对当前生产已实现状态的断言。本轮不修改生产代码、权重、band、服务或采集调度。

## 1. 统一预测对象与职责

预测对象始终是站点结算定义下的当日最高温 `Y`，内部尽量保留逐成员温度过程和变量时段。三个阶段表示信息集合扩大，而不是三个可独立搬动中心和宽度的修正器。

| 层 | 条件信息 | 负责的工作 | 必须避免 |
|---|---|---|---|
| 单系统 | 同一产品、run、成员、实际到达的原生过程 | 学习该系统的条件误差与离散程度，输出完整预测分布 | 各模型看不同版本真值或用今天校准件回填历史 |
| P0 | 多系统的上述输出及严格可知上下文 | 处理系统相关性、共同残差与融合后的分布校准 | 认为调权必能移出系统中心凸包；把低相关自动等同高质量 |
| P0-M | 已校准 TAF TX 及同报文云雨风 | 按现有合同原子完成确认／有限修正与物理一致性检查 | TX、云雨风重复计入；把 TAF 当作独立原生集合系统 |
| P1 | canonical 正式观测及此前已消费的信息 | 对当日最高温与剩余温度过程作条件预测，并应用可证明的硬支持约束 | 把每条相关观测当作独立新证据；用一次观测把剩余不确定性压没 |
| band 表 | 阶段输出的同一分布与实际市场桶合同 | 对桶区间积分并物化概率、lineage 和版本 | 在表端再平移、扩宽、设另一套尾部概率 |

P1 与前两阶段不同是合理的：观测已经实现了当天的一段过程，它不仅提供预测特征，还可能产生数学排除。若理想情况下已知真实过程截至当前的最高温为 `m`，则 `Y=max(m,M_remaining)`，在 `m` 处可以出现点质量，形状不必是对称高斯。在真实系统中，报文精度、时间覆盖与结算规则决定可证明下界；只有 canonical 合同给出的下界能用于硬排除，不能把舍入后的显示值直接视作精确连续 `m`。

这不要求现阶段更换为复杂路径模型。近期可以保留冻结 P0，并用一个低自由度联合条件分布作为研究候选；长期再决定逐成员过程是否带来足够增益。任何 P0-M/P1 候选还必须与**当前同阶段**基线比较，不能仅胜 P0 就声称替代现行阶段合格。

## 2. 共同误差与单系统误差分开识别

四家中心同向出错，说明中心调权有边界；不证明共同残差可提前预测，也不证明是某个物理变量造成。全队外层中心绝对误差中，46.896% 为超出系统中心区间的距离，不能解释成“46.896% 的分布概率缺失”。

拟合顺序要让参数可识别：先用时间交叉拟合产生单系统样本外分布和残差；固定这些输出，再拟合融合层或共同条件校准层。每个训练样本的上游输出必须来自当时可用模型，不能拿训练内校准残差拟合协方差，也不能让多个自由截距同时解释同一偏差。生产权重作为冻结基线保留，是否替换只接受增量留出证据。

共同残差层只能使用日前可知信息：原生温度路径、物理过程及明确的上下文。单站小样本参数向共享参数收缩；共享范围、季节结构和自由度在开发集确定。不能为一个漏报日新增一个永久分档。无法预测残差方向时，应通过合格的整体分布校准表达风险，不能强行推中心；扩大宽度也必须接受 CRPS/NLL 与 sharpness 的共同约束。

## 3. 先补信息合同，后比较模型

本轮已经发现两个实际约束：只有 739/1,414 站日能从检查目录配齐全部参与系统的温度曲线；现有曲线混有时点温度与三小时最高温语义。新输入 schema 因而必须显式包含 variable、level、unit、step_type、valid_start/end、member、run、source hash 和可验证 availability。所有派生特征只由同一输入快照生成。

云量／短波／降水／u/v 风按原生字段合同进入。累计降水与辐射先验证累计起点和重置，再求区间量；不做跨 run 差分。缺字段明确缺失，不能用日级 reference 表猜补。完整路径无法恢复时，把可用曲线标成系统平均汇总，不能伪造成员路径。

本轮未建立合格非温度原生历史输入。接下来先找可验证的历史官方对象与对应到达回执；如只有公共历史发布证明，则另建反事实实验身份。新到达的未来日只作接口与时序观察，不能作为 OOS、硬门或晋级依据。只有后续按既定规则完成闭日、canonical truth、strict-as-of 及独立留出认证的历史数据才能进入相应评估。

## 4. 一个分布输出，band 只是映射

本次指数倾斜候选继承 P0 的零支持，内层有三次命中零概率桶，完整 NLL 为无穷。这不是删除零桶评分就能解决的问题。后续候选应在分桶前建模结算变量的完整支持与尾部，再按实际桶边界积分：`P(bucket j)=P(lower_j <= Y < upper_j)`。

若采用混合分布或重尾分布，尾部质量必须由历史样本外证据估计并校准，不能在 band 表加任意 epsilon。P1 的硬排除在条件分布支持中显式实现；软低概率和数学不可能必须分开。C/F 换算、开放尾桶与舍入规则由 canonical 结算／市场合同唯一决定。

## 5. 实验与停止规则

只维护一条可追溯实验链：输入快照 → 单系统交叉拟合 → 融合/条件分布 → 阶段更新 → 实际桶积分 → 留出评分。固定分割、候选集合和超参数选择协议，保留 identity、无条件校准、TX、过程特征及联合消融，避免把重新校准收益冒充新信息收益。

评估完整 CRPS/NLL、零概率命中、区间覆盖与宽度、冷暖两侧、四系统、分歧日、C/F 和站点覆盖；按日期/天气事件相关性评估不确定性，不能把同日多个站当作独立天气样本。使用严格同样本对照并单列缺失覆盖，覆盖损失本身是架构代价。

在新独立历史留出之前，不继续围绕本轮八天调参。可接受增益和关键切片容忍边界必须在看到新留出前预注册，再同时遵守既有历史 OOS 与 exact activation 门；本文件不创造更宽松的上线规则。无稳定收益则保留基线、记录失败原因，不把不显著写成“到顶”或“没有任何方案”。
