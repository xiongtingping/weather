## 结论

1. **这一层做得出来，并且在这份样本上说多少中多少。** 候选 M5 的 24 个被判的档全部在区间内；它说 56% 的那一档，实际中 56%。
2. **它比市场和模型都清晰。** 平均最高桶 0.440（市场原样 0.383，模型 0.407）；LogScore 比市场原样好 0.046 nat、比模型原样好 0.177 nat。
3. **它量出来的真相：可兑现的 edge 很薄。** 吃单、扣费后：远端 NO 每份 +0.83¢ [+0.42, +1.31]（每元 +0.9%），声称 0.84¢、兑现 0.83¢；
   YES 没有可兑现的 edge（−0.45¢ [−2.76, +2.24]）。
4. **这层的收益八成是市场自己的结构，两成是模型。** 对市场原样的 0.046 nat 里，「市场自校准＋档距截距」占 0.038，模型分项占 0.008 [0.0005, 0.016]。
5. **模型的增量有条件：** 两个中心一致时 0.017 nat、>60h 0.070 nat、C 站 0.0125 nat；中心不一致与 F 站为零。
6. **M5 是读过第一轮之后加的。** 它只是候选，须在此后新结算的事件日上原样复读。

## 这一层是什么

模型向量 p 回答「只看天气」。这一层回答「看到 p、又看到市场 q 之后」：b_k = P(Y=k | p, q, 条件)。edge 只按 b 对可成交价算。

M5 的形式（整梯归一的多类对数池，7 个参数，按多类 LogLoss 逐日前推拟）：

    log b_k ∝ α·log q_k                                   市场自校准：α≈1.13，把市场向量拉尖
            + γ0·[k 是市场众数桶] + γ1·[k 在众数隔壁]        档距截距：0.38、0.41
            + w_宽·D_宽度 + w_形·D_形状                     模型的宽度与形状；中心一致时 0.48／0.39，不一致时 0.22／0.10
            （模型的中心分歧不进：系数固定为 0）

仓库里的 L4 后验（宪章 230，下线中）是它的第一版：一个 α、一个 γ、整个 p 一个系数。

## 按协议的判词

- 第一轮（M1–M4）：没有一层「可用」（M4 有 2／24 档不过）。事先写的保序映射后备没有改善。
- 我定的「所有档都过」没有考虑多重检验；判词照原文记，另报不过的档数对期望 1.2。
- 修订后的 M5：层可用＝是；比市场自校准（含同样截距）多带信息＝是；「有把握的 edge 扣费后兑现」＝NO 是、YES 否。

## 限制

- 可计分的只有 13 个事件日；样本是 v≤20 的服务记录、压顶之前的 p；M5 与 M1p 是读过前一轮之后加的。
- 条件档与分项的选择来自 10-04 在同一批数据上的读数。
- 只做了吃单、只吃最优一档、不计深度。挂单能拿到多少，成交的是哪批腿，只有实盘能答。
- 「有把握」只量了参数的不确定性，没有量卖一带来的选择效应。
