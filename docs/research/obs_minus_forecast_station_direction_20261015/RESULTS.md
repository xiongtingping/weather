## 测试一：市场有延迟——成立

目标 = 真值 − 市场均值(t+h)。四增量（站内收缩）逐日前推：

| 盘口时刻 | 行 | 样本外相关 | MSE 改善（对站均值基线） |
|---|---|---|---|
| t | 10,522 | **0.27** | −0.027 [−0.040, −0.016] |
| t+1h | 9,835 | 0.24 | −0.018 [−0.028, −0.009] |
| t+3h | 9,621 | 0.23 | −0.011 [−0.019, −0.005] |
| t+6h | 8,975 | **0.25** | −0.005 [−0.009, −0.002] |

- 六小时后增量仍以同样相关度预测「真值 − 市场」：**市场没有在六小时内把实况减预报吃进价格**（残差总量随时间缩小，是市场靠后续报文收敛，不是靠这条信息）。
- 市场在接下来 3 小时**没有朝信号方向挪**：斜率 −0.03 [−0.09, +0.03]。
- 按站：t 时相关 > 0.30 的有 LFPB 0.47、MPMG 0.47、OPKC 0.42、ZHHH 0.42、ZSQD 0.36、CYYZ 0.35、ZUUU 0.35、EDDM 0.33、RKSI 0.32、NZWN 0.31、LTAC/ZGGG/RCSS/KORD 0.30–0.31；
  ≈0 的有 KHOU −0.10、RPLL 0.01、KMIA 0.04、FACT 0.05。

**但同一批增量对 P1 一样成立**：预测「真值 − P1 均值」样本外相关 0.28（MSE 改善 0.036）；P1 均值本身比市场更不准（MAE 0.42 对 0.37，各时段都输）。
即：市场慢，P1 更慢。

预登记形态（P1 均值平移 ê，σ 取 P1 自身）：全队 ΔLogScore **+0.059 [+0.029, +0.092] 变差**。按站（BH q=0.10，≥10 站日）：

方向命中率（sign ê 对 sign e）多数站 0.55–0.87，**但命中方向不等于分数变好**：平移量对 P1 下午的窄分布太大。

**事后诊断（未预登记）**：强度 γ 前推选择——固定 γ=0.1 +0.001 跨零，0.25 起显著变差；全队前推 γ +0.007 变差；分站前推 γ +0.022 变差。
分站前推下没有站过 BH；ZSQD −0.054 [−0.104, −0.008]、OEJN −0.063 [−0.129, +0.003] 名义仍为负。

## 测试三：相对市场众数的方向强似然——方向就是市场自己的倾斜，强似然全亏

- 增量 + 市场倾斜预测的方向，与市场自身倾斜**同向 99.5%**：增量几乎不改变「偏暖还是偏冷」的判断。
- 真值离开众数的行上：**市场倾斜方向命中 86.7%，P1 倾斜只命中 80.4%**——P1 相对众数的方向判断比市场差。
- 但强似然 L(k)=exp(κ·d·side) 加在 P1 上全部变差：

| κ | 全队 ΔLogScore | BH 显著变好（≥10 站日） | BH 显著变差 |
|---|---|---|---|
| ln 1.5 | +0.009 [+0.005, +0.013] | 无 | KLAX RKPK RPLL WSSS ZUCK |
| ln 2 | +0.023 [+0.016, +0.030] | 无 | 8 站 |
| ln 3 | +0.052 [+0.039, +0.063] | 无 | 14 站 |
| 分站前推 κ | +0.006 [+0.003, +0.011] | 无 | EFHK EPWA KHOU MPMG RCSS |
| 对照：只用市场倾斜 | 与上表几乎相同 | | |

原因：有方向的行里**一半真值落在众数桶本身**（2,975 行中 1,387 离开众数），而 exp(κ·d·side) 归一化后把众数桶的质量也搬到一侧；
方向对了的那一半赚的，少于落在众数的那一半赔的。

## 结论（按熊先生三点）

1. **市场有延迟：对。** 实况减预报对「真值 − 市场」的预测力 6 小时不衰减，市场 3 小时内不朝它挪。但 P1 均值更慢、更不准。
2. **不按平均否定：分站看，OEJN、ZSQD 两站显著变好且前后半同号**；ZUUU/MMMX/LEMD/KDAL/KBKF 显著变差；其余跨零。
   两站只有 22 站日、全靠一种未调强度的形态，按 [[in-sample-signal-dies-out-of-sample]] 只能作前推候选，不能上线。
3. **方向强似然：现形态不成立。** 增量给出的方向就是市场倾斜；它比 P1 自己的方向准（87% 对 80%），
   但「把一侧整体加权」会把众数桶的质量也搬走，而真值一半落在众数。

## 下一步候选（需另行预登记）

  这是对测试三失败原因的直接修正：方向命中 87% 的价值不被「真值落众数」吃掉。
