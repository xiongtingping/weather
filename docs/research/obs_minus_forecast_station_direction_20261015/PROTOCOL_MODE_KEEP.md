# 预登记（二）：保众数的方向似然（2026-10-15，熊先生「众数桶概率不动，只在两侧之间按方向搬质量」）

写在读数之前；读数后不改，结果补 RESULTS.md 第二部分。样本、增量、前推方式、方向 d 的定义与第一份 PROTOCOL.md 测试三完全相同
（同一 rows.jsonl.gz、同一 `shrunk_station_predict`、|ê_m| < 0.25 桶宽静默）。

## 形态

众数 m = 决策时刻市场众数（宪章 266 同一函数）。P1 向量 p，A = 众数以上质量，B = 众数以下质量，R = A + B = 1 − p_m。
d = +1：A' = R·A·e^κ / (A·e^κ + B)，B' = R − A'；d = −1 对称；d = 0 不动。
两侧内部形状不变（各桶按原比例缩放），**p_m 精确不变**，硬下界排除的桶保持 0（某侧质量为 0 时不搬）。之后套 1e-3 下限。

## 臂

- 方向来源：①增量 + 市场倾斜（主）；②只用市场倾斜（对照）；③**神谕方向**（d = 真值相对众数的真实一侧，真值落众数时 d=0）——只作上限诊断，不作判决。
- 强度：κ ∈ {ln1.5, ln2, ln3} 固定；分站前推 κ ∈ {0, ln1.25, ln1.5, ln2, ln3}（站内 ≥ 8 站日，否则全队前推值）。

## 判据

宪章 240：LogScore 主、CRPS、Brier。全队 + 按站（BH q=0.10，只对 ≥ 10 站日的站）。按站给结论，不用全队平均否定。
另报：真值落众数 / 离开众数且方向对 / 离开且方向错 三类行各自的 ΔLogScore 均值，说明赚亏来自哪里。

## 预期

第一份测试三的亏损主要来自众数质量被搬走；本形态去掉这一项后，剩下的是「方向对 87%」对「方向错 13%」的权衡，
加上 P1 本身两侧形状是否已含方向。神谕臂给出上限：若神谕都只赚很少，说明两侧之间的搬运本身空间有限。
