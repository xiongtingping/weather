# 市场价格变化作为信号（Δp × Δq 同向/异向）— 2026-09-06

> 用户问：有没有把"市场价格变化方向"与"模型概率变化方向"合起来当信号的研究？
> 答：此前没有（只有 08-26 挂单腿 Edge×Δq 四象限、v9 诚实配对的顺带观察、"卖一跌幅≥50% 中标 2.4%"）。本日补量。
> 脚本：`scripts/probe_price_move_information.py`（概率层，全 checkpoint × 真值）、`scripts/probe_price_move_quadrants.py`（席位层，账本重放小库）。
> 数据：`replay_src_0815.db`（08-15→09-04），真值 852 站日，45 站。

## 1. 定义
- 窗口 = 该 checkpoint 最大质量的连续三桶（不是席位规则；这是概率层信号研究，不复刻生产规则）。
- Δp = 窗口质量 现在 − H 小时前的 checkpoint；Δq = 窗口卖一合计 现在 − 那个 checkpoint 之后第一张盘口（生产当时实际编译的书）。
- 结果 = 真值落在窗口。ε=0.02 判方向；分层表用 |Δq|≥0.05。
- a = q/p（成本/声称），即宪章 68 λ(a) 读的量。

## 2. 未分层：Δq 方向极强（6h，n=5,922；12h，n=5,141）

|---|---|---|---|
| up | 实现/声称 0.82（12h 0.72） | 1.00 | 1.16（12h 1.19） |

命中率差 up−down：6h +40.6 点、12h +50.6 点。三阶段同形状。
**Δp 的方向本身不带信息**：模型自己把窗口调低后，只要市场在抬，仍命中 89–91%。

副产品：实现/声称随 a 单调 0.11 / 0.49 / 0.75 / 1.00 / 1.30，是 λ(a) 表的一张独立校准（表最低档 0.14 对本表 0.11–0.14 吻合）。

## 4. 席位层（账本重放）
- 可配对席位仅 47（链内上一座）/59（6h）/81（3h），几乎全是 P1 与 P0 再入座。
- **P0 开仓结构上无先验**：203 个 P0 席位中 195 个坐在站日第一个 checkpoint 后 4 分钟内，第一张盘口与第一个信念同分钟落地（宪章 48 挂牌即建仓）。市场变化信号对 P0 开仓永远不可用，而亏损在 P0。

## 5. 结论
1. Δq 不是独立信号，是 a 的导数。要用它，落点只能是 λ(a) 表加一维（|Δq|≥0.05 且向下 → 额外折扣），且只对加仓/后阶段有意义。
2. "概率下降不加仓"已是宪章 69/71（Δp 规则）；概率层数据显示 Δp 方向本身不预测实现/声称，规则的钱来自它拦住了"刚降的桶=市场更便宜的桶"。
3. 用户所言"edge 折扣表也是对抗逆选择的方法"成立：λ(a) 是本系统对市场信息的唯一在产读法，本表是它的校准证据。
4. 增量 8–9 点能否变钱未测；账本席位样本太薄（<100），若做只能开影子车道攒。

## 7. 能不能拿来影响加仓（09-06 追问）
只看加仓所在阶段（P0-M+P1），按当前 a 分层再看象限（|Δq|≥0.05，|Δp|≥0.02）：

| a 档 | 象限 | 6h n / 实现÷声称 / 单位收益 | 12h n / 实现÷声称 / 单位收益 |
|---|---|---|---|
| 0.9–1.1 | p↑q↑ 同向 | 130 / 1.01 / −3% | 149 / 1.01 / −4% |
| 0.9–1.1 | p↑q↓ 异向 | 43 / 0.98 / 0% | 51 / 0.94 / −5% |
| ≥1.1 | p↑q↑ 同向 | 364 / 1.17 / −11% | 511 / 1.22 / −8% |
| ≥1.1 | p↑q↓ 异向 | 50 / 1.31 / +3% | 47 / 1.44 / +15% |
| <0.7 | p↑q↓ 异向 | 81 / 0.21 / −37% | 127 / 0.22 / (彩票) |

- 平价带（0.9–1.1）同向与异向差 3–7%，两边单位收益都≈0：没有可花的信号。
- 贵带（≥1.1）异向反而更好：市场把贵窗口压便宜一点，兑现更高、单位收益转正。"市场跌了就不加"在这里方向是反的。
- 便宜带（<0.7）不论同向异向全死，那是 a 的事，λ(a) 已在读。
**裁定：市场价格变化不作加仓信号，既不作"跌了不加"也不作"涨了多加"。** 后者是确定性溢价反转（同向上涨格单位收益 −8~−11%）。
加仓的钱在 a 的水平和概率身份变化（宪章 71）上；影子表继续攒，只为验证这条裁定是否随样本翻转。

## 8. "贵带里市场压下来"那格到底是什么（09-06 追问：确定性溢价吐出来是不是加仓时机）
两格分开看（P0-M+P1，a_now≥1.1，|Δq|≥0.05）：

| 格 | 6h | 12h |
|---|---|---|
| 模型升·市场跌·仍贵 | n=50 站30；a 1.71→1.22，p 0.49→0.63，q 0.92→0.80；命中 82%；单位 +3%，剔1/2/3 +1/0/−1，周 +4/−5/+30/−6 | n=47 站25；a 1.73→1.24，p 0.50→0.62，q 0.88→0.79；命中 89%；单位 +15%，剔1/2/3 +13/+11/+10，周 +11/+16/+29/−3 |
| 模型平·市场跌·仍贵 | n=70；p 0.62 不动，q 0.92→0.83；命中 70%；单位 −15%，剔后更差，四周全负 | n=54；命中 57%；单位 −27%，四周全负 |

- **纯"溢价吐出"（模型没变、市场跌）是坏格**，稳健地坏。市场离开一个模型没更新的窗口，不是让利。
- 好格是**双向收敛**：模型追上来 +14 点、市场退下来 −12 点，之后市场仍高于模型两成；实现 85–89% 远高于声称 0.63。溢价是相对真值说的，不是相对模型；这里错的是模型（低报），与 P1 "边际是观测" 一致。
- 同一批窗口 6h 前按当时价买是 −10%，收敛后买 +3%/+15%。
- **现行规则买不到这格**：抬价后声称 0.68 < 价 0.80，正 EV 闸拒绝；两视野各 50/47 个样本里能过闸的只有 4/4 个；账本 P1 加仓席位落在此格 0 个。
- 结论：它不是"加仓时机"，是"概率层缺市场证据"的最直接指证——要吃这格，得先让声称向市场隐含概率靠（§4-1），闸门才会开。6h 视野不稳健，12h 稳健但 n=47，尚非真钱。
