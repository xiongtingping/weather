# 预注册协议：哪些信息能提高「市场均值桶±1」的分辨率

写于 2026-10-10，任何读数之前。提问人：熊先生（「校准用logscore。分辨率是能不能把会中的日子和不会中的日子分开报：用logloss，并寻找条件化或者特征，以市场均值桶加减1桶为选桶目标去找！比如模型的均值桶、众数桶和市场的众数桶、比如历史温度、比如云雨辐射证据、比如模型的入座权重。看哪些信息能提高分辨率！」）。只读研究，不改生产。

## 0 终点线
一张表：每组信息 × 每个阶段家族，加到「市场自身」基线上之后，样本外（逐事件日前推）二元 LogLoss 的变化与区间、前后两半是否同号、是否过多重检验，以及 RES/REL（Murphy 分解）。判词只有三种：**有**（哪组、哪个家族、读数）／**没有**（最接近的组与区间）／**样本不足**。

## 1 样本
- 实服决策 `basket_policy_training_fact`（当时真的服务的 p、当时的盘口），事件日 2026-09-12..10-08，已结算（`basket_station_day_settlement_label` 最新修订，宪章 225）。抽数复用 `conditional_advantage_20261006/rows`（事件日 ≤10-04），10-05 起用同一 `extract.py` 另抽到本目录。
- 家族：P0 距结算 >36h（主）、P0 ≤36h、P0-M、P1。每站日每家族取**第一个市场完整**（`market_reference_v1` complete）的决策。
- p、q 先过 1e-3 下限再归一（宪章 224）。

## 2 目标桶与目标量
- M＝市场均值桶：μ_Q＝Σ q_k·T_k（T_k 为档中点，开放边档按半档外推，同 extract.py）落入的档（取中点最近者）。窗口 W＝{M−1, M, M+1}∩梯子；pos∈{−1,0,+1}。次口径（只报）：市场众数桶±1。
- 每个 (决策, b∈W) 一行，y_b＝1[结算桶＝b]。
- 分数：二元 LogLoss（截 [1e-6, 1−1e-6]），按决策求和；比较一律成对（同一行）。

## 3 模型与信息组
逻辑回归（特征标准化、L2 C=1.0，sklearn），逐事件日前推：用检验日之前的全部事件日拟合（至少 8 个事件日），预测检验日。
- **B0 市场基线**：pos 三个哑变量 + logit(q_b)×pos 哑变量（市场自校准）。
- 以下各组**分别**加到 B0 上（日级特征 x 以 x·pos 与 x·1[pos=0] 两种形式进入：前者表示整体冷暖平移，后者表示集中/分散）：
  - **G1 模型概率**：logit(p_b)、logit(p_b)×pos。
  - **G2 模型与市场的相对位置**：Δμ＝(μ_P−μ_Q)/档（日级）；|Δμ|；z_b＝(T_b−μ_P)/σ_P 与 z_b²；1[b＝模型众数桶]；模型众数桶−市场众数桶（档，日级）；1[模型均值桶＝M]（日级）。
  - **G3 历史温度**（只用决策时刻已提交的正式真值）：最近一个已知日最高温与 T_b 之差（档）、最近三个已知日均值与 T_b 之差（档）、最近已知日距事件日天数；该站最近 5 个已知日「真值−当日首个 P0 均值」的平均（模型近期偏差，°C→档，日级）；μ_Q 减该站近 30 个已知日真值均值（档，日级）。
  - **G4 云雨辐射**（Open-Meteo 预报版本表 as-of 决策时刻，事件当地日）：短波辐射和对该站全部版本历史的标准分、平均云量、降水和 log1p、10m 最大风速（均日级）。
  - **G5 入座权重**：N_eff＝1/Σw²、入座家族数、各家中心离散 B＝Σw(μ_j−μ̄)²/σ_P²、最大权重、AI 两家（AIFS、AIGEFS）权重和（日级）；方向一致度（中心与 μ_P 同在 μ_Q 一侧的权重和）×sign(Δμ)。
  - **G6 时效与盘口（附加）**：距结算小时、M 档点差、快照龄（分钟）、市场中价合计偏离 |Σmid−1|（日级）。
- **ALL**：B0+G1…G6 全部。
- 对照（只报）：**P-only**＝pos 哑变量＋logit(p_b)×pos（只看模型，量模型自身分辨率）。

## 4 判据（写死）
- 每组×家族：Δ＝组−B0 的每决策二元 LogLoss，事件日 3 日块自助 2000 次 95%；前后两半（检验日按中位切）各自的点值。
- **有**＝95% 上界<0 ∧ 两半同为负 ∧ 单侧 p<0.05/24（6 组×4 家族 Bonferroni）。只过前两条记「苗头」。
- 同表报 RES、REL（全部窗口行，概率档 0–0.05、0.05–0.1、0.1–0.2…0.9–1.0）。
- 判词之外新增的组只算候选。
