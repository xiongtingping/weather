# 报告：市场均值桶±1 上，没有一组信息能在市场之外提高分辨率

2026-10-10，按 PROTOCOL.md（含偏离一）。实服决策，事件日 09-12..10-08，每站日每家族取第一个盘口完整的决策；目标桶＝市场均值桶 M 及 M±1；逐事件日前推（≥8 个训练日），检验日 09-20..10-08 共 19 天。P0 ≤36h 只有 70 个决策，样本不足、不判。

在窗口桶上，模型自身的分辨率约为市场的一半（P0 >36h：9.0 对 17.4），到 P1 约为八成。

**判词：没有。** 18 格无一过门（95% 上界<0 ∧ 两半同负 ∧ Bonferroni），也无一「苗头」；最接近的是 P0-M 的 G3（−0.0010，区间跨零）。几组反而显著更差（过拟合：信息已在价格里，多加参数只加噪声）。预注册首读（缺失加标志口径）结论相同，见 results.json。

## 3. 单特征筛查（候选，不进判词；3 家族 × 26 个特征，95% 下期望约 2 个假阳性）
- 唯一「苗头」：**P1 的「桶离最近已知日最高温多远」**（d_last）Δ −0.0069 [−0.0129, −0.0004]，两半 −0.0082/−0.0057，单侧 p=0.018——过不了多重检验，量级约每决策 0.007 nat。白话：到了当天，昨天的最高温对「今天落在市场中心附近哪一档」还有一点点市场没用足的信息。
- 其余单特征（模型众数桶−市场众数桶、风、最大权重、近期模型偏差等）全部跨零，|Δ|≤0.0024。

## 4. 读法
- 在市场均值桶±1 这三档上，模型的均值桶/众数桶、它与市场众数的相对位置、历史温度、云雨辐射、入座权重，**都已经被市场价格吸收**；加进去样本外不提高分辨率。可检出下限约 0.002–0.01 nat/决策（各格区间半宽），比这更小的增益本样本看不出。
- 与兑现层滚动读数（模型项 −0.009 nat，全梯子多类）不矛盾：那份增益在宽度/形状、主要在窗口外的尾部；窗口三档内 G1 的上界只有 −0.0013。

## 5. 层级
研究，只读；不改生产、不改兑现层。P1 d_last 若要追，属兑现层/P1 的候选特征，须新样本原协议复读（≥30 个新检验日，约 11 月中）。
