# 逐站 TX 收缩权重（08-20 起长窗口前推，预先登记，2026-10-26）

熊先生 10-26「按协议测逐站 TX 收缩权重，08-20 起长窗口前推」。10-26 快速诊断里逐站 TX 技巧差别大
（LLBG 两半都约 +0.6，ZGSZ/ZUUU 两半都为负），合起来抵消为 0；本测试看按站给权重能否稳定挣分。

## 样本

每个已结算站日：当地 10:00 之前发布、带该日 TX 的最后一份 TAF（原文归档，08-20 起）；其发布时刻当时最新的 P0。
- **主样本（旧根，长窗口）**：P0 实际服务的向量（v31 的 F 平移日取 `pre_shift_probabilities`），08-20..10-24。
  新根只有 09-29 起，不够长，故主裁用旧根——回答「这个台的 TX 相对当时的 P0 有没有稳定信息」。
- **副样本（新根）**：宪章 281 新根历史重建，09-29..10-24（读数）。

## 规则

δ ＝ w_s·(TX − μ)，μ 为根的分布均值；把根向量整体平移 δ（桶内均匀、开口桶截一桶宽，重新积分到原桶界），1e-3 下限。
w_s ＝ clip( n_s·b_s / (n_s ＋ K), 0, 1 )，b_s 为该站训练日上 (真值 − μ) 对 (TX − μ) 的过原点最小二乘斜率，
n_s 为该站训练站日数，**K ＝ 15**（向 0 收缩），负斜率截为 0（反向的台不用，避免学噪声）。

## 臂

R（根）、S（逐站收缩权重）、G（全队一个权重，同式、n 为全队站日、K 同）。

## 前推与判据

逐事件日前推：w 只用该日之前的站日（且真值在该日开始前已提交）拟。打分从 08-27 起。
主比较 **S − R（旧根）**：LogScore 95% 上界 < 0、RPS/Brier 不显著变差、≥20 可评事件日（宪章 240）。
另报：S − G、逐站增量与最终 w_s、前后两半、新根副样本。过门只表示 TX 对 P0 有逐站信息，
是否进生产（新根上的形态）另行提请。
