# 预注册协议：入座哪几家（全队去掉一家）与家族上限

写于 2026-10-02，评分之前。裁决人：熊先生（「继续打入座，入座哪几家，多少家合适？还有家族上限 0.75」）。

## 数据与机器
`station_model_weights_20261001/pass1_all`（六家 1–9 月走查）；score.py 代表决策与下游；席位权重按现役 κ=0.25 重建（同 seat_weight_kappa）；服务权重＝宪章 242 EBP*（τ 前推选，选 τ 时不过上限，同生产 `choose_tau`）。计分 04-01..09-30，宪章 240 门，簇=站日。

## A. 全队去掉一家（6 臂）
每臂把系统 j 从每个决策的池里拿掉，席位权重在剩余家内归一，再走 242；若拿掉后不足两个家族则该决策保留原池（报告其数量）。对照＝六家全池。服务口径主判。
- 某臂对全池**过门**（去掉 j 显著更好）且两段同负 → 提议退役 j（属扩大范围，须裁）；否则维持全座。

## B. 家族上限（5 臂）
服务权重经 `fusion_blend.feasible` 按家族上限 c 截断：c ∈ {0.5, 0.6, 0.75（现役）, 0.9, 1.0（不设）}。对照＝0.75。报告上限起作用的决策比例。
- 某 c 对 0.75 过门且两段同负 → 提议改上限；否则不改。
