# 预登记：我们读「对称」的 P0-M/P1 站日，决策时手上的实况能否分出方向（2026-10-16）

熊先生 10-16「继续」（针对：看「我们读对称、市场判出偏斜」的 P0-M 241 / P1 191 站日，当时手上的实况能不能把方向分出来——已测最高温相对众数的位置、升温速度、离峰值还有几个小时）。
写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改。

## 行
`board_readings.skew_truth_rows(conn, since="2026-09-01")` 的 P0-M（接手前末份）与 P1（首份）行，**我们的服务向量读「对称」**（`_skew_point` sign＝0，门槛 0.20σ）且真值不在我们的众数桶。
目标 y＝真值在我们众数的上方（1）/下方（0）。
两个人群：**主**＝其中市场同刻判出偏斜的行（即上一份的「只有市场判出」）；**并报**＝全部我们读对称的行。

## 特征（决策时刻已到达，事先固定）
实况来源：`p1_forward_physics_20261015/inputs.db` 的 `obs`（AWC METAR/SPECI，`committed_at` ≤ 决策时刻，`valid_at` 落在该站当地事件日；`correction_suspected`＝1 的不用）。
众数中心 m＝我们众数桶的轴中心（`ladder_axis`；F 站按 2°F 桶），桶宽 w＝该站梯子桶宽中位。
- f_high＝(已测最高 − m)/w
- f_last＝(最新一报温度 − m)/w
- f_rate＝(最新一报 − 约 2 小时前一报)/小时（取 valid_at 在最新一报前 1.5–2.5 小时内最近的一报；没有则缺）
- f_hour＝决策时刻当地钟点（小时，含小数）
缺任一特征的行在该特征/组合里剔除并计数。

## 方法
- 单特征 AUC（按事件日 bootstrap 2,000、seed 7 给区间）。
- 组合：四特征＋截距的逻辑回归，按事件日逐日前推（训练＝更早事件日的同阶段行，≥10 事件日），AUC 与判对率（p>0.5 判上方）；在同一批前推评估行上并报市场判对率。
- 分 P0-M、P1 两阶段各自做。

## 判据
主人群上，前推组合 AUC 的区间下限 > 0.5 → 「实况能分出这些日子的方向」，并报它与市场判对率之差；否则 → 「当时手上的这几项实况分不出方向」。

## 已知限制
样本小（主人群约 190–240 行、30 个事件日）；实况只用 AWC 报文的整数温度；f_hour 不按站点日变化相位校正。
