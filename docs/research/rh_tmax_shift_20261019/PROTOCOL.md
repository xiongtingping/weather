# 湿度 · 实况对比预报 → 最高温 ΔT（协议，先于读数）

2026-10-19 熊先生「卡片增加湿度并拟合」。与露点、风（`dew_tmax_shift_20261019`、`wind_tmax_shift_20261019`）同一套做法，只读研究，只进看板显示。

## 数据
- 报文相对湿度：例行报（整点 ±10 分钟）的气温与露点，按 Magnus 公式（6.112·exp(17.62·T/(243.12+T))，水面）算，
  与看板同一函数（`station_day_board.relative_humidity`）。报文温度露点是整度，湿度分辨率约 5–7 个百分点。
- 预报相对湿度：Open-Meteo `relative_humidity_2m`（最新预报，卡片口径），previous-runs 接口，09-01..10-14；研究额度记账。
- y：结算真值 − 日前预报最高温（站去均值）。

## 定义（事先写定）
- **主口径（卡片口径）**：x = H 点报文相对湿度 − 同一小时最新预报相对湿度（百分点），H = 9..17。
- 辅口径：05..H 平均（只报告）。
- 模型：ΔT = 截距 + 偏干斜率·min(x,0) + 偏湿斜率·max(x,0)，x 截在 ±20 个百分点；卡片只用斜率部分。
- 至少 8 个站日的站才进样本；按事件日五折样本外，按日自助 95% 区间。

## 判据
- 样本外 ΔMSE 区间上沿 < 0 才算「样本外显著」，否则卡片 ΔT 标灰。
- 另报：与露点差在同一批站日上配对比较样本外（湿度 − 露点），供参考，不据此删卡。
