# P0 开仓是不是太早了 — 2026-09-06

> 用户问：P0 席位 195/203 坐在挂牌后 4 分钟内，是否太早？
> 账本上没有变化量可测（全在同一分钟），改读概率层：每个站日挂牌后 H 小时，最大质量三桶窗的声称、卖一成本、命中。脚本 `scripts/probe_p0_entry_timing.py`，库 `replay_src_0815.db`，真值 852 站日。
> 窗口是最大质量三桶，不是席位规则；有效边际用内核 `effective_edge_lambda` 与 P0 常量算。

## 1. P0 的在任期很短
940 站日：首个非 P0 checkpoint 是 P0-M 677、P1 220，43 个从未离开 P0。
P0 在任时长 p10 0.9h / p25 2.8h / **p50 5.0h** / p75 14.1h / p90 21.4h；≤6h 占 58%，≤24h 占 95%。
→ "把 P0 往后挪"对多数站日等于"让 P0-M 开链"，宪章 74 不许。挪 = 不开，不是晚开。

## 2. 同一站日自己对自己：越等越贵

声称几乎不动、价格不跌、命中不升；等 6 小时以上同一个窗口的买入 EV 掉 12–18 点。

## 3. 挂牌那一分钟的正有效边际窗口，之后只会变贵
0h 正有效边际窗口 41 个（27 站）：命中 51% 对声称 71%，单位收益 +31%，剔 1 个赢家 +1%、剔 2 个 −5%。
跟踪同一批：价 0.46→0.47(3h)→0.49(6h)，a 0.66→0.70→0.74，仍为正有效边际 38/38→22/39→14/29，单位收益 +36%→+14%→−32%。
市场不是"早期噪音、后来纠正到我们这边"，是往真值方向纠正、把我们看中的便宜收走。

## 4. 盘口成熟度
挂牌时 99–100% 桶已挂出；卖一总和（超额）1.17(0h)→1.14(1h)→1.06(36h)，价差随时间收窄，但目标函数看中的那些窗口不跟着变便宜。

## 5. 结论
1. **不是太早。** 挂牌分钟是同一窗口最不吃亏的时刻；P0 的亏损是选择问题（名义边际＝逆向选择，每个时刻都亏），不是时机问题。
2. 为了让 Δq 信号对 P0 可用而把 P0 后挪，代价 12–18 点，信号最多值 8–9 点，且多数站日根本等不到（P0-M 5 小时内接管）。
3. 未做账本臂：宪章 74 之下"延迟 P0"结构上混同"不开链"，账本臂量到的会是链数减少而非时机。
