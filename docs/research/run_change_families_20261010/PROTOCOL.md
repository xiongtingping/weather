# 预注册协议：「最新一轮改动」的分辨率——全部家族，及对 Proper 线的含义

写于 2026-10-10，任何本研究读数之前。熊先生：「并不一定是ECMWF家族，去研究一下其他家族。另外，这个对proper线有什么意义？之前一直说模型没有分辨率，现在找到了一条！」（同时撤回跟单线改动：跟单线不动。）只读研究，不改生产。

## 0 终点线
（1）一张表：每个系统（6 家原生集合、8 家确定性点预报、我方服务 P0）与几个合成，「本轮−上一轮」在我方到货 +1h 的方向技能、对市场倾向的样本外增量、市场随后的漂移；（2）对 Proper 线：改动能否改变众数桶的命中（Proper 现行腿）、以及「按改动方向买众数旁一档」的纸面盈亏（吃单与挂单情景分开）。判词三种：有／没有／样本不足。

## 1 样本与口径（同 direction_signal_20261010 补记二）
- 事件日 2026-09-12..10-08；决策行复用 `conditional_advantage_20261006/rows`（≤10-04）与 `resolution_features_20261010/rows`（≥10-05）。
- 原生集合：`calibration_native_ensemble_historical_member_run`（qc ACCEPTED，≥10 成员），到货＝该轮最早 archive_query_at；确定性点预报：`calibration_regional_point_run`，到货＝该轮最早 knowable_at。同站同目标日按 run init 排序，Δ＝本轮−上一轮（°C）。
- 我方 P0：每个 P0 决策的分布均值 μ_P；Δ＝本决策 μ_P − 该站日上一个与之相隔 ≥3h 的 P0 决策 μ_P；到货＝本决策时刻。
- 时刻 t＝到货+1h；盘口取 ≤t、≥t−2h、且快照观测时刻不早于到货的最近决策（严格口径）；t+h 的市场中心同法取 ≤t+h、≥t+h−2h。
- 合成（事先定义）：ECMWF 四家（AIFS 集合、IFS 集合、HRES 点、AIFS 单）之和；非 ECMWF 原生四家（GEFS、AIGEFS、ICON、GEM）之和；全部 14 家之和——合成在每个系统到货 +1h 时刻取「该时刻各家最新改动」求和。

## 2 指标与判据（每系统/合成）
- 方向分数：真值离开市场众数、|Δ|≥0.1°C 的实例上 mean(sign(Δ)·y_side)；事件日 3 日块自助 95%；两半同号。
- 增量：逐日前推 logit P(上)＝a+b·logit L_q(+c·Δ/档)，Δ二元 LogLoss；同自助。
- 漂移：mean(sign(Δ)·(μ_Q(t+h)−μ_Q(t)))，h＝1/3/6/12。
- **有**＝增量 95% 上界<0 ∧ 两半同负 ∧ 单侧 p<0.05/20（约 20 个系统与合成）。只过前两条＝苗头。方向分数与漂移只报。

## 3 对 Proper 线（只报，规则改动另须裁）
- 众数桶：真值落在众数的频率，按 |Δ| 分档（<0.3 / 0.3–1 / ≥1°C）对市场 q_mode——改动大时众数是否更不可能。
- 纸面规则 R：在 t 时刻，若合成改动（用第 2 节样本外最强的那个，事先定为「ECMWF 四家之和」，再报「全部之和」）|Δ|≥0.3°C，买众数旁改动方向那一档 YES：
  - 吃单：按卖一价＋手续费 0.05·p·(1−p)；
  - 挂单情景：按买一+0.01（假设成交，标明是情景不是上下界）。
  每股盈亏＝命中−价，按事件日块自助、两半；距结算 12–48h 与全部分开报。
