# D0 实况模型：从当天实况直接算当天最高温（设计方案，2026-10-15）

熊先生「换一个思路，不进 P1，而是建模型，通过云、雨、露点、METAR、辐射等计算当天的问题！设计方案！」

## 一、为什么换思路是对的，以及它能赢什么

三轮「实况增量作 P1 似然」都判空，根因不在数据：P1 = 根 × 似然，只能在根已经放了质量的桶之间搬运；当天实况若说「今天整体比模型想的凉 2°C」，似然搬不动根里近零的桶（ZUUU 08-12 判例）。**独立模型**直接回答「今天最高几度」，不受根约束，这是它唯一能多做到的事。

已有的证据说这条路有东西可挖，但也划定了上限：
- 当天实况差（报文气温/云量/日照 对 前一日预报）前推能预测 12 时的真值残差（第三十轮，平方误差 −0.004 显著）；上午日照亏欠对最高温残差 R² 0.10（9 时）→ 0.23（17 时），残差 SD 1.1°C（`sun_tmax_shift_20261013`）。
- 现有 `METAR_PHYSICAL_PATH_TMAX`（只用报文、中午出报）MAE 1.24°C、偏冷 0.65°C；市场 24–60h 约 1.04。
- **市场到 10 时已计入约 83%、12 时 92%**。所以这个模型的裁判只能是**市场**，不是 P0/P1；能赢的是上午 8–12 时市场还没计入的那 1–2 分，以及市场慢的站（F 站反应更不足）。

## 二、目标（可验证终点线）

每个站日、当地每小时 t（07..18）出一条当天最高温的桶分布 `D0(t)`，只用 t 时刻已到达的实况（带到货回执）＋一条**官方**预报曲线作基线；**不读 P0/P0-M/P1 的概率**。

终点线：前推 ≥30 个检验日、47 站，在至少一个时段（候选 08–10 / 10–12 / 12–14 时）**同时**满足
1. 对同时刻市场中价：LogScore 与 Brier 都显著更好（事件日块 bootstrap 95% 下界 < 0）；
2. 按钱：吃单规则（同 `fit_pnl.py`）与挂单规则（买一＋1 tick、15 分钟）前推盈亏 95% 下界 > 0。
达标才谈接入；不达标即结案，只保留看板展示。

## 三、建模

### 3.1 目标量
不直接预测绝对温度（气候与站点效应会淹没信号），预测**残差** `y = Tmax真值 − B(t)`，B 是 t 时刻可得的基线：
- 主臂 B = 官方确定性曲线的日最高（宪章 267 已采：IFS HRES / GFS / ICON 全球 / GDPS 原生 3 小时曲线，取各家中位，提前 ≥18 h 的那一轮）；
- 对照臂 B = `max(已报最高, 当前气温 + 预报剩余升温)`（现有 METAR 路径的构造，天然 ≥ 已报最高）。
输出 = `B + ŷ` 的分布 → 按站梯子切桶 → 1e-3 下限。

### 3.2 特征（全部 as-of，按首次可见/文件上架时间截断）
| 组 | 特征 | 来源 | 备注 |
|---|---|---|---|
| 热状态 | 已报最高、当前温、当前温 − 预报曲线此刻值、已升温/预报已升温、近 2 h 动量 | METAR（AWC / ASOS） | 第三十轮的主力 |
| 水汽 | 露点、露点差、露点 − 预报露点、湿+北风（ZUUU C1 型） | METAR、预报曲线 | 风向只按「相对预报」与「相对本站常年」进，不按站硬编码 |
| 云 | 报文低云；卫星云量/云型/光学厚度（东 90E JAXA；美洲 GOES CCL）− 预报总云 | METAR、JAXA CLP、GOES | 卫星只给光学厚度那一维新信息 |
| 辐射 | 累计卫星短波 / 累计预报短波（05 时起）、最近 2 h 缺口 | JAXA SWR、GOES DSR、欧非 Open-Meteo 转发（研究） | `sun_tmax_shift` 的 x |
| 雨 | GSMaP 近 3 h、报文降水、预报雨量 | GSMaP_NOW、METAR | 47 站 |
| 时间/站 | 距预报峰时小时数、当地小时、站点时钟偏移、站固定效应、C/F 梯子 | 既有 | |

### 3.3 估计器
- 每个时段一套参数（3 个时段 × 残差均值与 log σ 两头），**L2 正则线性 + 站固定效应** 为主臂；梯度提升（深度 ≤3、单调约束：日照亏欠↓、雨↑、云厚↑ 都只能压低 ŷ）为副臂。
- 分布：正态或两段正态（上行受「已报最高」硬截断，天然右偏消失）。
- 训练只用 d−2 以前已闭日、真值已提交的站日（`strict_as_of_truth_commit_v1`）。

### 3.4 样本
47 站 × 09-01..10-14 × 12 小时 ≈ 2.5 万行（数据已在手：`jaxa_cloud_rad_p1_20261015/` 的 JAXA 云/日照/GSMaP、`sat_cloud_obs_20261008/` 的 GOES、服务 P1 行里的报文与预报曲线）。官方确定性曲线已在库（`calibration_regional_point_run.hourly_c_json`，含 IFS HRES / GFS / ICON / GDPS 原生 3 小时值，带 `knowable_at_utc`），基线臂无需 Open-Meteo。

## 四、检验（事前登记，不得事后加格）
1. 前 12 日只训练；之后逐日前推，每日重拟。
2. 三个时段分别报：对**市场中价**的 ΔLogScore/ΔBrier（事件日块 bootstrap）；对服务 P1 的同口径（参考）；MAE/偏差。
3. 钱：吃单、挂单两种规则，强度/是否下注由训练日盈亏选。
4. 稳健性：卫星晚到 1 h；换基线臂；去掉卫星只留报文（看卫星值多少钱）。
5. 多重检验：3 时段 × 2 臂 = 6 格，Bonferroni。

## 五、接入路径（达标后，另立宪章条款）
- 不进 P0/P0-M/P1。进**兑现层 b**（宪章 254/265 的既有通道：b = P(Y | p, q, 特征)），D0 的残差中心作 b 的一个特征过前推门；Proper 线挂单读 b，正好对应上午市场未计入的那 1–2 分。
- 看板：新增「D0 实况模型」卡，每小时显示 B、ŷ、分布众数、对市场的差。

## 六、风险与止损
- 市场已计入 83–92%：预期净优势 ≤1.5 分/桶，可能被价差吃掉 → 以挂单规则为主判。
- 样本 44 天、北半球秋季一季：站固定效应与风向特征过拟合风险，故线性为主、提升为副。
- 欧非站卫星仍是 Open-Meteo 转发：研究可用，上线须换 EUMETSAT 官方（要账号）。
- 预算：数据已下载，主要是计算；每日前推全量约 10 分钟。
