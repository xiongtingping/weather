# 现行 P0 条件校准：闭日历史严格前推（计算前写定，2026-09-26）

熊先生：「如何在：某种条件校准在闭日历史、严格时序的样本外，确实改善完整桶概率。」只读研究，生产未改。

另一会话同日起草了 `p0_conditional_center_protocol_20260926`（未提交，本研究不动它）。本研究用已有回放，把现在就能跑的候选先跑一遍。

## 样本

- **模型**：今天的 P0 算术回放（`band_layer_recheck_20260925/pass1`：六家、216＋219＋224、宽度 0.75、现役共识桥），配更新前 30 分钟内的已提交盘口，即 `model_market_gap_decomposition_20260926` 的缓存。
- **范围**：严格 24≤h<60，14,419 次更新，1,671 站日，事件日 08-16..09-23。
- **真值**：结算标签表的最新修订（与生产 `knowable_labels` 同一张表），取桶和摄氏值。
- **训练集**：只用 known_at 早于该检验日最早决策时刻的站日。修订过的站日按修订时刻算可知。

## 候选

只用决策时已有的 NWP 结构和已结算真值。市场不入特征，也不入训练目标。

做法：δ（°C）取特征的线性函数。模型向量按第 190 条尾巴搬运整体平移 δ，再过第 224 条下限打分。

| 臂 | 内容 |
|---|---|
| A0 | δ=0 |
| A1 | 只截距（全队平移） |
| A1s | 截距＋站截距（收缩） |
| A2 | A1＋五项 NWP 结构：提前小时、模型标准差、系统间分歧（入座各家中心的极差）、入座家数、12 小时趋势 |
| A3 | A2＋两项已结算真值特征：距平、持续性 |
| A3s | A3＋站截距（收缩） |

- **12 小时趋势**：本站日当前均值，减去 ≥12h 前最近一次更新的均值。没有这样的更新则记 0，另加指示变量。
- **距平**：当前均值减去近 15 个已知真值的均值。已知真值少于 5 个则记 0，另加指示变量。
- **持续性**：当前均值减去最近一个已知真值。没有已知真值则记 0，另加指示变量。
- **拟合**：
  - 残差 r＝真值−模型均值，站日等权的加权岭回归；
  - 特征按训练集标准化；
  - 斜率惩罚 50 个伪站日，站截距惩罚 20 个，截距不罚；
  - 不设位移上限，另报 δ 分布。

## 前推

- 从训练站日满 300 的检验日起，每个检验日 D 用上面的训练集拟合一次，套到 D 当天的全部更新。
- 同一事件日的所有站、所有更新落在同一折。

## 判定（事前写定）

**主终点**：相对 A0 的配对 ΔLogScore 与 ΔBrier 都 <0，且两者按三日块自助（2,000 次）的 95% 区间上界都 <0。站日内先平均，再站日等权。

**另报**：
- 同一样本上，对市场的差距收回了多少；
- C/F 两类站，前后两半；
- 样本内上限：全样本拟合，不是 OOS，只作天花板。

所有候选都报，不挑。

## 已知限制

- δ 施加在服务向量（下限之前）上，不是施加在 `pre_layer_probability` 后再重跑服务层。宽度层绕均值缩放，二者只在开口尾桶处有差别。
- 回放里 AIFS/AIGEFS 的到货时刻按规则推算。
- 事件日 08-16..09-23 已被拆解研究看过，但没有在上面挑特征。它不是另一会话协议所要求的「未见外层段」。
