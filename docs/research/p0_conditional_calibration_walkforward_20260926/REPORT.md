# 现行 P0 条件校准：闭日历史严格前推，六个候选没有一个过关（2026-09-26）

口径见 `PROTOCOL.md`（计算前写定并先提交，1d78da6f）。`walkforward.py` 计算，读数在 `results.json`。只读研究，生产未改。

## 样本

- 检验日：08-27..09-23，共 28 个。从训练站日满 300 的那天起算。
- 规模：1,236 个站日，12,434 次更新，严格 24≤h<60。
- 基线：这批样本上，A0（今天的 P0）落后市场 LogScore +0.116、Brier +0.040。

## 主读数

相对 A0，负值为改善，方括号为三日块自助 95% 区间。

| 臂 | ΔLogScore | ΔBrier | 判定 |
|---|---|---|---|
| A1 全队平移 | +0.001 [−0.008, +0.010] | +0.000 [−0.002, +0.002] | 不过 |
| A1s 加站平移 | +0.011 [−0.003, +0.023] | +0.003 [−0.001, +0.006] | 不过 |
| A2 NWP 结构五项 | +0.003 [−0.008, +0.012] | +0.001 [−0.002, +0.003] | 不过 |
| A3 再加已结算真值两项 | +0.000 [−0.011, +0.012] | −0.001 [−0.004, +0.001] | 不过 |
| A3s 再加站平移 | **+0.014 [+0.001, +0.024]** | +0.003 [−0.000, +0.006] | 不过，LogScore 显著变差 |

前后两半的读数同向，没有一半过关。

## 为什么不过

- **条件变量看不见当天的中心误差。**
  - 当天中心误差（真值 − 模型均值）的标准差是 1.17°C，均值 −0.01°C。
  - 样本内 R²：A2 0.8%，A3 1.9%，A3s 5.8%。
- **样本内天花板也很低，而且一前推就翻号。** 天花板是拿检验日本身拟合，不是 OOS。
  - 最好的是 A3s −0.026 和 A1s −0.024。
  - 前推后分别变成 +0.014 和 +0.011，属于站平移过拟合。
- **全队偏差自己消失了。** 前推拟出的截距从 08-27 那一折的 +0.22°C，降到 09-23 那一折的 +0.02°C。用过去的偏差去平移未来，没有用。
- **量级对照（不是候选）**：单用「市场均值减模型均值」这一个量，就能解释当天中心误差的 22%。市场按第 211 条不进天气模型。

**例**：FACT 2026-09-22，09-21 06:07Z 开仓。
- 六家中心最多相差 8.5°C。条件变量只知道「今天分歧大」，不知道往哪边偏。
- A3 给的修正是 −0.02°C，方向还是反的。
- 模型均值 29.0°C，市场均值 30.9°C，结算 32°C。
- 模型给 32°C 桶 7.4%，市场给 19.8%。

## 另报

- **F 站的全队平移（A1）**：样本外 LogScore −0.016 [−0.027, −0.005]，Brier −0.004。
  - 但其中 75% 来自 5 个站日：KAUS 09-05、KLAX 09-10、KAUS 09-11、KLAX 09-08、KLAX 08-27。
  - 这 5 天都是暖尾漏判，模型给真值桶只有 0.6%–3.5%。约 +0.1°C 的平移把这点概率抬高，每天省下约 1 nat。
  - 去掉这 5 天后只剩 −0.004。按协议判为不稳健；而且是事后切片，不作候选。
- **另一会话的协议草案**（`p0_conditional_center_protocol_20260926`）：
  - 它的 A1 和 A2，本研究已给出读数。A2 这里用的是分歧的量级（各家中心的极差），不是逐系统的有方向差值。
  - 逐系统有方向差值的线性修正，等价于融合重配权。融合研究已经测过：近期中心配权 −0.007 贴零，199 覆盖层改 LogLoss 也不过。
  - 本研究的 12 小时趋势是 P0 整体层面的，含入座变化；逐系统新旧 run 且核验到货的版本没有测。

## 结论

**只用模型自己的信息，条件中心校准在闭日严格前推里改善不了完整桶概率。** 这里的信息指：NWP 结构、已结算真值、站点。

- 缺口的主体是当天的中心；这些信息对当天中心误差的解释力 ≤2%。
- 宽度已经比市场好（拆解研究：宽度分量为负）。
- 形状方面的 band、共识桥，已在 09-25 复测，不改。

|---|---|---|

**读法**
- 这些特征能判断「往哪边偏」，但信息全来自市场那一侧。
  - 按它们把模型往市场挪，0.116 的缺口收回 0.094，约八成。

- 用同样的特征反过来挪市场，市场变差。也就是说，模型的中心和质量在市场之上没有增量。
- 后半段 K2 对市场是 +0.003 [−0.025, +0.030]，只是打平，不是领先。

**例**：FACT 2026-09-22，09-21 06:07Z 开仓，结算 32°C。
- K2 把模型往暖挪了 1.94°C，模型均值从 29.0°C 挪到 30.8°C（市场 30.85°C）。
- 32°C 桶从 7.4% 升到 13.9%，但市场给的是 19.8%。
- 差在形状：市场把 66% 集中在 30–32°C，挪完的模型还在 26°C 以下和 36°C 以上各留 3–5%。

**与以前的结论同向**：09-17/18 的众数/均值重合研究，以及同日另一会话的 `model_vs_market_mode_by_stage_20260926`，都是这个方向。

## 补充三：K1 具体是什么，与篮子「均值桶为中心」的区别

熊先生：「按四个中心的关系挪动模型：具体是什么？和目前篮子策略的以均值桶为中心有什么区别？」计算见 `k1_vs_basket_centre.py`。

### K1 是什么

每个检验日，用此前已结算的站日重新拟一次下式。下面是 09-23 那一折的系数，各项都是「某个中心 − 模型均值」，单位 °C：

δ = 0.015 + 0.814×市场均值 + 0.273×市场众数桶 − 0.063×市场均值桶 + 0.076×模型众数桶 − 0.020×模型均值桶

然后把模型的整个分布沿温度轴平移 δ。开口尾桶按第 190 条的尾巴搬运，宽度和形状不改。

- 三个市场项的系数合计 1.02。拟出的 δ 对「市场均值 − 模型均值」的斜率是 0.95，R² 0.92。
- 实际效果：把模型均值挪到市场均值上，再往市场众数方向微调一点。
- 开仓时模型与市场均值差的中位数是 0.28°C，δ 的中位数是 0.27°C。挪完后，87% 的站日均值桶与市场均值桶相同。

### 与篮子的区别

**生产篮子怎么定中心**：
- 中心 c 取模型自己分布的均值桶（第 54 条）。
- 按模型自己「均值对众数」的偏斜摆 2–3 桶（第 131 条）：对称日摆 {c−1, c, c+1}，偏斜日摆 {c, c+d} 或 {c, c+d, c+2d}。
- 模型分布本身不挪。市场只以价格进来，另有一道「市场倾向闸」；第 131 条（二）在 09-12 把它降为影子，只计数、不拦单。

**同一批 1,236 个开仓站日**（今天的 P0 回放，08-27..09-23）的对比。窗口一律近似为 {c−1, c, c+1}：

| 中心取法 | 中心桶命中 | 三桶窗覆盖 | 两中心不同时（453 站日，37%）：命中 / 覆盖 |
|---|---|---|---|
| 模型均值桶（现篮子） | 38.9% | 83.4% | 27.4% / 72.8% |
| K1 挪后的均值桶 | 43.3% | 87.4% | 37.5% / 83.7% |
| 市场均值桶 | 42.9% | 87.3% | 38.2% / 83.4% |

**K1 的中心基本就是市场的中心**。它的命中率与市场均值桶打平，不是超过。

**按卖一买的价差**（`model_vs_market_mode_by_stage_20260926/basket_ladders.py`，服务的 P0 开仓）：
- 三桶梯子：模型中心 −9.4%，市场中心 −5.3%。
- 两者都是负的。换成市场中心只是少亏约 4 个点，不产生正期望。

## 补充四：K1 是否考虑中心两侧的概率质量

熊先生：「k1是否考虑中心两侧的概率质量？」计算见 `k2_vs_k1_masses.py`。

**K1 不直接考虑。** 它只用 5 个位置。其中两个均值本身按概率质量加权，所以两侧质量只以「均值被重的一侧拉过去」的方式间接进入。

**显式放进两侧质量的是 K2**：
- 模型、市场各自「均值桶以上 − 以下」的质量差；
- 各自众数桶的质量，以及交叉质量；
- 近似平局格。

**09-23 那一折的读数**：
- 市场两侧质量差的系数最大，+0.96°C/单位：市场在均值桶以上比以下多 20 个百分点，就再往暖挪 0.19°C。模型两侧质量差的系数是 +0.36°C/单位。
- 其余质量项每个标准差不到 0.03°C。

**K2 相对 K1**：
- 平移量平均只多 0.05°C，90% 分位 0.12°C。
- LogScore 再好 0.0035 [−0.006, −0.001]，显著；Brier −0.0012 [−0.003, +0.000]，不显著。
- 对市场仍落后 +0.021。

**例**：FACT 2026-09-22。
- 市场以 31°C 为均值桶：以上 35.4%，以下 38.7%，差 −0.03。
- 模型以 29°C 为均值桶：以上 38.2%，以下 43.0%，差 −0.05。
- 两项合计只改了约 −0.05°C。那天要挪的 1.9°C 全部来自两边中心的距离。

**K1、K2 都只平移、不改形状**。挪到市场中心之后剩下的差距是形状：模型比市场宽。两侧质量只能决定挪多少，补不了形状。要在形状上追平，就只能照抄市场的分布。

## 补充五：真值落位偏向均值还是众数

熊先生：「分别计算最后的真值落位的偏向，是偏均值还是众数？分别计算k1、篮子和市场」

- 计算：`truth_lean.py`，读数在 `results_truth_lean.json`；席位覆盖见 `seat_coverage.py`。
- 两个样本，每个站日取一次决策：
  - P0 开仓：1,236 站日，08-27..09-23；
  - P1 当天首次决策：966 站日，09-01..09-23。K1 用同一事件日由 P0 训练的那一折，P1 已排除的桶保持为 0。
- 三态用生产的 `mean_mode_skew_reading_v1`（0.35σ）。

| 分布 | 均值桶＝众数桶 | 两桶不同时命中：均值桶 / 众数桶 | 偏斜日真值落在：均值侧 / 众数桶 / 另一侧 |
|---|---|---|---|
| 篮子，P0 开仓 | 91% | 26.5% / **33.6%** | 44% / 42% / 13% |
| K1，P0 开仓 | 92% | 31.7% / **36.5%** | 44% / 46% / 11% |
| 市场，P0 开仓 | 83% | 34.1% / **39.9%** | 47% / 42% / 11% |
| 篮子，P1 首次 | 85% | 29.6% / **34.5%** | 45% / 44% / 12% |
| K1，P1 首次 | 84% | **41.5%** / 37.7% | 45% / 51% / 4% |
| 市场，P1 首次 | 88% | **40.5%** / 36.9% | 40% / 53% / 7% |

**读法**
- **单个最可能的桶是众数桶。**
  - 均值桶和众数桶在 83–92% 的站日是同一个桶。
  - 两者不同时，P0 开仓段三者都是众数桶更常中。只有 P1 首次决策时，K1 和市场的均值桶略好。
  - 按连续距离，真值离众数桶中心更近的站日占 57–65%。
- **不在众数桶时，偏向均值那一侧。** 偏斜日里，不中众数桶的真值有 77–93% 落在均值侧：
  - 篮子：P0 开仓 177:53，P1 首次 182:47；
  - K1：P0 开仓 114:28，P1 首次 153:12；
  - 市场：P0 开仓 135:33，P1 首次 162:30。

**对第 131 条席位的含义**（篮子分布，只在偏斜日比较）

| 窗口 | P0 开仓覆盖 | P1 首次覆盖 |
|---|---|---|
| 第 131 条三桶 {c, c+d, c+2d} | 75.2% | 74.1% |
| 第 131 条两桶 {c, c+d} | 69.0% | 69.6% |
| 以均值桶居中 {c−d, c, c+d} | 86.5% | 87.7% |
| 以众数桶居中 {mo−1, mo, mo+1} | 85.5% | 87.2% |

c 为均值桶，d 为尾巴那一侧，mo 为众数桶。

- 往尾巴延伸的席位让出了众数桶另一侧的那一格，覆盖少 11–14 个点。
- 这与第 131 条立条前的实测一致：偏斜席位少中 0.15–0.22，便宜 0.16–0.22。
- 覆盖不等于收益，划不划算由账本判。本研究不改规则。
