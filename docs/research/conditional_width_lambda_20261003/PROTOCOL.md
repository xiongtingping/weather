## 臂（全部逐日前推）

计分日 d 只用 `day ≤ d−2` 且 `known ≤ d 00:00Z` 的行（前缀自 07-30）；格内前缀不足 8 个事件日用 0.75。

- **L_h**：按 5 个提前量档各一个 λ。
- **L_nf**：按家数 {2, 3–4, 5–6} 各一个 λ。
- **L_D**：按 D 的三分位（切点取前缀）各一个 λ。
- **L_σ**：按 σ 的三分位（切点取前缀）各一个 λ。
- **L_joint**：log λ = a + b·1[nf≤3] + c·zD + e·zσ + f·(h/24)，zD、zσ 按前缀标准化；以前缀平均 LogScore（网格间线性插值）为目标，Nelder–Mead 从 (log 0.75, 0, 0, 0, 0) 起拟；λ 夹在 [0.5, 1.5]。
- 对照：**0.75 固定**（现役）；**F**（全队一个 λ 前推）。

## 修订（2026-10-03，计分之前）

回放的 `replay._score` 不施加宪章 224 的服务下限：生产 P0 在宽度层之后还有 `materialization.floor_probabilities`（每个桶 ≥1e-3），宽度车道自己的门也按下限后的向量打分（宪章 228）。不加下限时，真值落到概率约 1e-8 的桶，记 16–27 nat；生产里同一格约 6.9 nat。这会把 λ 往宽拉。

- **主读数**：每个 λ 的宽度层输出再过 `floor_probabilities`，即生产服务向量；真值桶不在整度格内时先补一个 0 再过下限（生产梯子有开口端，真值总落在某个 ≥1e-3 的桶里）。
- **副读数**：原 `replay._score`（不加下限），照报。
- 对等断言：λ=0.75 不加下限的分数须等于整链记录的分数（|ΔNLL|<2e-4）。真值概率 <1e-4 的行是存向量时 8 位小数舍入所致，豁免并计数。
- 判决规则不变。今日 `station_width_lambda_20261003` 的数据 B 各臂，在本数据上按两种打分再判一次，作稳健性核对。
