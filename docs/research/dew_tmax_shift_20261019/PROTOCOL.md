# 露点 · 实况对比预报 → 最高温 ΔT（协议，先于读数）

2026-10-19 熊先生「露点 · 实况对比预报：这个也拟合」。只读研究，结果只进看板显示，不进任何层。
做法与云卡同一套（`docs/research/cloud_tmax_shift_20261017/fit.py` 的两段直线、站去均值、按事件日五折样本外、按日自助区间）。

## 数据
- 报文露点：`archive.db` 的例行报（整点 ±10 分钟），解析与看板同一函数（`report_explain`）。
- 预报露点：Open-Meteo `dew_point_2m`（最新预报，看板卡片的口径），previous-runs 接口，09-01..10-14，
  每站一份缓存；研究额度记账（与 `fetch_low_d1.py` 相同）。
- y：结算真值 − 日前预报最高温（云线同一个 y，站去均值）。

## 定义（事先写定）
- **主口径（卡片口径）**：x = 当地 H 点报文露点 − 同一小时最新预报露点（°C），H = 9..17。
- 辅口径：x = 05..H 点逐小时差的平均（只报告，不上卡）。
- 模型：ΔT = 截距 + 偏干斜率·min(x,0) + 偏湿斜率·max(x,0)，x 截在 ±4°C；卡片只用斜率部分（与云、日照卡一致）。
- 至少 8 个站日的站才进样本。

## 判据
- 样本外（按事件日五折）对「只用均值」的 MSE 差，按日自助 95% 区间上沿 < 0 才算「样本外显著」；否则卡片 ΔT 标灰注明不显著。
- 另报：在有卫星日照的站日上，把露点差加进日照线，样本外是否更好。
