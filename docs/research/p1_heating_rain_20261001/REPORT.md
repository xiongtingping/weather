# 峰前加热窗降水：P0 / P1 能否接入（2026-10-01）

熊先生：「物理协变量：模型说的雨，站上到底下没下，目前是否可以进p0」「或p1」→「不要拉平均，不要拉峰后」→「做P1」。只读，生产未改。

## 1. 分格描述（build.py / an.py；08-15..09-22，P0 首决策 1,199 站日）
加热窗＝当地 09 时→实际最高温时刻；「模型说雨」＝Open-Meteo 历史短时效 09–15 时 ≥1 mm。
- 原始效应：加热窗下 ≥2 小时雨，最高温比同站 ±7 天干日低 2.0°C（中位），p25 低 3.3–4.0°C。
- 模型说雨且下 ≥2h：真值−P0 中位 +0.3（P0 已吃掉）。
- 模型说干却下 ≥2h（24 站日）：中位 −0.6，p10 −3.2，25% ≤−2°C（干日 5%）；P0 给真值桶 0.16、市场 0.156。发生在当天上午，P0（>36h）不可得。

## 2. P1 严格前推（build_dataset_p1.py / feat_p1.py / wf_p1.py；08-21..09-30，1,325 站日、5,340 决策点）
预注册主臂：09 时→决策时刻−15 分钟内 ≥2 个整点有降水、决策当地 9–16 时，冷移混合 p'=(1−w)p+w·shift(p,−s)，(s,w) 只用决策日之前的闭日按 LogScore 选；判决按宪章 240（站日整块 2,000 次）。

训练折里总能挑出 (2, 0.05) 小冷移，次日就输——样本内有、样本外无。

## 3. 为什么 P1 不要（diag_p1.py）
大样本里上午下 ≥2h 的 P1 并不比无雨日更偏：PIT 均值 0.45（无雨 0.46），PIT<0.1 为 7%（同 7%），真值−中心 p10/p50/p90 −1.1/−0.1/+0.7。§1 的「P1 冷尾太窄」来自 55 站日小样本，扩到 162 站日后消失。P1 本来就读实况温度轨迹与最后 6h / 6–10h 的降水，上午下雨造成的降温已经写在温度计上。雨日真值桶 <1% 的灾难 4.2%（干日 1.0%），但冷 6 / 暖 6、集中在 7 个站日，无方向可学。

## 结论
降水（加热窗实况）不进 P0（不可得）也不进 P1（预注册臂显著变差）。
