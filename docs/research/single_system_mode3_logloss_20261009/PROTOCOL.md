# 预注册协议：单系统校准目标改「市场众数桶±1 的二元 LogLoss」会怎样

写于 2026-10-09，任何评分之前。提问人：熊先生（「测试一下，如果把单系统的模型校准目标改为logloss（市场众数桶加减一桶），而不是logscore，会有什么结果？」）。研究，不改生产。

## 现役（CUR）
宪章 216：六家官方原生集合各自的单系统校准，先矩估计（偏差半衰期 5 天、宽度＝残差σ/成员离散），再在同一批训练样本上用**整条 1°C 桶分布的多类 LogLoss**（真值桶 −log p）拟合「中心平移 δ + 宽度系数 s」，半衰期 15 天，向矩估计收缩 κ=0.5（`native_ensemble_oos._logloss_refit`）。

## 候选（M3）
只换目标函数，其余逐项相同（同训练样本、同半衰期 15、同 κ=0.5、同边界 δ∈[−3,3]°C、s∈[0.5,5]、同 L-BFGS-B 60 次、同起点＝矩估计、同 247 加宽核规则）：

  目标 = Σ_i w_i · Σ_{b∈{m_i−1, m_i, m_i+1}} BLL(P_i(b), 1[T_i∈b]) / Σ_i w_i

- `m_i`＝训练样本 i（该系统该次 run 对应的站日）在**市场梯子**上的众数桶：生产 `market_reference_v1` 归一中价 + `market_mode_bucket`（最大、并列取低档）。取值时刻＝该 run 的到货时刻（与回放同一到货钟）；该时刻尚未挂牌则取挂牌后第一份完整盘口；均按整点向下取（as-of 该整点前最新 COMMITTED 快照）。快照不完整＝该时刻无众数。必须早于事件当地日终。
- 窗口桶按梯子顺序；众数在边缘桶时窗口只有两桶。
- `P_i(b)`＝该系统校准后分布在市场梯子区间 b 上的质量（生产 `_apply_parameters_on_ladder` 的算术，向量化；逐次拟合抽样对拍 ≤1e-9）。BLL 两侧截到 [1e-6, 1−1e-6]（同 216 的 P_FLOOR）。
- 没有市场众数或没有梯子的训练样本**不进**候选目标；剩余样本数 < `replay.MIN_TRAIN` 时候选退回矩估计（不重拟），并计数报告。
- 非原生集合（点预报等）两臂都不重拟，与生产相同。

## 机器
`single_system_logloss_reg_20260924/capture_reg.py` 一脉的六家走查（生产单家规则、模拟到货 `--model-backfill-arrivals`、IFS/GEFS 回灌按 live 期中位到货滞后），**一次走查同时算两臂**（同到货、同训练集、同席位）。席位权重＝稳定池（κ=0.25，按矩残差，两臂相同）；不叠宪章 242 站权重、按「全坐」。
服务链在**市场梯子**上逐项调生产函数：`_apply_parameters_on_ladder` → `bridged_cross_probability` → `_holdout_shape_stack(ladder=…)`（辐射位移按各臂自己的中心算 → 邻站倾斜 → 中心/宽度 + 248 切片 + 261 F 站尾混 + 253 压顶，经 `_day_center_width_layer` 按决策时刻解析）→ `_ladder_metrics`（含 224 的 1e-3 下限）。宽度表用现行表（两臂相同）。

## 样本
计分事件日 2026-09-01..10-07；训练窗 60 天（市场历史 07-28 起，冷层＋热层）。站点：先跑半衰期研究同一组 23 站（CYYZ,EFHK,EHAM,FACT,KAUS,KDAL,KLAX,KMIA,KSEA,LEMD,LIMC,MMMX,NZWN,OPKC,RJTT,RKSI,SAEZ,VILK,WSSS,ZGGG,ZHHH,ZSQD,ZUUU）。只看 P0、日终前决策。代表决策＝每站日按距结算小时数分 5 档（≥48、36–48、24–36、12–24、<12）各取最晚一次，站日内平均。

## 判决
- **A 层（宪章 240，主判）**：M3 对 CUR，站日簇自助，`center_width_store._proper_score_gate`（LogScore 主、CRPS 结构、Brier 护栏），95%；前后两段（09-01..09-19、09-20..10-07）ΔLogScore 同号。
- **B 层（宪章 259，只评不训）**：同一批代表决策上、在**决策时刻**市场众数桶±1 窗口的二元 LogLoss 之和：M3 对 CUR、两臂各对市场 q，站日簇 95%。
- 预期写在前面：M3 不看尾部 → A 层可能变差；它是否在交易窗口上更准由 B 层回答。
- 只有 A 层不变差（LogScore 不显著变差且 CRPS/Brier 护栏过）**且** B 层 M3 显著优于 CUR，才算「值得提给熊先生裁」；否则维持 216。
