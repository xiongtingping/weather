## 结论
1. **现役 216（多类 LogScore 训练）已经做到「说 30% 约 30% 发生」**：全部桶 ECE 0.3 个百分点，20–60% 各档偏差 ≤1.5 个百分点（中段略谦虚，60–70% 档 52 个样本偏自信）。
2. **改成众数±1 二元 LogLoss 后，逐桶校准与二元 LogLoss 都没有可测变化**（全部区间跨零）。机理：两者都是 proper score，模型只有「平移 + 宽度」两个参数可调，两种目标把它们拉到几乎同一处（中位平移 −0.005 vs +0.002°C，宽度系数 1.242 vs 1.263）。
3. **真正的校准缺口只在「以市场为条件」时出现**：在市场众数窗口里，我们说 2.9% 的桶实际中 11.1%，7.5% → 14.4%，15.2% → 20.5%；市场同窗口自己是准的（7.5% → 7.6%，34.8% → 34.7%）。即市场看好、我们看淡的桶，我们系统性说少了。这是信息缺口（P0 不看市场），单系统层的任何训练目标都补不上——候选在这一格也没改善（2.9% → 13.3%）。
4. 对市场：全部桶上我们的 REL/ECE 不比市场差（≥12h 有盘口：ECE 我方 0.0027 vs 市场 0.0075，我方显著更小），但二元 LogLoss 差 +0.0185/桶——差在**分辨力**（RES 19.2e-3 vs 24.7e-3），不在校准。
5. 附注（宪章 240 口径）：LogScore +0.0022 [−0.0019, +0.0070]、Brier −0.0003、CRPS +0.0001，全部跨零。

## 读法
「说 30% 中 30%」是必要条件，不是目标本身：一个永远报气候频率的预报也完全校准，但毫无用处。二元 LogLoss = 校准 + 分辨力，所以它适合当判据，可靠性图适合当诊断。我们在校准上已经合格；输给市场的是分辨力，以及以市场为条件时的那块缺口——后者正是兑现层 b = P(Y | p, q)（宪章 254，影子）在处理的东西。
