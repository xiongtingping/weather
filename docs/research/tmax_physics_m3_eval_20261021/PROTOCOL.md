# M3 协议：当日最高温增量模型的残差层与样本外判定（2026-10-21，先于读数提交）

上游文档：
- 架构：`docs/research/tmax_physics_model_design_20261020/ARCHITECTURE.md`；
- 数据：`docs/research/tmax_physics_m1_ingest_20261020`；
- 物理核：`docs/research/tmax_physics_m2_core_20261021`。

本协议提交时 M1 入库未完。实现期间只跑管线烟测（只看行数、缺失、形状，不打印任何分数）；判定在入库完成后跑一次，协议不改。

## 1. 目标量与样本
- **y**：IEM 当地日最高温 − 日前预报最高温（Open-Meteo `_previous_day1` 的 `temperature_2m`，取当地日 24 小时最大）。
- **检查时刻 H**：当地 9、11、13、15、17 点，表示已测到 H 点，即 H 点及之前的整点。
- **站日入样条件**：
  - 06..H 点的日前预报短波、实测短波（只要 `proxy=0` 的行；日出前记 0）和 METAR 都齐；
  - 事件日早于运行日。
- **检验窗**：训练满 120 天后开始，逐日前推，即每个检验日只用它之前的站日训练，每 7 个检验日重拟一次。
- **训练窗**：检验日之前的全部站日，最早 2024-01-19。

## 2. 特征（都只用 H 点及之前的信息）
| 名 | 定义 |
|---|---|
| `phys` | 物理核 ΔT(H) = c_s·(√(实测 06..H ＋ 预报 H+1..15) − √(预报 06..15))，c_s 用训练窗内「升温 = a + c·√Q」逐站拟合，并加站×月固定效应，去掉季节混杂（M2 自检所见） |
| `sw` | 06..H 点（实测 − 日前预报）短波平均，W/m²，截 ±300（看板现行口径） |
| `rh` | H 点报文相对湿度 − 日前预报相对湿度，百分点，截 ±20 |
| `dew` | H 点报文露点 − 日前预报露点，°C |
| `wind` | H 点报文风速 − 日前预报 10 米风速，m/s |
| `tdev` | H 点报文气温 − 日前预报气温，°C |
| `rain` | 06..H 点报文有降水现象的小时数 |

- 湿度、露点、风在看板卡片上对比的是最新预报，这里用日前预报：最新预报没有历史存档，只能统一用日前口径，写明偏差方向未知。

## 3. 对照臂（与架构第 4 节一致，事先固定）
| 臂 | 内容 |
|---|---|
| ① 均值 | 训练窗内按站的 y 均值 |
| ② 现行日照线 | `config/ui/sun_tmax_shift_v2.json` 原样套用（截距不计，与看板一致），加 ① |
| ③ 现行湿度线 | `config/ui/rh_tmax_shift_v1.json` 原样套用，加 ① |
| ④ 只有 B | 全队线性回归：y ~ sw + rh + dew + wind + tdev + rain，按 H 分开拟合，含站截距 |
| ⑤ A＋B | ④ 再加 `phys` |
| ⑥ A＋B 按站 | ⑤ 的系数逐站收缩：站系数 = 全队 + n/(n+100)·(站 OLS − 全队)，k=100 事先固定 |

- **预测分布**：均值取各臂的点预测，标准差取训练窗残差标准差（按站，向全队收缩，k 同上），按正态分布打分。

## 4. 打分与判定
- **指标**：
  - 主裁：LogScore（正态对数密度，取负）；
  - 结构：CRPS；
  - 直观：MAE。
  - y 是连续量，所以不用市场梯子分桶。本模型只用于看板展示，不进 P0/P0-M/P1，宪章 240 只借用它的「LogScore 主裁、CRPS 与 MAE 辅助」这一结构。
- **配对差**：同一站日两臂之差，按事件日块（3 天一块）自助 4,000 次，取 95% 区间。
- **主判**（每个 H 都要满足才算成立）：
  1. ⑤ − ② 的 LogScore 区间上界 < 0，且 ⑤ − ③ 的 LogScore 区间上界 < 0，即合成 ΔT 显著好于现行两条线。
  2. ⑤ − ④ 只报不判：回答物理核在 B 之外有没有增量。
  3. ⑥ − ⑤ 按站报，按站 BH 校正：回答分站值不值；只有全队区间上界 < 0 才改用 ⑥。
- **替换看板卡片**：①成立才提请熊先生裁决是否替换现有五张「不可相加」的卡。
- **按区分段报**（各区实测短波的来源不同）：亚太（JAXA，经 Open-Meteo）、欧非（DWD SIS／EUMETSAT）、美洲（GOES）。美洲只用 GOES 行，ERA5 代理不进判定。

## 5. 版本与口径（宪章 255）
- **数据**：IEM 与 Open-Meteo 均为 aggregator，只作研究用。
- **到货**：日前基线按 Open-Meteo 存档，不是当时的实际到货，属模拟口径；本模型只上看板，不作生产依据，结论旁写明。
- **真值**：IEM 日最高温。对正式真值 MAE 0.022°C；修订按最新版。

## 6. 不做什么
- 检验窗读数出来后，不改特征、不换臂、不调 k；要改须另立协议，在新的前向样本上判。
- 不进任何生产层。
