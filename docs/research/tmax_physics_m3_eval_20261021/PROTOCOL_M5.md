# M5 协议：物理核第二版（干湿调节感热比例），2026-10-21 先于读数提交

熊先生 10-21「继续3、2、6、4、5」第 5 项。架构 A 层第二版。

## 1. 改什么
- **原理**：混合层增温里 c = √(2·g·f/ρcp)，f 是入射短波中变成感热的比例。地面越干，蒸发越少，f 越大。早晨的温度露点差（DPD）是现成的干湿指标。
- **做法**：在 M3 臂 ⑥（A＋B 按站）的特征里再加一项 `phys_dpd = phys × DPD06`，DPD06 是 06 点报文气温减露点（°C）。与其他特征一样，按站分层收缩（k=100）。
- **另一半**：早晨稳定度 g 需要高空温度，M1 库里没有，本轮不测。

## 2. 臂与判定
- **⑦** ＝ ⑥ ＋ `phys_dpd`。数据、前推、检查时刻、指标与 M3 完全相同：LogScore 主裁，配对差按事件日 3 天一块自助 4,000 次。
- **成立**：⑦ − ⑥ 的 LogScore 区间上界在 9、11、13、15、17 点每个时刻都 < 0。成立才更新看板拟合。
- **不成立**：如实记录，第二版不上看板；物理核按 M3 结论维持现状。
