# M9 协议：「已观测最高温」在 12–17 点的增量（2026-10-21，先于读数提交）

熊先生 10-21：「另立协议测『已观测最高温』在 12–17 点的增量，样本外过关的小时再上。」

## 1. 特征与臂
- `rmax` 定义与 M8 完全相同：当地 00..H 点逐小时报文气温的最大值 − 日前预报最高温。
- ⑧ ＝ ⑥ ＋ `rmax`（按站分层收缩，k=100）；⑥ 即现行 12–17 点的合成卡。
- 检查时刻：12、13、14、15、16、17 点。数据、前推、指标、自助方法同 M3。

## 2. 判定
- ⑧ − ⑥ 的 LogScore 区间上界 < 0 的小时，看板改用 ⑧；其余小时保持 ⑥。
- 同时报 MAE，只报不判。

## 3. 已知风险
同 M8：整点报文可能取到 H 点后 30 分钟以内的那一条，最多半小时的提前量，读数旁写明。

## 4. 版本与口径

- 其他小时不受影响。
