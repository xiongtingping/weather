# M4 协议：合成 ΔT → 最高温各档概率（2026-10-21，先于读数提交）

熊先生 10-21「继续3、2、6、4、5」第 4 项。架构 C 层：把合成 ΔT 及其不确定度换算成最高温落在各结算档的概率，并检验是否校准。只上看板，不进 P0/P0-M/P1。

## 1. 样本与前推
- **数据与方法**：与 M3 相同，`m3_station_days.json`（48 站，含 VILK），逐日前推，训练满 120 天起，每 7 个检验日重拟一次；预测用 M3 臂 ⑥（A＋B 按站）。
- **检查时刻**：9、11、13、15、17 点。

## 2. 结算档（按站点单位）
- **C 站**：每档 1°C，真值四舍五入到整度后落入的那档，即 [k−0.5, k+0.5)。
- **F 站**：每档 2°F，下界取偶数（市场口径，如「76–77°F」），即 [b−0.5, b+1.5)°F，换算成 °C 后计算。
- 历史上大部分日子没有市场梯子，所以不按实际梯子打分（与宪章 213 不同）。本模型只上看板，按站点单位的等宽档已足够，结论旁写明这一点。

## 3. 分布形状（臂）
| 臂 | 分布 |
|---|---|
| D0 基线 | 正态：均值＝日前预报最高温＋站点平均偏差；标准差＝训练窗内站点原始误差的标准差（按 k=100 向全队收缩） |
| D1 正态 | 均值＝日前预报＋合成 ΔT；标准差＝臂 ⑥ 按站残差标准差（M3 现行口径） |
| D2 t 分布 | 中心与方差同 D1；自由度在训练窗标准化残差上逐检查时刻按最大似然取 {3, 4, 5, 7, 10, 15, 30}，尺度换算到同一方差 |

## 4. 指标与判定
- **主裁**：分档 LogScore，概率下限 1e-3 后重新归一（同宪章 224）。
- **辅助**：分档 Brier、连续 PIT 的 KS 距离、50/80/95% 中心区间的实际覆盖率。
- **配对差**：同 M3，按事件日 3 天一块自助 4,000 次，取 95% 区间。
- **判定**：
  1. D1 − D0 的 LogScore 区间上界 < 0（每个检查时刻都要满足），才说「分档概率比日前预报好」。
  2. D2 − D1：区间上界 < 0 则看板用 D2；区间下界 > 0 或跨零则用 D1。
  3. 覆盖率只报不判；与名义值（50/80/95%）差超过 5 个百分点的时刻，在看板卡片的悬停说明里写明。
- **去向**：判定 1 成立后，看板合成卡增加「最可能的两三档及概率」。

## 5. 版本与口径
- 数据口径同 M3 的 RESULTS「版本与口径」一节。
- 真值是 IEM 日最高温，换算回 °F 的舍入误差在 0.01°F 量级。
