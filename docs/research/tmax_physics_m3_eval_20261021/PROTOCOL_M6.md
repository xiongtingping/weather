# M6 协议：合成 ΔT 补到当地 0–8 点（2026-10-21，先于读数提交）

熊先生 10-21「补 0–8 点：按同样方法补拟凌晨各小时系数，样本外过关的小时才上图」。

## 1. 特征在 0–8 点的定义
与 9–17 点相同的七项，只有起算时刻和缺项处理不同：

| 特征 | 0–8 点的取法 |
|---|---|
| 气温差、露点、湿度、风 | 当地 00..H 点里最新一个报文与日前预报都有的小时（9–17 点仍按原定义从 06 点起找，不变） |
| 降水 | 00..H 点报文有降水的小时数 |
| 日照 sw | H ≥ 6 时为 06..H 点平均；H < 6 时为 0 |
| 物理核 phys | 同原定义；H < 6 时没有实测小时，自然为 0 |

数据：`features.py` 给每个站日补上 00–05 点的报文与日前预报（其余字段不变）。

## 2. 臂与判定
- **臂**：每个 H 与 M3 相同，⑥（A＋B 按站，k=100）对 ①（只用站点平均偏差）；逐日前推、指标、自助方法均同 M3。
- **过关**：⑥ − ① 的 LogScore 区间上界 < 0 的小时，才写进看板参数并在图上显示。不过关的小时不画。
- **0–8 点的分档概率**：用同一过程的 t 分布自由度，口径同 M4，不另判。

## 3. 版本与口径
- 同 M3；样本为 48 站。
- 9–17 点的定义与读数不受影响。
- 本协议提交时尚未看过任何 0–8 点读数。
