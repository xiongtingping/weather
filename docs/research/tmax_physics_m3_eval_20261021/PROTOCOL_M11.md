# M11 协议：虚线外推怎样延续实况趋势（2026-10-21，先于读数提交）

熊先生 10-21：「不是按照最新的预报走，而是按照目前的实况趋势……不一定是最近3小时实况，你用最佳的。」

## 1. 要选什么
看板虚线：最新报文之后的各小时，用逐小时日前预报加上「今天实况相对预报的偏差」，再跑同一套合成拟合。
本协议只决定每个变量的偏差怎样延续，拟合系数不变。

## 2. 候选（每个变量都从同一组里选）
- **F**：不延续，只用预报。
- **Wk**：最近 k 个有报文的小时的平均偏差，原样延续到后面各小时；k ∈ {1, 2, 3, 4, 6}。
- **全天**：06 点（或 00 点，取决于锚点）以来全部小时的平均偏差。
- **W3·衰减τ**：W3 的偏差按 exp(−Δh/τ) 衰减，τ ∈ {3, 6} 小时。

各变量的偏差口径：
- 日照：比值（实况/预报，只用预报 ≥20 W/m² 的小时，比值限制在 0–3）与差值两种口径都参选。
- 气温、露点、湿度、风：差值。
- 降水只看有没有：最近 k 小时里有雨的比例 ≥0.5 记为有雨；F 记为无雨（研究表里没有降水预报）。

## 3. 打分
- 锚点 H＝当地 6..22 点（日照只用 6..16，只外推到 17 点）。对每个锚点，预测 H+1..23 各小时的偏差，与真实偏差比。
- 日照、气温、露点、湿度、风用 MAE（单位：W/m²、°C、%、m/s）；降水用 Brier。
- 前推检查：按日期分前 2/3 与后 1/3 两段。在前段选出最优候选，后段如果仍是最优，或与后段最优相差不到 2%，就采用；否则采用后段与前段合计最优的候选，并在读数里写明。
- 数据：`data/tmax_physics/m3_station_days.json`（48 站）。
