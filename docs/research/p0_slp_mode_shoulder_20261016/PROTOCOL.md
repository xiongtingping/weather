## 起因
宽窄类旋钮（全队 c、每家 c_s、桥强度）三次测试都收不回 D1 两肩缺口（现行 SLP D1 两肩说 0.449/实 0.488），缺口最大在家间分歧中间的三分之一（众数说 0.384/实 0.317）。
宽窄旋钮只能在「众数」与「其余全部」之间换质量；众数→肩部是形状旋钮，只在众数与两肩之间换。

## 行
`p0_slp_per_system_c_20261016` 的 D0/D1/D2 行合在一起（事件日 09-01..10-14，48 站）。每行先算**现行 SLP 向量**：各家展宽×c（宪章 273：按距结算小时 0.6/0.8/1.0）→ 生产 `bridged_cross_probability` → 辐射平移（回执 shift_sigma × 新池标准差），未加下限。

## 臂（事先固定）
- **CURRENT_SLP（对照）**：上述向量 → 1e-3 下限。
- **SLP_SHOULDER_WF（主）**：上述向量 → 生产 `apply_mode_shoulder`（宪章 271 的变换：众数质量的 s 份按两肩自身比例分给两肩，边缘众数只给内侧）→ 1e-3 下限。
  s 按距结算小时分三档（生产 `mode_shoulder_bin_for`：h0_24 / h24_48 / h48_plus），网格 `MODE_SHOULDER_SHARE_GRID`＝{0, 0.05, …, 0.30}；
  每档逐日前推：训练＝该档、事件日早于评估日的全部行（≥10 事件日），取整梯子平均 LogScore 最小的 s（同值取小）。

## 判据
SLP_SHOULDER_WF − CURRENT_SLP，按距结算小时三档分报：宪章 240（ΔLogScore 主、ΔCRPS 不稳定变差、ΔBrier 不显著变差），站日等权、按事件日 bootstrap 2,000（seed 7）。
按站：每站 ΔLogScore、BH q=0.10（≥10 站日）。三块校准（众数／两肩／更远，说 vs 实）全体与按家间中心离散三分位并列。逐日选中的 s。
**成立**：某档三项过 240 且无 BH 显著变差站 → 该档「SLP＋众数→肩部」为上线候选（是否上线另裁）；跨零 → 不加。
