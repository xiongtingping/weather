# P0-M 观测下界：按比例重归一 → 下界桶承接（宪章 241，2026-10-01）

熊先生「修p0m」。只读 SSOT，生产原语打分（`center_width_store._served_scores` 三分数、`_proper_score_gate` 站日重抽 2,000 次，宪章 240 分级判据）。

## 缺陷

P0-M ＝ P0 × L_TAF × 观测硬下界（宪章 61/150）。硬下界把已测最高排除的桶置零后**按比例重归一**，等于只用了「真值 ≥ 已测最高」。
被排除的质量按 P0 原比例摊到上方各桶，所以有下界的 P0-M 格偏暖。

## 新算术

日最高 ＝ max(已测最高, 当日余下最高)。P0 里结束在已测最高以下的情景，结算在已测最高所在桶：被排除的质量整份落到最低存活桶。
不读时钟、不读天气，仍是第 61 条的算术事实。

## 样本

`capture.py`：P0-M 决策 2026-09-19 起（宪章 150 算术）、事件日 09-19..09-30、正式真值（宪章 225 两车道最新修订）；18,913 行，16 行 TAF 回执取整超容差剔除，余 18,897 格 / 539 站日，其中有下界 6,725 格 / 527 站日。
复原：P0 根 × TAF 回执似然 × 掩码 → 按比例 → 零地板，与存档服务向量逐桶比对（无 TAF 行 0 误差；TAF 行 ≈1e-7，回执取 6 位小数）。

P1 以 P0-M 为根。3,801 个 P1 格（站日×3 小时块中位，根是 P0-M），2,284 格的 P1 已报桶恰是 P0-M 承接落点。

整体中性，但 15–18 时显著变差：P1 的观测更新已经读「余下时段还升多少」，再吃承接质量是同一证据计两次。
所以 P1 不吃承接根：P0-M 在 lineage 里带按比例口径向量，P1 经 `observed_floor_censoring.p1_root_probabilities` 读它，服务、轨迹证明、特征、P1 拟合与样本构建同读一个函数。P1 服务数字逐位不变（测试钉住），不升版。
