# 同心线按实际成交时点重放（计算前协议，2026-09-24）

熊先生 2026-09-24：「如果算进去能盈利吗」——把实盘实际的成交时点与方式算进同心线的评估。只读。单一策略、不搜格子；结果出来后不改下列口径。

## 人口（与实盘同一节奏）

- 决策 = `basket_policy_training_fact` 的 P1 事实（同一决策秒取最后提交的一条），事件日 2026-08-27..09-23（事实从 08-27 起才连续有），已结算站日；真值 = 结算标签最新修订，再按 `venue_truth_overrides.json` 覆盖。
- 判定时刻 = 决策时刻 + 21.5 秒（实盘评估表 `fact_age_seconds` 中位）。盘口 = 离判定时刻最近、前后 90 秒以内的已提交 WS 快照（实盘另读实时 WS，快照约 2 分钟一份，这是近似）；没有则该决策不判。
- 触发 = 车道自己的函数：`p1_consensus_lane.evaluate_consensus`（包络概率与序号 × 该快照 `market_reference_v1` 向量）四心同桶，离结算 [6,10) 小时（`hours_to_settlement`），该桶卖一 ∈ [0.50, 0.70)。
- 上限与实盘 v2 相同：每站日 ≤2 笔、每桶 ≤1 笔、同站日相邻两笔隔 ≥20 分钟；每笔 5 USDC。

## 两种成交方式

- **A 吃单（v1）**：判定时刻那份盘口，按卖一成交，限价 = 卖一 + 1 跳，卖一深度够买 5 USDC 才成交。
- **B 挂单（v2，现行）**：判定时刻按车道 `tiebreak_lane.maker_rung`（买一 + 1 跳、贴不到卖一）挂单。信念有效期 = max(包络 `fresh_until_utc`, 决策 + 1200 秒)，且离结算 ≥ 6 小时；此后每一份快照上先判成交，再按当时盘口重判四心同桶与价带、重新定价挂出。成交判据两种：
  - **保守**：下一份快照卖一 ≤ 我方挂价；
  - **乐观**：保守条件，或下一份快照买一低于上一份买一（我方前面那一档被吃掉或撤走，按被吃算）。
  成交价 = 我方挂价。有效期内新的触发决策延长有效期。

## 读数

每种方式：笔数、站日、事件日、命中率、均价、ROI（每笔 r = 命中/价 − 1 的均值）、按事件日自助 90% 区间、前后半段。挂单另报：触发站日中成交的比例；触发但没成交的站日若按触发时卖一吃单，其命中率与 ROI（看逆选择：没成交的是不是更容易中）。
