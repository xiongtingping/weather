## 3. 读法

- 首决策时，模型比市场差约 0.18 nat/站日（这批配对）。等 8 小时，模型确实变准了，但市场同期也在学，差距只缩到约 0.10。
- 所以「等到四家」翻不正 Proper 线的实现 edge。而且 60% 的站日在窗口内根本等不到四家。
- 与此前读数同向：
  - 服务 P0 在 36–60h 的实现 edge 为 −0.231（`p0_conditional_calibration_walkforward_20260926` 补充七）；
  - 宪章 231 上线前实测：双边 Log 份额按卖价成交，ROI −3.0% [−4.4, −1.7]。

## 4. 待查：Proper 线为什么一条腿都没计划

297 行 `planned_legs` 全为 0，原因记在 `refusal` 列。本机可以用一行只读查询看分布：

```
sqlite3 "file:data/bayes_basket_target_ssot.db?mode=ro" "SELECT COALESCE(substr(refusal,1,instr(refusal||':',':')-1),'(plan)') AS r, COUNT(*) FROM proper_bet_lane_evaluation WHERE stage='P0' GROUP BY r ORDER BY 2 DESC;"
```

一个可能的机制，未证实：

- lane 只在首决策 1 小时内把它当新鲜（`first_decision_fresh_seconds`=3600）。
- 盘口不完整时，lane 只记 waiting，不写行；本核查的配对里，80% 有一个时点盘口不完整。
- 等盘口完整时，首决策可能已过 1 小时，于是被记成 `first_decision_stale`。
