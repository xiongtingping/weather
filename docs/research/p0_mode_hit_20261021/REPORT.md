# P0 众数桶 vs 市场众数桶：真值命中率与「P0 中、市场不中」的条件搜索（2026-10-21）

## 口径
- 行＝站日 × 距结算时段 的**首个** P0 决策（`basket_policy_training_fact` 的 P0 阶段，市场向量 `market_reference_v1` state=complete 才用）；P0 向量与市场向量在同一桶集上归一；众数＝argmax；真值＝最新修订结算标签。
- 两窗：A＝事件日 09-12..10-05（复用 `conditional_advantage_20261006/rows`），B＝10-06..10-20（本目录 `rows/`，`extract.py` 同一抽取器）。
- 「买 P0 桶 edge」＝P0 命中率 − 市场给 P0 众数桶的归一化中价 q_at_pm（不含点差）。
- 日聚类自举 95% 区间；切片按三分位 / 分类；前推＝窗 A 拟合、窗 B 验证。
- 脚本：`build.py`（行→recs.jsonl）、`analyze.py`（总表+特征均值）、`analyze2.py`（切片，`slices.txt`）、`walkforward.py`（GBM/Logit 前推、站点持续性、复合条件，`walkforward.txt`）。

## 结论
1. P0 众数桶命中率系统性低于市场众数桶约 9 个点；众数不同时低 20 个点。
2. **不存在事前可识别的「P0 命中而市场不命中」条件**：P0 独中的站日在模型自信度、市场自信度、两边中心差、六家一致性、盘口、日照、到货龄、站点、季节相位、时段上与市场独中的站日无法区分；窗 A 学到的任何规则在窗 B 全部归零或反号。
3. 买 P0 众数桶按市场价算 edge≈0（A +0.9%，B −4.0%）：市场已把 P0 的桶定价到 P0 的实际命中率，P0 对市场无中心层面的信息增量。与 09-17 `mode-mean-overlap`、10-07 `conditional_advantage`（E[d|Z] 无存活格、GBM 能认坏日不能认好日）、10-10 `resolution_features`（窗口桶 18 格无增量）同一答案。
