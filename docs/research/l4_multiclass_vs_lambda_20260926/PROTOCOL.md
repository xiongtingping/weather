# L4 按宪章 211 重拟：多类 LogLoss 对逐桶二元、L4 对市场、L4 对现役 λ（计算前写定，2026-09-26）

熊先生：「按l4做」——有效边际 λ 退役，L4 后验成为篮子唯一信念。本研究是实施前的只读测量，回答三件事；生产未改。

## 问题

- **Q1 目标函数**：现行 L4 按逐桶二元 logistic 拟合、事后整梯归一（`posterior_store._fit_logistic`），与宪章 211 的训练规则（整梯 multiclass LogLoss）不是同一目标。改为直接极大化归一后 b 在真值桶上的对数似然（`_fit_multiclass`，本次新增、未接生产），样本外两分数是否不差。
- **Q2 准入**：多类 L4 在每个「阶段 × 提前量档」上，样本外桶 Brier 与 LogScore 是否都优于市场 m——即上线后哪些档允许 w/γ 非零（其余 b = m）。
- **Q3 对现役 λ**：在同一批候选窗上，λ 信念（λ(a) × 声称，按决策时刻的在役表）、L4 窗信念（Σ b）、市场（Σ m）三者对「窗是否命中」的 Brier 与 LogScore；以及三者各自按「信念 − 全包价 ≥ 经济门槛」放行的窗，每份实际盈亏。

## 样本

- 生产 L4 总体（`valuation_store.population`，每次决策 × 整梯 × 真值；取法同 `posterior_forward_and_edge_20260926/forward_edge.py` 的 `load_population`），三阶段，70 天，**不按服务算术锚截断**（锚后样本太少；这是研究读数，与生产锚定口径不同，报告中标明）。
- 候选窗：`basket_candidate_window_scored`（09-16 起有），按 (站, 事件日, 阶段, 决策时刻) 与总体配对；λ 用生产 `effective_edge_lambda_resolved` 与 `load_effective_edge_tables(as_of_utc=决策时刻)`。

## 前推（照生产 L4 车道）

每个检验日 D、每个阶段：训练集＝真值在 D 当天首个决策前已可知、事件日在 D 前 28 天内的决策（生产 `WINDOW_DAYS`）；先拟阶段整行，再拟五个提前量档（生产 `BETA_LEAD_BANDS`）并按 8 个伪日向阶段收缩；某行站日 <100 或天数 <8 即「积累中」。检验日每个决策按运行时的取法读行：所在档不在积累中读档行，否则读阶段行，阶段也在积累中则 b = m。两种目标（二元、多类）各走一遍，其余逐位相同。

## 评分与判定（事前写定）

- 桶 LogScore（−log b_y）与桶 Brier，站日等权，按事件日自助 2,000 次，95% 区间。
- Q1：多类对二元两项都不显著变差即采用多类（这是宪章 211 的裁定，本研究只核对不伤）。
- Q2：某档多类 L4 对市场两项区间上界都 <0 才记为「可准入」；这张表就是上线时的初始准入状态的参照（生产按自己的前推门逐日判，不抄本表）。
- Q3：只作对照读数，不作门；λ 退役是熊先生已下的裁决。
