# 预登记：P1 实况更新「升多少」斜线重拟三臂（含根的均值/众数），严格前推（2026-10-16）

熊先生 10-16「斜线能否用刚上线的均值/众数，重新拟合？做三臂一起预登记，严格前推」。
写在读数之前；读数后不改，结果写 RESULTS.md。只读，生产不改。

## 起因
宪章 161：P1(k) ∝ 根(k)·硬下界·exp f(k)，f(k)＝rise_k·(x·θ_rise)＋slope_k·(x·θ_slope)＋slope_k²·θ_sq＋open_top_k·θ_top；
rung r＝已测最高以上第几档，rise＝1[r≥1]，slope＝(r−1)₊。上午拟出的斜线约 −0.15/档（ZUUU 10-16 09:00），22–25°C 比例照搬根；
全队上午「高于已测最高各档」的条件 LogScore 比同刻市场差 +0.150 nat（`p1_morning_rise_shape_20261016`）。

## 数据与基线
生产拟合器 `scripts/fit_p1_observation_likelihood.py` 的同一套：样本库 `p1_observation_samples.db`（事件日 09-02..10-15），`label_samples`、`scorable_rows`、`direct_design`（根＝样本编译时的 P0/P0-M 信封）。
钟点按现行服务工件的站钟（`OL.clock_hours` 读 `p1_observation_likelihood_artifact.json`；各臂共用，见限制）。
**BASE**＝现行形式按生产 `direct_choose`（λ∈{0.3,1,3}，末 3 个训练日选）逐日重拟——即「现行模型的严格前推」，各臂都对它比。

## 前推
评估日＝第 15 个事件日起的每一天；当天训练行＝真值提交时间早于当天第一条样本时刻的全部可用行（生产 `known_at ≤ 当天最早 as_of`）。λ 与各臂的额外超参都只在训练行内选（末 3 个训练日作内验证），不碰评估日。

## 三臂（事先固定）
新增两个根状态特征（「刚上线的均值/众数」＝生产偏斜读数用的同一对量，在根的存活档上算，以档计）：
- `root_mode_rung`：根众数所在的 rung（已测最高以上第几档，众数在已测最高档为 0）；
- `root_mean_minus_mode`：根的加权均值序号 − 众数序号（偏斜读数的 gap）。
- **甲**：x 加入上面两个特征（标准化后进入主块），并加一个**上午块**：early＝1[剩余小时 ≥ 10]（与现行 late <6、mid 6–10 并列）× 全部标准化状态；其余与 BASE 同（同 λ 选择）。
- **乙**：甲 ＋ **平移基**：f 再加 shift_k·(x·θ_shift)，shift_k＝r_k / v，v＝根在存活档上的方差（以档²计，下限 0.25）。线性倾斜 β 使均值移动约 β·v，故 θ_shift 的单位就是「平移多少档」，不随根宽窄变。
- **丙**：BASE 的拟合不变，把斜线分量（θ_slope 与 θ_sq）整体乘 k，k∈{1, 1.5, 2, 3}；k 在训练行内选：去掉末 3 个训练日重拟 BASE，在末 3 日上取 LogScore 最好的 k。

## 指标（评估日上，按站日权重 `station_day_weight`）
1. 整条梯子服务 LogScore（1e-3 下限，同生产 `direct_scores`）：各臂 − BASE。
2. 上午行（样本 `local_hour` 07–12）：同上；再取「真值高于已测最高」的行算条件 LogScore（只取已测最高以上各档归一）。
3. 上午行与同刻市场（`board_readings._ladder_market_reference`，30 分钟内完整盘口、梯子相同）：条件 LogScore 各臂 − 市场。
4. 判左右（上午、条件分布、各自条件众数为参照、均值−众数符号）判对率，各臂与市场。
区间：按事件日 bootstrap 2,000（seed 7）。按站：主指标 1 的 各臂 − BASE，BH q=0.10（≥10 站日）。

## 判据（宪章 240：LogScore 主，CRPS/Brier 护栏本研究只报不判）
某臂整梯子 ΔLogScore 区间 < 0 且上午条件 ΔLogScore 区间 < 0、无 BH 显著变差站 → 该臂为上线候选（是否上线另裁）。
丙前推选出 k>1 且成立 → 「力度低」；丙选回 1 或不成立 → 斜线弱不是力度问题。
只有上午指标显著变好、整梯子跨零 → 报为「只改上午」的候选，另议。
