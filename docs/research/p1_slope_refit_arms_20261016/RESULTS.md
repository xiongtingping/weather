# 结果：P1「升多少」斜线三臂重拟，严格前推（2026-10-16，按 PROTOCOL.md，读数后未改协议）

数据：生产样本库 66,347 行（44 个事件日）；评估第 15 个事件日起 30 天（09-16..10-15）、45,733 行；上午（当地 07–12 点）12,325 行，其中 7,139 行有同刻完整盘口。
BASE 用生产拟合函数逐日重拟；本研究对 BASE 的重写与生产 `direct_fit` 的后验逐位一致（最大差 0.0）。
（计分时修正了一处实现错误：样本当地钟点是小数，起初按整数判上午只取到 356 行；改为 7 ≤ 钟点 < 13，协议未改。walk 记录里的「上午斜线中位」诊断仍是旧判法，不用。）

上午条件判左右（有盘口的行）：BASE 65.0%、甲 64.8%、乙 65.9%、丙 65.6%，市场 74.8%。

**判定（按协议）**：三臂都不成立。
- 丙前推多数选回 k＝1，放大斜线在上午与整梯子都显著变差 → **斜线弱不是力度问题**；
- 甲加入根的众数位置与均值−众数（偏斜读数那一对量）和上午块，整梯子显著变差、上午不变 → 根的均值/众数里没有 P1 尚未用上的「升多少」信息；
- 乙的平移基与 BASE 无可分差。
上午「会升的话落哪档」对同刻市场的差距在现行形式上是 +0.137 nat，三臂都没有收回；按现有特征重拟 P1 实况更新，补不上这一块。
