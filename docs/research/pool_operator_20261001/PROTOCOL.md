# 预注册协议：打线性池——换合并算子，而不是换宽度常数

写于 2026-10-01，跑之前。裁决人：熊先生（「继续打线性池」）。续 `width_broad_pool_slice_20261001`（按家数收窄不值钱）。

## 问题
线性池是 mixture：家间中心分歧全部进方差，形状随分歧变平/多峰。统一 λ 只能缩放，不能改形状。
问：**换一个合并算子（形状不同），再各自配一个按同样规则拟出的 λ，在第 240 条判决上能否胜过生产的「线性池 + 桥 + 0.75」？**

## 数据
codex 10-01 捕获的 1,066 条生产 P0 包（45 站、09-22..30、每站日最多 3 个检查点、单家向量/权重/中心/桥/物理/宽度回执齐全，
最终 P0 重放误差 1.9e-15）。评分每站日先平均。只有 9 个闭日：结论只作本窗口读数。

## 算子（全部从同一组单家向量与同一权重出发，之后同一物理位移、同一 λ 变换、同一 1e-3 下限、同一生产评分器 `_served_scores`）
- A0 生产原样：线性池 → 桥 λ(gap) → 物理 → λ=0.75（基线，不重拟）。
- A1 线性池 + 桥 → 物理 → λ 按前缀重拟（公平对照：只重拟 λ 的收益）。
- B 完全共识：每家用生产 `shift_probability` 平移到共识中心后按权重混合（桥 β=1）→ 物理 → λ 重拟。形状=组内宽度，去掉组间项。
- C 几何池：normalize(∏ p_j^{w_j})，单家先设 1e-3 下限 → 物理 → λ 重拟。形状由各家重叠区决定，分歧越大越尖。
- D 线性池无桥 → 物理 → λ 重拟（对照桥的作用）。

## λ 重拟规则（与 `_search_slice_lambda` 同）
网格 0.55..1.25 步 0.025，位移 0，按前缀各日全部格的平均 LogScore（下限后）取最小；滚动起点：第 d 日用 <d 日拟（d 从第 4 日起），
取不到前缀的日不计分。

## 判决
每个算子对 A0 配对：生产 `_proper_score_gate`（LogScore 上界<0；CRPS、Brier 下界≤0），簇=站日。
**落地条件**：B 或 C 相对 A0 且相对 A1 都过门。只过 A0 不过 A1 = 是 λ 重拟的功劳不是算子的。
副读数（只报不裁）：按家数（≤3 / 4–5 / 6）、按提前量（≤36h / >36h）分组的配对差。

## 不做的事
不改 SSOT、不改生产、不重启、不下单。本协议外的切分不进结论。

codex 子集表核对：六家 1.09 对实测 1.058、四家 1.149 对 1.114、两家 1.325 对 1.285。旧桥目标 A（去 B 留宽）方向错。

- E3 = E1 不重拟 λ（λ=1）：看 v2 是否自校准。
