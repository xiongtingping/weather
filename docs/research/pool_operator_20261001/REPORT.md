## 几何池的读数怎么分布（diag.json / results.json 子组，ΔLogScore 对 A0）
- 逐日 C−A1：6 个计分日全部为负（−0.004 / −0.026 / −0.000 / −0.022 / −0.020 / −0.004），不是一天撑起来的。
- 按家数：≤3 家 −0.003、4–5 家 −0.008、**6 家 −0.016**；按提前量：**≤36h −0.021**、>36h −0.008。收益在六家、日内——正是线性池 mixture 形状最平的地方。
- 单家预置下限（协议钉 1e-3=生产下限）：1e-2 时失效（+0.005）、1e-4 时 −0.007（5/6 日负）。是参数，不是免费的；1e-3 没调过但也不能宣称稳健。

## 完全共识为什么更差
B 只去掉组间项、保留每家自己的宽度（方差 = 组内 A≈1.57）；而六家融合中心的误差只有 1.06——各家自报的宽度本身就比合议后该有的宽。
把所有家平移到一个中心只是把 mixture 摞成一座山，山还是各家的山；几何池则按重叠区重新划形状，分歧越大越尖、一致处越实。
