# 集合 × 确定性融合：A/B/C/D 严格对照（预先登记，2026-10-25）

熊先生 10-25：「先不要直接替换生产模型，做一个严格的对照实验」。本文件在跑数之前提交，
跑完后不改判据；改动只能以「补记」追加并写明原因。

## 问题

在 P0（原始信念）上，确定性预报应当以什么形态与全球成员集合融合：只动中心，还是中心
与宽度一起动，宽度是否还应读确定性模式之间的分歧。

## 四个臂

所有臂共用同一条桶轴、同一组样本、同一套去偏方式与 1e-3 下限（宪章 224），差别只在下表。

| 臂 | 中心 μ | 宽度 |
|---|---|---|
| A | 集合校准后的 P0 向量原样（生产 P0 在确定性共识服务之前的向量：v31 起读回执 `pre_shift_probabilities`，之前读服务向量） | 原样 |
| B | μ_B = μ_A + δ，δ = a + (w0 + w1·L)·(F − μ_A) | 原样（s = 1） |
| C | 同 B | log s = c0 + c1·L |
| D | 同 B | log s = c0 + c1·L + c2·Z |

- μ_A：A 向量的分布均值（桶代表温度加权）。
- F：决策时刻已到手的十家确定性日最高温（与宪章 279 同一读点、同一名单），**逐家**减去该家在训练日上的全队偏差后取中位数；不足 3 家的决策不计入任何臂（四臂同一样本）。
- L = (距结算小时 − 36) / 24，连续变量；12h 以内的 P0 不计入。
- Z = log(SD_det + 0.2)，SD_det 为逐家去偏后的十家标准差（°C）。
- 变换：把 A 向量看成每桶内均匀的分段密度（开口桶按一个桶宽截断），施仿射映射 x → μ_B + s·(x − μ_A)，按新桶界重新积分，再施 1e-3 下限。B 即 s = 1 的纯平移，与宪章 279 影子同构，只是权重随提前量连续、带截距、F 逐家去偏。

## 样本与前推

- 样本：48 站，60 天窗；每站日取距结算 >36h 与 12–36h 两族各自首个 P0 决策（与每日拟合同一抽样）；真值为正式真值（宪章 225 两车道取最新修订）。
- 严格前推：对每个打分事件日，参数只用之前的事件日拟合（训练含该日之前的全部日子）；F 的逐家偏差同样只用之前的日子。
- 拟合目标：训练集上的平均桶 LogScore（下限后），scipy L-BFGS-B，初值 a=0, w=0, c=0。
- 打分口径（宪章 255）：只给 2026-10-01 及以后的决策打分（现行链），参数仍可用更早的日子拟。敏感性：训练也只用 10-01 以后（每个打分日至少 8 个训练日才打分）。

## 判据（宪章 240）

逐对比较 B−A、C−B、D−C，以及 C−A、D−A：
- 主裁 LogScore 差，事件日为单位 bootstrap（2000 次）95% 区间上界 < 0；
- CRPS（桶序 RPS）与 Brier 不得显著变差（区间下界 > 0 即变差）；
- 可评事件日 ≥ 20，否则只叫读数。
另报：分远近两族、前后两半、逐站符号、拟合参数随时间的轨迹、PIT 的 E[z²]。

## 补记一（2026-10-25，跑数前提交）：P0_lt12 族的 A/B

熊先生 10-25「按 A/B 协议测 F 进 12 小时以内 P0（新族 P0_lt12）是否过 240 门，过了再裁是否服务」。
起因：距结算 <12h 的 P0 不服务 F，此后 P0-M/P1 以它为根，当天最后 12 小时整条链不含 F。

- 样本：每站日两个 P0 决策——距结算 <12h 的首个（`lt12_first`）与当天最后一个（`lt12_last`，
  仍须 <12h；两者相同时只记一次）。主裁为两者合并；两者分别作切片。
- 臂：A 与 B 定义不变（A＝集合校准后的服务 P0；B＝δ ＝ a ＋ (w0 ＋ w1·L)(F − μ_A)，L 同正文）。
  B 只用 P0_lt12 族自己的训练记录拟合（不借 >12h 的族）。F 的逐家偏差同正文、只用之前的日子。
- 前推、打分口径（≥10-01 决策）、下限、判据（宪章 240，≥20 可评事件日）同正文。
- 另报：拟合出的 w 与 >12h 两族的比较、远近切片（<6h / 6–12h）、前后两半、逐站符号。
- 过门只表示可以提请裁决服务；不改生产。
