# 结算地板偏置篮子：固定输入/输出模板

## 输入

```text
日期：YYYY-MM-DD
城市：city
预算：50U

主核心资金桶：
副核心资金桶：
主核心份额桶：
副核心份额桶：
保本/成本桶：
保本/成本桶：
彩票桶：
彩票桶：

已有持仓：未填写则按 q=0
安全垫：默认0.01U
执行：待确认/下单
```

## 固定规则

- 只使用官方 CLOB WebSocket YES 卖盘逐档深度。
- 预算是上限；未明确执行时只计算、不下单。
- 可见盘口有多少先用 FAK 买入多少；深度不足的剩余差额默认挂 GTC。GTC 单笔价格必须为有效的 `<1.00`，不再受篮子卖一价合计 `<1` 的挂单阶段限制；挂单未成交不计入已实现结算地板，成交后下一轮只补实际差额并重算。
- 主核心、副核心、份额桶、保本桶和彩票桶均参与结算地板；彩票桶不再固定金额，按地板与预算动态配仓。
- 标记为 `C/成本计入桶` 的已有仓位计入篮子总成本，但不参与结算地板且不新增。
- 允许受控角色调仓：只可卖出 `S/B/L/C` 桶为恢复 `M>S>A>B>F` 顺序所需的超额份额；`M/A/F` 桶禁止卖出，禁止用卖出控制预算。
- 调仓卖出使用官方 CLOB YES bid 逐档深度；卖出成交额计入篮子净结算成本。成交后必须重算所有地板利润；部分/未知成交或地板跌破安全垫时阻断。
- 同一温度桶重复填写角色时，保留更高优先级角色；副核心同时属于地板，不重复建立保本角色。
- 未填写已有持仓按 `q=0`；安全垫默认 `0.01U`。
